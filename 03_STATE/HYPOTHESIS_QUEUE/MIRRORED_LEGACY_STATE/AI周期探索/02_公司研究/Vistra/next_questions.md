# Vistra Next Questions

## 高优先级（影响分类）

### 1. 最新季度财报数据
- **问题**: Q1'26 实际营收/EBITDA/FCF？毛利率和净利润率？
- **验证方式**: Q1'26 财报（预计2026年5月发布）
- **判断影响**: EBITDA 低于预期 → 高杠杆下偿债压力增大 → 风险上升

### 2. 再融资时间表
- **问题**: $15.8B 债务中多少需要在 2026-2028 年再融资？利率环境对再融资成本的影响？
- **验证方式**: 财报债务到期日披露、信用评级动态
- **判断影响**: 大额到期+利率高位 → 再融资成本显著上升 → 利润率受压

### 3. PPA 管道
- **问题**: Meta PPA 之后是否还有新的 hyperscaler PPA 在谈？2,609 MW 之后还有多少增量？
- **验证方式**: 季度财报电话会、投资者日
- **判断影响**: 无新PPA → 增长叙事中断 → 从"期权"下调

## 中优先级（影响评分）

### 4. Comanche Peak 核能扩产
- **问题**: Comanche Peak 是否有扩产计划？1,200 MW 之后能否增加？
- **验证方式**: NRC 许可动态、公司公告
- **判断影响**: 核能扩产获批 → 长期供电能力增强 → 上行期权扩大

### 5. 数据中心电力需求实际增速
- **问题**: AI 数据中心实际电力消耗增速？与 hyperscaler capex 增速是否一致？
- **验证方式**: ERCOT/PJM 负荷数据、行业报告
- **判断影响**: 电力需求增速 < 预期 → PPA 定价权减弱

### 6. 竞争格局演变
- **问题**: Constellation/Talen 等对手也在签 PPA，市场份额如何分配？
- **验证方式**: 竞争者 PPA 公告、行业数据
- **判断影响**: Vistra PPA 份额下降 → 护城河不如预期
