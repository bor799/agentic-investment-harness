# 沪电股份 Next Questions

## 高优先级

1. **AI PCB收入占比**：Q1 2026的62.14亿营收中，AI服务器/交换机PCB占比多少？传统通信PCB占比如何变化？
2. **毛利率具体数值**：Q1毛利率具体是多少？趋势是上升还是持平？与AI PCB占比提升是否同步？
3. **大客户验证**：Nvidia/亚马逊/Microsoft/Google等超大规模厂商是否已验证？订单规模？

## 中优先级

4. **与竞争对手对比**：vs 胜宏科技/深南电路/生益电子/广合科技——毛利率、AI PCB占比、产能、客户结构横向对比
5. **扩产时间表**：新产能具体投产时间？产能爬坡计划？满产后毛利率预期？
6. **估值合理性**：P/E 40x隐含的增速预期是否合理？PCB行业历史上P/E中枢是多少？

## 低优先级

7. **先进封装影响**：CoWoS等先进封装是否会减少高层数PCB需求？
8. **通信PCB基盘**：传统通信PCB业务是否稳定？5G投资放缓对基盘影响？
9. **海外产能布局**：是否有海外建厂计划？地缘政治风险如何应对？
