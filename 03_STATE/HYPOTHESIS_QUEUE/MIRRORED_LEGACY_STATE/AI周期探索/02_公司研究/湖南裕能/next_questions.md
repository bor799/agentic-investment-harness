# 湖南裕能 Next Questions

## 高优先级

1. **客户集中度量化**：CATL和BYD在湖南裕能营收中的精确占比是多少？是否超过60%？客户集中度如何影响议价能力和利润率可持续性？
2. **LFP价格持续性**：当前6万/吨的LFP价格能维持多久？行业扩产计划（德方纳米/万润新能/龙蟠科技）会不会在2027年导致新一轮过剩？
3. **LMFP技术差异化**：32万吨/年LMFP产能的实际出货量和客户验证进展？LMFP相比传统LFP的能量密度提升是否能带来ASP溢价？

## 中优先级

4. **磷矿自给的经济价值**：自有磷矿对成本的实际贡献是多少？磷矿价格波动如何影响利润率？
5. **储能vs动力电池收入拆分**：储能LFP需求增速是否足以对冲动力电池需求放缓？
6. **CATL持股7.88%的战略含义**：是财务投资还是战略合作？是否有进一步增持计划？

## 低优先级

7. **创业板权限确认**：交易权限开通后，是否应从期权池调整至可买池？
8. **钠离子电池替代风险**：钠离子电池商业化进展是否构成LFP长期替代威胁？
