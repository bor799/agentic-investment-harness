# Lumentum Next Questions

## 升级条件（→核心候选）
- 营业利润率/净利率显著改善（从100x earnings走出来）
- FY2027 管理层指引确认 $4.5B+ 营收
- OCS 订单继续扩大到 $600M+
- 硅光子替代技术进展缓慢

## 降级条件（→观察/暂不研究）
- AI 数据中心建设放缓导致光互联需求不及预期
- 毛利率回落（定价权丧失）
- 硅光子/POET 技术加速突破
- 季度营收增速显著低于 $2.9B→$6.4B 路径

## 下一步验证
1. **[最关键] 最近季度营业利润率和净利率** — 盈利能力改善速度
2. **[最关键] FY2027 营收指引** — 管理层是否确认翻倍路径
3. **前瞻 P/E 和 EV/营收** — 独立估值数据
4. **InP 40% 扩产时间表** — 产能何时到位
5. **硅光子/POET 替代技术进展** — 对 InP 需求的长期影响

## 重新评估时间
- 下一次财报发布后
- Web search 恢复后（2026-05-26+）可补充估值数据
