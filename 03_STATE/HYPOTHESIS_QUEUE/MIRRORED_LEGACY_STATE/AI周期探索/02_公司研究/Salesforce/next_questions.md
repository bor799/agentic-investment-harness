# Salesforce Next Questions

## 高优先级（影响分类）

### 1. 消耗收入占比和 AWU 数据
- **问题**：Agentforce 消耗收入在总收入中占比？AWU 增长趋势？座位收入是否开始减速？
- **验证方式**：Q1'27 财报（约 2026 年 5-6 月）、财报电话会
- **判断影响**：消耗收入 >5% 且加速 → 转型验证开始；座位收入减速 >3pp → SaaSpocalypse 风险上升

### 2. Headless 360 开发者采纳
- **问题**：100+ MCP 工具和 Agent SDK 的开发者使用数据？第三方 AgentExchange 上架速度？
- **验证方式**：TDX'26 后开发者社区反馈、GitHub 活跃度、Salesforce 官方博客
- **判断影响**：开发者活跃 → 生态锁定增强；冷清 → 平台转型可能失败

### 3. Slack AI 对座位收入的影响
- **问题**：30+ AI 功能是否推动 Slack 座位增长或只是功能填充？是否带来额外付费？
- **验证方式**：财报中 Slack 独立数据（如果披露）、客户案例
- **判断影响**：AI 功能推动付费转化 → 协作层价值验证；无额外收入 → AI 功能未变现

## 中优先级（影响评分）

### 4. Klaviyo/Writer 竞争侵蚀
- **问题**：Klaviyo "Autonomous CRM" 是否在 Salesforce 客户中渗透？Writer 的事件触发代理是否分流 Agentforce 客户？
- **验证方式**：行业报告、客户调查
- **判断影响**：SMB 段流失加速 → 定价权分数下调

### 5. Informatica 整合进展
- **问题**：$8B 收购后数据集成能力是否增强？客户是否采用联合方案？
- **验证方式**：财报电话会、产品发布
- **判断影响**：整合成功 → 数据引力护城河增强；整合失败 → $8B 减值风险

### 6. 利润率在消耗模式下的变化
- **问题**：消耗计费的毛利率？代理推理成本是否被定价覆盖？
- **验证方式**：Q1'27-Q2'27 财报
- **判断影响**：消耗模式毛利率 >60% → 模式验证；<40% → 利润率恶化
