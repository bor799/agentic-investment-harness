# Tesla Next Questions (PRO Updated 2026-05-16)

## 升级条件（→观察）
- 季度营收增速持续转正且加速
- Robotaxi 扩展至 10+ 城市且规模显著
- Optimus 产线投产并交付首批客户
- 汽车毛利率回升至 25%+
- FSD 获得无监督监管批准

## 降级条件（→暂不研究）
- 营收持续下降或零增长 2+ 季度
- Robotaxi 重大安全事故导致监管叫停
- Optimus 量产再次延期
- P/E 从 400x+ 开始回归（股价下跌 50%+）
- BYD 在全球进一步蚕食份额

## 下一步验证
1. **[最关键] Q2 2026 营收趋势** — 能否延续 Q1 +16% 增长
2. **[最关键] Robotaxi 规模化** — 城市数量、车队规模、收入贡献
3. **Optimus 产线进度** — Fremont 量产线和 Giga Texas 二代线时间表
4. **中国市场竞争** — vs BYD/XPENG 份额变化
5. **估值风险** — 如果 AI 期权推迟，股价下行空间测算

## 重新评估时间
- Q2 2026 财报发布后（~2026-07）
- Optimus 产线投产前后
- Robotaxi 扩展至新城市时
