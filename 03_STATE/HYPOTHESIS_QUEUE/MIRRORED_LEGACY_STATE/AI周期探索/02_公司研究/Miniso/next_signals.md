## 升级 / 降级触发

### 升级条件（→ 讨论加仓 / 升级确认仓）

任一组合出现，且 H_R 也回到 pass，可启动升级讨论：
1. 2026Q2 调整后经营利润率（剔除 FX）回升至 ≥15%；
2. FCF 单季回到 RMB 1B+；
3. 大陆 SSSG 维持 high-single digit 且海外 SSSG 升至 mid-single digit；
4. 自有 IP 收入占比超过 55% 且 IP 相关毛利率上行；
5. 永辉连续 2 季度盈利。

**当前升级条件达成数：0/5**（H_R 仍 fail，前置不满足）。

### 降级条件（→ 讨论降级或退出）

任一组合出现，进入降级或退出讨论：
1. 大陆同店连续 2 季度 SSSG 转负；
2. 调整后经营利润率（剔除 FX）连续 2 季度 <12%；
3. FCF 连续 2 季度接近零或转负；
4. 永辉再次出现 RMB 500M+ 单季损失；
5. 公司取消分红或 Equity Linked Securities 出现强制转股稀释。

**当前降级条件达成数：0/5**，但"FCF 单季接近零"已亮黄灯。
