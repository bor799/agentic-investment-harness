# Nvidia Next Questions

## 高优先级（影响分类）

### 1. Hyperscaler capex 路径
- **问题**: 四大 hyperscaler 2026 年合计 capex ~$700B (+60% YoY)，2027 年能否维持或增长？增速放缓的具体信号是什么？
- **验证方式**: 每季度 hyperscaler capex 实际值 vs 指引、Nvidia 季度营收增速趋势、数据中心收入环比变化
- **判断影响**: capex 增速降至 <20% → Nvidia 营收增速可能断崖式下降

### 2. FY27 Q1 实际财报（4月季度）
- **问题**: $78B 指引实际完成度？环比增速是否如管理层承诺持续增长？
- **验证方式**: FY27 Q1 财报（预计 2026 年 5 月底发布）
- **判断影响**: 营收 < $75B 或环比减速 → 增长叙事受损

### 3. Vera Rubin 量产节奏
- **问题**: Vera Rubin 下半年量产是否能按时？客户采纳速度如何？
- **验证方式**: GTC 2026 产品更新、客户采购公告、供应链出货数据
- **判断影响**: 延迟 → Blackwell 到 Rubin 之间出现需求空窗

## 中优先级（影响评分）

### 4. Custom ASIC 市场份额侵蚀
- **问题**: Broadcom/custom ASIC 在 AI 推理市场的实际份额增长？OpenAI/Meta 转向替代方案的速度？
- **验证方式**: Broadcom 季度 AI 收入、hyperscaler 自研芯片出货量
- **判断影响**: 推理市场 ASIC 份额 >30% → Nvidia 长期增长天花板下降

### 5. Groq 整合成果
- **问题**: $20B Groq 收购是否产出具体产品路线图？在推理市场的竞争力如何？
- **验证方式**: 产品发布、客户案例、技术白皮书
- **判断影响**: 无明确产品 → 收购被市场视为浪费资本

### 6. 中国市场恢复可能性
- **问题**: 出口管制放松的可能性？如果恢复，中国可贡献多少增量收入（分析师估计 $200-300B/年）？
- **验证方式**: 美中贸易谈判进展、出口许可审批
- **判断影响**: 中国恢复 → 巨大上行期权；进一步收紧 → 基本面风险
