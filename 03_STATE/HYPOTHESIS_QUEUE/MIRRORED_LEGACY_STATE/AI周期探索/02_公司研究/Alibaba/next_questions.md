# Alibaba Next Questions (PRO Updated 2026-05-16)

- AI ARR达¥30B目标且云增速维持在35%+
- 调整后EBITA恢复增长（投资期结束）
- 快消UE转正（FY2027预期）
- 电商CMR恢复至5%+增长
- 股价突破$200（分析师目标区上沿）

- AI ARR增速显著低于目标
- 云增速降至25%以下
- 电商CMR负增长
- 快消亏损持续扩大
- CapEx投入无对应收入增长

## 下一步验证
1. **[最关键] Q1 FY2027 AI ARR** — 是否达¥10B目标（6月季度）
2. **[最关键] 云利润率趋势** — EBITA改善是否持续
3. **快消UE进展** — 向FY2027转正的季度进展
4. **电商CMR增长** — 是否从+1%恢复
5. **T-head芯片进展** — 自研芯片规模和成本优势

## 重新评估时间
- Q1 FY2027 财报发布后（~2026-08）
