# ServiceNow Next Questions

## 高优先级（影响分类和仓位）

### 1. Usage-based 收入占比和增速
- **问题**：混合定价模型中 usage-based 收入的实际增速和占比是多少？
- **验证方式**：Q2-Q3 FY26 财报电话会中的定价结构披露
- **预期时间**：2026 Q2-Q3
- **判断影响**：若 usage-based 占比提升 >20% → 定价权转型确认，上调分类

### 2. AI ACV 从 $600M 到 $1B 的季度路径
- **问题**：AI ACV 是否按季度线性增长？还是集中在 Q4？
- **验证方式**：后续季度的 ACV 披露
- **预期时间**：2026 Q2-Q4
- **判断影响**：若 Q2/Q3 ACV 已达 $800M+ → agentic AI 变现验证

### 3. Seat count 与 AI ACV 的关系
- **问题**：AI 增长是在替代座位还是在增加价值？企业是否在缩减 seat 数？
- **验证方式**：财报中 subscription revenue 增速 vs seat count 增速的对比
- **预期时间**：2026 H2

## 中优先级（影响估值判断）

### 4. Armis 整合进展
- **问题**：$7.75B 收购是否产生营收协同？整合时间表？
- **验证方式**：管理层在电话会中的 Armis 专项更新、独立研报
- **预期时间**：2026 H2 - 2027 H1

### 5. Microsoft Agent 365 竞争影响
- **问题**：Agent 365 的企业治理层是否与 ServiceNow 流程编排直接竞争？
- **验证方式**：企业 IT 决策者反馈、竞品对比报告
- **预期时间**：持续跟踪

### 6. 大型合同趋势
- **问题**：$5M+ 合同的数量和增速是否持续？是否有 $10M+ 合同出现？
- **验证方式**：后续季度财报中的合同规模分布
- **预期时间**：2026 Q2-Q4
