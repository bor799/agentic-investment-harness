# Moments

Moment 是一次临时认知差分：它只回答“什么材料触发了我们、旧判断是什么、新判断是什么、接下来验证什么”。

状态只用：

- `open`：尚未吸收；
- `absorbed`：已进入 Knowledge、State 或 Case；
- `rejected`：没有有效认知增量。

`absorbed` 与 `rejected` 条目移到 [[05_EVIDENCE_META/_ARCHIVE/MOMENTS/README]]。当前没有未吸收 Moment。
