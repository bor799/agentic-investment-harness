## 第零步：Key Forces（决定性力量）

未来3-5年，将根本性改变名创优品价值的**1-3个力量**：

### Key Force #1：IP战略的可持续性与护城河宽度

**核心论点**：名创优品已从"十元店"进化为"全球IP零售平台"，150+IP合作网络和自有IP孵化能力构成了其核心护城河。

**证据**：
- IP产品累计销售超8亿件
- 年推出超1万款IP产品
- MINISO LAND上海店9个月销售额破亿
- 毛利率从2022年的低30%提升至2024年的44.9%

**风险**：
- IP授权成本持续上升可能侵蚀利润率
- 消费者对IP新鲜感下降（审美疲劳）
- 竞争对手（如KKV、THE COLORIST）同样发力IP联名

**可跟踪指标**：
- IP产品销售占比（当前未单独披露，需关注）
- 同店GMV中IP产品贡献
- 新IP签约数量和质量

---

### Key Force #2：海外扩张的盈利能力兑现

**核心论点**：海外门店突破3000家，从"规模扩张"转向"盈利质量"阶段，直营店占比提升将改善利润结构。

**证据**：
- 海外门店：3118家（2024年末），其中直营店503家（16%）
- 海外收入占比：39.4%
- 直营店毛利率显著高于代理模式
- 巴黎香榭丽舍店单日58万营业额标杆案例

**风险**：
- 地缘政治风险（欧美市场保护主义）
- 海外运营复杂度超预期
- 汇率波动影响财务表现

**可跟踪指标**：
- 海外直营店单店盈利模型
- 海外同店销售增长（SSSG）
- 各地区毛利率差异

---

### Key Force #3：消费降级下的韧性验证

**核心论点**："极致性价比+情绪价值"的组合在消费降级周期中展现韧性，但需验证客单价提升的可持续性。

**证据**：
- 客单价从10元提升至14元（+40%）
- 毛利率提升至44.9%（+3.7pct）
- 国内同店GMV增速从30-35%放缓至高个位数

**风险**：
- 消费降级超预期，客单价提升遇阻
- "谷子经济"泡沫破裂
- 竞争加剧导致价格战

**可跟踪指标**：
- 国内同店销售增长（SSSG）
- 客单价趋势
- 市场份额变化

#### 方法1：Owner Earnings（巴菲特视角）

```
Owner Earnings = 净利润 + 折旧摊销 - 维持性CapEx - 营运资本变动

| 倍数 | 估值（每股） | 对应港元 |

#### 方法2：PEG Ratio（彼得·林奇视角）

```
PEG = PE / EPS增长率
     = 17.01 / 16.5
     = 1.03
```

**林奇判断**：PEG ≈ 1，估值合理。

#### 方法3：EV/EBITDA（达摩达兰视角）

```
EV = 市值 + 净负债
   = 33.12港元 × 12.51亿股 × 0.92汇率 - 5.67亿借款
   ≈ 400亿元

EBITDA（调整后）= 43.34亿元

EV/EBITDA = 400 / 43.34 = 9.2x

**你的投资逻辑中最大的盲点是永辉。**

**核心问题**：永辉是名创IP零售战略的延伸，还是叶国富个人的多元化冲动？如果是前者，长期可能创造巨大价值；如果是后者，将拖累名创的股东回报。

- 如果永辉同店销售转正，名创的估值有重大重估空间
- 如果永辉继续恶化，建议果断减仓止损

- 名创主业年收入~$2.77B
