# B_AI基础设施瓶颈

> 更新：2026-06-17
> 来源：[[../../分析报告/archive/260617AI算力连接与材料瓶颈_挖掘端框架]]

## 核心判断

AI 基础设施不是单点芯片周期，而是 Leontief 式互补系统：

```text
可用算力 = min(GPU, HBM, CoWoS, 网络连接, PCB/ABF/CCL, 电力, 冷却, 储能, 并网, 运维)
```

每解决一个短板，下一个短板会暴露。研究重点不是“AI 需求大”，而是需求如何沿工程系统传导到具体材料、设备、工艺、交付周期和定价权。

## 挖掘端公式

```text
宏观需求
  -> 工程参数
  -> 设备结构
  -> BOM / 材料 / 工艺
  -> 供给瓶颈
  -> 控制定价权的公司
  -> 财务兑现与估值赔率
```

四个认知模型：

| 模型 | 用法 |
|---|---|
| Leontief 短板 | 找系统最短板，不只找最大市场 |
| 波松到达率 | 看订单、招标、产品发布、涨价事件密度是否上移 |
| 幂律分布 | 需求扩散，但利润集中在少数控制点 |
| 贝叶斯更新 | 用新证据持续更新先验，保留失败条件 |

一句话：

```text
需求是波松到达率；利润是幂律集中；判断靠贝叶斯更新；产出由 Leontief 短板决定。
```

## 2026-2028 瓶颈迁移图

| 阶段 | 主要瓶颈 | 投资含义 |
|---|---|---|
| 2022-2024 | GPU / CoWoS | 平台赢家和先进封装 |
| 2024-2026 | HBM / 存储墙 | HBM、先进封装、内存供应 |
| 2025-2027 | 网络连接 / 数据搬运 | 800G/1.6T、LPO/NPO、铜缆、PCB/ABF/CCL、光源、测试 |
| 2026-2028 | 电力 / 储能 / 冷却 | 变压器、配电、UPS/BESS、PCS、液冷、构网型储能 |
| 2028+ | CPO / 光 I/O / 算电协同 | 架构期权，利润池重构 |

## 铜的正确位置

铜非常重要，但不能把所有瓶颈都懒惰地归因于铜。

```text
供电路径：发电/电网/变压器/电缆/母排/UPS/BESS
连接路径：高速铜缆/连接器/PCB铜箔/CCL
散热路径：冷板/液冷导热部件
```

真正瓶颈可能是：

- 上游资源：矿山开发、品位、海外运营、冶炼加工费。
- PCB/CCL：低损耗树脂、玻纤、T-glass、ABF 膜、层数、良率。
- 光互连：InP 激光器、外置光源、FAU、耦合、测试。
- 电力：变压器、开关设备、并网排队、施工周期。

研究时必须区分：

- 资源端 Beta：紫金矿业、江西铜业等，核心看铜价、产量、成本、现金流。
- 制造端 Alpha：PCB/CCL/ABF/连接器等，核心看客户认证、毛利率、材料短缺、扩产节奏。

## 当前优先研究方向

| 方向 | 优先级 | 关键问题 |
|---|---:|---|
| AI PCB / ABF / CCL | 高 | AI 订单是否进入毛利率，扩产是否反噬 |
| 1.6T / LPO / NPO / InP 光源 | 高 | 2026 是否真实出货，谁跨多阶段供货 |
| 电力设备 / 储能 / UPS | 高 | AI 数据中心用电是否转成订单和利润 |
| 铜资源 | 中高 | 铜价和产量是否形成资源端现金流 |
| CPO 纯概念 | 中 | 2027-2028 期权，不作为 2026 主仓逻辑 |
| 液冷 | 中 | 是否有订单、毛利率和系统集成控制权 |

## 标的映射

| 层级 | 代表方向 | 当前分类倾向 |
|---|---|---|
| 平台架构 | NVDA、AVGO、TSMC | 核心复利 / 瓶颈观察，市值大限制三倍 |
| AI PCB | 沪电股份、胜宏科技、深南电路、生益电子、广合科技 | 瓶颈观察 |
| 光学/光源 | Lumentum、Coherent、Fabrinet、中际旭创、新易盛、天孚通信 | 观察，需验证出货和估值 |
| 铜连接/精密制造 | 立讯精密、Amphenol | 观察，重点看客户认证和铜缆份额 |
| 电力设备 | 四方股份、思源电气、许继电气、南瑞继保、Eaton、Vertiv | 观察，重点看 AIDC/UPS/配电订单 |
| 储能材料链 | 宁德时代、亿纬锂能、湖南裕能、天赐材料、新宙邦、恩捷股份 | 已进入储能材料链跟踪 |
| 铜资源 | 紫金矿业、江西铜业 | 资源端硬约束，但需区分 AI Alpha 与铜 Beta |

## 失败条件

1. AI CapEx 下修，服务器和交换机订单放缓。
2. CPO/LPO/NPO 认证慢于预期，光学链估值先杀。
3. PCB/ABF/CCL 扩产过快，供给反噬毛利率。
4. 储能招标高增但价格重新下行，量增不留利。
5. 铜价上涨来自宏观金融交易，而非可持续物理短缺。
6. 电网并网瓶颈导致数据中心项目延期，设备订单确认后移。
7. 公司只是参与者，不控制材料、认证、客户入口或产能。
