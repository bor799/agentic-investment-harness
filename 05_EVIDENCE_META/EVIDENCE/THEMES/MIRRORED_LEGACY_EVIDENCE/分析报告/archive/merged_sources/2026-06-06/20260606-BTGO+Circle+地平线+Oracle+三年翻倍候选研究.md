# 三年翻倍候选研究：BTGO / Circle / 地平线 / Oracle

> 研究日期: 2026-06-06
> 核心验证框架: 现实需求增长 → 公司处在关键瓶颈 → 能收费 → 能留住利润 → 当前估值允许三年翻倍

---

## 1. 一页结论

### 最可能三年翻倍：无高置信标的

三家候选公司的三年翻倍概率均低于 45%。这不是因为公司不好，而是因为"三年翻倍"是一个极高门槛，需要基本面 + 估值 + 催化剂三者同时配合。

### 赔率排序（三年翻倍概率）

| 排名 | 公司 | 概率 | 一句话理由 |
|---|---|---|---|
| 1 | **BTGO** | 30-40% | 小盘数学 + 衍生品转型 + 稳定币增长，但本质是加密周期杠杆 |
| 2 | **Circle** | 35-45% | 更好的生意，但 $20B 市值需要 $20B 新价值创造，极度利率敏感 |
| 3 | **地平线** | 25-35% | 平台叙事部分成立，但 R&D 占收入 132%，盈利遥遥无期 |
| 4 | **Oracle** | <10% | 仅作验证器，FCF -$24.7B，非翻倍标的 |

### 最确定但赔率可能不足：Circle

Circle 是四家中唯一盈利且 FCF 为正的公司（TTM $491M），USDC 网络效应真实，GENIUS 法案加深护城河。但 94% 收入依赖利率，本质是"利率敏感型金融基础设施"而非高增长科技股。P/S 7x 已定价高增长。

### 最需要继续观察：BTGO 和地平线

- **BTGO**: 衍生品转型才 1 个季度数据，稳定币仅 1 个客户，RWA 零收入。但 take rate 在改善（20→32 bps），客户增长 97% CAGR。需要再观察 2-3 个季度。
- **地平线**: J6P/HSD 2025 Q3 才量产，2026 年数据才能验证规模化假设。R&D 占收入比需要降至 100% 以下才能看到运营杠杆。

### 最大风险

| 公司 | 最大单一风险 |
|---|---|
| BTGO | 加密价格下跌 30% → 托管资产、交易量、staking 收入全部收缩 |
| Circle | 联邦基金利率每降 100bps → 收入减少 ~$750M |
| 地平线 | 头部 OEM（理想、比亚迪）自研芯片成功 → 市场份额被蚕食 |
| Oracle | RPO 无法转化为收入 + capex 吞噬现金流 |

### 下一步最该补的证据

1. **BTGO**: Q2-Q3 2026 衍生品收入拆分（净额 vs 总额）；稳定币客户是否从 1 个增加到 2+；goUSD 推出进展
2. **Circle**: 美联储利率路径明确化；USDC 供应能否在利率下降时维持增长
3. **地平线**: HSD/J6P 2025 Q3 量产实际数据；大众 CARIZON 2026 车型量产节奏
4. **Oracle**: FY2027 Q1-Q2 OCI 收入增速是否维持 50%+

## 2. BTGO 深度研究

### 2.1 一句话投资假设

BTGO 是数字资产机构基础设施公司，如果 RWA、stablecoin、tokenization 继续发展，银行、资管、fintech 将需要托管、钱包、结算、合规、交易、staking、API 等底层服务，BTGO 可能成为中间收租渠道。

**假设验证结果：假设被严重削弱。**

### 2.2 公司到底在产业链里收什么钱

**表面叙事**：机构级数字资产托管、钱包、结算、合规基础设施平台。

**财报真相**：

| 收入来源 | FY2025 金额 | 占比 | 毛利 |
|---|---|---|---|
| 数字资产销售（交易） | $15,577M | 96.5% | ~$32M (2 bps) |
| Staking | $385M | 2.4% | ~$8M (2.1% net) |
| 订阅及服务 | $122M | 0.8% | — |
| 稳定币即服务 | $67M | 0.4% | ~$2.7M (4% net) |
| 利息 | $2M | 0.0% | — |

**96.5% 的收入来自低毛利数字资产交易（总基确认），而非平台服务费。** 这是做市商/主要当事人业务，不是"收费公路"。

### 2.3 收费权来自哪里

| 收费权来源 | BTGO 实际情况 | 评估 |
|---|---|---|
| 牌照 | OCC 国民银行信托执照、NYDFS、Dubai | 真实，但 Coinbase、Anchorage 也有 |
| 技术 | 多签钱包、冷热分离、保险 $250M | 真实，但非独占 |
| 客户关系 | 5,322 客户（2 年 97% CAGR） | 积极但客户集中度高 |
| 网络效应 | 未观察到显著网络效应 | 薄弱 |
| 合规 | OCC、NYDFS 监管，GENIUS 法案受益 | 真实但非独家 |
| 数据 | 无显著数据优势 | — |
| 软硬一体 | 不适用 | — |
| 生态位 | 机构数字资产服务 | 有定位但竞争激烈 |

**收费权结论：薄弱。** 托管、钱包、交易均非独家能力，客户可以迁移到 Coinbase Prime、Fireblocks、Anchorage、传统银行或自建方案。SAB 122 降低了银行进入数字资产托管的门槛。

### 2.4 财报验证指标

#### 收入与毛利趋势

| 指标 | FY2023 | FY2024 | FY2025 | Q1 2026 |

| 总收入 | $926M | $3,081M | $16,152M | $3,774M |
| 毛利润 | $62.8M | $130.7M | $226.9M | $49.0M |
| **毛利率** | **6.8%** | **4.2%** | **1.4%** | **1.3%** |
| 调整后 EBITDA | -$29.7M | $3.2M | $32.4M | -$1.7M |
| 净利润 | -$2.1M | $156.6M* | -$14.8M | -$60.7M |

*FY2024 净利润包含 WBTC 出售收益 $115M + 未实现加密收益 $112M - 商誉减值 $36.5M，非经常性项目。

**关键发现：收入增长 17 倍（FY2023→FY2025），但毛利率从 6.8% 压缩至 1.4%。** 这完全不符合"规模效应带来经营杠杆"的平台逻辑。

Take rate 在改善，说明平台在结构上变得更好。但基数极低（32 bps on trading）。

#### 客户增长

### 2.5 四条增长线逐一验证

#### Line 1: RWA / Tokenization 放大托管资产

**判定：叙事为主，实际收入贡献为零。**

- 10-K 和 10-Q 中没有 RWA、tokenization 相关收入项目
- 代币化用例在 10-K 中作为前瞻性定位提及，但没有产生实质收入
- 无银行合作伙伴在 tokenization 领域的具体合同

#### Line 2: Stablecoin-as-a-Service

**判定：真实的增长线，但规模极小且仅 1 个客户。**

| 指标 | FY2025 | Q1 2026 |
|---|---|---|
| 稳定币收入 | $66.7M | $38.2M |
| 稳定币费用 | $64.0M | $35.3M |
| **净稳定币利润** | **$2.7M** | **$2.9M** |

- 10-K 明确披露："one active Stablecoin-as-a-Service client"
- goUSD（内部稳定币）计划 Q2 2026 推出，但"无法保证其商业推出"
- 已申请 OCC 国民银行执照以符合 GENIUS 法案 PPSI 资格

#### Line 3: 机构交易 / 衍生品 / Prime Brokerage

**判定：正在发生，方向正确，但仅 1 个季度数据。**

- Q1 2026 推出衍生品，名义交易量 ~$30 亿
- 客户从总基确认的现货交易转向净基确认的衍生品 → 报告收入下降但经济利润可能改善
- CFO 明确表示："排除衍生品结构变化相关的会计影响，底层平台经济显著比报告收入趋势所暗示的更具韧性"
- **这是 BTGO 最重要的结构性转变，但需要更多季度验证**

#### Line 4: Crypto 牛市 Beta

**判定：完全确认，仍是最主要收入驱动因素。**

- 加密价格对托管资产、交易量、staking 收入、公司自持 BTC 价值均有直接影响
- Q1 2026 净亏损 $60.7M 中，$53.7M 来自 BTC 未实现亏损
- 公司自持 2,449 BTC ($167M)，BTC 价格每变动 50% 影响净利润 ~$84M

### 2.6 Earnings Call / 管理层信号

**CEO Mike Belshe (2026-05-13):**
- 强调标准化托管资产 +29.4% YoY
- 定位稳定币和代币化为"数字金融的下一阶段"

**CFO Ed Reginelli:**
- 数字资产销售利润率从 20 bps 改善至 32 bps
- Q1 包含 ~$3.0M 一次性 IPO 相关费用
- 衍生品名义交易量 $30 亿（Q1 2026）

**核心信号：管理层正在将公司从总基交易模式转向更高利润率的衍生品/净基模式。方向正确，但需要更多季度数据。**

### 2.7 反证条件

| 反证条件 | 是否触发 | 严重程度 |

| Stablecoin / RWA 只是营销叙事 | **触发** — RWA 零收入，稳定币仅 1 客户 | **严重** |
| 监管牌照不足以形成护城河 | **部分触发** — Coinbase/Anchorage 也有类似牌照 | **中高** |
| 客户可以轻易迁移 | **持续观察** — 无显著转换成本证据 | **中** |

### 2.8 三年翻倍估值反推

| 指标 | 当前 |

| 股价 | ~$5.00 |
| 市值 | ~$578M |
| 企业价值 | ~$224M（扣除现金 + BTC 金库） |

**三年翻倍路径（$5 → $10，市值 $578M → $1,156M）：**

| 场景 | 所需条件 | 可行性 |

| A: 加密牛市续创 | AoP 回到 $100B+，收入 $30B+，GP $390M，3x P/GP | 取决于 BTC 价格 |

| **最可能: A+C 结合** | 加密牛市 + 衍生品改善 + 稳定币增长 | **30-40% 概率** |

**最敏感变量：BTC 价格。** 如果 BTC 在 2026-2028 年维持在 $60K 以下，BTGO 的所有指标都会收缩。

## 3. Circle vs BTGO 生态位比较

### 3.1 RWA 产业链定位

| 层级 | Circle | BTGO |
|---|---|---|
| 资产发行方 | **核心** — USDC/EURC 发行商 | 间接（第三方稳定币基础设施） |
| 法律结构/SPV | 最小 | 最小 |
| Tokenization 平台 | **核心** — Arc L1 区块链、开发者工具 | 开发中（Brassica 收购） |
| 托管 | 有限（公司稳定币储备） | **核心** — BitGo Bank & Trust，$63B AoP |
| 钱包/密钥管理 | CPN、开发者 API | **核心** — 热冷钱包、多签、机构钱包 |
| 稳定币结算 | **主导** — USDC 是 RWA 结算轨道 | 使用 USDC/USDT，赚取 SaaS 费用 |
| 交易流动性 | 间接（USDC 交易对） | **活跃** — BitGo Prime 交易、结算 |
| 合规/KYC/AML | 内置于发行基础设施 | **核心** — KYC/AML 合规基础设施 |
| 报告/审计/税务 | 储备透明度、认证 | 投资组合报告、税务基础设施 |
| 分销 | **强劲** — Coinbase、Apple、Visa 合作 | 机构分销至 5,320+ 客户 |

### 3.2 RWA 爆发时谁吃到什么

**Circle 吃到的层**：
- **结算层（最大）**：每笔 RWA 交易如果用 USDC 结算，Circle 赚储备利息。$75.5B USDC 储备，年化 3.39% 收益。
- **发行层**：EURC、USYC 等新稳定币产品扩大覆盖
- **开发者工具层**：CCTP 锁定开发者生态，Arc L1 提供基础设施

**BTGO 吃到的层**：
- **托管层**：RWA tokenization 需要合格托管，BTGO 提供 $63B 级别托管能力
- **合规层**：机构进入 RWA 需要 KYC/AML 基础设施
- **稳定币基础设施层**：为第三方发行方提供 SaaS 服务

### 3.3 确定性 vs 赔率

| 维度 | Circle | BTGO |
|---|---|---|
| **确定性** | **远高于 BTGO** | 较低 |
| 收入规模 | TTM $2.86B | ~$337M 净收入 |
| 盈利能力 | TTM 净利润 $189M，FCF $491M | 净亏损 -$61M，FCF 负 |
| 收入机制 | 利率 × USDC 供应量 = 机械式收入引擎 | 无机械式收入引擎 |
| 竞争护城河 | USDC 网络效应（合规稳定币默认选择） | 托管服务竞争激烈 |
| 监管优势 | GENIUS 法案天然合规 | OCC 执照但非独家 |

| 维度 | Circle | BTGO |
|---|---|---|
| **赔率** | 较低 | **高于 Circle** |
| 翻倍所需价值创造 | $20B → $40B（需新增 $20B） | $578M → $1.16B（需新增 $578M） |
| 当前 P/S | 7.0x | 1.6x（净收入） |
| 利润率扩张空间 | 有限（已达 8% 净利率） | 大（从亏损到盈亏平衡） |
| 催化剂 | USDC 供应增长 + 利率维持 | 加密牛市 + 衍生品转型 + 稳定币增长 |

### 3.4 谁更容易被影响

| 风险因素 | Circle | BTGO |
|---|---|---|
| **利率下降** | **极度敏感** — 每 100bps = -$750M 收入 | 低影响 — 托管费与利率无关 |
| **监管变化** | 混合 — GENIUS 法案利好但可能增加合规成本 | 混合 — OCC 执照提供清晰度但增加合规成本 |
| **竞争** | 高 — Tether $187.5B 主导，银行可能入局 | 高 — 托管商品化，无显著转换成本 |
| **分销成本** | 高 — Q1 分销成本占收入 58%（$405M/$694M） | 低 — 直销为主 |

### 3.5 只看当前估值和利润弹性，谁更可能三年翻倍

**BTGO，但附带重大前提条件。**

理由：$578M → $1.16B 只需 $578M 价值创造。一个成功的衍生品转型 + 2-3 个稳定币客户 + 加密价格维持即可实现。Circle 需要 $20B 价值创造，在降息周期中极其困难。

**但 Circle 是更好的生意。** 它有机械式收入引擎、真实盈利、强劲 FCF。BTGO 本质是对加密周期的高杠杆赌注，加上管理层能否成功转型的乐观预期。

**如果 BTGO 到 2027 年底仍未盈利，论点破裂。**

## 4. 地平线深度研究

### 4.1 一句话投资假设

地平线押的是智能驾驶软硬一体生态位——芯片 + 算法 + 工具链 + 量产方案 + OEM 适配 + 数据闭环。短期 L2/L2+ 和 NOA 普及是收入基础，长期 L3/L4 是终局期权。

**假设验证结果：部分成立。**

### 4.2 公司到底在产业链里收什么钱

| 收入来源 | 2024A 金额 | 占比 | 毛利率 |
|---|---|---|---|
| 产品解决方案（芯片/硬件） | RMB 664M | 27.9% | 46.4% |
| 授权及服务（IP/软件/研发） | RMB 1,647M | 69.1% | 92.0% |
| 非汽车 | RMB 72M | 3.0% | — |
| **总计** | **RMB 2,384M** | 100% | **77.3%** |

**关键 nuance：授权及服务收入的 46%（~RMB 750M）来自大众 CARIZON 单一客户，更像"大客户定制研发"而非持续性版税。**

### 4.3 收费权来自哪里

| 收费权来源 | 地平线实际情况 | 评估 |
|---|---|---|
| 芯片设计 | J2-J7 全系列，10-1000+ TOPS | 真实，但 Black Sesame 也有 |
| 算法 | HSD 城区 NOA、Horizon Mono ADAS | 真实 |
| 工具链 | 天工 = 中国版 CUDA | **最强的护城河** |
| 云平台 | 艾迪 AIDI = 中国版 Nvidia DRIVE | 有竞争力 |
| 车载 OS | Tago OS | 有竞争力 |
| 量产交付 | 310+ 车型定点，7.7M+ 累计出货 | 中国第一 |
| IP 授权 | BPU IP 给 VW（类 ARM 模式） | 国内唯一 |

### 4.6 核心问题验证

#### 它是平台，还是零部件供应商？

**结论：正在从"芯片供应商"向"平台"演化，但尚未达到。**

更准确的定位是"带软件栈的芯片平台公司"，介于 Nvidia 和 Mobileye 之间。工具链（天工）是最接近真正平台护城河的资产。但授权及服务收入 46% 来自单一客户，说明更偏"大客户定制研发"。

#### 毛利率下降是否被规模化抵消？

**结论：目前成立。** 毛利绝对额增长 68.3%（远超收入 53.6%），毛利率从 70.5% 升至 77.3%。产品解决方案 GPM 仅 46%，但授权及服务 GPM 92% 且占比提升。

**但风险在于：** 如果未来产品解决方案占比大幅提升（1H25 已到 46%），混合毛利率可能下降。需要 J6P/HSD 高 ASP 产品放量来维持。

#### 车厂自研是否会杀死地平线？

**结论：大概率不会完全杀死，但会蚕食中高算力市场。**

Bernstein 测算：芯片自研盈亏平衡需要年产 ~150 万辆。2024 年中国仅 BYD 和吉利达到。手机行业类比：高通/联发科仍占 50-60% 市场份额。

**基准假设：3P 供应商守住 60% 市场，Horizon 在 3P 中占 ~47%，整体 ~31%。**

#### L2/L2+ 是否足够支撑三年增长？

**结论：是。** 高速 NOA 下沉到 10 万级车型 + HSD 城区 NOA 首次量产 + 大众 CARIZON 放量 + Tier-1 渠道（Bosch/Denso/Continental）打开全球 OEM。这才是 2026-2028 年的真正收入引擎。

#### 全球化能力？

**结论：早期阶段，有潜力但未验证。** 大众深度 JV、Bosch/Denso 全球渠道是桥梁，但地缘政治风险（TSMC 代工）和品牌认知差距是障碍。
