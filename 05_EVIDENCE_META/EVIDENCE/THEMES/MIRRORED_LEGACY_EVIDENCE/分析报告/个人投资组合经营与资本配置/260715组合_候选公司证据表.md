# 组合：企业类型与候选证据表

## 先说人话

**今天发生了什么：**候选公司不再用“谁更能分散组合”统一排名，而是先区分长期复利、结构性供给、数据优势经营交易和高赔率期权四种游戏。

**为什么重要：**顺丰的数据优势、天赐的周期价差、紫金的资源运营和 ORCL 的期权错价不能用同一把尺。先辨认赚哪种钱，才能选对过程指标和仓位表达。

**现在该做什么：**A 股当前冠军是天赐材料，备选是紫金矿业；顺丰继续验证数据领先性，亨通等待赔率。美股只给候选排序，不在缺少实时盘口时指定合约。

## 一、企业类型地图

| 类型 | 标的 | 主要赚什么钱 | 关键误区 |
|---|---|---|---|
| 长期产品/平台 | 地平线、名创、LMND、CRCL、ORCL、NBIS | 产品、平台、品牌或收费权变强的基本面钱 | 把行业增长当公司控制权 |
| 结构性供给窗口 | 天赐、紫金、亨通 | 短缺、产量、价差和资本开支周期的钱 | 把阶段短缺当永久护城河 |
| 数据优势经营交易 | 顺丰 | 领先经营数据与市场预期差 | 数据能解释历史，不代表能预测股价 |
| 基金工具 | 513130、501096 | 指数/经理/主题/流动性 | 用公司研究语言解释基金 |
| 高赔率专项 | MSTR、BTGO及美股期权 | 状态跳变、IV 错价和事件波动 | 方向正确但波动买得太贵 |

## 二、A 股冠军决赛

### 1. 决策矩阵

评分不是自动买卖信号。总分只在同类证据口径下比较，最终还要过价格与失败路径。

| 标的 | 十年经营/25 | 控制权/20 | 过程可观测/15 | 现金质量/15 | 当前赔率/25 | 合计 | 当前角色 |
|---|---:|---:|---:|---:|---:|---:|---|
| 天赐材料 | 18 | 14 | 13 | 7 | 22 | **74** | **赔率冠军** |
| 紫金矿业 | 20 | 17 | 13 | 14 | 18 | **82** | **胜率备选**；总质量最高但当前体量更大 |
| 顺丰 | 15 | 14 | 15 | 12 | 15 | **71** | 数据领先性验证候选 |
| 亨通光电 | 17 | 14 | 12 | 8 | 5 | **56** | 好经营、低当前赔率 |

这张表对决策的意思是：紫金的公司质量和胜率最高，但用户这 9 万元当前优先追求赔率；天赐在 37.55 元有更厚右尾，因此成为冠军。若现金流失败，冠军立即让位给紫金，而不是继续用长期储能故事加仓。

### 2. 三情景与换位

| 标的 | 悲观经营价值 | 基准经营价值 | 乐观经营价值 | 主观概率（悲/基/乐） | 粗算期望总回报 | 换位条件 |
|---|---:|---:|---:|---:|---:|---|
| 天赐 | ¥20-25 | ¥45-55 | ¥70-90 | 25%/45%/30% | **约 +39%** | OCF/营运资本失败则失位 |
| 紫金 | ¥20-23 | ¥36-43 | ¥50-65 | 30%/50%/20% | **约 +31%** | ≤¥27.5 且产量/OCF不坏则晋级 |
| 顺丰 | ¥25-30 | ¥42-53 | ¥60-75 | 30%/55%/15% | **约 +33%** | 数据领先 + FCF确认 + ≤¥31 |
| 亨通 | ¥38-45 | ¥68-82 | ¥100-125 | 35%/50%/15% | **约 -3%** | ≤¥55 或前瞻 PE≤20 |

期望值按 2026-07-15 收盘价和区间中点计算，是未来约 2-3 年的主观总回报，不是年化预测。顺丰的数学期望暂高于紫金，但其中包含尚未通过独立财报验证的数据优势，所以不能仅凭该数字成为胜率备选。

现有主板候选中，永辉已做门槛预筛：门店调改、供应链效率和自由现金流尚未形成足以进入决赛的独立证据，暂不进入赔率计算。立讯精密按用户指令排除；513130、501096 是基金工具，不参加公司冠军赛。

## 三、A 股证据卡

### 天赐材料 002709.SZ

| 项目 | 证据/闸门 |
|---|---|
| 原始经营假设 | 储能/锂电需求穿透到电解液和六氟；认证、一体化、自供和配方守住价差 |
| 过程指标 | 电解液/六氟价格与价差；出货与利用率；Q3 排产；LiPF6/LiFSI 自供；高端产品占比 |
| 结果指标 | 毛利率；OCF；应收/存货相对收入；单吨利润 |
| 当前正证据 | H1 归母 27-30 亿元；出货 +40%；6 月接近满产 |
| 当前反证 | Q1 OCF 为负；周期价格和新增供给可能反转 |
| 三层肉 | 内在价值预期 + 风险偏好；流动性放大波动 |
| 估值语法 | 周期 PEG + 事件跳变，不用永久 DCF |
| 赚哪种钱 | 利润修复、供需紧平衡和市场错杀的钱 |
| 价格纪律 | ≤38.2 第一笔；第二笔等 H1；第三笔等 Q3/现金流 |
| 最短失败路径 | OCF 仍负 + 应收存货快于收入，或六氟破线 + Q3利润下滑 |
| 不做什么 | 不把油价或储能新闻直接当公司利润；不因满产忽略单吨利润 |

### 紫金矿业 601899.SH

| 项目 | 证据/闸门 |
|---|---|
| 原始经营假设 | 资源储量、低品位矿技术和全球项目运营能持续增加铜金产量与每股现金流 |
| 过程指标 | 矿产铜/金产量；Julong/锂项目爬坡；金铜售价与单位成本；海外许可/安全 |
| 结果指标 | 矿山毛利率；OCF/FCF；ROE；少数股东与资本开支后的每股现金 |
| 最新正证据 | Q1收入 +24.79%、归母 +97.50%、OCF +122.15%；矿山毛利 71.01% |
| 最新反证 | Q1矿产铜同比下降；利润高度受金铜价格上涨贡献；海外地缘风险 |
| 三层肉 | 内在价值为主，商品风险偏好次之 |
| 估值语法 | 商品周期 PE/FCF + 资源净现值，不用单一静态 PE |
| 赚哪种钱 | 产量增长、低成本运营和铜金价格中枢的钱 |
| 当前价格 | ¥28.83；胜率备选，不因高质量直接追价 |
| 最短失败路径 | 重大项目延期 + 成本上涨 + 金铜价格回落，OCF同步下行 |
| 不做什么 | 不把价格上涨与产量增长重复计票；不忽略少数股东和国别风险 |

### 顺丰控股 002352.SZ

| 项目 | 证据/闸门 |
|---|---|
| 原始经营假设 | 内部经营数据可领先公开财报，帮助识别利润池和现金流拐点 |
| 过程指标 | 时效收入/服务质量；客户折扣；电商、大件、国际核心利润；单位成本 |
| 结果指标 | 公开扣非利润；TTM FCF；OCF/利润；ROIC |
| 最新正证据 | H1内部收入 +12.2%、核心税前利润 +35.5%，改善较广 |
| 最新反证 | 时效收入 -1.3%；Q1 FCF下降；折扣提高 |
| 数据优势检验 | 内部指标须至少领先一个报告期，并能解释公开结果相对市场预期差 |
| 三层肉 | 内在价值主导 |
| 估值语法 | PE/DCF + 修复 PEG |
| 赚哪种钱 | 基本面修复与数据领先的预期差钱 |
| 当前价格 | ¥33.48；继续验证，不设固定买入数量 |
| 最短失败路径 | 时效收入与利润同坏，FCF<100亿元，服务质量下降 |
| 不做什么 | 不把减亏当新护城河；不复制内部敏感明细 |

### 亨通光电 600487.SH

| 项目 | 证据/闸门 |
|---|---|
| 原始经营假设 | AI数据中心光纤短缺与海洋项目交付推动量价，高端产品留下更厚利润 |
| 过程指标 | 光纤价格/产量；高端光纤占比；海洋订单与交付；扩产上线；海外需求 |
| 结果指标 | 分部毛利；OCF；应收/存货；前瞻 EPS 与估值 |
| 最新正证据 | Q1收入 +34.09%、扣非 +107.68%；H1归母预告 +86.94%-121.20% |
| 最新反证 | Q1 OCF为负；2025利润与OCF下降；普通线缆供给会追上 |
| 三层肉 | 风险偏好和盈利预期很厚 |
| 估值语法 | PEG；重点看增长斜率边际而非利润绝对值 |
| 赚哪种钱 | 光纤紧缺与海洋交付的事件/基本面钱 |
| 当前价格 | ¥71.05；等待 ≤55 或盈利/现金流追上估值 |
| 最短失败路径 | 光纤价格回落 + 新产能投放 + OCF继续弱 |
| 不做什么 | 不因H1利润翻倍追高；不把全公司收入当AI光纤收入 |

## 五、美股期权候选

| 标的 | 六个月状态跳变 | 领先过程指标 | 结果指标 | 期权主要风险 | 当前状态 |
|---|---|---|---|---|---|
| ORCL | RPO/OCI/Agent数据库转收入 | RPO转化；OCI；利用率；客户预付 | FCF/股；CapEx/收入；稀释 | IV、融资、催化错位 | 优先比较实时赔率 |
| CRCL | USDC与支付网络收费权 | 平均USDC；真实支付；分发集中 | RLDC margin；其他收入/OCF | 利率、渠道分成、IV | 第二顺位 |
| NBIS | 产能上电和利用率转ARR | MW/GW；利用率；合同转收入 | EBITDA；FCF；每股收入 | 高IV、交付、融资稀释 | 等IV/价格改善 |
| MSTR | 每股BTC经资本结构增厚 | 每股BTC；mNAV；融资成本 | 优先证券覆盖；完全稀释价值 | BTC、mNAV、结构侵蚀 | 专项观察 |
| BTGO | 托管/稳定币净贡献转正 | 客户；AOP；订阅续约 | 净贡献；EBITDA；OCF | gross收入幻觉、流动性 | 继续观察 |

期权共同规则：下单前刷新 bid/ask、IV/IV分位、Delta、Theta、Vega、OI、成交量和催化时间；单一假设最大损失 US$1,100，总最大损失 US$3,300；只用买方或借方价差。
