# 研究知识层

这里保存的不是“道”、研究方法或交易动作，而是我们在研究中形成、允许被证伪的行业与实体认知。

```text
Source（材料与原话）
→ Moment（判断发生了什么变化）
→ Knowledge（当前最值得相信的领域/实体模型）
→ 03_STATE（带时效的预期与标的 thesis）
→ Case（结算后学习）
```
