# AI 领域知识

## 一句话叙事

企业 AI 正从购买裸模型，转向持续购买能够保存状态、治理数据、控制权限、审计任务并调度算力的生产系统；价值可能流向拥有企业数据引力或高利用率 AI 云能力的平台，但只有客户付费转成利润与现金流、且尚未被价格充分反映时，才形成投资机会。

这句话是研究导航，不是事实结论，更不产生资本动作。

## `ljg-invest` 只读投影

```yaml
projection_type: ljg_invest
projection_authority: none

new_order: 模型成为可替换生产要素，控制平面负责把智能变成可担责任务
flywheel: 使用量增加 → 合同与任务流增加 → 企业语义和治理沉淀 → 切换成本上升 → 更多任务进入
power_shift: 从单一模型 API 向数据语义、权限、路由、审计、交付和容量效率迁移
market_old_lens: 仍用模型排行榜或裸算力收入解释所有企业 AI 价值
```

这个 Lens 只帮助提出原子 belief。它不能写金额、资本动作、旧研究路径或 `murphy_confirmed`。

## 基础因果链

```text
模型达到够用线
→ 多模型路由成为可行替代
→ 裸模型的普通能力定价受压
→ 企业仍需状态、数据、权限、审计、回退和成本治理
→ 控制平面与云运行层获得付费机会
→ 合同与使用量必须转成利用率、利润和现金
→ 再与市场隐含预期比较
```

任一步断裂，都不能用前一步的热度补上。

## 稀缺环节与利润池

| 环节 | 稀缺来源 | 最容易断在哪里 |
|---|---|---|
| 企业数据语义 | 历史业务对象、口径和权限关系 | 数据可迁移、平台无法收费 |
| 控制平面 | 路由、评测、回退、审计和责任链 | 云/模型厂商免费打包 |
| 云运行与容量 | GPU、电力、网络、数据中心和利用率 | 供给扩张、闲置、融资成本 |
| 物理基础设施 | 认证、良率、交付和扩产周期 | 工程绕开、扩产反噬 |
