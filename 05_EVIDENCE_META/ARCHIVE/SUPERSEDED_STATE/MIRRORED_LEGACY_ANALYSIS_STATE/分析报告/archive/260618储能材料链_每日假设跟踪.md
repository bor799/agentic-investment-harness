## 一句话判断

今天新增的最重要变化是：

```text
储能需求和付款人继续兑现
+ 海外大储仍在扩张
+ 电芯利润开始进半年报预告
- 材料价格信号重新转弱
- 材料环节仍未看到正式报表修复
= 主假设维持，不升级确认仓
```

换句话说，假设前两段

`储能建设放量 -> 储能电芯需求增长`

今天比昨天更强；但最后一段

`-> 高质量材料环节利润修复`

今天还没有被证明，反而价格端出现黄灯。

## 新增证据

### 1. 宏观 λ 仍强，且新增了海外大储与算力配储的付款人线索

- 国家能源局 **2026-06-16** 月度调度会继续要求提升新能源并网消纳，明确“依托价格信号带动储能发展”。
- 国家能源局等四部门 **2026-05-08** 印发《关于促进人工智能与能源双向赋能的行动方案》，继续把算力设施、电力系统、储能协同放在一个框架里。
- 国家发改委、国家能源局 **2026-05-20** 多用户绿电直连通知明确优先支持算力设施，且项目连接线路、变电设施、**储能** 及运营平台原则上由项目主责单位投资建设。
- 海外大储新增可验证落地：
  - Grenergy **2026-06-08** 官宣智利 `Elena` 项目已投运 **3.5GWh**，并规划扩容到 **7GWh**，同时配套推进 **1GW IT** 的 AI 数据中心平台。
  - Sonnedix 与阳光电源 **2026-05-28** 签署智利 `Librillo` 项目 **643.8MWh** 独立储能供货协议。

判断：`宏观 λ` 没有转弱，且“海外大储 + 算力配储 + 绿电直连”还在扩展付款人池。

### 2. 需求和付款人继续兑现，但装机兑现节奏仍分化

- CNESA **2026-06-11**：
  - 5 月储能系统招标 **7.3GW / 23.8GWh**
  - 同比 **+518.1% / +704.9%**
  - 5 月储能系统中标 **3.5GW / 13.5GWh**
  - 4h 储能系统中标均价 **598.2 元/kWh**
- 中国能建 **30GWh** 储能集采、国电南瑞 **4GWh** 储能电芯框采继续说明国内付款人没有消失。
- 但 CNESA **2026-06-16** 同时披露：
  - 5 月国内新增投运新型储能 **1.78GW / 5.22GWh**
  - 同比 **-85% / -82%**
  - 环比 **-51% / -44%**
  - 联盟解释主因是去年“531”抢装高基数和项目建设周期扰动

判断：订单和预算还在，但 `招标 -> 开工 -> 装机 -> 回款` 这条链路并不顺滑，所以今天不能升级为“假设增强”。

### 3. 财务验证新增到了“电芯”，还没有新增到“材料”

- 亿纬锂能 **2026-06-15** 发布半年度业绩预告：
  - 归母净利润预计 **31.30-33.71 亿元**
  - 同比 **+95% 到 +110%**
  - 扣非净利润预计 **24.30-26.03 亿元**
  - 同比 **+110% 到 +125%**
  - 公司同时披露 **营业收入同比增长约 60%**
  - 管理层解释中明确提到通过前置采购和供应链多元化缓冲材料成本上涨

判断：这证明“储能电芯需求增长”正在进入财务层；但它也说明利润先落在了**电芯端**，并没有自动证明湖南裕能、天赐材料、新宙邦、恩捷股份、璞泰来已经同步修复。

- 这对“高质量材料利润修复”是一个明确黄灯。

## 泊松节奏

未来 3-12 个月最关键的重定价事件：

1. **6 月下旬到 7 月**：继续看 4h 系统价格能否稳定在 **0.50 元/Wh** 以上，314Ah 电芯价格是否止跌。

3. **7 月初后**：基金 Q2 持仓披露窗口前后，验证 `001616` 是否继续锚定湖南裕能 / 天赐 / 宁德 / 亿纬。

5. **Q3**：若材料价格止跌回升，且单吨盈利 / 毛利率 / 经营现金流同步改善，才有资格从观察仓升级确认仓。

## 假设层变化

变化前：

```text
宏观 λ 强
招标付款人强
材料利润修复仍未进报表
```

变化后：

```text
宏观 λ 仍强
国内外付款人继续兑现
电芯利润开始进半年报预告
但材料价格重新转弱
材料利润修复仍未进入正式财务验证
```

今天真正发生的变化不是“假设被证伪”，而是：

```text
验证链条推进到了电芯
但停在了材料之前
```

所以结论只能是 **假设维持**，不能升级为 **假设增强**。

## 仓位动作建议

- 允许动作：`观察仓`、`不加仓`
- 不升级：`确认仓`

原因：

1. `宏观 λ` 没坏。
2. 国内外付款人还在兑现。
3. `001616` 映射稳定。
4. 亿纬锂能的半年度预告说明电芯端财务验证在前进。
5. 但材料价格今天重新转弱，说明利润修复还没传导到材料。
6. 材料环节还缺正式的 **毛利率、单吨盈利、经营现金流、库存、利用率** 验证。

这只是按你的框架给出的仓位纪律，不是绝对投资建议。

- `招标强、装机弱`：**黄灯，未反证**

- 314Ah 储能电芯价格继续下杀：**未触发**

- `001616` 持仓或净值映射漂移：**未触发**
- 重点公司出现正式披露的库存失控、回款恶化、经营现金流恶化：**未触发**

如果后续连续出现：

```text
装机兑现继续弱
+ 材料价格继续走弱
+ 材料公司 Q2/H1 毛利和现金流不改善
```

那么下一步应从 **假设维持** 下调到 **假设转弱**。
