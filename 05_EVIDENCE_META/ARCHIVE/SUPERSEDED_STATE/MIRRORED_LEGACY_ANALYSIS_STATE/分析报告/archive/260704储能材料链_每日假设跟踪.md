## 一句话判断

```text
到 2026 年 7 月 4 日，储能建设放量的宏观需求 λ 还在，
电网侧、独立储能业主、能源央企仍是主要付款人，
AI 算电协同也继续提供方向性支撑。

但新增硬证据主要停在 L1 物理需求、L2 订单/业绩预告和电芯层，
没有推进到“高质量材料利润修复”本体。

InfoLink 7 月 1 日口径显示 314Ah 电芯 0.375 元/Wh、4h 系统 0.53 元/Wh，
这更像价格止跌企稳，不是材料端重新掌握定价权。
7 月 3 日正式净值里，159566/159796 为正而 001616/003984 为负，
也说明当前交易更偏电池/系统，不是材料确认窗口。

因此结论仍是：假设维持。
```

## 新增证据

### 1. 宏观需求 λ：继续偏强，但没有新增全国级跳点

- 国家发展改革委、国家能源局 `2026-06-25` 印发《新型能源体系建设“十五五”规划》，继续把新型储能、长时储能和电力系统灵活性放在底层能力位置。
- 国家能源局 `2026-06-29` 披露：`2026年1-5月` 全国累计完成电力市场交易电量 `30573` 亿千瓦时，同比增长 `24.8%`。
- 国家能源局 `2026-06-24` 披露：截至 `2026年5月底`，全国充电基础设施总数达到 `2249.7` 万个，同比增长 `44.9%`。
- 国家能源局 `2026-06-26` 与 `2026-07-03` 连续发布“算力跟着绿电走”“不止于储电”相关内容，说明 AI 负荷与储能扩容仍在政策与产业口径里被强化。
- 海南省 `2026-07-01` 公布 `2026` 年电网侧独立新型储能剩余可开放容量 `2.15GW`，共 `22` 个可接入站点。

判断：

```text
宏观 λ 没有转弱，且电网调峰、快充底座、AI 算电协同和地方储能接入能力都还在继续累积。

但今天没有出现新的全国级强制配储、容量电价上修、海外大储超预期订单、
或 AIDC 配储强约束这类“跳变证据”。

所以宏观层只能给“维持偏强”，不能上调到“假设增强”。
```

### 2. 需求与付款人：需求链成立，回款链仍未穿透到材料端

- CNESA `2026-06-11` 披露：`2026年5月` 储能系统招标 `7.3GW / 23.8GWh`，同比 `+518.1% / +704.9%`；中标 `3.5GW / 13.5GWh`，同比 `+92.9% / +154.7%`。
- CNESA `2026-06-06` 披露：中国能建启动 `2026` 年度 `30GWh` 磷酸铁锂储能系统集采，仍是 `7 月中旬` 重要开标窗口。
- 亿纬锂能 `2026-06-15` 披露 `2026H1` 业绩预告：归母净利润预计 `31.30-33.71` 亿元，同比增长 `95%-110%`，营业收入同比约增长 `60%`。

付款人判断：

- 国内主付款人仍是电网侧业主、独立储能业主、能源央企和大型系统集成商。
- AI 数据中心负荷增长更多体现在“未来电力与储能预算方向”上，今天没有新增项目级 CapEx 公告把它直接落到材料利润。
- 海外大储今天没有新增足够高可信的材料端订单/回款证据。

判断：

```text
问题已经不是“有没有人买储能”，而是“储能系统订单 -> 电芯出货 -> 材料采购 -> 回款”
有没有顺滑到足以修复材料利润和现金流。

今天新增硬证据能证明电芯和系统层还不差，
但还不能证明材料端已经拿回现金流主动权。
```

### 3. 产业链卡点与供给锁死：仍未成立

- InfoLink `2026-07-01` 最新公开口径：
  - `314Ah` 磷酸铁锂储能电芯均价 `0.375 元/Wh`
  - 中国 `4h` AC 液冷储能系统均价 `0.53 元/Wh`
  - 页面结论仍是：锂盐先弱后稳，电芯及系统价格暂稳
- 这说明价格没有继续塌陷，但也没有进入“材料顺利提价、下游全面接受涨价、供给明显锁死”的阶段。
- 今天没有新增公开证据显示龙头材料被客户自建或竞品明确绕开，但也没有证据显示龙头材料已经成为不可绕开的最窄瓶颈。
- 最新正式持仓仍显示：
  - `001616` 偏材料/电芯链
  - `159566` 偏电池+系统+设备
  - `159796` 偏更宽的电池主题
  这说明市场当前利润池并没有明确向材料端单点聚焦。

判断：

```text
现在更像“价格稳住了”，不是“供给锁死了”。

如果供给锁死成立，通常会同时看到：
材料提价、下游接受涨价、竞品难扩、客户难绕开、报表毛利改善。
今天这几件事没有同时出现。
```

### 4. 财务验证：只前进到电芯，没有推进到高质量材料

- 亿纬锂能 H1 业绩预告偏强，是今天最重要的公司层新增证据，但它首先验证的是电芯需求、产品结构和经营效率。
- 截至 `2026-07-04 21:04 CST`，未见湖南裕能、天赐材料、新宙邦、璞泰来、恩捷股份等材料侧公司，正式披露足以确认“储能材料利润修复”的 `2026H1` 报表或同等级业绩预告。
- 因此，主假设中的关键一跳仍卡在：
  - 毛利率是否回升；
  - 单吨盈利是否修复；
  - 经营利润是否放大；
  - 经营现金流是否跟上。

判断：

```text
电芯开始写报表，不等于材料已经写报表。

今天可以上调“电芯需求没问题”的把握，
但不能上调“高质量材料利润修复”的把握。
```

## 四层传导验证

| 层级 | 今日新增证据 | 判断 | 下一步要看什么 |
|---|---|---|---|
| L1 物理消耗 | 电力市场交易、充电基础设施、地方储能接入能力继续扩张 | 通过 | `6 月` 招标 / 投运 / 开工数据 |
| L2 订单采购 | 5 月招中标强，30GWh 集采推进，亿纬 H1 预告偏强 | 通过但偏电芯/系统 | 回款与材料采购节奏 |
| L3 价格利润 | 电芯与系统价格暂稳，但材料议价权未确认 | 未通过 | LFP / 电解液 / 六氟单吨盈利 |
| L4 估值预期 | 材料和系统未形成一致性强趋势 | 只是交易层读数 | H1 报表后是否重估 |

判断：

```text
今天新增证据主要落在 L1 和 L2。
L1 -> L2 的传导是成立的，
但 L2 -> L3 还没有走通。

因此今天不能因为电芯或系统层的改善，
```
