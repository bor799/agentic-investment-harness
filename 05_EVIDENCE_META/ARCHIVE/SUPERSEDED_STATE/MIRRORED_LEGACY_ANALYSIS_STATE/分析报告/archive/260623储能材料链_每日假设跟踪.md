## 一句话判断

```text
6月22日国家发改委/国家能源局把国家枢纽节点新建数据中心、5G基站、充电基础设施纳入更硬的绿电消费约束，
说明宏观需求 λ 仍在增强；
但今天没有新增材料端订单、回款或 H1 报表验证，
LFP/电解液/隔膜/PCS 也没有出现新的供给锁死，
所以只能把宏观层上调，不能把整条“储能建设放量 -> 材料利润修复”假设上调为增强。
```

今天最关键的新事实不是股价，而是：**`2026-06-22` 发布、`2026-08-01` 起施行的可再生能源消费新规，已经把“国家枢纽节点新建数据中心”放进绿电消费约束框架，并明确提到“十五五”期间全国算力用电量年均增加 `1000 亿度` 以上。** 这强化了储能和电力调节需求的宏观 `λ`，但还没有直接穿透到材料公司的收费权和报表。

## 新增证据

### 1. 宏观需求 λ：**偏正面新增，但只强化宏观层**

- 国家发展改革委 / 国家能源局 `2026-06-22` 发布的《可再生能源消费最低比重目标和可再生能源电力消纳责任权重制度实施办法》答记者问明确：
  - 目前已经对**国家枢纽节点新建数据中心**提出绿色电力消费比例要求；
  - **算力设施、5G 基站、充电基础设施**将成为未来用电量增长的重要组成部分；
  - 预计“十五五”期间全国**算力用电量年均增加 `1000 亿度` 以上**。
- 这意味着“AI 数据中心 CapEx -> 配电/调峰/储能需求”的付款人约束在政策上更硬了一层，不再只是主题叙事。
- 国家能源局 `2026-05-14` 印发《新型储能电站建设工程质量监督大纲》，继续提高新型储能电站建设和并网规范性。它对行业长期质量是正面，但对材料利润不是立刻兑现。

判断：`宏观需求 λ` **维持偏强，并有新增制度级强化**。

### 2. 需求和付款人：**招标和收益机制还在，但现金流验证仍缺**

- CNESA `2026-06-11` 披露的 `2026-05` 数据仍是当前最硬的付款人证据：
  - 储能系统招标 `7.3GW / 23.8GWh`，同比 `+518.1% / +704.9%`；
  - 储能系统中标 `3.5GW / 13.5GWh`，同比 `+92.9% / +154.7%`；
  - 4h 储能系统中标均价 `598.2 元/kWh`，同比 `+27.1%`。
- CNESA `2026-06-16` 同时给出另一个重要现实：
  - `2026-05` 国内新增投运新型储能仅 `1.78GW / 5.22GWh`，同比 `-85% / -82%`，环比 `-51% / -44%`；
  - 但平均时长升到 `2.93h`，新能源配储平均时长 `3.78h`；
  - 新疆自 `2026-06-01` 起把电网侧独立储能纳入容量补偿，容量电价 `165 元/千瓦·年`。
- 这说明付款人并没有消失，反而收益机制在变硬；但**项目开工和投运节奏仍有明显月度波动**，现金流兑现不能只看招标。

判断：`需求兑现 / 付款人` **维持偏强**，但今天没有新增回款或交付证据。

### 3. 产业链卡点：**终端需求强，材料端收费权仍未确认**

- InfoLink `2026-05-19` 披露，`2026Q1` 全球储能电芯出货 `205.52GWh`，同比 `+98.70%`；
- 大储电芯出货 `178.27GWh`，同比 `+84.54%`；
- 宁德时代、海辰储能、亿纬锂能、比亚迪储能、中创新航位居前五。
- 但 InfoLink 同时给出负面约束：
  - 行业 `CR10` 已降到 `85.2%`；
  - `500Ah+` 电芯渗透率约 `5%`，全年可能接近 `20%`。

这意味着：
- 终端需求没有问题；
- 但**电芯端扩产和规格迭代仍在继续**；
- 对上游 LFP 正极、电解液、隔膜、负极而言，今天依然不能说“客户只能高价拿货”。

判断：`产业链卡点` **仍主要在系统交付和项目收益端，不在材料收费权端**。

### 4. 供给锁死：**今天没有变硬**

- SMM `2026-06-23` 电池级碳酸锂均价回到 `15.85 万元/吨`，较 `2026-06-22` 的 `15.70 万元/吨`小幅修复；
- SMM `2026-06-18` 储能 314Ah 电芯均价 `0.364 元/Wh`，5MWh 预制舱均价 `0.455 元/Wh`；
- InfoLink `2026-06-17` 口径下，锂盐价格偏强，但电芯和系统价格总体持稳。

这组价格的含义是：
- **价格没有跌穿红线**，所以反证没触发；
- 但**价格修复并不等于供给锁死**；
- LFP 正极、电解液、隔膜、PCS/BESS/UPS 没有出现“新产能退出、交期拉长、客户绕不开”的新证据。

判断：`供给锁死` **维持偏弱**。

### 5. 财务验证：**还没进报表**

- 今天没有看到宁德时代、亿纬锂能、湖南裕能、天赐材料、新宙邦、璞泰来、恩捷股份、盐湖股份、中矿资源、阳光电源、科华数据、盛弘股份、上能电气、南都电源的 `2026H1` 业绩预告或经营快报，能把本轮需求直接映射到毛利率、单吨盈利、经营利润或经营现金流。
- 所以当前只能说：
  - 宏观需求更硬；
  - 招标和收益机制仍在；
  - 商品和系统价格没坏；
  - **但材料利润修复还停留在“待 Q2/H1 验证”阶段**。

判断：`财务验证` **待验证**。

```text

供给锁死不足
价格结构偏黄灯
```

变化后：

```text
宏观 λ 因 6月22日新规变得更硬
付款人和收益机制继续强化，但回款与报表仍未新增
```

所以今天最准确的表述不是“增强”，而是：
