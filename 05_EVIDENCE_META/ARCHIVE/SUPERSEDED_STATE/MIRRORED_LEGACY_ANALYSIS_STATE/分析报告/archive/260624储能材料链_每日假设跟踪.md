## 一句话判断

```text
今天新增的硬证据仍然站在“储能建设会继续放量”这一侧：
政策继续把算力设施和绿电直连绑定，招标价格没有跌穿红线，AIDC 与海外大储订单继续出现；
但材料端仍没有出现供给锁死和 Q2/H1 财务兑现，
所以“储能建设放量 -> 储能电芯需求增长 -> 高质量材料环节利润修复”这条假设今天只能维持，不能上调为增强。
```

今天最重要的变化不是股价，而是：**需求端继续变硬，材料端验证仍然滞后。**  
也就是说，`宏观 λ` 和付款人继续强化，但利润修复还没有真正穿进湖南裕能、天赐材料、新宙邦、璞泰来、恩捷股份等公司的报表。

## 新增证据

### 1. 宏观需求 λ：继续增强，但增强点仍主要在电力系统和算力侧

- 国家发改委 / 国家能源局 `2026-06-22` 的消纳责任权重新规答记者问再次明确：
  - 已对**国家枢纽节点新建数据中心**提出绿色电力消费比例要求；
  - **算力设施、5G 基站、充电基础设施**会成为未来用电量增长的重要组成部分；
  - 预计“十五五”期间全国**算力用电量年均增加 1000 亿度以上**。
- 国家能源局 `2026-05-08`《关于促进人工智能与能源双向赋能的行动方案》进一步把“算力 + 电力 + 储能”写进正式框架：
  - 鼓励算力设施配置**构网型储能**；
  - 支持算力设施通过**绿电直连、绿电交易**提高绿电消费比例。
- 国家能源局 `2026-05-20` 多用户绿电直连文件明确：
  - **优先支持算力设施**开展绿电直连；
  - 项目应通过**合理配置储能**提升就近消纳能力。
- 国家能源局 `2026-01-30` 新闻发布会口径：
  - 到 `2027` 年全国新型储能装机目标达到 `1.8 亿千瓦以上`；
  - 预计带动投资约 `2500 亿元`。

判断：`宏观需求 λ` **继续偏强**，而且增强点更集中在**算电协同、绿电直连、系统调节**，不是单纯主题叙事。

### 2. 需求和付款人：招标、项目和海外订单继续兑现，但兑现位置更偏系统层

- CNESA `2026-06-11` 披露 `2026-05` 数据：
  - 储能系统招标 `7.3GW / 23.8GWh`，同比 `+518.1% / +704.9%`；
  - 储能系统中标 `3.5GW / 13.5GWh`，同比 `+92.9% / +154.7%`；
  - `4h` 储能系统中标均价 `598.2 元/kWh`，同比 `+27.1%`，环比 `+15.3%`。
- CNESA `2026-06-03` 项目动态：
  - 宁夏 `200MW/400MWh` 共享储能项目中标价 `0.54 元/Wh`。
  - 这说明低价竞争仍在，但**仍未跌破 `0.50 元/Wh` 红线**。
- CNESA `2026-06-04` 披露：
  - 万国数据与乌兰察布市签约，未来五年投资**超过 300 亿元**，建设**GW 级数据中心园区**，并通过绿电直连、绿电交易实现**80%+ 绿电覆盖**。
- 亿纬锂能官方 `2026-06-23` 在 IDCE 上海数据中心展披露：
  - AIDC 储能方案覆盖源网侧长时储能、配电设备侧高倍率备电、机架侧 BBU。
- 亿纬锂能官方 `2026-05-12` 披露与印度 GNEPL 签署**8GWh** 储能大电池订单，五年潜在合作规模 **60GWh**。
- 亿纬锂能官方 `2026-06-09` 披露 SNEC 现场累计签约**超 67GWh**。
- CNESA `2026-06-01` 汇总 5 月中下旬全球储能大单，累计签约、投运规模**超 77GWh**，其中包括阳光电源中东 `7.5GWh` 大单。

判断：`需求兑现 / 付款人` **继续偏强**，但资金和订单首先流向的是**系统、电芯和项目层**，尚未直接证明材料龙头利润已经同步修复。

### 3. 产业链卡点：卡点仍然在系统收益和项目落地，不在材料供给稀缺

- 今天能确认的新增事实，仍然是：
  - 电网侧 / 数据中心侧 / 海外大储**项目在落地**；
  - 价格没有继续失速；
  - 但**没有新增证据证明 LFP 正极、电解液、隔膜、六氟已经进入“客户绕不开、交期拉长、加工费抬升”的卡点状态**。
- 这意味着当前产业链最窄的地方更像：
  - 电力市场收益机制；
  - 系统集成交付能力；
  - 大客户项目获取和执行能力；
  - 而不是材料环节的绝对供给锁死。

判断：`产业链卡点` **仍偏系统层，不偏材料层**。

### 4. 供给锁死：今天仍不成立

- SMM `2026-06-24`：
  - 电池级碳酸锂均价 `15.75 万元/吨`，较前一日回落 `1000 元/吨`；
  - 储能型 `314Ah` 电芯均价 `0.364 元/Wh`；
  - `5MWh` 预制舱均价 `0.455 元/Wh`。
- 这组价格说明：
  - **没有跌穿红线**，反证没有触发；
  - 但碳酸锂今天是**回落**而不是持续上攻；
  - 电芯、预制舱价格仍然偏稳，并没有出现“全链条紧平衡导致材料提价权显著增强”的状态。

判断：`供给锁死` **继续偏弱**。  
今天的价格结构更像“项目需求支撑仍在”，不像“材料稀缺性已经建立”。

### 5. 财务验证：还没进报表

- 今天没有看到重点股票出现新的 `Q2/H1` 业绩预告、经营快报或利润修复公告，能直接映射到：
  - 毛利率；
  - 单吨盈利；
  - 经营利润；
  - 经营现金流；
  - 存货和产能利用率。
- 因此当前最谨慎的说法仍是：
  - **订单和政策先到了**；
  - **材料利润修复还停留在待验证阶段**。

判断：`财务验证` **继续待验证**。

## 假设层变化

变化前：

```text
宏观 λ 已强
付款人继续兑现
材料供给锁死不足
财务验证待 Q2/H1
结构只允许观察仓
```

变化后：

```text
宏观 λ 继续强化，尤其是算电协同和绿电直连
付款人与项目侧订单继续变多
但利润修复仍停在系统/电芯层，尚未稳定传导到材料报表
材料供给锁死依然不足
因此整条假设不升级，只维持
```

最准确的表述是：

> **需求端在增强，材料端仍在等验证，所以假设维持。**

## 仓位动作建议

- 允许动作：`观察仓`、`不加仓`
- 暂不升级：`确认仓`
- 暂不执行：`降仓`、`退出`

理由：

1. 宏观 `λ`、付款人和订单今天没有变坏，反而继续强化。  
2. `4h` 系统均价、`314Ah` 电芯、`5MWh` 预制舱、碳酸锂都还没跌穿反证红线。
