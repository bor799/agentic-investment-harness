  - 太阳能装机 `12.6 亿千瓦`，同比 `+16.3%`；
  - 风电装机 `6.6 亿千瓦`，同比 `+17.0%`。
- 国家发改委、国家能源局 `2026-06-25` 印发《新型能源体系建设“十五五”规划》：
  - 到 `2030` 年非化石能源消费比重达到 `25%`；
  - 新型储能装机目标达到 `300GW`；
  - 明确提出大力发展新型储能、加力发展长时储能。
- 国家能源局 `2026-05-26` 发布首批 `51` 个“人工智能+”能源高价值场景；

判断：`宏观 λ` **维持偏强**。  
但这些证据主要在证明“储能系统需求”和“算电协同需求”，还不是材料利润修复本身。

- 这说明付款人仍然主要是：
  - 电网侧与独立储能投资方；
  - 园区/数据中心的绿电直连和配储需求；
  - 海外大储项目业主。

判断：`付款人` **成立且未削弱**。  
但今天仍然没有新增证据显示付款已经明显传导到材料采购、材料回款或材料涨价接受。

### 3. 供给锁死：今天仍不成立

3. 电芯和系统价格处在可接受区间，更像支撑系统链盈利与项目开工，而不是把利润挤回材料端。

截至 `2026-06-26 20:28`，重点名单未检索到新增 `Q2/H1` 业绩预告、经营快报或现金流修复公告，可以直接证明：

这条假设目前仍处在 **政策/订单领先，材料报表落后** 的阶段。

## 价格 / 结构判断

今天是否仍是结构窗口？  

答案：**仍是观察窗口，不是确认窗口。**

原因：

1. 宏观需求窗口还在。  
2. 但材料供给锁死没出现。  
3. 价格权和盈利权还没有从系统链传回材料链。  
4. 市场结构也还没把票投给材料利润修复。  

所以今天的仓位动作只允许：

- `观察仓`：可保留。  
- `确认仓`：不升级。  
- `加仓`：不建议。  
- `降仓/退出`：今天未触发。
