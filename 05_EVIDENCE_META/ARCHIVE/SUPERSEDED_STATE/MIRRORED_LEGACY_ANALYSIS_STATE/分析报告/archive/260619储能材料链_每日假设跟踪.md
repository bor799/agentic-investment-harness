## 一句话判断

今天新增了一条偏正面的宏观证据：

```text
全球储能建设继续扩张
+ 国内电网侧招标/中标景气仍强
+ 海外大储项目继续落地
- 材料价格没有止跌回升
- 材料端没有新增业绩预告或报表验证
= 假设维持，仍不到确认仓
```

主假设前两段

`储能建设放量 -> 储能电芯需求增长`

仍在加强；但最后一段

`-> 高质量材料环节利润修复`

今天依旧缺少新增验证。

---

## 新增证据

### 1. 宏观 λ：今天新增的是“全球储能建设仍在加速”的官方正证据

- 国家能源局 **2026-06-18** 发布《全球储能电池发展驶入快车道》，文中写到：
  - **2025 年全球储能电池新增装机容量 108GW**
  - 同比约 **+40%**
  - 公用储能约 **87GW**
  - 澳大利亚、中东、智利等地区继续放量
- 这条证据不是中国单月装机数据，但它强化了“海外大储付款人没有消失、全球建设节奏仍在向上”的判断。

判断：`宏观需求 λ` 继续维持偏强，没有出现方向性转弱。

### 2. 需求和付款人：今天没有新增订单/回款强证据，但旧证据没有被推翻

- CNESA **2026-06-11** 的 5 月数据仍是当前最关键的国内景气验证：
  - 储能系统招标 **7.3GW / 23.8GWh**
  - 同比 **+518.1% / +704.9%**
  - 储能系统中标 **3.5GW / 13.5GWh**
  - 4h 储能系统中标均价 **598.2 元/kWh**
- 华能 **4GWh** 储能框采中，入围名单仍包括 **亿纬、宁德、阳光、南瑞、海辰、中车株洲所** 等，说明付款人在持续下单，但竞争并不稀缺。
- 海外大储方面：
  - Grenergy **2026-06-09** 宣布智利 `Elena` 项目已投运 **3.5GWh**，并规划扩至 **7GWh**
  - 阳光电源与 Sonnedix 的智利 `Librillo` 项目为 **643.8MWh**

判断：`付款人兑现` 没有转弱，但今天也没有出现足以把结论升级成“假设增强”的新增国内订单或回款证据。

### 3. 产业链卡点与供给锁死：今天依旧没有看到“材料环节锁死”的新证据

- CNESA 5 月招中标覆盖 **储能系统、电芯、Pack、PCS、EMS、BMS** 全链条，公开招标仍是多家参与的开放竞争格局。
- 华能 **4GWh** 框采 **48 家投标、10 家入围**，再次说明：
  - 电芯/BESS/PCS 环节仍能扩产、仍有替代
  - 客户并未把利润池锁给单一供应商
- 材料端今天没有看到新的“客户自建失败”“竞品无法绕开”“高品质产能卡住行业”的增量证据。

判断：`供给锁死` 仍然只成立在“高景气”层面，不成立在“强定价权/强稀缺”层面，尤其对 **LFP 正极、电解液、六氟、隔膜** 仍是这样。

### 4. 财务验证：验证链条仍停在电芯，没有推进到材料

- 目前新增的财务强证据仍是 **亿纬锂能 2026H1 业绩预告**：
  - 归母净利润预计 **31.30-33.71 亿元**
  - 同比 **+95% 至 +110%**
  - 扣非净利润预计 **24.30-26.03 亿元**
  - 同比 **+110% 至 +125%**
- 今天没有看到 **湖南裕能、天赐材料、新宙邦、璞泰来、恩捷股份** 新的 H1 预告或经营快报，不能证明材料利润已同步修复。

判断：财务验证仍是“**电芯先修复，材料尚未进报表**”。

### 5. 价格/结构：最新可得价格快照仍然不支持今天升级

最新可得仍为 **2026-06-18**：

- SMM：
  - 储能型磷酸铁锂 `>=2.30g/cm3`：**58190 元/吨**，日变动 **-550**
  - 储能型磷酸铁锂 `>=2.40g/cm3`：**59480 元/吨**，日变动 **-550**
  - 储能用电解液：**26700 元/吨**，日变动 **0**
  - 六氟磷酸锂（国产）：**111000 元/吨**，日变动 **-3000**
- InfoLink：
  - 314Ah 方形 LFP 储能电芯：**0.375 元/Wh**
  - 280Ah 方形 LFP 储能电芯：**0.378 元/Wh**
  - 4h 液冷储能系统：**0.53 元/Wh**

判断：

- 电芯价、系统价没有恶化，是好信号。
- 但材料价格还没止跌回升，说明“需求增长 -> 材料利润修复”尚未打通。

## 假设层变化

变化前：

```text
宏观 λ 强
付款人兑现
材料利润修复未进报表
```

变化后：

```text
宏观 λ 新增一条全球储能高增速正证据
付款人没有转弱
材料利润修复仍未新增报表验证
材料价格仍未止跌回升
```

所以今天的真实变化不是“更差”，而是：

```text
宏观侧更稳了一点
但材料侧没有往前走
```

这只足够支撑 **假设维持**，不够支撑 **假设增强**。

## 仓位动作建议

- 允许动作：`观察仓`、`不加仓`
- 不升级：`确认仓`

原因：

1. 宏观需求 `λ` 没坏，反而新增了全球储能高增长的官方正证据。
2. 付款人还在，国内招标/中标和海外大储都没断。
3. 供给锁死没有增强，材料环节还是竞争格局。
4. 财务验证仍主要落在电芯端，没有推进到材料端。
5. 材料价格没有止跌回升，所以“利润修复”还不能当成已发生事实。

这只是按你的框架执行的仓位纪律，不是绝对投资建议。

## 反证条件检查

今天 **未触发反证**，但以下四条仍是最值得盯的红黄灯：

1. **4h 储能系统价** 再次跌回 **0.50 元/Wh** 下方，甚至逼近 **0.48 元/Wh**
2. **六氟/LFP 价格** 继续下跌，而材料企业 H1 仍无盈利修复
3. **材料龙头 H1** 若出现毛利率、单吨盈利、经营现金流继续恶化
4. `001616` 下一次披露若明显漂移出“宁德/湖南裕能/天赐/亿纬”这一映射
