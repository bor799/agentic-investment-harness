# Scorecard — Nvidia (NVDA)

| 维度 | 分数 | 理由 |
|---|---:|---|
| 结构性转变 | 9/10 | 从芯片公司→AI全栈基础设施平台（芯片+系统+网络+软件），CUDA生态锁定+年度产品迭代+机架级系统定价，是AI时代最清晰的结构性转变案例 |
| 真瓶颈 | 9/10 | AI算力需求远超供给，HBM全球短缺+台积电CoWoS产能限制+数据中心电力约束，旧代Hopper/Ampere仍然售罄是最强瓶颈信号 |
| 定价权 | 9/10 | 75%毛利率+系统级定价（不仅仅是芯片），NVLink网络$10.98B(+263%)创造新收入层，黄仁勋称"性能领先是保护毛利的关键杠杆" |
| 利润率变化 | 8/10 | 净利润$43B翻倍，毛利率维持mid-70s，但内存成本上升+Groq $20B收购+供应链多元化投资可能短期压制利润率 |
| 6-12个月验证信号 | 8/10 | 高度可追踪：季度营收增速（当前73%→指引77%加速）、Vera Rubin量产节奏、hyperscaler capex兑现、AMD/custom ASIC市场份额变化 |
| 3年翻倍路径 | 4/10 | FY26已~$260B年化，翻倍需$520B+，依赖AI需求持续爆发+hyperscaler capex不降+竞争不侵蚀份额，路径存在但概率不高 |
| 能力圈匹配 | 7/10 | CUDA生态是真正的护城河，但hyperscaler自研趋势(OpenAI/Meta转向Trainium/TPU/AMD)是长期威胁，Groq整合不确定性 |

总分：54/70
