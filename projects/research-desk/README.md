# Murphy Research Desk · 统一投资工作台

每天的投资信息收口到这一个工作台：**看核心趋势 → 找到值得关注的变化 → 查看依据与多空观点 → 用语音或文字记下判断 → 到期复查。**

## 主视图（三列工作台）

- **左导航**：今日 / 市场 / 金银 / 半导体 / 20 标的 / 日记本 / 报告 / 自动化。
- **中内容**：
  - 今日：12 个固定观察槽位（顺序稳定，不随涨跌重排）+ 消息看板（需我处理 / 重点更新 / 观点流 / 运行健康）。
  - 主题页：TradingView 式联动图表（1M/3M/1Y/3Y、十字光标、归一化对比、事件标记）+ 事件时间线 + 证据墙（官方事实 / 外部观点 / AI 解释分组）。
  - 研究池：20 标的 + 7 辅助观察（研究池 ≠ 持仓；账户模块未接入就显示未接入）。
- **右操作台**：快速记录（投资日记，停止输入约 1 秒自动保存，支持系统听写；编辑冲突保留两版让你选）、当前上下文自动附加、观点参考。

## 数据来源（每条标供应商与口径，缺失保留缺口）

| 内容 | 来源 |
|---|---|
| ETF 日线（大盘/板块/金银/信用/池） | 本机 Alpaca SIP 连接优先，Yahoo 兜底 |
| VIX / VIX3M / VVIX | CBOE 官方历史 CSV（VVIX 单列格式单独解析） |
| 利率 / 高收益利差 / 广义美元 | FRED（此前多次超时，未接通时如实显示缺口） |
| 半导体三个情绪视图 | semiconductor.feargreedchart.com 来源卡；数值由哨兵读页后入库，不编造 |
| 消息 / 观点 / 报告 | Agent 批次入库（ingest_batch），同根来源去重、修订生成新版本 |

## 工具

| 工具 | 用途 |
|---|---|
| `get_snapshot` / `refresh_market` | 读取 / 刷新行情快照；刷新同时把观测写入 Library 持久库 |
| `get_desk_context` | 槽位状态、数据截止、待验证与消息计数（不含私人日记正文） |
| `ingest_batch` | 批次入库：幂等（同 batch_id 返回原回执）、同事件内容变化出新版本、序列按 (key, date) 去重 |
| `list_updates` | 按视图/主题/标的/日期查询消息 |
| `submit_note_draft` | AI 整理草稿：独立保存，不覆盖用户原文，用户接受后才产生新版本 |
| `sync_automation_status` | 导入宿主调度读回的任务与运行状态 |

## 存储

用户数据存 Cindy Library 持久库（`desk.sqlite`）：消息与版本、日记原文/草稿/版本、验证事项、序列观测、批次回执、运行记录。Library 不可用时如实报障，不建空库冒充恢复；日记可导出 Markdown 到 Library `exports/`。

## X 关注圈共识差

B 组每天 05:30（上海时间）采集原帖并留下完成回执。E 组周日 18:00 读取当日与近七天的已完成材料，经 [确定性脚本](x-consensus/desk_twitter_pipeline.py) 筛选、去重和统计，由 [周报提示词](x-consensus/DESK_TWITTER_CONSENSUS.md) 找出值得追踪的分歧，再由脚本校验批次。E 组通过 Desk 工具入库并回读。主题解读和代表原帖在「消息看板 → 观点流」，缺口在「运行健康」。当日无完成材料时只发布缺口，不沿用旧批次。

观点人数按同一论题内的独立作者计算，卡片显示样本范围。经营解释附同口径数字、期间、基准和原始披露。缺可比数字的判断会显示为待验证，并注明下一观察。

## 红线

不自动交易、不改投资规则与仓位、AI 解释不当作官方事实、互动量不等于重要性、旧报告不当当前行情。JNK–SPY 的 −1.5 是历史经验口径，不是价格跌幅阈值。


## 作为 Cindy 插件使用

本目录同时是 Cindy 插件 `murphy-research-desk` 的源码（见 `ghost.json`）。安装后即得三列工作台与本页所列工具。行情默认走 Yahoo / CBOE / FRED 公开数据，Alpaca 为可选的本机凭证增强，未配置时自动兜底并如实标注缺口。
