# agentic-investment-harness

> 把投资纪律做成文件系统：人类保留最终权威，AI 只做研究与反证。
>
> An investment operating system where discipline lives in structure, not willpower — the AI does research and counter-argument, and never trades.

---

## 为什么造这套系统：一个散户的三个痛点

我是一个有主业的个人投资者。股票、基金、加密资产都碰，投入的金额对家庭不算小。真正让我动手造这套系统的，不是"想让 AI 帮我选股"，而是三个反复出现的痛点：

1. **盯盘吃掉精力。** 每天的碎片时间被行情和消息切碎，涨了想知道为什么涨，跌了想知道要不要跑。注意力被持仓绑架，主业反而成了后台程序。而且这不是无损的：Thaler、Tversky、Kahneman 与 Schwartz（1997）的实验里，高频查看结果的那组人，股票配置只有约 41%，低频组约 70%——**看盘越勤，越拿不住风险资产**。
2. **信息过载，但增量很少。** AI 一分钟能生成一百篇"深度报告"，可哪份有真增量、哪份只是顺着最近的涨跌在附和？旧报告越攒越多，谁也说不清哪份还在指导当前决策。散户的真实买入常常被"注意力"而不是研究驱动——Barber & Odean（2008）发现个人投资者系统性净买入那些放量、上新闻、当日大涨的股票，这类买入随后表现偏弱。
3. **情绪让好计划变形（核心痛点）。** 短期波动带来的情绪波动，靠意志力消除不了：跌了想补仓，涨了怕踏空，亏了想翻本。Odean（1998）对一万个券商账户的统计：投资者卖出盈利股的概率（14.8%）约是卖出亏损股（9.8%）的 1.5 倍——赚小钱就跑、亏大钱死扛；坚持日内交易超过 300 天的人里 97% 亏损（Chague et al., 2020）。事后复盘，多数亏损不是信息不足，而是**在该冷静的时刻做了情绪化的动作**。

所以这个项目的第一性认知是：**我最大的敌人不是市场，是自己在波动中的反应。** 系统要解决的不是"预测得更准"，而是"让情绪进不了决策路径"，同时把信息处理外包给 AI。

## 系统要达成的目标

**第一目标：不亏钱，保住本金。第二目标：在保住本金的基础上，扩大收益率。**

把这两个目标翻译成三个可验收的承诺：

| 承诺 | 验收标准 |
|---|---|
| **免盯盘** | 持仓期间可以一两周不看盘；判断带过期时间，系统到期自动提醒复查 |
| **信息处理提效** | 丢进来的材料快速得到"有没有增量 / 值不值得细读"的判断，不再全文精读 |
| **纪律与赔率** | 每个资本动作过四道票；亏损后新增风险默认冻结 24 小时；只在赔率有利时行动 |

这张表的意思：如果一套系统让我更勤快地盯盘、更焦虑，那它就是失败的——不管它的分析多漂亮。

同样重要的是它**不承诺**什么：

| 痛点 | 这套系统能解 | 不能解 |
|---|---|---|
| 情绪化决策 | 冷静期 + 强制反方证据，把冲动变成"先过流程" | 消除情绪本身；你仍然可以绕过它 |
| 盯盘时间 | 状态到期扫描 + 事件触发提醒，降低看的必要性 | 消除"想看"的冲动 |
| 信息过载 | 来源分层、同根信息只计一次、只萃取增量 | 创造新信息；保证预测正确 |
| 收益差距 | 收窄行为差距（少亏在自己手上） | 承诺收益；创造 alpha |

## 第一步不是选股，是先想清楚赚什么钱

普通人能赚的钱分三类，载体和要盯的东西完全不同：

| 钱的类型 | 例子 | 载体 | 真正要盯什么 |
|---|---|---|---|
| **宏观流动性的钱**（整个水池水位变化） | 全球放水/收水，稀缺资产重估 | 黄金、比特币 | 水位（流动性、稀缺性共识），不是某家公司基本面 |
| **行业 beta 的钱**（行业趋势） | 行业景气上行 | 行业 ETF | 行业景气度与拥挤度 |
| **个股 alpha 的钱**（公司超预期） | 经营持续超市场认知 | 个股 | 经营证据：订单、利润、现金流 |

白话解释：不同类的钱，证据要求不同。拿着水池的逻辑去买个股，或者用个股的逻辑去拿 ETF，都是框架错配——钱亏了都不知道该怪哪一层。所以这个系统里，每个投资判断必须先声明**赚的是哪一类钱**，再谈值不值。

周期同样要先声明：**短期（半年内要见到结果）** 和 **长期（一到两年）** 用的是两套耐心。同一个回调，对长期持仓是噪声，对半年内要用的钱是实打实的风险。

## Harness 是什么：不是让 AI 更聪明，是让聪明变得可靠

Harness（直译"马具"）= **模型权重之外的一切工程设施**——指令、工具、环境、状态、反馈。同一个模型，裸跑和配上完整 harness，可靠性的差距远大于换一个更贵的模型。

这套系统不改模型权重（也改不了），做的是三件事：

### 1. 把投资理念写进系统——改变 AI 在这里的"调性"

模型的默认倾向来自训练，通用且中位。Harness 的做法是：把我的投资宪法、决策合同、认知清单、踩过的坑，做成常驻或按需加载的知识层。AI 在这个仓库里工作，**先加载"我"，再加载通用知识**——我的先验比模型的通用倾向优先级高，AI 之间的一致意见不算独立证据。

这不是玄学，就是上下文工程：你喂给它的判断标准，决定了它输出判断的形状。

### 2. 把调研方法做成流程——让 AI 干信息处理的活

AI 的比较优势是信息处理，不是替我做决定。选标的的流程被固化下来：

```
明确赚什么钱 → 按钱种路由到对应证据要求 → 候选池
→ 负向筛选（踩过的坑进错误库，命中即排除）
→ 幸存者进入深度研究 → 四票评估 → 六档动作
```

其中"负向筛选"是积累出来的资产：每个失败案例沉淀为错误库条目，下次同类标的自动命中排除。AI 记性好、不知疲倦、没有面子问题，干这活比人强。

### 3. 把纪律做进结构——不靠和 AI 聊天，靠结构

"和一个非常理性的 AI 交流就能改善纪律"——这个想法试验过，靠不住，因为 AI 会被说服。真正可靠的是结构：

- **四票分立**：经营（H_B）、赔率（H_R）、周期（H_L）、仓位（H_C）分开投票。价格下跌只能改善赔率票，**不能**提高经营票；
- **时间锁**：亏损后想加仓/抄底，默认冻结新增风险 24 小时；
- ** maker-checker**：干活的 AI 和只读的审查 AI 分开，写入前再过一遍机械校验脚本，校验失败一律挡住（fail-closed）；
- **判断会腐烂**：每个判断带数据截止日和过期日，旧判断不自动授权今天的行为。

一句话：**我不依赖 AI 的理性，我靠结构让情绪进不了决策路径。**

## 运行架构速览

### 最小加载

Agent 不全量加载所有文件。按问题分流，只读命中的路径：

```
AGENTS.md → PATHS.md → CONTENT_ROUTER.md → 命中的道/Skill → Current State → Evidence
```

### 四票：H_B / H_R / H_L / H_C

| 票 | 判断什么 | 只靠什么更新 |
|---|---|---|
| **H_B** 经营胜率 | 这家公司/资产能不能持续赚钱 | 经营证据（订单、利润、现金） |
| **H_R** 赔率 | 当前价格值不值 | 价格 vs 价值差距 |
| **H_L** 周期 | 现在是什么市场阶段 | 软探测器，只影响进入时点 |
| **H_C** 仓位 | 该投多少 | 总资本分母和风险预算 |

三张硬门票（经营/赔率/仓位）任一失败或未知，默认不增加风险。动作只有六档：`不投入 / 继续观察 / 建立验证仓 / 升级确认仓 / 不加仓 / 降级或退出`。

### 双重检查

- **独立 Reviewer**：触发硬条件时，工具权限硬限制为只读的审查 Agent 必须先审；`PASS` 放行、`BLOCK` 退回、`DISAGREE` 保留双方判断不折中。主 Agent 只能增加审查，不能取消。
- **Validator**：写入前跑 `validate_investment_output.py`（路径白名单、时间自洽、来源完整、备份存在，fail-closed）。

### 状态会过期

`03_STATE/` 里每个 thesis 都带 `data_cutoff` 与 `expires_at`。到期扫描替代盯盘——不是我知道了什么，而是系统提醒我"哪个判断该重新验证了"。

## 实际使用起来什么样

- 持仓周期一到两个月，期间基本不看盘；
- 到期扫描给出信号：什么过期了、什么该复查、什么被新证据证伪；
- 每个过去的决策可以完整回溯：当时依据什么证据、哪个证据后来被证伪、案例进了错误库还是案例库；
- AI 生成一百篇报告不再是我的负担——萃取层只留有增量的部分，其余归档。

---

## 项目不做什么

- **不荐股** — 不提供选股信号、目标价、仓位建议；
- **不保证收益** — 没有"确定涨"的判断；
- **不自动交易** — AI 没有交易授权、仓位修改权、自动成交权；
- 公开的 `03_STATE/` 是作者的个人状态记录，**不是他人的买卖建议**。

## 怎么换成你自己的

1. **保留 `90_AUTOMATION/`** — 验证器和测试是通用骨架；
2. **替换 `01_道/`** — 写你自己的投资宪法、认知、风险纪律；
3. **改 `02_术/TRADING_SYSTEM/PARAMETERS.md`** — 设置你自己的总资本和风险预算；
4. **清空 `03_STATE/` 和 `05_EVIDENCE_META/`** — 从你自己的研究开始积累；
5. **读懂 `AGENTS.md` 再改** — 它定义 Agent 行为边界。

## 自进化如何发生

```
Evidence / Case
    ↓
Method Proposal（对话中形成，不直接落盘）
    ↓
独立 Reviewer
    ↓
CI / Validator
    ↓
人类合并
```

AI 只能提方案，不能直接改宪法与交易系统正文。每一次方法进化都经过：提案 → 反方审查 → 机械校验 → 人类合并。

## 风险声明

本仓库是一个个人投资操作系统的**公开记录**，不是投资建议。

- `03_STATE/` 中的 thesis 和动作表达是作者的个人状态快照，**有过期时间**，不代表当前判断；
- 任何人不应基于本仓库内容做出投资决策；
- 投资有风险，决策需自行判断并承担后果。
