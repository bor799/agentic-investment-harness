# AI电力、液冷、光互连与核能ETF筛选：AI长报告原文

> 数据截止：2026-06-29。ETF持仓主要采用基金公司 2026-06-26 日度持仓；A股行情采用 2026-06-29 盘中/收盘前快照；美国行情采用 2026-06-29 盘中快照。  
> 本文研究的是“AI物理基础设施主题仓”，不是完整资产配置，也不构成无条件买入建议。

## 一、先给结论

如果只选三只，不把同一个逻辑买三遍，我会选：

1. **GRID**：全球电网设备核心仓。电气化、并网、数据中心供配电共同驱动，需求持续时间最长，产品最成熟。
2. **NLR**：核能全链条核心仓。不是只押铀矿，也不是只押尚未商业化的SMR；同时覆盖核电运营、核燃料、设备与服务。
3. **TCAI**：AI物理基础设施进攻仓。是目前最接近“HBM/存储—光互连—电力—液冷—数据中心运营”整条瓶颈链的ETF。

中国电网设备用 **159326** 替代 GRID，而不是机械地两只都买。159326确实持有四方股份，但四方在基金中的当前估算权重只有约 **2.1%**；买159326主要是在买特变电工、思源电气、国电南瑞等整个电网设备篮子，不是在曲线买四方。

**EUV只进观察池，不进入当前主组合。** 它是目前能较直接覆盖康宁、Coherent、Lumentum和光子产业链的ETF，但成立不足两个月，组合市盈率约72倍，康宁权重也只有约5%。这只基金适合等估值和持仓结构沉淀后再看，不适合拿来追康宁。

### 主题仓建议

AI物理基础设施主题仓只占总资产的 **10%-15%上限**。主题仓内部：

| ETF | 主题仓权重 | 角色 |
|---|---:|---|
| GRID | 40% | 电网与电气设备核心仓 |
| NLR | 35% | 核能、核燃料与核设备核心仓 |
| TCAI | 25% | 液冷、数据中心电力、存储和光连接进攻仓 |

如果主要使用人民币/A股账户，把 GRID 的40%替换为159326；如果已经重仓AI半导体或存储，把TCAI降到10%-15%，差额留现金，不再重复买MU、DELL、SNDK等高波动持仓。

当前不适合一次性买满：

- NLR可先建立计划仓的 **1/3**；
- GRID/159326只建立观察仓，等待估值或价格回撤；
- TCAI暂不追涨，等待至少一次组合层面的正常回撤；
- EUV维持0仓位观察。

## 二、原文逻辑哪里对，哪里要修正

原文的核心模型是对的：

```text
可用AI算力
= min(GPU, HBM, 封装, 网络, 光纤, 电力, 冷却, 并网, 运维)
```

AI基础设施是Leontief式互补系统，最短板决定整套系统能不能运行。瓶颈从GPU扩散到HBM、互连、电力和冷却，并不意味着前一个瓶颈消失，而是资本开支开始同时向多个物理环节扩散。

但投资上需要三处修正：

1. **物理瓶颈最硬，不等于股票赔率最好。** 电网、液冷和光纤都是真需求，但相关龙头和ETF在过去一年已经大涨。
2. **没有纯液冷ETF。** 名称里写“AI基础设施”或“数据中心”的ETF，也可能主要装的是存储、服务器、数据中心REIT或通信塔。
3. **核能不是电力缺口的短期解法。** 现役核电延寿、重启、PPA和燃料服务能较快兑现；新建大型核电和SMR则受审批、建设周期、融资和成本约束。

因此，最合理的做法不是押一条单线，而是：

```text
电网设备的长期确定性
+ 核电现役资产/燃料服务的稀缺性
+ 液冷与AI物理基础设施的高弹性
+ 对光互连高估值阶段保持观察
```

## 三、行业优先级：基本面与买点分开排

| 方向 | 需求确定性 | 财务兑现速度 | ETF纯度 | 当前拥挤度 | 当前判断 |
|---|---:|---:|---:|---:|---|
| 电网/电力设备 | 高 | 高 | 高 | 高 | 核心方向，分批等回撤 |
| 核能全链条 | 中高 | 分化 | 高 | 中高 | 当前相对更适合先建仓 |
| 液冷/数据中心电力 | 高 | 高 | 低 | 很高 | 逻辑最硬，工具不纯，仓位要小 |
| 光互连/康宁 | 高 | 高 | 中低 | 极高 | 公司证据强，当前价格赔率差 |

### 1. 电网设备：最像长期“收费权”

AI数据中心不是独立于电网的孤岛。负荷增长最终要经过发电、输电、变电、配电、开关、保护控制和机房侧电力系统。无论GPU路线怎么变化，电气化和并网投资都要发生。

它的创生公式是：

```text
负荷增长与电网老化
→ 电网资本开支
→ 变压器/开关/保护/配电/施工订单
→ 交付能力和认证壁垒
→ 收入、毛利和现金流
```

这条链的优点是需求不只来自AI，还来自新能源并网、储能、电动车、工业回流和电网更新。缺点是市场已经看见了它。

### 2. 核能：不是“核电马上盖好”，而是可靠电力稀缺性重估

核能的近端价值来自：

- 现役核电站延寿、提功率与重启；
- 长期购电协议和数据中心负荷锁定；
- 核燃料、浓缩、设备维护和关键部件；
- 中长期新建大型核电与SMR期权。

创生公式是：

```text
24/7可靠无碳电力稀缺
→ 现役核电资产利用率和合同价值上升
→ 燃料/浓缩/设备服务需求增长
→ 现金流与资产估值重估
```

NLR比URNM更适合本主题，因为URNM主要是铀矿和实物铀价格Beta；本次要买的是“AI电力缺口”，不是单押铀价。

### 3. 液冷：需求最硬，但ETF表达最差

机柜功率密度提高后，冷板、CDU、泵、换热器、液路和机房侧热管理会成为必须品。但液冷是系统工程，价值可能在冷板、CDU、连接件、整机集成、施工和服务之间重新分配。

液冷的创生公式是：

```text
GPU功率和机柜密度上升
→ 风冷失效
→ 直接芯片液冷/CDU/液路/热管理成为强制配置
→ 订单、服务和运维收入
```

问题不是需求，而是谁能留下利润。纯零部件可能被系统集成商压价，Vertiv这类全栈供应商更有入口，但其估值已经非常高。

### 4. 康宁：它不是液冷公司，而是AI光连接材料与制造平台

康宁的AI逻辑已经从“可能受益”跨到“订单验证”：

- 2026-01-27，康宁与Meta宣布多年、最高 **60亿美元** 的光纤、光缆和连接产品协议；
- 2026Q1，康宁披露又有两家超大规模客户签署与Meta协议规模和期限相近的长期协议；光通信收入同比增长 **36%**；
- 2026-05-06，康宁与NVIDIA宣布长期商业与技术合作，计划将美国光连接产能提高 **10倍**、美国光纤产能提高 **50%以上**；
- 2026-06-08，Amazon宣布与康宁签署多年、数十亿美元协议。

这已经证明康宁不是普通玻璃公司，而是“AI集群从铜走向光时的材料、光纤、连接和规模制造平台”。

创生公式是：

```text
AI集群规模和带宽密度上升
→ 每个数据中心所需光纤、连接器和光子器件数量上升
→ hyperscaler用长单锁定美国本土产能
→ 康宁扩产、收入增长、产品结构升级
```

但**好公司不等于好价格**。2026-06-29盘中，GLW约241.53美元，市值约2078亿美元，静态市盈率约116倍。市场已经把它从成熟材料公司重新定价成AI光连接平台。现在追的风险不是产业逻辑错，而是增长兑现速度跟不上估值。

## 五、市场看见的 vs 我们看见的

### 市场已经看见

- AI需要更多电力、变压器、开关和配电设备；
- 高密度机柜需要液冷；
- 大集群需要更多光纤和光互连；
- 核电是24/7可靠低碳电力；
- VRT、GLW、四方股份、思源电气等已经被贴上AI基础设施标签。

### 仍可能被低估

1. **需求持续时间**：电网和供配电改造可能持续十年以上，不只是一轮GPU资本开支。
2. **安装基数与服务收入**：设备交付后还会产生维护、升级、备件和系统集成收入。
3. **核电现役资产价值**：最先变现的可能不是新SMR，而是已经运行、可延寿、可签长期PPA的核电站。
4. **长单改变行业结构**：康宁拿到多年协议和锚定客户后，扩产风险由客户承诺部分对冲，光纤行业可能从库存周期走向更长合同周期。

### 仍可能被高估

1. 所有“AI相关订单”都能获得高毛利；

## 八、失败条件

这组投资共同依赖的核心假设只有三个：

1. hyperscaler AI资本开支在2027年前不出现系统性下修；
2. 电力、连接和冷却需求能转成供应商收入、毛利和现金流；
3. 高估值能被盈利增长逐步消化。

任何一个被证伪，主题仓都要降级。特别需要警惕：

- GPU/ASIC能效提升快于总算力需求增长；
- 并网瓶颈导致数据中心延期，设备订单确认向后推；
- 供应商大扩产导致2027-2028年供给反噬；
- 利率上升压缩长久期成长股估值；
- 政策变化延缓核电建设和PPA；
- 主题ETF持仓漂移，名字仍在，经济暴露已经变了。
