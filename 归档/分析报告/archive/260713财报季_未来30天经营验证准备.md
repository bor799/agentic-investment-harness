# 财报季：未来30天经营验证准备

核验时点：`2026-07-13 04:32 CST`  
正式窗口：`2026-07-13—2026-08-12`

## 本周结论

未来 30 天内，覆盖名单里有三类事件需要处理：

1. **正式确认披露/业绩会日期**：Microsoft `2026-07-29`、广合科技 `2026-08-08`、腾讯 `2026-08-12 20:00 HKT`。
2. **已经有 H1 业绩预告但正式半年报尚未验收**：广合科技、天华新能、天赐材料。它们都只算“利润表前哨”，不能替代毛利率、经营现金流、应收、存货和扩产回报验收。
3. **可能按历史节奏进入窗口但官方未确认**：Cloudflare、Datadog、Palantir。只能建准备清单，不能写成正式倒计时。

本周新增变化不是新闻数量，而是验证重心变了：

- A 股 PCB 链从“等日期”推进到“广合科技先进入正式 H1 验收队列”；
- 储能材料链从“电解液单链验证”推进到“电解液 + 隔膜双链验证”，但湖南裕能和正极环节仍没有同级别 H1 利润前哨；
- GitLab 8-K/July Investor Update 把 Flex、Consumption Run Rate、Duo Agent Platform 从产品叙事推进到早期经营信号，但规模仍小；
- OUST 专项结论不变：价格回到证据区，但基本面后验不变，继续不动作。

## 3）高毛利潜力但尚未充分进报表的瓶颈

1. **Microsoft Agent/Copilot 企业控制面**  
   高毛利潜力来自身份、权限、办公、代码和安全的捆绑控制。报表仍主要汇总在 Azure、M365 和 Productivity，缺独立 Copilot paid seats/收入穿透。

2. **Cloudflare Workers AI / MCP / agent 网络治理**  
   运行时、边缘治理和安全策略具备软件毛利，但 Q1 以后仍未看到可单列收入和利润池证据。若只披露开发者、客户或架构，不披露 cRPO/RPO 与毛利差分，继续按产品期权处理。

3. **GitLab Duo Agent Platform + Flex 消费计费**  
   `paid CRR` 约 `1500万美元`只是早期信号。高毛利潜力成立的前提是 first orders 能转 ARR/RPO，而不是只靠裁员改善非 GAAP 利润。

4. **地平线 license/services 与 HSD 软件收费**  
   license/services 毛利率很高，但产品方案放量会稀释整体毛利。下一阶段必须证明装车增长没有把公司从软件/IP 收费权拖回硬件方案商。

## 4）谁面临扩产同质化、客户自建、双供或价格战

| 风险类型 | 标的 | 失败条件 |
|---|---|---|
| 同步扩产、客户双供 | 沪电、深南、胜宏、生益电子、广合科技 | 收入高增但毛利率、应收、存货、OCF 不同步改善；AI PCB 占比只讲趋势不披露数字 |
| 周期价格与扩产 | 湖南裕能、天华新能、天赐材料 | 利润高增来自价格弹性但经营现金流背离；预付款/存货吞噬利润；锂盐、电解液、LFP 价格反转 |
| Hyperscaler 自建/打包替代 | Snowflake、MongoDB、Datadog、Cloudflare | AI 功能不单列收入，NRR/RPO 下滑，云厂商把数据、监控、边缘和安全打包压价 |
| 客户自研/双供 | Marvell、地平线机器人 | 设计胜出或装机增长无法转成高毛利收入；大客户自研或多供应商压低单价 |
| IP 热度和库存周期 | Pop Mart、Miniso | 收入高增但库存、渠道折扣、海外费用和周转恶化；IP 热度不再转成现金流 |

## 5）本周最值得补证据的三个标的及唯一关键数字

| 优先级 | 标的 | 唯一关键数字 | 为什么 |
|---:|---|---|---|
| 1 | Microsoft | **Microsoft 365 Copilot 付费席位数/净新增席位** | 这是 Agent 控制面从产品进入可留存软件收入的最短证据；Azure 增速不能替代 Copilot 收费验证 |
| 2 | 广合科技 | **2026H1 经营现金流净额** | H1 预告已经证明利润方向，下一关是利润有没有变成现金；若 OCF 明显背离净利润，AI PCB 逻辑降级 |
| 3 | 腾讯 | **营销服务收入同比增速** | AI 如果真在报表里产生效率，最先应体现在广告加载、转化和毛利质量，而不是只体现在模型叙事 |

备选观察：Cloudflare 一旦正式公告 Q2 日期，唯一关键数字仍是 **cRPO 同比增速**；Palantir 一旦正式公告，唯一关键数字仍是 **美国商业收入同比增速**。

## 6）即使财报很好也不应追价的标的

| 标的 | 不追理由 | 财报后仍不追的条件 |
|---|---|---|
| Palantir | 估值仍高度依赖多年高增长和风险偏好 | 美国商业高增但估值仍要求极高增长，不因单季超预期追 |
| Cloudflare | 产品方向强，但 GAAP 盈利、毛利率和 AI 收入穿透仍未验证 | 收入 30%+ 但 GAAP 毛利或现金流不改善，不追 |
| Datadog | AI observability 叙事强，估值和 usage-based 波动都放大风险 | AI 收入不单列、RPO/FCF margin 不扩张，不追 |
| 广合、胜宏、沪电、深南 | AI PCB 景气真实但扩产和客户双供同步发生 | H1 高增但 AI 收入占比、毛利率、应收、OCF 没有一起改善，不追板块共振 |
| Pop Mart | IP 资产优质但交易拥挤、库存和海外扩张费用可能放大利润波动 | 收入继续高增但库存周转或渠道折扣恶化，不追 |
| Marvell | 设计胜出叙事容易提前资本化 | 订单/设计胜出未转成量产收入、毛利率和 FCF，不追 |
