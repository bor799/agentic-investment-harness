# 组合：行为纠偏与资本纪律操作系统 AI 长报告原文

> [!warning] 证据底稿，不直接授权交易
> 本文保留完整诊断、统计口径、案例回放和参数来源。日常执行以 [[兴趣领域/股票投资/归档/分析报告/archive/260719组合_行为纠偏与资本纪律操作系统]] 为准。本文不自动改变任何现有持仓，不替本人下单。

## 先说人话

**今天发生了什么：**这次不是再增加一套选股知识，而是重做“谁有权改变仓位”。本地案例已经证明：连续下跌、已有持仓、回本愿望和 AI 的完整叙事，会一起把“价格更低”偷换成“胜率更高”。

**为什么重要：**真正危险的不是有情绪，而是情绪可以同时改写先验、目标价、失败条件、仓位角色和最大损失。这样一来，`胜率 × 赔率` 看起来很理性，实际只是把同一个偏见乘了两次。

**现在该做什么：**采用非补偿式硬门。先保证不出局，再判断生意、价格和路径，最后才允许讨论赔率与仓位。没有校准的概率不进入期望值；没有新增经营证据，不因下跌加仓；AI 只有研究权和反对权，没有交易授权。

### 本文缩写的白话意思

- `thesis`：投资假设，也就是“为什么买、靠什么赚钱、什么事实说明我错了”。
- `OCF`：经营现金流，也就是公司日常生意真正流进来的现金。
- `FCF`：自由现金流，也就是经营现金流扣掉维持和扩张生意所需资本开支后，真正可以留给股东的钱。
- `ROIC`：投入资本回报率，也就是公司每投入一元长期资本能赚回多少经营利润。
- `PE`：市盈率，也就是当前价格相当于多少年的当期利润；`PEG` 是把市盈率再与利润增长速度对照。
- `DCF`：现金流折现，也就是把未来可能收到的现金按风险和时间折回今天。
- `NAV`：净资产价值，常用于资源、基金和资产重型公司。
- `NRR/RPO`：客户续费扩张率/尚未确认收入的合同余额，用来判断成长是否可重复。
- `IV`：期权隐含波动率，也就是期权价格里已经收取了多大的未来波动预期；`bid/ask` 是当前买价与卖价。
- `Expected Shortfall`：最坏尾部平均损失，也就是最差一小部分情景平均会亏多少。
- `Attention`：市场注意力、仓位和资金拥挤程度，它主要影响价格路径，不等于公司生意变好。

## 一、最终结论

当前最主要的问题不是传统意义上的“怕跌卖出”，而是：

> **亏损触发的框架迁移，或称“赔率劫持”。**

它的表现是：原本用企业质量和现金流判断胜率，连续下跌后却把参照点移到成本价，把目标从“买一项好资产”改成“抓住反弹、回到成本、证明市场错了”。随后又用更低价格维持原目标价，从而同时抬高主观胜率和赔率。

因此，新的投资操作系统不再以一个总分或单一期望值为中心，而使用以下顺序：

```text
长期留在牌桌上
> 避免永久资本损失
> 提高经营判断胜率
> 控制判断错误时的损失
> 获得合理赔率
> 用少量、定义损失的资本购买右尾
```

任何后一项都不能补偿前一项失败。高赔率不能补偿无法生存，优秀产品不能补偿现金流断裂，便宜价格不能补偿基本面不可判断。

## 二、四种视角的交叉审查

| 视角 | 主要发现 | 对系统的要求 |
|---|---|---|
| 独立投资委员会 | 原有价值、供需、利率、Attention、贝叶斯和泊松各有用，但容易被固定总分强行平均 | 每个模块只回答自己的问题，冲突保留为独立票，不做加权平均 |
| 风险负责人 | 现有风险常按代码看，未按共同假设穿透；“心理上能亏”被当成风险预算 | 股票、基金、期权和账户按同一 thesis 合并；仓位从最大损失倒推 |
| 行为金融研究者 | 亏损后不是单纯保守，而可能因回本目标变得更冒险 | 情绪可以出现，但一旦出现就触发冷静期和新增风险冻结 |
| 长期价值投资者 | 价值投资的耐心被错误外借给 PEG、周期、市梦率和基金工具 | 只有现金流可验证、估值有安全边际的内在价值资产，才有资格谈越跌越买 |

白话解释：四种视角没有互相投票打分，而是各自拥有否决权；任何一方发现生存、证据或方法错配，风险就不能增加。

### 保留什么

- 保留“股价三层肉”：内在价值、流动性溢价、风险偏好。
- 保留资产状态和估值语法路由：市梦率、PEG、DCF/PE/股息率、周期中枢、基金工具、衍生品回报。
- 保留供需链：需求、供给锁死、实现价格、单位成本、毛利、经营利润、现金流。
- 保留贝叶斯更新，但只对事前冻结、可结算、可去重的假设更新。
- 保留泊松和多重分布，但只在生成机制匹配时使用；泊松不预测股价。
- 保留 Attention，但它先更新路径与流动性，不能直接更新企业经营胜率。

### 废止或降级什么

- 废止固定权重总分。产品故事不能用高分抵消现金流或生存硬门。
- 废止“每条强证据固定加 15%—25%”和“所有判断必须填 0—100%”。没有参考类时应写 `uncalibrated`，不是编一个数字。
- 废止用情景区间中点和主观概率直接排名标的。
- 废止“计划仓位的 20%—30%”这类没有总资本分母和最大损失口径的表达。
- 废止因亏损把赔率仓改名长期仓，或把等待反弹写成已经执行退出。

## 三、任务一：行为模式诊断

### 1. 主因果链

```text
价格连续下跌
→ 控制感下降、后悔、回本愿望、怕错过反弹
→ 参照点从未来价值移到买入成本
→ 问题从“今天是否值得新买”变成“怎样尽快涨回来”
→ 更低价格被写进赔率，同时旧目标价保持不变
→ 市场恐慌被自动解释为错杀
→ 搜索支持性证据，AI生成更完整的支持叙事
→ 同根报道被当成多份独立证据
→ 主观胜率与主观赔率一起上升
→ 加仓、接刀、扩大同一风险簇，或延长错误持有期
→ 流动性、尾部和机会成本上升
→ 一旦被迫退出，浮亏转成永久损失
```

这条链包含五个互相强化的机制：

1. **回本效应。**亏损后，能“回到成本”的方案会显得异常有吸引力，即使它的前瞻胜率没有提高。
2. **处置效应与成本锚。**不愿实现亏损，成本价逐渐替代未来现金流成为决策中心。
3. **沉没研究成本。**研究越多，越想证明研究有价值，越难把已有 thesis 当成可被推翻的假设。
4. **过度自信与自我归因。**上涨被解释为能力，下跌被解释为市场情绪；于是自己的信息精度只升不降。
5. **逆向投资身份。**“别人恐惧我贪婪”从条件命题变成身份命题，反对市场本身被误当成优势。

### 2. AI 如何放大这条链

AI 的主要风险不是单次答案错，而是“叙事流畅度被误当成证据质量”：

```text
带方向的问题
→ AI选择与问题方向一致的材料
→ 多个AI重复同一根公开信息
→ 语言越来越完整
→ 主观上感觉证据越来越多
→ 实际独立根事件没有增加
```

所以，AI 同意不能提高经营后验。只有客户、订单、实现价格、毛利、经营利润、现金流、融资或治理等独立现实反馈，才有资格改变经营票。

### 3. 正常心理反应与系统性错误

| 状态 | 正常反应 | 进入系统性损失的标志 |
|---|---|---|
| 浮亏 | 难受、想看行情、重新检查 thesis | 因难受而同日加仓、取消失败条件或追求回本 |
| 市场恐慌 | 怀疑市场是否过度反应 | 自动认定市场错，不检查它可能掌握的未知信息 |
| 深度研究 | 对自己理解更有信心 | 把“能完整解释”当成“信息比市场完整” |
| AI支持 | 获得更多假设和线索 | 把 AI 共识当独立证据或交易授权 |
| 盈利 | 愉悦、愿意继续跟踪 | 因盈利扩大赔率桶、杠杆或单一风险簇 |
| 亏损 | 想减少错误 | 通过补仓、卖 Put 或改成长期仓来证明自己没错 |

情绪不是违规。**情绪获得了改变风险的权限**才是违规。

### 4. 什么才算真实信息优势

“我知道很多”不是信息优势。只有同时过以下六问，才允许把优势写进研究：

1. 信息是否在决策前存在，而不是看见结果后补写？
2. 是否比公开共识更早、更准确或更接近经营现场？
3. 是否会改变收入、毛利、费用、现金流或估值，而不只是丰富故事？
4. 是否有独立来源确认，且不是同一事件的转载？
5. 市场为什么尚未定价：覆盖缺失、分析成本、期限错配，还是其实已经定价？
6. 扣除交易成本、流动性和等待期后，这个优势还能变成收益吗？

任何一问答不出来，只能叫“认知假设”，不能叫信息优势。

## 四、任务二：重构投资目标函数

### 1. `胜率 × 赔率` 为什么会失效

公式本身没有错。错在同一个情绪化主体临时填写全部变量：

- 先想买，再挑选较高先验；
- 价格下跌后保持旧目标价，扩大上行；
- 下行只用短期止损，上行却用多年终局，时间口径不一致；
- 未知信息填成 50%，再凑出三个情景合计 100%；
- 把破产、摊薄、技术替代、强平和流动性排除在情景之外；
- 把同一条产业链或同一新闻的多个副本重复相乘。

于是：

```text
越兴奋
→ 经营成功概率越高
→ 乐观目标越远
→ 悲观损失越窄
→ 数学期望越好看
```

### 2. 新系统先建立“可行域”

不再先算总分，而是逐层删除不合法动作：

```text
A0 = 六档动作全集
A1 = 证据和数据截止合法的动作
A2 = 工具、资本桶和最大损失合法的动作
A3 = 经营票 H_B、赔率票 H_R、周期票 H_L 全部通过的风险增加动作
A4 = 在多个合理模型下仍有稳健正边际的动作
```

任何一关失败，后一关的高赔率不能补偿。

三张票分别回答：

| 票 | 问题 | 价格权限 |
|---|---|---|
| `H_B` 经营票 | 公司或底层资产真的更赚钱吗，能否活到兑现 | 价格不得直接更新 |
| `H_R` 赔率票 | 当前全成本价格是否给足安全边际或净赔率 | 价格可以更新 |
| `H_L` 周期票 | 流动性、期限、杠杆、融资和个人现金需求是否允许等待 | 价格和 Attention 可以更新 |

白话解释：公司可以是好公司、价格也可以便宜，但如果工具会到期、账户会被强平或生活现金等不起，仍然不能增加风险。

基金还要单独通过底层资产票和工具/经理票；期权还要通过合约回报、期限、IV 和最大损失票。

### 2.1 目标函数十一项验收表

| 必查项 | 新系统怎样处理 |
|---|---|
| 胜率 | 先判断业务状态；只有参考类合法时才转成概率 |
| 胜率置信区间 | 正面事件使用概率下界 `p_L`，永久损失使用概率上界 `p_U`；未校准时不提供区间 |
| 潜在收益 | 使用同一期限、币种和扣除成本后的情景区间，不用单点目标价 |
| 最大下行 | 同时写终端永久损失和持有过程的压力损失，不用一个止损价代替 |
| 永久资本损失风险 | 单独列破产、稀释、技术替代、治理、再融资和长期价值坍塌 |
| 模型误差 | 至少使用多个合法模型；删掉任何一个模型就改变动作时，不升级仓位 |
| 信息不完全 | 写 `unknown/uncalibrated`，不能填 50% 或用 AI 叙事补空白 |
| 时间成本 | 报告兑现时间、年化回报、催化延期和等待造成的机会成本 |
| 流动性 | 用压力期可退出规模、买卖价差和冲击成本，不用日常成交量 |
| 仓位 | 从单票、风险簇、组合和工具的最大损失反推 |
| 尾部风险 | 使用厚尾压力情景和最坏尾部平均损失，不假设收益服从普通正态分布 |

白话解释：这十一项不是再做一个总分，而是十一项都要有答案；缺少关键答案时，动作缩到 `继续观察/不加仓`，不能用别项高分补偿。

### 3. 从单点概率改成合理模型集合

```text
PlausibleModels = {
  不同参考类,
  不同经营状态,
  不同利率与信用状态,
  不同Attention与去杠杆状态,
  不同相关性和尾部依赖,
  不同合法估值模型
}
```

每个模型都要输出：

- 终端回报区间；
- 永久损失概率上界与严重度；
- 路径最大损失；
- 兑现时间区间；
- 压力期流动性成本；
- 模型误差和缺失信息。

若必须形式化，目标不是最大化平均乐观 EV，而是：

```text
在所有合理模型中，最大化保守的终端财富确定性等价

同时满足：
- 永久损失上界不超预算；
- 最坏尾部平均损失不超单票、风险簇和组合预算；
- 兑现时间不超过资金期限；
- 压力期可以退出；
- 资本桶和工具合法。
```

“最坏尾部平均损失”即 Expected Shortfall：看最差一小部分情景平均会亏多少，而不是只看一个止损点。

### 4. 仓位从损失反推

```text
允许仓位上限
= min(
  单标的损失额度 / 单位压力损失,
  风险簇剩余额度 / 单位共同损失,
  组合路径剩余额度 / 单位联合损失,
  压力期可退出量,
  资本桶剩余额度,
  工具合同最大损失约束
)
```

这个结果是上限，不是必须投入的目标。小仓也不能叫“信息费”；如果只是提醒自己关注，放入观察清单即可。

### 5. 贝叶斯的合法使用

概率只有满足以下条件才有统计含义：

- 假设、期限、结算规则和参考类事前冻结；
- 决策只使用当时可见的数据版本；
- 同根事件只计一次；
- 有足够已结算、未选择性删除的历史样本；
- 同公司和同风险簇的相关预测被聚类处理；
- 过去校准记录与当前状态可比。

否则统一写：

```yaml
probability_status: uncalibrated
interval: unavailable
```

未知不等于 50%。固定 `LR 1.8`、固定 `+15%` 不得进入正式后验。正面判断使用概率下界，永久损失使用概率上界，不用区间中点下单。

### 6. 直觉如何获得有效反馈

每个可结算判断必须冻结：问题、期限、概率或区间、证据截止、失败条件和动作。到期后全部结算，包括没买、没发生、失败和数据模糊案例。

反馈分三张成绩单：

| 成绩单 | 看什么 | 不看什么 |
|---|---|---|
| 预测 | Brier 分数、区间覆盖率、是否过度自信 | 单次输赢 |
| 流程 | 是否去重、是否先写反证、是否遵守数据截止 | 最终是否赚钱 |
| 仓位 | 错时损失是否在预算内、是否出现强迫退出 | “我最终猜对了” |

白话解释：系统分别评价“有没有判断准、有没有按流程做、错了会不会伤筋动骨”，避免只用最终盈亏给所有错误洗白。

赚钱但违反纪律，是坏流程；亏钱但事前逻辑、仓位和退出都合格，可以是好决策。

## 五、任务三：建立“高证据/胜率优先”系统

### 1. 重新定义高胜率

高胜率不是“我有 80% 把握”，也不是“价格跌了很多”。它是以下条件的交集：

```text
生意能理解
× 现金流或状态迁移能验证
× 资产负债表允许等待
× 竞争优势能落到数字
× 估值语法与资产状态匹配
× 当前价格保留失败空间
× 失败能在永久损失前被看见
× 仓位错误不会伤害系统生存
```

通用必查项：商业模式、收入质量、毛利、经营费用、经营利润、现金转换、ROIC、资产负债表、行业结构、竞争优势、管理层资本配置、估值、可预测性和下行保护。

### 2. 不同资产不能共用一把尺子

| 资产 | 胜率主要来自 | 关键验证数字 | 合法估值语法 | 典型失败 |
|---|---|---|---|---|
| 科技成长 | 付费采用、单位经济、经营杠杆和每股现金流 | 客户/用量、NRR或RPO、毛利、经营费用率、OCF、摊薄 | PEG、反向估值；未盈利时只能事件树/实物期权 | 收入仍增但毛利、现金流和每股价值恶化 |
| 周期/商品 | 供给退出、库存、实现价格—单位成本剪刀差和资本纪律 | 有效产能、库存方向、合同价、单位成本、OCF、CapEx | 中周期利润、NAV、成本曲线、重置成本 | 峰值低 PE、恐慌采购、扩产兑现、成本同步上升 |
| 消费 | 复购/同店、品牌或渠道控制权、单位店经济和资本配置 | 同店、店效、复购、毛利、成熟店回收期、授权费、FCF | 正常化 PE/FCF、门店或客户 cohort | 折扣换增长、渠道伪装品牌、并购侵蚀主业 |
| 成熟企业 | 可重复现金流、ROIC、资产负债表和每股资本配置 | OCF、维持性CapEx、FCF、ROIC、净负债、回购/分红 | DCF、正常化 PE、FCF yield、股息率 | 价值陷阱、债务再融资、低回报再投资 |

表的白话意思是：成长股的“利润创新高”不够，要看增速和现金流；周期股的“PE 很低”常常是高点；消费股必须分清品牌控制权和渠道效率；只有成熟现金流资产才有资格把下跌当作潜在安全边际。

### 3. 长尾机会的定义

AI 时代的长尾不是“媒体没报道”，而是：

```text
可验证的经营证据
+ 生存能力
+ 保守估值仍有空间
+ Attention尚未充分编码
+ 有匹配参考类
- 拥挤和退出风险
```

“AI 搜不到很多信息”可能只是信息质量差，不是认知差。多个模型读同一批公开资料时，应降低独立证据数，不能把模型数量当专家数量。

## 六、任务四：资本宪法与交易纪律

### 1. 解决 `90/10` 与旧 `3%` 的冲突

两者属于不同账本：

> `90% / 10%` 管资本职责和暴露上限；`3%` 管赔率侧最大损失。

“90%胜率”改名为“90%高证据/价值侧”，因为它不是对单笔投资声称 90% 会赢。

```text
可投资资本 R（排除生活、应急和近期必用现金）
├─ H 高证据/价值职责：目标职责 90%
│  ├─ 高证据资产实际暴露
│  ├─ H-cash
│  └─ 生存流动性 S：保守默认至少 7%R
└─ O 赔率职责：资本暴露上限 10%R
   └─ 在险最大损失 + 滚动已实现损失 + 新拟风险 ≤ 3%R
```

90% 是职责，不是必须始终投满。赔率额度用不完不是失败。

### 2. 原则硬规则

1. 同一 thesis 的股票、基金、期权和不同账户合并记账。
2. 每个头寸同时过资本暴露、经济/集群暴露、最大损失三本账。
3. 头寸角色入场前确定；亏损后改名不改变原风险记账。
4. 价格只更新赔率票；加仓必须有新增独立经营证据。
5. 无法定义最大损失的衍生品禁止；风险降低动作不被研究不完整阻断。
6. 生活现金和生存流动性不得作为期权保证金或接货承诺。
7. AI 不能修改资本参数，也不能给自己的结论升级交易权限。

### 3. 保守启动参数

这些值用于尚未完成个人校准时保护系统，不是假装存在普适最优参数：

| 参数 | 保守默认 | 含义 |
|---|---:|---|
| 生存流动性 | `≥7%R` | 留出生活与压力期行动权 |
| O 资本暴露 | `≤10%R` | 探索许可，不是投入目标 |
| O 总最大损失 | `≤3%R` | 滚动 12 个月已实现损失 + 当前开放风险 + 新风险 |
| O 单笔最大损失 | `≤0.5%R` | 一次错误不能吃完赔率预算 |
| O 单一 thesis 最大损失 | `≤1%R` | 跨工具、跨账户合并 |
| H 单一个股资本暴露 | `≤10%R` | 成熟价值例外也必须重新审批 |
| 宽基基金资本暴露 | `≤25%R` | 只适用于真正分散的底层 |
| 单一经济集群暴露 | `≤25%R` | 防止不同代码重复下注 |
| H 单标的压力损失 | `≤5%R` | 仓位与生意失效共同约束 |
| 单集群压力损失 | `≤12%R` | 压力期按相关性上升计算 |
| 组合经济暴露 | `≤100%R` | 默认不借钱、不隐含加杠杆 |

白话解释：这些数字首先限制新风险，不是自动卖出指令；如果旧仓超限，先冻结加仓，再由本人重新承保。

未校准压力损失系数：宽基 35%；成熟盈利公司 50%；PEG、周期、行业基金 60%；未盈利、市梦率、事件股和买入期权 100%。

这些默认值只冻结新增风险，不自动要求卖出现有持仓。现有超限仓必须标记为 `grandfathered_over_limit`，只能减险或等待用户完成重新承保，不能继续增加。

### 4. 期权权限

默认只允许 Long Call、Long Put、Debit spread 和与现有风险匹配的保护性 Put。默认禁止裸卖、保证金放大、把杠杆 ETF 放进 H，以及在没有实时报价、bid/ask、IV、成交量和持仓量时指定合约。

Cash-secured Put 如果以后开放，只能属于 H 的条件买入：必须全额隔离现金，接货本金计入单标的与集群暴露，且被指派后仍愿意长期持有。它不属于正凸性的 O 赔率桶。

### 5. 什么时候禁止交易或加仓

出现任一项，当日禁止增加风险：

- 主要理由是“已经跌很多、想回本、怕错过、市场都在恐慌”；
- 无法离开 AI 用自己的话说明买什么、赚什么钱、为什么现在、错在哪里；
- 没有资本桶、失败条件、最大损失和下一验证数字；
- 主要证据是价格、Attention、同一新闻的多个副本或未经校准的概率；
- 券商委托和成交状态尚未核对；
- 当日已违反一条交易纪律；
- 单票、风险簇、赔率桶或组合预算已经超限。

### 6. 连续下跌后的完整重评

不使用所有资产统一的 `-10%/-15%` 作为基本面结论。固定跌幅可以保留为执行提醒，但完整重评使用两级触发：

**一级：一个硬事件立即触发。**财报/指引、客户取消、融资/增发、审计治理异常、主动基金经理或持仓漂移、异常赎回、周期价差/库存跳变、原承诺节点逾期。

**二级：以下五类中任意两类共振触发。**

1. 相对匹配基准和风险簇的异常跌幅进入该资产自身历史极端区；
2. 持续创新低、反弹无法站回成交均价，且持续时间异常；
3. 价差、折溢价、赎回、融资或盘口深度出现流动性异常；
4. 领先经营指标同步恶化；
5. 当前压力损失耗尽单票或风险簇剩余额度。

另加一个行为触发器：**任何亏损后产生加仓冲动，先冻结 24 小时并完成简版重评；若价格异常与任何一项业务/流动性信号共振，升级为完整重评。**

完整重评不是自动卖单：

```text
触发
→ 冻结新增风险
→ 纯减险仍可执行
→ 重建证据截止和根事件
→ 分开 H_B / H_R / H_L
→ 判断是价格、业务、工具还是资本冲击
→ 只输出六档动作
```

### 7. 冷静期

| 触发 | 最短冷静期 | 冷静期内允许什么 |
|---|---:|---|
| 亏损后想加仓、抄底或卖 Put | 24 小时 | 记录事实、撤销新增风险挂单、纯减险 |
| 组合单日损失超过本人预设路径阈值，或出现纪律违规 | 72 小时 | 核对持仓、压力测试、纯减险 |
| 核心经营数据缺失，却想用价格替代 | 直到下一条独立硬证据 | 继续观察 |
| 融资、审计、治理或工具结构突变 | 完整重评完成前 | 纯减险或退出 |

白话解释：冷静期只冻结“增加风险”，不会阻止撤单、平仓或其他纯减险动作。

### 8. 加仓、降级与失败

加仓必须同时满足：新增独立根证据提高经营票；保守价值下界未下降；周期票通过；单票和集群预算有余量；新仓本身仍有正价值。价格下降只能改善赔率票，不能单独触发加仓。

失败条件必须是“可观测数字 + 截止时间 + 动作”，例如：

```text
若连续两个报告期产品毛利低于35%，且软件占比下降，
则业务状态不再满足PEG迁移，动作降级为“不加仓/降级或退出”。
```

“长期看好”“市场会理解”“最终会涨回来”都不是失败条件。

## 七、任务五：投资心理微训练

目标不是消灭情绪，而是把情绪从仓位权限中隔离。

### 1. 交易前 30 秒：五问

```text
1. 我现在是兴奋、恐慌、后悔，还是想回本？
2. 新增的独立经营事实是什么？
3. 价格、价值、胜率和赔率有没有被我混在一起？
4. 如果错了，最大损失占总资本多少？
5. 没有 AI，我能否用一句话解释为什么现在必须做？
```

任一题答不清，动作是 `不投入` 或 `继续观察`。

### 2. 暴跌后的 5 分钟

| 时间 | 动作 |
|---|---|
| 第 0—1 分钟 | 不下单；写出身体和情绪状态 |
| 第 1—2 分钟 | 只记新增事实，不写解释 |
| 第 2—3 分钟 | 分开经营票、赔率票、周期票 |
| 第 3—4 分钟 | 计算单票、集群和赔率桶剩余损失预算 |
| 第 4—5 分钟 | 从六档动作中选一档；默认不加仓 |

白话解释：这五分钟的目的不是预测反弹，而是把解释权从情绪手里拿回来。

### 3. 交易后 2 分钟

冻结四项：原始 thesis、三项验证数字、失败条件、最大损失。再记录当时情绪和券商成交事实。以后可以新建版本，不能覆盖原判断。

### 4. 每周 15 分钟

- 随机抽三次“买、卖、不行动”；
- 各写一条完整因果链：情绪 → 认知 → 判断 → 仓位 → 后果；
- 检查是否把同根信息重复计票；
- 选一笔盈利但流程差、或亏损但流程合格的案例，防止只看结果。

### 5. 每月 20 分钟纪律评分

每项 0 或 1 分：

1. 所有风险增加动作都有本人独立 thesis；
2. 所有证据有截止时间和根事件；
3. 没有用价格直接提高业务概率；
4. 没有未经校准的概率进入 EV；
5. 每笔都有永久损失情景；
6. 仓位从最大损失倒推；
7. 同一风险簇跨工具合并；
8. 冷静期和禁买规则全部遵守；
9. 委托与成交完成闭环；
10. 到期案例全部结算，未挑选赢家。

`9—10`：系统正常；`7—8`：下月所有新增仓先停 24 小时；`≤6`：进入 7 天 `research_only`，只允许纯减险。

## 八、任务六：GPT 未来的反制机制

### 1. 何时自动进入反方审查

输入中出现以下任一类信号：已经跌很多、错杀、必须回本、梭哈、怕错过、别人都不懂、市场恐慌、我很确定、赶紧加仓、卖 Put 降成本、AI 都同意；或已知用户处在大额浮盈亏、连续涨跌、纪律触发状态。

### 2. GPT 的响应顺序

1. 标记情绪状态，不评价人格。
2. 冻结事实截止、持仓角色和用户原始 thesis。
3. 先给出当前最大的三处漏洞。
4. 强制回答九个反方问题：
   - 哪三个事实最可能证明我错？
   - 市场为什么可能是对的？
   - 我忽略了什么未知信息？
   - 胜率真的提高了吗？
   - 赔率是否只是价格下降造成的视觉错觉？
   - 最坏情况下会损失多少、是否永久？
   - 这笔收益值得承担该风险吗？
   - 有没有更低风险的同观点表达？
   - 如果今天空仓，我是否仍会建立同样仓位？
5. 分开 `H_B/H_R/H_L`，基金和期权增加工具票。
6. 计算资本桶、单票、集群和最大损失权限。
7. 最后才从六档动作中选择。

### 3. GPT 的权限边界

GPT 可以找证据、找反证、做情景、检查计算、记录预测、提醒纪律；不能：

- 把自己的置信度当统计概率；
- 因多个 AI 同意而增加独立证据数；
- 在缺少资本参数时给仓位；
- 用固定总分覆盖硬门；
- 修改资本宪法或自动成交；
- 因用户语气坚定而省略反方审查；
- 用支持性长文替代一句可证伪 thesis。

### 4. 标准输出字段

```yaml
decision_cutoff:
emotion_flags:
human_thesis_frozen:
asset_state:
valuation_grammar:
capital_bucket: H | O | research_only
H_B: pass | fail | unknown
H_R: pass | fail | unknown
H_L: pass | fail | unknown
root_evidence:
strongest_counterevidence:
probability_status: calibrated | uncalibrated
permanent_loss_case:
stress_loss_budget:
cooldown_until:
next_hard_evidence:
failure_condition:
allowed_action: 不投入 | 继续观察 | 建立验证仓 | 升级确认仓 | 不加仓 | 降级或退出
```

## 九、历史案例回放

| 案例 | 流程错误 | 结果不替流程洗白 | 新系统第一阻断门 |
|---|---|---|---|
| 501096 | 连续急跌制造便宜感，Q1滞后持仓被当当前存储工具，一次投入 15.43%，触线后等待反弹价 | 截至 7 月17 日浮亏约 ¥6,307；卖出未确认 | 本人独立 thesis + 基金底层/工具/回报/路径四票 + 集群预算 |
| 天赐 | 正确识别周期 PEG，但把主观概率和精确挂单价直接变成授权 | 未成交避免了即时亏损；若 39.2 买入持到 35.62，约亏 ¥3,580 | 先分 H/O，再算最大损失；允许小型 O 验证，不要求首仓等全部现金流 |
| 名创 | 已知 IP 源头控制者与授权渠道商不同，却因相对便宜买入弱控制权资产 | 截至 7 月17 日约浮亏 HK$4,480 | 最强反证未解决，不进入估值与下单 |
| 地平线 | 价格下降被写成胜率上升，“0.5单位”没有资本分母，实际成为 15.12% 进攻仓 | 当前浮盈不证明流程正确；坏情景潜在亏 HK$9,120—15,960 | 未完成财务迁移只能小型 O/验证仓；最大损失必须翻译成总资本比例 |
| LMND | 脆弱 DCF 包装未成熟保险经营；后置卖 Put 方案超过现金承受能力 | 1 股浮盈不证明卖 Put 合法；旧方案最坏可能亏约 US$7,700，而美元现金约 US$3,300 | 保险经营票 + 合约定义损失 + 全额现金覆盖 |

案例的共同结论是：**盈利不能证明流程正确，亏损也不能自动证明 thesis 错。应分别结算判断、仓位和执行。**

## 十、不做清单

1. 不把价格下跌写进企业经营胜率。
2. 不在亏损后把 O 改名 H、把交易仓改名长期仓。
3. 不用固定权重、固定加分和主观总分授权交易。
4. 不把未知填成 50%，不把区间中点当真相。
5. 不把同根新闻、多个 AI 输出或产业链相邻指标当独立证据。
6. 不用远期乐观终局对比短期悲观止损。
7. 不忽略永久稀释、再融资、技术替代、强平和流动性尾部。
8. 不用 DCF 包装市梦率，不用峰值低 PE 判断周期便宜。
9. 不用成熟价值心法接 PEG、周期或 Attention 资产的杀估值。
10. 不让高赔率补偿生存、现金流或工具硬门失败。
11. 不让单一 thesis 跨股票、基金、期权和账户重复下注。
12. 不把大成交量当压力期退出流动性。
13. 不把 Cash-secured Put 当正凸性策略，不裸卖未定义损失。
14. 不因为研究很多就必须下注；观察清单可以替代“信息费”。
15. 不因为错过上涨就重写当时证据不足的正确决定。
16. 不因为最终赚钱就原谅违规流程。
17. 不因为短期亏损就否定合规、可承受的正确过程。
18. 不在成交事实未确认时改主账。
19. 不让 AI 修改方法权威、风险预算或交易权限。
20. 证据不足时，不行动就是完成了一次正确决策。

- 组合多大路径回撤触发 72 小时停手；
