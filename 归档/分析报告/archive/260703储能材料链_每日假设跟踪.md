
## 新增证据

### 1. 宏观需求 λ：维持偏强，没有新增跳变

- 国家发展改革委、国家能源局 `2026-06-25` 印发《新型能源体系建设“十五五”规划》，继续强化新型储能、长时储能和电力系统灵活性底座。
- 国家能源局 `2026-06-29` 披露：`2026年1-5月` 全国电力市场交易电量 `30573` 亿千瓦时，同比增长 `24.8%`。
- 国家能源局 `2026-06-24` 披露：截至 `2026年5月底`，全国充电基础设施总数 `2249.7` 万个，同比增长 `44.9%`。
- CNESA `2026-07-02` 披露：海南 `2026` 年电网侧独立新型储能剩余可开放容量 `2.15GW`，共 `22` 个可接入站点。
- 关于 AI 数据中心 CapEx / 算电协同，公开层面仍以国家发改委 `2026-05-15` 对“AI+能源行动方案”的解读和国家能源局体系内 `2026-07-01` “算力跟着绿电走”表述为主，**今天没有新的硬订单或硬 CapEx 跳点**。

判断：

```text
宏观 λ 仍然成立，而且底座偏强；
但今天没有出现全国级强制配储、容量电价再上修、AIDC 配储强约束、海外大储超预期订单这类新跳点。

因此宏观层只能给“维持偏强”，不能上调到“增强”。
```

### 2. 需求兑现与付款人：需求链在，回款链仍未证实

- CNESA `2026-06-11` 的最新月度招中标公开口径仍显示：`2026年5月` 储能系统招标 `7.3GW / 23.8GWh`，同比 `+518.1% / +704.9%`；中标 `3.5GW / 13.5GWh`，同比 `+92.9% / +154.7%`。
- CNESA `2026-06-06` 披露中国能建启动 `30GWh` 磷酸铁锂储能系统集采，仍处在重要开标窗口。
- 付款人仍以电网侧、独立储能业主、能源央企、大型系统集成商为主；但截至今天中午，**没有新增公开回款改善证据** 能证明上游材料已经拿回现金流主动权。

判断：

```text
需求和付款人都在，问题不是“有没有人买”，
而是“订单 -> 验收 -> 回款 -> 现金流”是否顺滑到足以修复材料利润。

今天这条链条没有走到新的层级。
```

### 3. 供给锁死：仍未成立

- InfoLink `2026-07-01` 公开页最新口径：
  - `314Ah` 储能电芯均价 `0.375 元/Wh`
  - 中国 `4h` AC 液冷储能系统均价 `0.53 元/Wh`
  - 页面标题直接给出的判断是：**“锂盐先弱后稳，电芯和系统价格持稳”**
- InfoLink 同页同时指出：下游对更高电芯报价的接受度仍有限。
- 这意味着价格没有重新塌陷，但也不是材料链已经顺利把成本上涨传导给下游。

判断：

```text
这还是“价格底住了、但议价权没完全回来”的状态。

如果供给锁死成立，通常会同时看到：
电芯紧平衡、材料顺利提价、系统不再继续压价、客户接受涨价。
今天这四个条件没有同时满足。
```

### 4. 财务验证：仍未进报表

- 截至 `2026-07-03 13:07 CST`，未见宁德时代、湖南裕能、天赐材料、新宙邦、璞泰来、恩捷股份、盐湖股份、中矿资源、阳光电源、科华数据、盛弘股份、上能电气、南都电源披露足以直接确认“材料利润修复”的 `2026H1` 正式报表。
- 也未见足够高质量的公开披露，把“材料出货增长”直接写成“毛利率 / 单吨盈利 / 经营利润 / 经营现金流同步改善”。

判断：

```text
主假设的关键不是“储能还在增长”，
而是“高质量材料环节利润修复”。

只要 H1 报表没把毛利、利润和现金流写出来，
就仍然只能停留在观察仓。
```

