```text

所以今天不是“假设增强”，也不是“触发反证”；
它更像是：需求 λ 维持偏强，结构窗口仍在，但利润修复仍卡在 L3 / G6。
```

## 新增证据

### 1. 宏观需求 λ：小幅增强，但还不是足以改档的跳点

- 国家发展改革委、国家能源局 `2026-06-25` 印发《新型能源体系建设“十五五”规划》，继续给新型储能和长时储能制度底座。
- 国家能源局 `2026-06-30` 披露：`2026年1-5月` 全国电力市场交易电量同比 `+24.8%`。
- 国家能源局 `2026-06-24` 披露：截至 `2026年5月底`，全国充电基础设施总数 `2249.7 万个`，同比 `+44.9%`。
- CNESA `2026-07-02` 跟踪海南新政：海南公布 `2026` 年电网侧独立新型储能剩余可开放容量 `2.15GW`，共 `22` 个可接入站点。

判断：

```text
今天新增的 2.15GW 更像“省级可接入容量继续放开”，
说明大储建设环境没有收缩，宏观 λ 比早间版本略强。

但这仍不是全国级强制配储、容量电价再抬升、AIDC 配储硬约束升级这类跳变。
因此宏观 λ 只能上调到“小幅增强”，不足以把总结论从“维持”升级为“增强”。
```

### 2. 付款人与兑现：付款人没丢，但回款链条仍未证明改善

- 主付款人仍是电网侧、独立储能业主、能源央企、大型系统集成商。
- CNESA `2026-06-29` 关于动力和储能电池企业供应商账款支付规范倡议仍是今天最重要的付款链信号：
  - 材料类、部件类原则上验收不超过 `7` 个工作日；
  - 中小企业供应商账期原则上不超过 `60` 个自然日。

判断：

```text
这证明需求链条存在，但也反向说明“订单 -> 验收 -> 回款 -> 现金流”还没有自然顺滑到
让上游材料端获得强议价权。

付款人仍成立，回款改善仍未验证。
```

### 3. 供给锁死：仍未成立，材料只是相对强，不是全链提价

- 公开价格链今日没有新的强变化：
  - InfoLink 最新公开口径仍为 `314Ah` 储能电芯 `0.375 元/Wh`；
  - 中国 `4h` AC 液冷储能系统 `0.53 元/Wh`；
  - SMM 公开页最新可见口径仍沿用 `2026-07-01`，电解液、六氟偏平，正极和锂盐局部偏强。
- `2026-07-02` 收盘结构显示：
  - 天赐材料 `+0.68%`、中矿资源 `+0.92%`；
  - 宁德时代 `-0.39%`、亿纬锂能 `-3.13%`、湖南裕能 `-1.81%`、新宙邦 `-6.16%`；
  - 阳光电源 `-6.63%`、科华数据 `-5.80%`。

判断：

```text
今天的结构更像“材料 / 资源相对系统继续占优”，
不是“材料环节已经拿回定价权”。

如果供给锁死真的成立，通常会先看到：
电芯紧平衡、材料顺利扩价、系统价格不再持续承压、客户接受涨价。
今天这些条件仍没同时出现。
```

### 4. 财务验证：仍未进材料报表

- 截至 `2026-07-02 21:18 CST`，未见宁德时代、湖南裕能、天赐材料、新宙邦、璞泰来、恩捷股份、盐湖股份、中矿资源、阳光电源、科华数据、盛弘股份、上能电气发布足以直接确认“高质量材料利润修复”的 `2026H1` 财务验证。
- 已知更靠前的经营验证仍主要在电芯端，不能替代材料端毛利率、单吨利润、经营现金流验证。

判断：

```text
主假设的核心不是“储能还在增长”，
而是“高质量材料环节利润修复”。

只要湖南裕能 / 天赐材料 / 新宙邦 / 恩捷 / 璞泰来的 H1
还没把毛利、利润、现金流写进报表，
就不能从观察仓升级确认仓。
```

## 反证条件是否触发

今天未触发反证，但以下条件一旦出现，需要把结论下调：

1. `314Ah` 电芯价格连续数周跌破 `0.36 元/Wh`，或进一步接近 `0.34 元/Wh`。
2. `4h` AC 液冷系统价格连续数周跌破 `0.50 元/Wh`。
3. 湖南裕能、天赐材料、新宙邦、恩捷股份、璞泰来 `H1` 出现“出货增但毛利、现金流、库存恶化”的组合。
4. 电网侧 / 央国企招标持续，但交付、验收、回款继续拖延。
5. `001616`、`003984` 在 `Q2` 正式持仓中明显漂离材料 / 电芯链。

今日结论：

```text
反证没有触发；
但系统链连续弱、材料端仍未进报表，
意味着这条假设还停留在“可跟踪、不可确认”的阶段。
```
