# 锂电池与储能产业链：第一性原理与基金决策

## 一句话结论

**储能需求是真增长，电芯、海外系统和一体化电解液的利润修复也已有报表证据；但材料全面紧缺并未成立。7 月 1 日电解液走强有基本面底座，却不是当天现货涨价驱动，股价已提前交易 Q2 利润延续。当前只能保留观察仓，等单吨利润、现金流和基金 Q2 持仓确认。**

## 最关键的证据链

```text
储能装机/招标高增
→ 电芯与系统订单兑现
→ CATL、阳光电源已留下高毛利和现金
→ 材料出货同步增长
→ 但材料供给未全面锁死
→ 只有一体化电解液率先出现高利润弹性
→ LFP 高利用率仍被营运资金吞噬
```

三个数字把问题说透：

1. 宁德时代 2025 年储能收入 **624.40 亿元**，毛利率 **26.71%**；
2. 阳光电源 2025 年储能收入 **372.87 亿元**，毛利率 **36.49%**；
3. 湖南裕能 2025 年 LFP 销量增长 **60.03%**、产能利用率 **113.76%**，经营现金流却为 **-15.46 亿元**。

所以，需求最大的环节不一定最赚钱；系统与电芯目前比多数材料更能留下利润。

## 第一性原理分工

| 环节 | 解决的问题 | 利润验证数字 |
|---|---|---|
| 正极 | 电压、能量密度、安全和寿命 | 单吨加工利润、现金流 |
| 负极 | 快充、低温、循环和首效 | 石墨化利用率、硅基收入 |
| 电解液 | 离子传输和界面稳定 | 价差、单吨利润、现金流 |
| 隔膜 | 防短路并允许离子通过 | 平米价格、涂覆占比 |
| 铜箔 | 导出电子 | 加工费、良率，不看铜价本身 |
| 电芯 | 把材料变成可靠单体 | 单 Wh 利润、储能毛利率 |
| BMS/热管理 | 管理安全、温度和可用容量 | 故障率、软件价值、客户认证 |
| PCS/系统 | 把电池变成可并网、可调度资产 | 海外占比、毛利、回款 |
| 电网设备 | 连接并控制发输配用 | 招标份额、订单、毛利 |

## 为什么今天电解液强

2026-07-01 盘中，天赐约 +5.31%、湖南裕能约 +3.39%、新宙邦约 +3.02%，但阳光电源约 -13.65%，PCS/AIDC 电源链同步下跌。

这说明今天是**材料/资源相对系统链的资金切换**，不是储能全链共振。

基本面底座：

- 天赐材料 2026Q1 归母净利润 16.54 亿元，同比 +1005.75%，毛利率约 38.65%；
- 新宙邦 2026Q1 净利润同比约 +109.56%，经营现金流转正；
- 湖南裕能 2026Q1 归母净利润同比 +1337.77%。

反向证据：

- 2026-06-30 LFP 用电解液均价 2.76 万元/吨，持平；
- LiPF6 均价 10.35 万元/吨，当日下降 3000 元/吨。

结论：**市场在交易利润修复延续，不是在交易当天现货上涨。**

## 收益点双排序

长期利润确定性：

1. 电芯龙头；
2. 海外系统/PCS 龙头；
3. 强认证电网设备；
4. 一体化电解液；
5. LFP；
6. 锂资源；
7. 隔膜/负极；
8. 标准铜箔。

未来 6—12 个月利润弹性：

1. 一体化电解液/LiPF6/LiFSI；
2. 锂资源；
3. LFP；
4. 电芯与系统；
5. 隔膜/负极；
6. 标准铜箔。

电解液适合做“利润弹性”，不适合直接定义为永久护城河。

## 假设验证

| 假设 | 判断 | 关键修正 |
|---|---|---|
| 电池升级是长期趋势 | 成立 | 技术升级不自动提高材料利润 |
| 储能是电力基础设施 | 成立 | 要看收益机制和利用率，不只看装机 |
| AI 强化储能 | 部分成立 | AI 先拉动电网、变压器、UPS；BESS 需项目验证 |
| 高油价强化电气化 | 对 EV 成立 | 对固定式储能只是二阶驱动 |
| 电解液短期价格弹性强 | 成立 | Q2 是否守住单吨利润是核心 |
| 高端电解液提升价值量 | 有条件成立 | 要看高端收入占比和溢价 |
| 铜链受益 | 物理量成立 | 铜矿、铜箔、电缆利润不能混为一谈 |
| 两轮车大容量需求增加 | 局部成立 | 将转向合规换电，不等于大储需求 |
| To C 可反推 To B | 条件性成立 | 必须证明共享产能与产能迁移 |

## To C 反推 To B 的硬规则

只有满足以下条件，消费端信号才可升级：

```text
To C 与 To B 共用产能
→ 厂商确实把产能迁往 To B
→ 排除成本、监管、渠道和季节因素
→ 企业排产、交期、订单和利润回验
```

两轮车新国标后，最有价值的监控项是：

- 合规大容量电池认证型号；
- 外卖/物流经营车辆销量；
- 换电柜采购、站点、日换电次数；
- 48V/60V 合规电池包 Wh 单价和交期；
- BMS、互认充电器、定位模块订单；
- 两轮锂电回收量。

这些信号更直接映射小动力电芯、BMS、换电运营与安全认证，对 314Ah 大储电芯和电网储能只是弱旁证。

## 基金选择

| 工具 | 真实表达 | 决策 |
|---|---|---|
| 001616 嘉实环保低碳 | 电芯 + LFP + 电解液 + 负极 + 隔膜 + 锂 | 材料修复首选；当前只做观察仓 |
| 159566/021033 易方达储能电池 | 电芯 + 系统 + PCS + 温控 | 更适合 BESS/AIDC 电源 |
| 159796/012862 汇添富电池 | 宽电池链 | 费率低、分散，材料不够纯 |
| 003984 嘉实新能源新材料 | 材料 + 高锂资源 | 只在明确看多锂价时使用 |

001616 最新正式前十合计 57.18%：宁德、湖南裕能、天赐、亿纬、雅化、璞泰来、中矿、盐湖、恩捷、新宙邦。

仓位口径：

- 现在：主题计划仓位的 **20%—30% 观察仓**；
- H1/Q2 至少四项确认后：提高到主题计划仓位的 **50%—60%**；
- 单一高波动主题合计不宜超过个人总投资资产的 **10%—15%**；具体还取决于现金需求和承受回撤能力。

## 加仓信号

至少满足四项：

- 天赐/新宙邦 Q2 单吨利润和毛利率未明显回落；
- 湖南裕能利润增长同时伴随经营现金流改善；
- 宁德储能毛利率保持约 25%；
- 大型储能集采价格未重新坍塌；
- 001616 Q2 持仓不漂移；
- 六氟、电解液价差企稳，不是只有股价上涨。

## 放弃条件

- 4h AC 系统价连续四周低于 0.48 元/Wh；
- 314Ah 电芯连续四周低于 0.36 元/Wh；
- 电解液出货增长但毛利、单吨利润、现金流同步回落；
- LiPF6/VC/LiFSI 复产、库存和价格形成“三杀”；
- 湖南裕能高利用率下现金流继续恶化；
- AI 只有政策，没有可验证 BESS 订单；
- 001616 Q2 漂移出材料/电芯链。

## 周度监控

1. 储能招标、中标、投运 GWh 与时长；
2. 314Ah 电芯与 2h/4h 系统价格；
3. 碳酸锂、LiPF6、VC、LiFSI、电解液价差；
4. LFP、负极、隔膜、铜箔加工费；
5. 海外储能和 AIDC 电源订单；
6. 电网、变压器、特高压招标；
7. 龙头毛利、单吨利润、经营现金流；
8. 基金 Q2 持仓和净值相关性；
9. 股价与现货/利润是否背离；
10. To C 代理是否在企业订单中得到回验。

## 决策

**现在不追电解液强势，不把储能需求增长等同于材料全面涨价。保留 001616 小观察仓，主等 2026H1：电解液利润能否守住、LFP 现金流能否修复、电芯/系统毛利能否保持、基金持仓是否仍表达原命题。**
