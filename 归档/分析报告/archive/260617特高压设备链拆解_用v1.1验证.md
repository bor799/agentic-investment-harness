# 特高压设备链拆解：从政策到元件的七级拆解

> 本文件用 SOP v1.1 跑通**特高压设备链**——这是终止条件 #3（跑通 ≥ 2 条新链）的第二条新链。
>
> **本轮训练的不是"特高压行业报告"，而是**：
> 1. v1.1 在**贝叶斯主导（政策驱动）链**的泛化性验证（前 4 轮都是 Leontief/泊松/资源幂律主导）
> 2. 重资产 + 长认证 + 寡头链上 v1.1 八维评估是否够用
> 3. 政策事件作为"泊松到达率"的判定方式
> 4. 与已有三链（AI/储能/铜）的分布指纹对比，验证判别式 #1-#8 的跨链覆盖度

---

## 0. 一句话结论

```text
特高压设备链是"政策驱动的贝叶斯 + 寡头锁定的幂律 + 发输配用互补的 Leontief"三模型叠加链。

真正的瓶颈不在变压器、GIS 等一次设备（产能可扩），
而在上游关键材料（取向硅钢 HiB、绝缘油）+ 下游核心元件（换流阀晶闸管、控保芯片）——
这些环节 CR3 ≥ 80%、认证周期 24-36 月、客户只有国家电网+南方电网（极强双边锁定）。

投资纪律：
- 一次设备看"国网招标份额 + 产能扩张匹配度"（特变电工、中国西电、平高电气）
- 二次设备看"技术壁垒 + 寡头锁定"（国电南瑞、许继电气）
- 关键元件看"国产替代进度 + 认证"（中车时代、士兰微）
- 不要把"政策利好"等同于"全产业链受益"—— Transmission 测试是硬闸门
```

## 2. S1 宏观叙事解码

### 2.1 主题卡

| 字段 | 内容 |
|---|---|
| 宏观叙事 | 新型电力系统 + 沙戈荒新能源基地 + 西电东送持续性需求 + 灵活性和稳定性挑战 |
| λ（到达率）变化 | 2024-2026 特高压招标从年均 4 条上升到 6-8 条（国家电网"十四五"规划 24 条直流 + 交流配套） |
| 关键事件簇 | 2024 年国网第 1-4 批招标、白鹤滩-浙江投运、陇东-山东启动、沙戈荒大基地配套特高压加速 |
| 证据强度 | 强（多源同时变密：政策密度 + 招标条数 + 设备订单 + 投运节奏） |

### 2.2 λ 上升的 6 个事件类型

| 事件类型 | 2024-2026 实例 | 数据源 |
|---|---|---|
| 政策文件 | "十四五"现代能源体系规划、新型电力系统实施意见、沙戈荒规划 | 发改委/能源局 |
| 招标公告 | 国网年度特高压设备招标（4-6 批/年）、南网招标 | 国家电网电子商务平台 |
| 工程开工 | 陇东-山东、宁夏-湖南、哈密-重庆等 | 国网公告 |
| 设备订单 | 特变电工/中国西电中标公告 | 公司公告 |
| 投运节奏 | 白鹤滩-江苏/浙江、雅中-江西等 | 国网年报 |
| 国产替代 | IGBT 国产化、控保系统自主化、晶闸管国产替代 | 行业报告 |

**λ 上升确认**：6 个事件类型同时变密，符合 v1.1 决策表 §2.2 阈值。

### 2.3 但是——政策驱动的贝叶斯特征

特高压的关键特征是**贝叶斯主导**（不像 AI/储能/铜），原因：

- **政策是先验**：每五年规划一次，期间可能调整（如"十三五"特高压投资曾缩减）
- **新证据持续更新**：每年招标批次、每条工程开工、每个国产替代节点都在更新概率
- **路线分叉**：交流特高压 vs 直流特高压、传统晶闸管 vs 可控自换流（VSC）、IGBT 国产 vs 进口
- **后验不收敛**：即使"十四五"24 条直流已规划，每年仍可能调整节奏

**贝叶斯主导的纪律**：

```text
不要押单一政策（如"特高压必然翻倍"）；
要看政策事件密度（招标批次 + 工程开工 + 国产替代节点）是否持续上移。
```

## 3. S2 付款人优先级（v1.1 §1.1）

特高压链的付款人**极其集中**——这是与 AI/储能/铜最大的不同。

| 付款人类型 | 在特高压链的位置 | 预算可见度 | 付费刚性 | 跟踪指标 |
|---|---|---|---|---|
| **政府采购**（国家电网 + 南方电网） | **唯一主要付款人**（占 90%+） | 高（"五年规划" + 年度招标） | 极高（电网刚性 + 政策执行） | 国网/南网招标公告 |
| **企业战略 CapEx**（发电集团） | 上游拉动力（发电端升压设备） | 高（五大发电 CapEx） | 高（新能源装机刚性） | 发电集团 CapEx |
| **产业链下游付款** | 不适用（电网公司是终端） | — | — | — |
| **项目融资**（特高压工程） | 工程级融资 | 中（项目 IRR 评估） | 高（政策执行） | 项目贷款公告 |

**S2 关键发现**：

- 特高压链**只有 1 个主要付款人**（国家电网 + 南方电网），是 SOP v1.1 训练集中**最集中的付款结构**
- 与铜链（产业链下游付款分散）形成**极端对照**——铜链付款分散、特高压付款集中
- 付款集中度极高 → **客户议价能力极强** → 候选公司的 Capture 测试（利润能否留成）是关键
- 付费刚性极高 + 可见度高 → 是**强主题**

### 3.1 付款人集中度的双刃剑

| 优势 | 劣势 |
|---|---|
| 付款刚性极高（电网必须建） | 客户议价能力极强（压价） |
| 预算可见度高（"五年规划"公开） | 招标条件苛刻（技术+商务+履约） |
| 长期合作（一旦认证，多年稳定） | 价格受政策周期影响（电价改革、监管要求） |
| 政策背书（新型电力系统） | 客户有"国产替代"诉求（压进口价格） |

## 4. S3 七级产业链地图

把特高压从政策拆到核心元件，按 7 级：

```text
Level 1: 政策/规划（发改委/能源局/国网规划）
    ↓
Level 2: 工程 EPC（中国能建/中国电建/省级电力设计院）
    ↓
Level 3: 一次设备 - 变压器（特变电工/中国西电/保变电气/山东电力设备）
Level 4: 一次设备 - 换流阀（国电南瑞/许继电气/中电普瑞/ABB）
Level 5: 一次设备 - GIS 组合电器（平高电气/中国西电/西门子/平高）
    ↓
Level 6: 二次设备 - 控保系统（国电南瑞/许继电气/四方股份/长园深瑞）
    ↓
Level 7: 关键元件 - 晶闸管/IGBT/取向硅钢（中车时代/士兰微/斯达半导/宝武股份/首钢）★
```

★ 标记的是**真正的瓶颈环节**。

### 4.1 各级物理参数和成本结构

| 级别 | 物理参数 | 成本结构 | 单位经济 |
|---|---|---|---|
| L1 政策规划 | 电压等级（±800kV/-1100kV/1000kV 交流） | 财政 + 电网投资 | 单条特高压工程投资 200-300 亿元 |
| L2 EPC | 工程周期 3-5 年 | 设计 + 施工 + 管理 | 单工程 EPC 价值 30-50 亿 |
| L3 变压器 | 容量（8000MVA+）、损耗、绝缘等级 | 重资产、长认证 | 单台变压器 3000-8000 万元 |
| L4 换流阀 | 电压（±800kV）、电流（5000A）、晶闸管数量 | 极高技术门槛 | 单换流阀 5-15 亿元 |
| L5 GIS | 电压等级、断流能力、绝缘 | 重资产 | 间隔单价 800-1500 万元 |
| L6 控保系统 | 响应时间（ms）、可靠性、冗余度 | 软硬件结合 | 单工程控保价值 1-3 亿元 |
| L7 关键元件 | 晶闸管 6 英寸/8 英寸、IGBT 4500V/3000A、取向硅钢 HiB 等级 | 极高工艺 | 晶闸管单价 1-3 万元/支；HiB 硅钢 15000-25000 元/吨 |

## 5. S4 逆向溯源到瓶颈材料

从控保系统倒推到关键元件和材料。

| 级别 | 瓶颈强度 | 关键证据 |
|---|---|---|
| L6 控保系统 | **高** ★ | 国电南瑞寡头、认证周期 24-36 月、毛利率 25-35% |
| L4 换流阀 | **极高** ★★ | 晶闸管供给集中（中车时代+ABB+西门林 CR3 90%）、认证 T1 24 月+ |
| L7 取向硅钢 HiB | **极高** ★★ | 宝武 + 首钢 CR2 90%、海外仅韩国浦项/日本 JFE/俄罗斯 NLMK |
| L7 换流阀晶闸管 | **极高** ★★ | 中车时代国内独家 + ABB + 西门子 |
| L7 IGBT（柔性直流） | **高** ★ | 英飞凌+赛米控+三菱 70%，国产替代中（中车时代/斯达半导/士兰微） |
| L3 变压器 | 中 | 产能可扩（特变电工/中国西电/保变电气三家竞争） |
| L5 GIS | 中 | 平高 + 中国西电 + 西门子三家，国产替代较成熟 |
| L2 EPC | 低 | 中国能建/中国电建完全竞争 |
| L1 政策 | — | 不可投资 |

**S4 结论**：与铜链一致（判别式 #7 验证）——**瓶颈不在源头（政策）和中游一次设备（变压器、GIS 产能可扩），而在上游关键元件（晶闸管、IGBT）+ 关键材料（取向硅钢 HiB）+ 下游控保系统**。

这是判别式 #7（瓶颈不在源头，而在认证+工艺+寡头）在特高压链上的**再次验证**。

### 6.2 地缘集中度专题

| 环节 | 地缘评分 | 主要风险 |
|---|---|---|
| L3 变压器 | 5（中国主导） | 政策周期，但本身低风险 |

**v1.1 关键发现**：

- 特高压链整体地缘集中度高（多在 4-5 分），但**中国国内环节地缘风险低**（控保 5 分但是中国主导，实质风险低）
- IGBT 环节是**真正的卡点**（海外主导 + 美中博弈）
- 这进一步验证判别式 #8：**地缘集中度 ≠ 垄断溢价**——中国控保地缘集中度 5 但定价权受国网议价压制；IGBT 地缘集中度 5 且是真正的卡点

|---|---|---|---|---|

**关键判断**：特高压链的反噬时点普遍较长（7-10 季），因为**认证周期长 + 客户锁定**。这与储能链（2-3 季反噬）形成鲜明对比。

### 6.4 客户认证分级（v1.1 §1.4）

| Tier | 客户类型 | 认证周期 | 例子 |
|---|---|---|---|

### 7.2 客户集中度子项（v1.1 §1.5）

特高压链的客户集中度**极端**——比铜链还集中。

| 环节 | 单一客户占比 | 前 3 客户占比 | 风险等级 | 调整因子 |
|---|---|---|---|---|
| L3 变压器（特变电工） | 国网 ~50% | 国网+南网+发电 80% | 极高风险 | **客户切换成本极高（认证 T1 24-36 月）→ 降一级** |
| L4 换流阀（国电南瑞） | 国网 ~60% | 国网+南网+出口 85% | 极高风险 | 降一级 |
| L6 控保（国电南瑞） | 国网 ~55% | 80% | 极高风险 | 降一级 |
| L7 晶闸管（中车时代） | 国网 ~40% + 出口 30% | 75% | 极高风险 | 降一级（认证 T1 严） |
| L7 取向硅钢 HiB（宝武） | 国网间接 ~50% + 出口 30% | 75% | 极高风险 | 降一级 |

### 7.3 v1.1 客户集中度的修正发现

特高压链是**v1.1 客户集中度阈值的最严苛测试**：

- **几乎所有环节单一客户占比 > 50%**（按原阈值全部"极高风险"）
- 但**调整因子（认证 T1 24-36 月 + 客户切换成本极高）让实质风险降一级**
- 真正的风险不是"客户换供应商"，而是"**客户（国网）议价压价**"
- 这暴露 v1.1 §1.5 的**新维度缺失**：**客户议价能力**（不只是客户集中度）

**v1.1.1 patch 候选**：

> 在客户集中度子项里加"客户议价能力"维度：
> - 单一客户 + 客户有议价能力（如国网）→ 风险升一级（即使有认证壁垒）
> - 多元客户 + 客户无议价能力 → 风险降一级

**触发原因**：特高压链的客户（国网）虽然不会换供应商，但有强议价能力（招标条件、价格监管）。这与铜链 NVIDIA（强议价 + 强切换成本）不同。

**v1.1.1 落地判定**：作为 F9 后的 patch 候选，待 F10 完成后决定。

## 11. 反简单叙事测试

### 11.1 误读 1：政策利好 = 全产业链受益

**改写**：

```text
不是政策利好就让全产业链受益；
而是政策利好通过 Transmission 测试才能传导到具体环节——
L4/L6/L7 通过 Transmission（认证 + 寡头锁定）；
L2 EPC 不通过（完全竞争）；
L3 变压器部分通过（产能可扩 + 国网议价）。
```

### 11.2 误读 2：特高压投资 = 国电南瑞独赢

**改写**：

```text
不是国电南瑞独赢；
而是国电南瑞 + 许继 + 中车时代 + 宝武 + 平高 + 特变 多家共享。
关键看每家在哪个环节（换流阀/控保/晶闸管/HiB/GIS/变压器）。
不要只看龙头，要看龙头所在的环节是不是真瓶颈。
```

### 11.3 误读 3：客户集中度 80%+ = 极高风险

**改写**：

```text
不是高客户集中度就是高风险；
而是要看调整因子——
认证 T1 24-36 月 + 客户切换成本极高 → 实质风险降一级；
真正的风险是客户（国网）议价能力，不是客户换供应商。
```

### 11.4 误读 4：国产替代 = 利润流失

**改写**：

```text
不是国产替代让利润流失；
而是国产替代把进口环节的利润转给国产厂商——
IGBT 国产替代 = 中车时代/士兰微受益；
HiB 硅钢国产替代 = 宝武/首钢受益；
关键是判断"国产替代节奏"和"谁是国内第一替代者"。
```

## 14. 可泛化判别式

### 14.1 判别式 #9：贝叶斯主导链的"政策事件密度"判定

**一句话**：政策驱动的链上，不要押单一政策，要看政策事件密度（招标 + 开工 + 国产替代节点）是否持续上移。

**适用场景**：所有"五年规划"驱动的链（特高压、核电、半导体、新能源车补贴等）。

**判断步骤**：

1. 列出政策事件类型（招标、开工、投运、国产替代、政策文件）
2. 按月度跟踪事件密度
3. 同方向事件 ≥ 3 类同时变密 → λ 上升确认
4. 同方向事件 ≥ 2 类 + ≥ 1 类反向 → 待验证
5. 仅 1 类变密 → 不构成 λ 上升

**正例**：特高压 2024-2025（招标 + 开工 + 投运 + 国产替代 4 类同时变密）
**反例**：押"特高压必然翻倍"（忽略政策周期）
**失败条件**：政策驱动的链上没有月度事件跟踪（如只看年度政策）
**下次测试**：核电链、半导体大基金链

### 14.2 判别式 #10：客户议价能力 ≠ 客户集中度

**一句话**：客户集中度高（如特高压 80%）不一定是风险，关键看客户的议价能力——客户能压价才是真风险。

**适用场景**：所有"单一/少数客户"驱动的链。

**判断步骤**：

1. 看客户集中度（前 3 客户占比）
2. 看客户议价能力（客户是政府采购？大平台？垄断企业？）
3. 看客户切换成本（认证 T1/T2 + 时间 + 资本）
4. 综合判断：客户集中 + 强议价 = 风险；客户集中 + 弱议价 + 高切换成本 = 锁定

**正例**：
- 特高压链客户集中度高（80%+）+ 国网强议价 → Capture 测试是关键
- ABF 载板客户集中度高（70%+）+ NVIDIA 弱议价（缺货）+ 高切换成本 → 锁定

**反例**：把"客户集中度高"直接当高风险，忽略议价能力差异

**失败条件**：客户分散但议价能力强（如苹果对供应商）

**v1.1.1 patch 候选**：在 v1.1 §1.5 客户集中度子项里加"客户议价能力"维度
