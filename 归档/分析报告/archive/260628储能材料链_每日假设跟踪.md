```text
仍然是材料出货 -> 材料提价 -> 单吨利润 -> 经营现金流。
```

## 价格 / 结构判断

当前仍是**结构窗口，不是确认窗口**。

原因没有变化：

1. 需求增量仍先兑现到系统链和电芯链。
2. 材料环节还没有重新拿回价格权。
3. 正式净值和股价结构都没有给出“材料利润修复已开始”的右侧确认。

仓位解释：

- `观察仓`：可以保留。
- `确认仓`：今天依然**不允许升级**。
- `加仓动作`：今天依然是 **不加仓**。

## 反证条件是否触发

今天仍然**没有触发反证**。  
需要持续盯住的反证条件不变：

1. `4h` 储能系统价格跌破 `0.50 元/Wh` 并持续下探。
2. 电池级碳酸锂跌破 `13 万元/吨`。
3. 材料基金持仓明显漂移出储能材料链。
4. `Q2/H1` 财报继续显示单吨盈利、毛利率、经营现金流无修复。
5. 数据中心 / 海外大储订单只停留在签约，不进入交付与回款。
