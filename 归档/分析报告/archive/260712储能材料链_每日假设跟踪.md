## 一句话判断

```text
今天维持上午已上调后的“假设增强”，
不是因为周五股价跌得更便宜，
而是因为财务验证从电解液子链继续扩散到了隔膜子链，
且截至今晚复核没有新的官方披露把这条结论推回“维持”或“转弱”。

7 月 10 日恩捷股份披露 2026H1 业绩预告，
明确给出“销量增长 + 价格企稳回升 + 毛利率显著提升 + 扭亏为盈”。

这意味着“储能建设放量 -> 电芯需求增长 -> 高质量材料利润修复”
已经不再只靠天赐材料、新宙邦两条电解液证据支撑，
而是开始出现隔膜环节共振。

但这仍不是“确认仓”信号：
付款纪律还要看现金流，
电芯、LFP 正极、PCS/UPS 仍没有证明全链供给锁死，
价格层依旧被风险偏好压制。
```

## 新增证据

### 1. 宏观需求 `λ`：继续偏强，但今天没有新增到 AIDC / 快充 / 海外大储的一手硬单

- 国家能源局 `2026-07-10` 印发《能源领域节能降碳行动计划（2026—2028年）》，继续明确：
  - 大力发展新型储能；
  - 探索长时储能应用；
  - 加强配电网建设改造和智慧升级；
  - 发展绿电直连、智能微电网、源网荷储一体化。
- 宁夏发改委 `2026-07-09` 下发并由 CNESA `2026-07-10` 转发的下半年并网计划显示：
  - `2026年7-12月` 新型储能项目共 `33` 个；
  - 合计 `10.04GW / 29.03GWh`；
  - 其中超过 `1GWh` 的项目 `8` 个。
- CNESA `2026-07-07` 公布 `2026H1` 储能系统招标 `24.5GW / 148.1GWh`、EPC（含 PC）`80.1GW / 227.9GWh`，能量口径分别同比 `+88.3%`、`+112.21%`。
- 今天额外扫描了 AIDC 配储、快充配储、海外大储相关新闻与重点公司公告页，**截至 `2026-07-12 21:14 CST` 仍未新增看到足以单独加分的一手 CapEx / GWh 级新订单 / 正式业绩预告**，因此这三项今天不额外上调 `λ` 评分。

判断：

```text
宏观 λ 继续偏强。

今天的加分点不在“方向有没有了”，
而在“政策 + 并网计划 + H1 招标统计”三件事仍在同向强化。

但 AIDC / 快充 / 海外这三条支线，今天没有新增一手硬证据，
所以不把主假设增强归因到这些分支上。
```

### 2. 付款人：仍然存在，但“能招标”不等于“材料端已经收回现金”

- H1 招标和 EPC 高增说明付款人没有消失，主要仍是：
  - 电网侧业主；
  - 央国企新能源开发主体；
  - 大型 EPC；
  - 海外公用事业客户。
- 甘肃腾格里两大光伏配储项目 `900MW / 1800MWh` 于 `2026-07-07` 开标，报价区间约 `0.53-0.625 元/Wh`，项目真实存在、业主真实存在、系统价格并未继续失真塌陷。
- 但 `2026-06-29` 的《动力和储能电池企业供应商账款支付规范倡议》继续提示：
  - 中小供应商账期原则上最长不超过 `60` 个自然日；
  - 鼓励现金支付，逐步降低商票和电子凭证比例。

判断：

```text
付款人这一关仍是“部分通过”。

有项目、有业主、有招标，不等于材料端回款已经改善。
真正要进报表确认的仍是：
经营现金流、应收、票据、存货和账期。
```

### 3. 产业链卡点与供给锁死：局部成立，但不是全链锁死

- 系统端环境仍比 6 月底健康：
  - `2h` 储能系统 H1 中标均价约 `602.1 元/kWh`，同比 `+8.8%`；
  - `4h` 储能系统 H1 中标均价约 `541.3 元/kWh`，同比 `+21.1%`。
- 电芯与 PCS/BESS 仍不满足“锁死供给”：
  - 框采、集采占比高；
  - 报价仍有竞争性区间；
  - 客户对系统集成商与电芯厂仍可切换。
- 但高质量材料环节的局部锁死开始更清楚：
  - 天赐材料：电解液、六氟受益于需求旺盛、价格上行、利用率接近满产；
  - 新宙邦：电池化学品量利双增；
  - 恩捷股份：隔膜下游需求旺盛、产品价格较上年低点企稳回升、综合毛利率显著提升。

判断：

```text
今天可以把“高质量材料局部锁死”再向前推进半步，
但只能限定在电解液 / 六氟 / 隔膜这些已经出现利润证据的环节。

电芯、LFP 正极、PCS、UPS、BESS 集成并没有拿到同级别结论。
所以 G4 仍不能写“通过”，
只能写“全链未通过，局部材料环节更清晰”。
```

### 4. 财务验证：从电解液扩散到隔膜，这是今天最重要的新变化

- 天赐材料 `2026-07-10` 披露 `2026H1` 业绩预告：
  - 归母净利润预计 `27.0-30.0 亿元`；
  - 同比 `+907.84% ~ +1019.82%`；
  - 核心原因是电解液及六氟磷酸锂需求旺盛、销量显著增长、产能利用率接近满产、产品价格上行。
- 新宙邦 `2026-07-09` 披露 `2026H1` 业绩预告：
  - 归母净利润预计 `9.70-10.30 亿元`；
  - 同比 `+100.48% ~ +112.88%`；
  - 明确提到电池化学品业务紧抓储能景气，销量、销售额和盈利同比大幅增长。
- **恩捷股份 `2026-07-10` 披露 `2026H1` 业绩预告：**
  - 归母净利润预计 `7.36-9.00 亿元`；
  - 去年同期亏损 `0.93 亿元`；
  - 扣非净利润预计 `7.62-9.30 亿元`；
  - 去年同期亏损 `0.95 亿元`；
  - 公司在公告中明确写到：隔膜下游市场需求旺盛、销量稳步攀升、产品价格企稳回升、综合毛利率显著提升。

判断：

```text
G6 仍然不能写成“全面通过”，
但今天已经从“电解液单链验证”升级为“电解液 + 隔膜双链验证”。

这就是今天把结论上调到“假设增强”的核心原因。
```

```text
当前市场更接近用“`PEG + 景气修复`”语法在试探材料链，
而不是已经切换到“`DCF / PE 锚定成熟现金流`”语法。
这意味着现在赚的还主要是“财务验证继续扩散后的认知差钱”，
不是稳定股息或成熟价值重估的钱。

这反而说明：
如果后续 H1 报表继续扩散验证，
这条假设还有从“财务证据增强”向“估值预期修复”跳变的空间；
但今天还没有到可以把观察仓升级为确认仓的程度。
```

仓位动作建议：

```text
继续以观察仓对待，不追高，不因为一天盘面弱就否定假设。

只有在后续 H1 / Q2 报表里，
看到更多环节把毛利率、经营利润、现金流、库存和利用率一起验证，
才考虑从观察仓升级确认仓。
```

不做什么：

```text
不因为周五下跌就把“增强”误读成“确认仓买点”；
不把 159566 / 159796 这类系统宽基工具，直接当成“高质量材料利润修复”的纯代理；
不在 001616 的 Q2 正式持仓披露前，把基金映射稳定性默认当成已确认事实；
不把单一业绩预告当成全链供给锁死已经成立。
```

---

## 反证条件是否触发

结论：**未触发反证**

当前最需要继续盯的反证条件：

1. `2026H1` 更多材料龙头未能兑现毛利率、经营利润和现金流修复，只剩天赐 / 新宙邦 / 恩捷三家孤证。  
2. 系统价、电芯价重新快速下探，材料端价格无法稳住。  
3. `001616` 的 `Q2` 持仓明显漂移出宁德 / 湖南裕能 / 天赐 / 亿纬 / 恩捷 / 璞泰来等材料电芯主链。  
4. 付款链没有改善，H1 经营现金流、应收、票据显著恶化。  
5. 宁夏并网计划、H2 招投标高景气没有继续兑现成真实并网与消耗。  
6. AIDC / 海外大储 / 电网侧支线继续只有叙事，没有新增真实订单与回款证据。
