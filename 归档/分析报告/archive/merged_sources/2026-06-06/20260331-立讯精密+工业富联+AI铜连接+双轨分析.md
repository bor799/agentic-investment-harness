## 二、轨道A：一级市场 / VC视角

### 2.1 秩序创造机器判定

**立讯精密** -- **秩序升级者** (不是创造者)

立讯精密并非创造全新的市场秩序，而是在既有秩序中实现持续升级：
- 从连接器 -> 线缆 -> 模组 -> 整机组装，沿着价值链持续攀升
- 从消费电子 -> 通信 -> 汽车电子 -> AI基础设施，跨领域复制精密制造能力
- 这是一种**执行力驱动型**的公司，而非范式创造型

评级: B+ (在既有轨道上做到极致，但并非从0到1)

**工业富联** -- **秩序受益者** (非创造者)

工业富联是AI基础设施大潮的直接受益者：
- NVIDIA GB200的规模化量产直接拉动了其服务器代工业务
- 但其本质上仍是代工模式，不掌握核心技术（芯片设计、架构定义）
- 在AI服务器价值链中处于"制造执行"层，而非"价值定义"层

评级: B (确定性受益，但护城河来自规模而非创新)

### 2.2 创生公式分析

**立讯精密的创生公式:**

```
精密制造能力 x 苹果生态绑定 x 跨领域复制 = 持续增长飞轮

从连接器到AI基础设施的路径:
消费电子连接器 -> 高速数据连接器 -> 服务器互连组件 -> AI服务器整机
                  -> 汽车电子连接器
                  -> 光模块/铜缆组件
```

关键变量:
- 立讯正在从"零件供应商"向"系统级供应商"转型
- 2025前三季毛利率从10.41%提升到12.15%，说明产品结构在优化
- 汽车电子和通信业务增速预计超过消费电子

**工业富联的创生公式:**

```
全球最大电子代工网络 x AI服务器爆发 x NVIDIA深度绑定 = 利润超级周期

增长路径:
传统服务器代工 -> GPU服务器代工 -> AI训练/推理服务器全栈 -> 数据中心解决方案
```

关键变量:
- 2025年净利润352.9亿，同比+52%，这是爆发性增长
- 但ROE从15.85%跃升到21.65%，说明资本效率在提升
- 毛利率从7.28%微降到6.98%，说明增长仍以量取胜

### 2.3 市场认知差分析

**立讯精密 -- 被低估的认知差:**

1. **AI连接器叙事尚未充分定价**: 市场仍主要将立讯定位为"苹果链"，AI服务器高速铜连接的贡献尚未在估值中充分体现
2. **从Tier-2到Tier-1供应商的跃迁**: 立讯正在突破苹果的整机代工壁垒（Vision Pro、iPhone组装），这一战略性变化的价值未被充分认知
3. **汽车电子的隐藏期权**: 汽车电子业务是10-15年的长周期机会，当前估值几乎不反映

**工业富联 -- 认知差在缩小:**

1. **AI服务器增长已经被充分认知**: 2025年报营收+48%、利润+52%的爆发性增长已经price-in了相当程度
2. **但持续性问题被低估**: 市场可能低估了AI基础设施投资的持续性（2026-2028年仍有望维持高增速）
3. **代工模式的天花板被低估**: 6.98%的毛利率说明利润增长高度依赖规模，一旦AI投资放缓，弹性向下

### 2.4 护城河七力评估

| 维度 | 立讯精密 | 工业富联 |
|------|---------|---------|
| **规模效应** | 中高 -- 精密制造规模大，但未到极致 | 极高 -- 全球最大电子代工网络 |
| **转换成本** | 高 -- 苹果/NVIDIA认证壁垒，客户粘性强 | 中高 -- 大客户转换成本高，但可替代性也高 |
| **流程优势** | 高 -- 精密制造工艺积累深厚 | 中 -- 代工流程标准化，优势来自规模而非独特工艺 |
| **反向定位** | 高 -- 从连接器向整机延伸，价值链攀升 | 中 -- 始终在代工层，未向价值定义层突破 |
| **网络效应** | 低 -- 制造型企业网络效应有限 | 低 -- 同上 |
| **品牌价值** | 低 -- 2B业务，终端品牌认知弱 | 低 -- 同上 |
| **护城河总分** | **3.5/5** | **3/5** |

## 三、轨道B：二级市场视角

### 3.1 长期视角

**立讯精密**

优势:
- 苹果生态绑定深度: 从连接器到整机，"立讯+"的渗透率持续提升
- 多元化业务结构: 消费电子 + 通信 + 汽车电子，降低单一客户风险
- 管理层执行力: 王来春团队的战略定力和执行能力已得到验证
- ROE稳定在21%+，资本回报优秀

风险:
- 苹果依赖症: 大客户集中度仍然很高
- 地缘政治风险: 中美科技博弈可能影响苹果供应链格局
- 从零件到整机的转型是否顺利仍需观察

**工业富联**

优势:
- AI服务器超级周期: NVIDIA GB200量产带来的确定性增量
- 全球客户覆盖: 服务于几乎所有头部云厂商
- 2025年ROE跃升至21.65%，资本效率大幅改善
- 营收规模9,029亿，规模效应显著

风险:
- 代工模式天花板: 6.98%毛利率，利润弹性受限于定价权
- AI投资周期性: 一旦大客户削减Capex，业绩弹性向下
- 依赖NVIDIA: 如果GB200铜缆方案发生变化，影响面大
- 中美关系: 台资企业背景在中国大陆上市的独特敏感性

### 3.3 财报深度解读

**立讯精密 -- 三个关键发现:**

1. **营收加速是最大亮点**: 从2024年的+15.9%加速到2025前三季的+24.7%，说明新业务（通信/AI/汽车）正在贡献增量
2. **毛利率改善**: 从10.41%提升到12.15%（前三季），产品结构优化正在进行
3. **但ROE同比下滑**: 2024年报ROE 21.34% vs 2023年报21.61%，2025前三季仅15.24%（受季节性影响，全年预计仍在20%+）

**工业富联 -- 三个关键发现:**

1. **增速爆发**: 营收+48%、利润+52%，这是超级周期的典型特征
2. **但毛利率微降**: 7.28% -> 6.98%，说明增长主要靠量而非价
3. **ROE大幅提升**: 15.85% -> 21.65%，利润增速远超营收增速，经营杠杆在发挥作用

### 3.4 竞争格局分析

**AI服务器高速铜连接赛道:**

竞争对手:
- 安费诺 (Amphenol) -- 全球连接器龙头，224G方案领先
- 莫仕 (Molex) -- 高速互连方案成熟
- 泰科 (TE Connectivity) -- 车规级连接器强
- 国内: 华丰科技、鼎通股份、沃尔核材、兆龙互连

立讯精密的定位:
- 在NVIDIA GB200铜缆方案中，立讯主要参与铜缆组件和连接器供应
- 与安费诺相比，立讯的优势在于成本和制造规模，劣势在于技术原创性

工业富联的定位:
- 在AI服务器代工领域，主要竞争对手是广达、纬创、英业达
- 工业富联的规模优势明显，但利润率偏低说明定价权有限

### 结论

#### 立讯精密 (002475.SZ)

- **评级: 买入**
- **置信度: 中高**
- **核心逻辑**: 营收增速加速（8% -> 16% -> 25%），毛利率改善，AI连接器+汽车电子的多元增长引擎正在形成。PE 23x在成长股中属于合理偏低水平。
- **关键信号**:
  - 关注2025年报毛利率是否持续在12%+（验证产品结构优化）
  - 关注通信/AI服务器业务占比是否突破15%
  - 关注汽车电子订单增速
- **退出信号**:
  - 苹果砍单或供应链转移
  - 毛利率持续回落至10%以下
  - ROE连续两季低于15%

#### 工业富联 (601138.SH)

- **评级: 观望（谨慎偏多）**
- **置信度: 中**
- **核心逻辑**: AI服务器超级周期正在兑现（2025利润+52%），但PE 29x对于6.98%毛利率的代工企业而言已不便宜。增速在2026年大概率放缓，估值扩张空间有限。
- **关键信号**:
  - 关注2026Q1增速是否维持30%+（判断周期持续性）
  - 关注毛利率是否止跌回升（定价权信号）
  - 关注NVIDIA下一代平台（Rubin）对铜缆方案的影响
- **退出信号**:
  - AI服务器收入增速降至20%以下
  - 毛利率跌破6.5%
  - 大客户（微软/谷歌/Meta）削减AI Capex指引

如果要做选择，在当前时点（2026-03-31）：
