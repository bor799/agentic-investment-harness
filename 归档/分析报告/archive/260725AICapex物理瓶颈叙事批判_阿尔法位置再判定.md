# AI Capex "物理瓶颈"叙事批判——阿尔法位置再判定

> 检验对象：RockFlow 2026-07-23《谷歌财报跌倒，半导体吃饱？AI Capex 狂潮下的两条隐性主线》
> 核心问题：文章把"电力、液冷、接口、CXL"标为"隐性瓶颈 Alpha"，这个判定成不成立？
> 框架：ljg-invest——**这个东西在创造新秩序，还是在搬运旧秩序？**
> 增补（2026-07-25 对话补强）：原报告聚焦框架层判定，本版新增"增补判定"章节，从地缘、时间、算法、理论四个维度加强 L0 alpha 的判定。

## 判定图（先看图，后读文）

| 层      | 内容                                            | 文章判定       | 我们判定        | 性质   | 关键备注                                   |
| ------ | --------------------------------------------- | ---------- | ----------- | ---- | -------------------------------------- |
| **L0** | 算法-硬件协同定义者（DeepSeek / NVIDIA 架构 / TSMC 制程规则）  | 显性共识（建议规避） | **🟦 真阿尔法** | 秩序创造 | 梁文锋证明：算法可从 H800 抽出接近 H100 的效率，硬件离天花板尚远 |
| **L1** | 物理牌照稀缺（核电 PPA、电网接入权、高压输电走廊）                   | 隐性瓶颈（推荐）   | 🟧 半阿尔法     | 秩序锁定 | 你点对了——是"重资产+长周期"的牌照逻辑，但仍是锁定，不是创造       |
| **L2** | 标准制定者（SerDes / CXL / UCIe 协议 owner、CoWoS 持有者） | 隐性瓶颈（推荐）   | 🟧 半阿尔法     | 标准权力 | 仅对**协议 owner** 成立，对执行方/模块厂不成立          |
| **L3** | 商品化执行（通用液冷板、变压器、CDU、冷却介质、开关柜）                 | 隐性瓶颈（推荐）   | ⬜ 非阿尔法      | 秩序搬运 | 护城河薄，定价权弱——文章把这层当 Alpha 是错配            |
| **L4** | 显性龙头（博通、美光、Arista）                            | 显性共识（建议规避） | 🟨 周期受益     | 顺周期  | 文章说"避开"略激进，但定价确实已透支                    |

**核心一句话**：文章把"瓶颈"误当成"秩序"。**瓶颈是物理限制**（可以被工程化绕过，比如算法优化把 H800 用到极致），**秩序是权力**（竞争者无法复制的生成机制）。RockFlow 的框架是"经验主义的物理主义"——看起来很硬核、很底层，实际上把搬运秩序的环节（L3）误判为创造秩序，又把真正创造秩序的环节（L0）当作"已被定价"而规避。

## 一、这是什么

| 维度 | 内容 |
|---|---|
| 检验对象 | RockFlow 投研团队的 AI Capex 配置框架 |
| 赛道定义（我们的语言） | **不是"AI 基础设施投资框架"，是"一阶思维被定价后，从硬件链往物理瓶颈层下沉的避险叙事"**——本质是一种相对价值交易，不是秩序创造投资 |
| 阶段 | 共识形成期（2026 年中）：文章本身就承认"显性龙头已被充分定价"，所以这套框架是被市场逼出来的 |
| 数据快照 | 文章未给具体估值/数据，纯框架性论述 |
| 文章隐性假设 | **"设备已买完，现在的问题是如何让设备高效运转"**——这是用户在对话中识别出来的关键假设 |

**赛道定义拆解**：RockFlow 的真实逻辑链是——

> 半导体龙头已被定价 → 必须找未定价的环节 → 物理瓶颈看起来未定价 → 所以 Alpha 在物理瓶颈

这是一个"**相对价值寻宝**"逻辑，不是"**秩序生成判断**"逻辑。两者完全不同：前者问"哪里还有未被定价的边际"，后者问"谁在创造新的价值形态"。RockFlow 用前者伪装成后者。

## 二、秩序创造机器判定

这是整篇报告的心脏。我们要回答：**文章推荐的"物理瓶颈层"，本身是不是秩序创造机器？**

### 飞轮在不在转？

把文章推荐的环节一个一个拆：

**电力 / PPA / 微电网**：飞轮不在转。这是**双边议价市场**——发电方和云厂商签长期 PPA，本质是合同生意。发电资产不会因为 AI 越强而自己变强，它只是被需求推着走。没有"越用越好"的结构。

**液冷散热**：飞轮不在转。液冷是工程执行——冷板、CDU、管路、介质，都是成熟的工业品。技术迭代慢，竞争者多，没有数据/网络效应。

**SerDes / CXL / 光互连**：飞轮弱转。**协议 owner**（比如 CXL 联盟的核心发起方）有一点标准权力飞轮，但大部分"做接口芯片"的公司是工程执行方，飞轮不在它们身上。

**内存池化**：飞轮不在转。是架构升级，不是秩序升级——做 CXL 控制器的公司没有"用得越多越好"的结构。

**判定**：文章推荐的整层，**几乎没有一个环节是真正的秩序创造机器**。它们大多是"被需求拉着走的工程执行方"。

### 冲击后变强还是变弱？

这是关键测试。问一个问题：**如果算法效率突然提升一倍（比如 DeepSeek 又发了一篇论文），这一层是变强还是变弱？**

- L0（算法-芯片定义者）：变强。算法突破让他们的话语权更高。
- L1（核电 PPA / 电网接入）：基本不变。物理牌照的稀缺性不受算法效率影响。
- L3（通用液冷、变压器、冷却介质）：**变弱**。算法效率提升意味着单位算力能耗下降，对散热和配电的边际需求减弱。

也就是说，**文章主推的 L3 层，对算法进步是负暴露**。DeepSeek V3 那种 5% 成本做到 GPT-4 级别的突破如果再次发生，L3 是被吃掉的一方。

### 资源是被推过来的，还是自己来的？

- L0：自己来的。算法-硬件协同定义者吸引所有想追前沿的人主动靠拢（NVIDIA 的生态、DeepSeek 的开源影响力）。
- L1：半推半就。核电 PPA 是云厂商主动签的，但发电资产本身是被动接收方。
- L3：被推过来的。需要一家一家谈订单、一块一块建产能，纯执行。

**判定**：文章主推的层，资源是被推过来的，不是引力聚来的。

### 综合判定

**文章推荐的"物理瓶颈层"整体不是秩序创造机器。** 它是**秩序搬运机器**——把已经创造的算力秩序搬运到物理世界去落地。这是必要的工程，但不是 Alpha 来源。

## 增补判定：四个加强 L0 alpha 的视角

> 2026-07-25 用户对话补强——原报告聚焦"框架层"判定（文章 vs 我们的 L0-L4 错位）。本节从**地缘、时间、算法、理论**四个维度给 L0 alpha 加支柱，关闭四条可能的逃逸路径。四节互相支撑：任何单一维度被攻破，其他三个维度仍然成立。这是结构性 alpha 的真正含义。
> 引用框架：[[STRUCTURAL_CHANGE_BOTTLENECK]] 七步瓶颈测试 + [[CONSTITUTION]] G-06 不伪造确定性。

### 增补 1：华为卡批判——"用 L3 数量 + L2 标准模仿"伪造 L0

**现象**：华为 Ascend 910B/910C 纸面性能（FLOPS、显存带宽）接近 A100/H100，中文自媒体和部分卖方报告普遍描述为"国产替代突破""英伟达Equivalent"。这是当下最容易被误读为"L0 国产化"的叙事。

**真相三层拆解**：

| 维度 | 华为做法 | 实际含义 |
|---|---|---|
| **单卡** | 堆面积（更大的 die）、堆功耗、堆 HBM 容量换纸面 FLOPS | 单位晶体管效率远低于 NVIDIA——同样制程下算力密度落后 |
| **集群** | 靠堆数量补单卡效率差距 | 集群线性度差（万卡规模实际利用率显著低于 NVIDIA 集群），Scale-up 网络（对标 NVLink）落后一代以上 |
| **生态** | CANN 对标 CUDA | 框架支持少、迁移成本高、开发者社区薄——CANN 是兼容层，不是规则层 |

**框架映射**：在 5 层判定下，华为实际上是用 **L3（工程执行方数量：堆卡）+ L2（标准模仿：跟随 CUDA 接口）** 来伪造 **L0（秩序创造）** 的表象。这是典型的"秩序搬运伪装成秩序创造"。

**七步瓶颈测试采样**（[[STRUCTURAL_CHANGE_BOTTLENECK]] 七步）：

- **Control**：华为不控制 CUDA 替代协议的制定权。开发者用脚投票（主流框架 PyTorch / JAX / vLLM 仍以 CUDA 为一等公民），CANN 是兼容层而非规则层。规则制定权仍在 NVIDIA + AMD + Intel + Google TPU 联盟手中。
- **Pricing**：靠低价 + 政策采购撑毛利，不是靠技术不可替代性提价。NVIDIA H100 在缺货期毛利维持 75%+，华为 Ascend 在政策保护下毛利远低于此。
- **Duration**：一旦国产先进制程被卡（ASML EUV 受限、二手光刻机管控升级），稀缺期反而缩短——制造端没有自主可控的"第二来源"。

**结论**：国内仅靠华为 → **永远在 L0 之外**。"国产替代"的真实位置不在 L0，在 L3（卡数）+ L4（系统集成）。把"华为 Ascend 跑通千卡训练"等同于"L0 国产化"是层级的根本错配。

**对原报告的增益**：强化 L0 alpha 的地缘维度。如果国产替代的真实天花板在 L3/L4，那么 NVIDIA / TSMC 在 L0 的 alpha 持续期不受"国产替代叙事"威胁——所谓"被国产替代吃掉"的是 L3/L4 的执行方利润，不是 L0 的秩序权力。

### 增补 2：国产替代 2030 时间窗——给 L0 alpha 加时间维度

**制程链完整拆解**：

| 环节 | 当前格局 | 国产替代时间窗（保守估计） |
|---|---|---|
| ASML EUV 光刻机 | 荷兰 ASML 垄断，10+ 年研发周期 | 2030 前无法国产化（无 EUV 产能） |
| TSMC 2nm / A14 先进制程 | TSMC 垄断，客户已 locked in | SMIC 7nm 是上限，2nm 路径不通 |
| HBM4 / HBM5 | SK Hynix / Micron / Samsung 领先 2 代 | 国产 HBM 仍停在 HBM2e 水平 |
| 先进封装 CoWoS / SoIC | TSMC 垄断 90%+ | 国产封装在 PKG 工艺层，未到 CoWoS |
| 芯片设计架构（GPU/ASIC） | NVIDIA / AMD / Google TPU 18-24 个月迭代 | 华为 Ascend 单点追赶，架构代际落后 1-2 代 |
| 系统集成（整机柜、网络） | NVIDIA NVLink + InfiniBand + Spectrum-X 锁死 | 国产可用 SuperPod 范式，但生态封闭 |
| 应用部署（CUDA / Triton） | CUDA 深度锁定 | Triton / 国产编译器在追赶，但开发者迁移慢 |

**时间窗判定**：即使 2026 全力投入，到 2030 最多完成"**非先进制程**"国产化（28nm 及以上自主可控）；**先进制程（2nm 以下）+ HBM4+ + CXL 协议 owner** 仍在外部。

**框架映射**：这是 [[STRUCTURAL_CHANGE_BOTTLENECK]] 七步瓶颈测试的 **Duration 测试**——L0 的稀缺持续期 ≥ 4-5 年（保守到 2030）。

**对原报告"假设 1"退出信号的精度提升**：

- 原退出信号（性能侧）："主流大模型性能停滞 + NVIDIA 架构升级边际收益大幅递减 + DeepSeek 等创新者没有新突破"
- **新增并行退出信号（供给侧）**："国产先进制程在 2nm 以下突破 + 国产 HBM4 量产 + CXL 协议出现国产 owner"——若三个条件**同时**满足，L0 alpha 持续期判定下调

**关键约束**：性能侧退出信号和供给侧退出信号是"或"的关系——任何一个先到，都需要重新评估；但同时满足两个，才能彻底推翻 L0 alpha 判定。当前（2026-07-25）两个都远未触发。

### 增补 3：蒸馏天花板——中国大模型追赶的隐性闸门

**现状**：DeepSeek、Qwen、Kimi、智谱 GLM 等中国大模型在多个基准上逼近 GPT-4 / Claude 级别，部分评测声称超越。但底层方法论严重依赖**从 GPT-4 / Claude 蒸馏**——用 frontier 模型的输出当训练信号，让小模型 / 二线模型继承其能力。

**蒸馏通道的三个限制条件**：

1. **黑盒化加速**：OpenAI / Anthropic 持续收紧 API 输出限制（如 o1 系列 hide CoT），模型权重彻底封闭，reasoning chain 不可观测。
2. **范式迁移**：GPT-5/6 时代若大规模转向 test-time compute / RL inference / 隐式 reasoning，外部观察者无法从最终输出反推中间过程，蒸馏信号源衰减。
3. **数据枯竭 + 合成数据回流**：当 frontier 模型自身开始用合成数据训练，蒸馏出来的"学生模型"实际上是在学一个"自我强化"的分布，与 frontier 模型真正的能力增长路径脱钩。

**框架映射**：蒸馏是**秩序搬运**（搬运他人的推理分布），不是**秩序创造**（定义新的推理范式）。在 ljg-invest 视角下，蒸馏者永远落后秩序创造者一个代际——除非蒸馏者自己也成为秩序创造者。

**对 L0 alpha 的影响**：进一步强化。因为 L0 的真正秩序创造（CUDA + NVLink + 架构定义 + 制程联盟）**无法被蒸馏**，只能被跟跑。蒸馏天花板意味着中国 LLM 厂商在**算法层**也无法绕过 L0——他们蒸馏的是 L0 算法定义者产出的能力，而不是 L0 本身。

**与增补 2 的耦合（关键收口）**：

> **蒸馏天花板 + 国产替代时间窗 = L0 alpha 双重保险**
>
> - 国产算法即便追上来了，硬件还在外面（增补 2）
> - 国产硬件即便追上来了，协议 owner 还在外面（增补 1）
> - 算法 + 协议即便都被模仿了，秩序创造者已经跑到下一个范式（增补 3）
>
> 任何单一维度的"突破"都不构成对 L0 alpha 的颠覆——必须三个维度同时突破。

### 增补 4：工程累积 vs 天才突破——L0 alpha 的理论根基

> 用户原话（2026-07-25 对话）：
> > "大模型的设计和算力的设计...靠的不是人力和智力的密度...它重点是靠算力的集中度去试错弄出来的，是一种工程化的东西"

**这一节是理论补强，回答"为什么 L0 难以追赶"的底层问题**。

**论证链**：

1. **Scaling Law 是经验公式**（Hoffmann et al. 2022, "Training Compute-Optimal Large Language Models"），背后是**千亿美元级算力试错**堆积出来的统计规律——不是理论推导。
2. **任何人想验证新的 scaling 范式**（比如非 Transformer 架构、新 MoE 路由、新 RL 训练范式），**必须有同量级算力投入**——否则连"试错"的入场券都没有。
3. 这把 L0 的护城河从"**算法天才**"重新锚定为"**算力资本累积**"。算力资本累积是物理限制的——制程、封装、电力、土地、人——**无法被智商或人力密度替代**。

**反例检验**：

- **反例假设**：如果 L0 是天才游戏，那 DeepSeek 这样的小团队理论上可以靠算法创新追上。
- **实际情况**：DeepSeek V3 / R1 确实是算法突破，但他们的突破只能在**算法层**（L0 的一个子集），无法动摇**硬件层**。他们仍然跑在 H800 / H100 上，仍然依赖 CUDA。DeepSeek 的突破证明"L0 内部有子赛道"，但**没有打开逃逸 L0 的路径**。

**七步瓶颈测试采样**（[[STRUCTURAL_CHANGE_BOTTLENECK]]）：

- **Control**：NVIDIA / TSMC 控制的是"千亿美元级算力试错基础设施"——这是任何人难以复制的入口。即使有天才算法，也必须经过这个入口才能验证。
- **Duration**：算力累积的窗口期等于资本周期，至少 5-10 年。任何新进入者要从零积累到 NVIDIA / TSMC 当前的"试错预算存量"，需要至少一个完整资本周期。

**与原报告"资源是被推过来的还是自己来的"测试的强化**：

- **NVIDIA / TSMC 的资源是自己来的**：千亿美元 capex 自动流过去，因为别处没效率。资本家不是被政策推过去的，是被回报率拉过去的。
- **华为 / 国产厂商的资源是被推过去的**：需要政策（"国产替代"指令）、补贴（科研经费、税收优惠）、强制采购（央国企采购目录）、关税保护——一旦政策松动，资源立刻回流到效率更高的 L0秩序创造者。

这是"自己来的资源"和"被推过去的资源"的本质差别：前者是结构性引力，后者是政策性压力。压力可逆，引力不可逆。

### 四节合起来的综合增益

| 新角度 | 维度 | 关闭的逃逸路径 | 对原报告的增益 |
|---|---|---|---|
| 增补 1 华为卡批判 | **地缘** | "华为 Ascend 跑通千卡 = L0 国产化" | 给 L0 alpha 加地缘维度，明确"国产替代叙事"对 L0 无威胁 |
| 增补 2 2030 时间窗 | **时间** | "国产替代随时可能突破" | 给 L0 alpha 加时间维度，Duration 测试精度提升，新增供给侧并行退出信号 |
| 增补 3 蒸馏天花板 | **算法** | "DeepSeek 算法追上 = L0 失效" | 给 L0 alpha 加算法维度，关闭"算法创新绕过硬件"的逃逸路径 |
| 增补 4 工程累积 | **理论** | "天才团队可以小博大" | 给 L0 alpha 加理论根基，回答"为什么 L0 难以追赶"的底层问题 |

**核心收口**：四节合起来，把 L0 alpha 从"**一个判断**"变成"**四个维度互相支撑的判定**"——

- 增补 1 关闭**地缘逃逸**（华为伪造 L0）
- 增补 2 关闭**时间逃逸**（2030 前国产替代不可能完成）
- 增补 3 关闭**算法逃逸**（蒸馏到头）
- 增补 4 关闭**天才逃逸**（工程累积游戏无法靠智商跳过）

任何单一维度被攻破，其他三个维度仍然成立。这是结构性 alpha 的真正含义——**不是"暂时没人能追上"，而是"四条逃逸路径同时关闭"**。

## 三、创生公式

### 文章的公式

> Capex 增加 → 物理瓶颈显现 → 瓶颈环节获得定价权 → Alpha

这个公式有两处偷换：

1. **"瓶颈"≠"定价权"**。瓶颈是物理限制，定价权是商业权力。变压器供应紧张不等于变压器厂商有定价权——因为进入门槛不高，价格一涨新产能就涌入。
2. **"未被定价"≠"会涨"**。市场可能确实没给液冷公司高估值，但这是因为它们的生意质量本来就该低估值。低估值不是 Alpha，是合理定价。

### 正确的公式（我们认为）

> 算法-硬件协同定义新形态 → 新形态需要新设备/新协议/新电力形态 → **新形态的"定义者"获得秩序权力** → Alpha

举例说明：

- **DeepSeek 的公式**：算法创新 → 用 H800 训出 GPT-4 级模型 → 重新定义"什么是好的 AI 算法" → 倒逼硬件厂商适配 → DeepSeek 成为算法-硬件协同的规则制定者之一
- **NVIDIA 的公式**：架构定义（CUDA + NVLink + Blackwell）→ 软件生态锁定 → 每一代架构都重新定义"什么是高性能 AI 芯片" → 定价权来自秩序定义
- **核电 PPA 持有方（如 Vistra、Constellation）的公式**：拥有不可复制的物理资产 → AI 厂商被迫签长约 → **捕获 AI 需求的租金**

注意第三种公式——它是**租金捕获**，不是**秩序创造**。所以核电 PPA 是"半阿尔法"——它赚的是稀缺租金，不创造新秩序，但稀缺性是真实的。

### 公式验证度

- DeepSeek 的公式：验证过（V3 论文 + R1 推理突破）
- NVIDIA 的公式：验证过多次（Ampere → Hopper → Blackwell）
- 核电 PPA 的公式：验证中（Constellation 2024-2026 涨幅巨大，但尚未经历完整周期）
- 液冷/变压器公式：**未被验证**。历史上这类工业品公司的超额收益都是周期性的，不是结构性的

## 四、市场看见的 vs 我们看见的

### 它在 S 曲线的哪里？

这是文章最值得商榷的地方。它隐含说"物理瓶颈层在 S 曲线拐点前"。

**我们的判定**：

- L0（算法-芯片）：在 S 曲线**加速期**。每一代架构都在重新定义算力上限，远未见顶。
- L1（核电 PPA）：在 S 曲线**积累期向拐点过渡**。稀缺性正在被市场重估，但部分已反映在 Constellation 等股价里。
- L3（通用液冷/变压器）：在 S 曲线**平台期**。这是成熟工业品，只是被 AI 需求临时拉高，没有结构性跃迁。

**文章的错位**：把 L3（平台期被临时拉高的工业品）当成"拐点前的 Alpha 来源"，把 L0（加速期的秩序定义者）当成"已被定价的共识资产"——**S 曲线方向完全看反**。

### 市场在用什么旧眼睛看它？

文章用的是"**类比互联网泡沫后期**"的旧眼睛——认为显性龙头必然被定价、Alpha 必然在边缘。

这套旧眼睛在 2000 年互联网泡沫是对的，因为当时思科、英特尔确实被严重高估，Alpha 后来出现在 Google、Amazon 这些"边缘公司"。

但 2026 年的 AI 不是 2000 年的互联网。区别在于：

- 2000 年的"显性龙头"是硬件公司（思科卖路由器），它们没有飞轮
- 2026 年的"显性龙头"是**算法-生态定义者**（NVIDIA 的 CUDA、TSMC 的工艺联盟），它们有强飞轮

把 2000 年的相对价值框架套到 2026 年，是错把"硬件周期"当"秩序周期"。

### 三个认知折价信号检测

1. **需要很复杂的解释别人才能听懂？** 不是。文章的逻辑很顺滑，反而是顺滑得可疑——"共识太顺滑就是风险"这句自我描述，恰恰描述了它自己的逻辑。

2. **定价持续异常（部分之和 ≠ 整体）？** 部分（液冷公司、电力设备公司）之和确实不等于整体（AI 价值链），但方向反了——**整体的价值远大于这些部分之和**，因为价值在算法-芯片定义者那里，不在执行层。

3. **已有的类比全部失效？** 文章用了"卖水人"类比（淘金热里卖水的人赚钱）。这个类比**有效但不利于文章**——历史上"卖水人"的护城河其实很薄，淘金热一过就倒闭一批。真正的赢家是发明新淘金技术的人（相当于算法-芯片定义者）。

### 它控制了什么别人拿不走的东西？

- L0：控制算法/架构的**规则制定权**——别人拿不走
- L1：控制**物理位置和牌照**——别人难以拿走（这就是你说的"高压电设备比较重"，是物理稀缺性）
- L3：**不控制任何别人拿不走的东西**——液冷技术是公开的，变压器制造是成熟工业

### 它在搭哪趟便车？

坍缩的成本：

- **理解成本**坍缩：DeepSeek 这种突破让 AI 理解成本下降
- **协作成本**坍缩：开放协议（CXL、UCIe）让模块化协作成本下降
- **行动成本**坍缩：开源模型让部署 AI 的行动成本下降

L0 是**制造坍缩的人**——他们创造坍缩，捕获最大价值。
L3 是**搭便车的人**——他们因为坍缩而多卖了一些设备，但捕获的价值比例小。

文章主推 L3，等于推荐"搭便车方"而不是"制造坍缩方"。

## 五、换不换

### 对 RockFlow 文章的建议

**建议**：作为投资框架——**部分采纳，核心修正**。

**可采纳**：
- "显性龙头已被定价"的警示——可以降低博通、美光的预期超额收益
- "核电 PPA 是被低估的物理牌照"——这点我们同意（你之前选的 NLR ETF 就是这个逻辑）
- "Time-to-Power 是新的算力牌照"——这是一个真洞察，值得纳入

**必须修正**：
- 把 L3（通用液冷、变压器、冷却介质）当作"Alpha 来源"——**这是错配**。这层是周期受益，不是秩序创造，应该当作"顺周期交易机会"而非"长期 Alpha 持仓"
- 把 L0（算法-芯片定义者）当作"已被定价的共识"而规避——**这是更大的错配**。NVIDIA、TSMC、以及 DeepSeek 这种算法创新者，仍然是 Alpha 的主战场
- 没有区分"协议 owner"和"协议执行方"——SerDes、CXL 的真正受益者是标准 owner（比如 NVIDIA、AMD、Intel 这种协议核心方），不是做接口芯片的二线公司

**假设 1：算法-硬件协同仍在加速期，没到天花板**

- 性能侧退出信号：若未来 12 个月内出现"主流大模型性能停滞 + NVIDIA 架构升级边际收益大幅递减 + DeepSeek 等创新者没有新突破"——说明 L0 真的被定价完了，文章的"避开显性龙头"成立
- **供给侧并行退出信号（增补 2 新增）**：若"国产先进制程在 2nm 以下突破 + 国产 HBM4 量产 + CXL 协议出现国产 owner"三个条件**同时**满足——L0 alpha 持续期判定下调
- **退出逻辑**：性能侧和供给侧是"或"的关系，但同时满足两个才能彻底推翻 L0 alpha 判定

**假设 2：核电 PPA / 电网接入的稀缺性是结构性的，不是临时的**

- 退出信号：若美国/中国出现"核电审批大幅放开 + 电网升级政策性加速到 3-5 年完成"——L1 的稀缺性被政策稀释，半阿尔法降级为周期受益

**假设 3：液冷、变压器等 L3 工业品的护城河薄**

- 退出信号：若出现"某液冷或变压器公司形成全球垄断 + 毛利率持续 > 40% + 客户无法切换"——说明 L3 出现了真正的秩序创造者，需要重新评估

**一句话**：文章让你"站在物理世界，而非故事云端"，但正确的位置是**站在秩序创造源头，而非物理账单支付端**。
