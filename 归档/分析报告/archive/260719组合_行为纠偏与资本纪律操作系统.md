# 组合：行为纠偏与资本纪律操作系统 v3.1

## 先说人话

**今天发生了什么：**投资系统从“算出哪只最值得买”，升级为“先决定哪些动作根本没有资格发生”；同时补上宏观流动性的权限边界和“卖飞”复盘纪律。

**为什么重要：**连续下跌时容易把“赔率更高”偷换成“胜率更高”；市场上涨时又容易把“流动性更好”偷换成“公司更强”，再用 AI、宏观叙事和数学替动作找理由。

**现在该做什么：**任何风险增加动作先过业务、回报、路径和资本四道硬门；涉及宽松或增量资金时，再验收政策水到标的水的传导；没有新增经营证据，不升级，亏损后想加仓先停 24 小时。

> [!important] 本文是当前行为与资本纪律权威
> 旧报告中的固定权重总分、固定证据加分、强制填写单点概率和无总资本分母的“计划仓位比例”，不再拥有交易授权。

### 白话词典

- `thesis` 是投资假设；`OCF` 是公司日常生意真正流入的经营现金；`FCF` 是扣除资本开支后可留给股东的自由现金。
- `ROIC` 是公司每投入一元长期资本能赚回多少；`PE/PEG/DCF` 分别是利润倍数、利润倍数与增长速度的匹配、未来现金折回今天。
- `IV` 是期权价格里已经收取的波动预期；`Expected Shortfall` 是最差一小部分情景的平均损失。
- `Attention` 是注意力、仓位和资金拥挤，它主要改变路径，不等于公司经营改善。

## 一、系统唯一目标顺序

```text
1. 避免永久资本损失
2. 提高经营判断胜率
3. 控制错误时的损失
4. 获得合理赔率
5. 用少量、定义损失的资本购买右尾
```

后一项不能补偿前一项失败。

## 二、最主要的行为错误

```text
连续下跌
→ 想回本、怕错过反弹
→ 成本价替代未来价值成为参照点
→ 价格更低被写成胜率更高
→ AI补齐支持叙事，同根信息重复计票
→ 主观胜率和主观赔率同时上升
→ 接刀、补仓、改成长期仓、等待反弹才卖
→ 单票和风险簇失控
```

这叫“赔率劫持”。情绪本身不违规；情绪获得改变仓位的权限才违规。

## 三、四张票与六档动作

### 四张票

| 票 | 必答问题 | 价格能否直接更新 |
|---|---|---|
| 经营票 `H_B` | 公司或底层资产真的更赚钱吗，能否活到兑现 | 不能 |
| 赔率票 `H_R` | 当前全成本价格是否保留安全边际或净赔率 | 可以 |
| 周期票 `H_L` | 流动性、期限、杠杆、融资和个人现金是否允许等待 | 可以 |
| 仓位票 `H_C` | 资本桶、单票、风险簇和最大损失是否合法 | 不能由信心覆盖 |

风险增加要求四票全部通过。基金另加底层/经理/工具票，期权另加合约/IV/期限/最大损失票。

白话解释：好公司、好价格和可等待缺一不可；即使前三项都好，仓位会伤害组合生存时也不能买。

### 宏观流动性的权限边界

宏观与资金信号按 [[兴趣领域/股票投资/归档/基础概念/交易策略组合/260720投资框架_宏观流动性过滤器与认知退出纪律]] 处理：

```text
政策水 → 市场水 → 板块水 → 标的水
```

- 降息、信用宽松和权益资金流只有权限更新赔率票 `H_R` 与周期票 `H_L`，不能直接提高经营票 `H_B`；是否改善回报还取决于价格是否已经透支。
- 只看到政策宽松、没有权益和板块承接时，写“传导待验证”，不得写“增量资金已经进入标的”。
- 板块热度、高关注和事件后的流动性修复只改变路径与赔率；没有新增经营证据，不得触发 `升级确认仓`。
- 市场、板块和标的流动性共振恶化时，先冻结新增风险；是否 `降级或退出` 仍按事前失败条件与仓位票执行。

### 六档动作

`不投入 / 继续观察 / 建立验证仓 / 升级确认仓 / 不加仓 / 降级或退出`

- 任一硬门失败：`不投入`。
- 空仓且未来信息有价值：`继续观察`。
- 小仓本身已有稳健正价值，损失合法：`建立验证仓`。
- 新增独立经营证据收窄不确定性，资本仍合法：`升级确认仓`。
- 现有仓已满、模型分歧或路径不合法：`不加仓`。
- 目标仓低于当前仓或核心票失败：`降级或退出`。

## 四、资本宪法

### 1. 百分比的最终解释

```text
可投资资本 R
├─ H 高证据/价值职责：90%
│  ├─ 高证据资产
│  ├─ H-cash
│  └─ 生存流动性 S：默认至少 7%R
└─ O 赔率职责：资本暴露最多 10%R
   └─ 最大损失预算最多 3%R
```

`90/10` 管资本职责；`3%` 管赔率侧最大损失。90% 不是单笔“90%胜率”，也不要求始终投满。

### 2. 保守启动参数

| 参数 | 默认值 |
|---|---:|
| 生存流动性 | `≥7%R` |
| O 资本暴露 | `≤10%R` |
| O 滚动总最大损失 | `≤3%R` |
| O 单笔最大损失 | `≤0.5%R` |
| O 单一 thesis 最大损失 | `≤1%R` |
| H 单一个股暴露 | `≤10%R` |
| 宽基基金暴露 | `≤25%R` |
| 单一经济集群暴露 | `≤25%R` |
| H 单标的压力损失 | `≤5%R` |
| 单集群压力损失 | `≤12%R` |
| 组合经济暴露 | `≤100%R` |

滚动总最大损失 = 最近 12 个月已实现 O 损失 + 当前开放最大损失 + 新拟风险。盈利不能抵销已用损失预算。

白话解释：这是新风险的保守护栏，不是自动卖出现有仓位的命令。

未校准压力损失系数：宽基 35%；成熟盈利公司 50%；PEG、周期、行业基金 60%；未盈利、市梦率、事件股、买入期权 100%。

现有超限仓不自动卖出，但标记 `grandfathered_over_limit`：只允许减险或重新承保，不允许新增风险。

### 3. 仓位公式

```text
允许仓位上限
= min(
  单标的损失剩余额度 / 单位压力损失,
  风险簇损失剩余额度 / 单位共同损失,
  组合路径剩余额度 / 单位联合损失,
  压力期可退出量,
  资本桶剩余额度,
  工具合同最大损失
)
```

仓位上限不是目标仓位；不必为了用完额度而交易。

## 五、稳健目标函数

不再使用固定总分。决策顺序：

```text
证据合法
→ 工具和资本合法
→ H_B / H_R / H_L 全过
→ 多个合理模型下仍有正边际
→ 选择更简单、更可退出的表达
```

每个模型至少包含：永久损失、长期停滞、基准兑现、右尾兑现和强制退出/流动性情景；所有情景使用同一时间、币种和净成本。

每次必须逐项回答：胜率状态、胜率置信区间、潜在收益、最大下行、永久资本损失、模型误差、信息不完全、时间成本、流动性、仓位和尾部风险。关键项未知时不能取平均，动作缩到 `继续观察/不加仓`。

### 贝叶斯权限

- 未知不填 50%。
- 没有固定参考类、期限、结算规则和历史校准时，写 `uncalibrated`。
- 固定 `+15%`、固定 LR 和区间中点不授权交易。
- 同根事件只计一次。
- 价格只更新赔率票，不直接更新经营票。

## 六、不同资产如何判断“高证据”

| 资产 | 核心验证 | 不做什么 |
|---|---|---|
| 科技成长 | 付费客户/用量 → 收入 → 毛利 → 经营杠杆 → OCF/每股现金流 | 不因收入增长忽略摊薄和现金消耗；未盈利时不用精确 DCF |
| 周期/商品 | 有效供给 → 库存 → 实现价格－单位成本 → 毛利 → OCF | 不用峰值低 PE 判断便宜；不把恐慌采购当终端需求 |
| 消费 | 同店/复购 → 单位店经济 → 毛利 → FCF → 资本配置 | 不把授权渠道商当 IP 源头控制者；不因相对便宜忽略生意厚度 |
| 成熟企业 | 可重复现金流、ROIC、净负债、分红/回购/再投资 | 不把低估值自动当安全边际；只在内在价值没坏时谈越跌越买 |

白话解释：四类资产的“好”不是同一个好；成长看兑现斜率，周期看价差与供给，消费看复购和控制权，成熟企业看现金与资本回报。

## 七、禁止交易与完整重评

### 当日禁止增加风险

- 理由是“已经跌很多、想回本、怕错过、市场恐慌”；
- 不能离开 AI 讲清买什么、赚什么钱、为什么现在、错在哪里；
- 没有资本桶、失败条件、最大损失和下一验证数字；
- 主要证据是价格、Attention、AI 共识或同一新闻副本；
- 券商委托/成交状态未闭环；
- 当日违反纪律；
- 单票、风险簇或 O 预算超限。

### 完整重评触发

以下硬事件任一出现立即重评：财报/指引、客户取消、融资/增发、审计治理异常、基金经理或持仓漂移、异常赎回、周期价差/库存跳变、承诺节点逾期。

没有硬事件时，以下五类中任意两类共振也触发：相对异常跌幅、持续创新低、流动性异常、领先经营指标恶化、压力损失预算耗尽。

任何亏损后产生加仓冲动：冻结 24 小时；若价格异常与业务或流动性信号共振，升级完整重评。

重评不是自动卖出：只冻结新增风险，纯减险仍可执行。

## 八、冷静期与加仓纪律

| 情况 | 最短冷静期 |
|---|---:|
| 亏损后想加仓、抄底、卖 Put | 24 小时 |
| 组合路径损失触线或纪律违规 | 72 小时 |
| 核心经营数据缺失却想用价格替代 | 直到下一条独立硬证据 |
| 融资、审计、治理或工具突变 | 完整重评完成前 |

加仓必须同时满足：新增独立经营证据、保守价值下界未下降、周期票通过、资本预算有余量、新仓本身仍有正价值。价格下降不能单独触发加仓。

白话解释：冷静期拦的是冲动加风险，不拦撤单、平仓和其他纯减险。

## 九、最小心理训练

### 交易前 30 秒

1. 我现在是什么情绪？
2. 新增独立经营事实是什么？
3. 是否把价格、价值、胜率、赔率混在一起？
4. 错了最多损失总资本多少？
5. 没有 AI，我能否一句话解释为什么现在做？

答不清：`不投入/继续观察`。

### 暴跌后 5 分钟

```text
1分钟不下单、记情绪
→ 1分钟只写事实
→ 1分钟分 H_B/H_R/H_L
→ 1分钟算单票/集群/O预算
→ 1分钟从六档动作中选择，默认不加仓
```

### 交易后、每周、每月

- 交易后 2 分钟：冻结 thesis、三项验证数字、失败条件、最大损失和成交事实。
- 每周 15 分钟：随机复盘三次“做/不做”，写情绪到后果的因果链。
- 每月 20 分钟：只给纪律评分，不按盈亏评分。`≤6/10` 时进入 7 天 `research_only`。

### “卖飞”与不动纪律

- 卖出后继续上涨，不自动证明当时卖错；先检查当时冻结的 thesis、估值、路径和仓位票。
- 原 thesis 未坏，只因短期波动退出，记为流程问题；按事前失败条件正确退出，记为认知边界内的正确动作。
- “优质资产面前不要动”只有在四票持续通过时成立。任一票失败后继续不动，是主动承担风险，不是长期主义。
- 不因害怕卖飞而取消退出条件；也不因卖飞羞辱自己。复盘目标是修正规则，不是追求吃完整段行情。

### 悬置容器：训练“先不闭合”

当问题重要、信息未到齐、且没有立即降险要求时，允许主动悬置：

```yaml
question:
current_state: suspended
known_facts:
missing_evidence:
strongest_counterevidence:
next_review:
failure_condition:
allowed_action: 继续观察 | 不加仓
```

`suspended` 不是第七种交易动作；它在六档动作中映射为 `继续观察/不加仓`。它也不是拖延：必须写下缺失证据和复查时间。若失败条件、资本超限或退出规则已经触发，不能用“悬而未决”阻断 `降级或退出`。

## 十、GPT 反制协议

出现“跌很多、错杀、回本、梭哈、怕错过、别人不懂、市场恐慌、卖 Put 降成本、AI 都同意”等信号，GPT 自动先做反方审查。

必须先回答：

1. 最大三个漏洞是什么？
2. 哪些事实会证明我错？
3. 市场为什么可能是对的？
4. 我忽略了哪些未知信息？
5. 胜率真的提高了吗？
6. 赔率是否只是价格下降的视觉错觉？
7. 最坏代价和永久损失是什么？
8. 潜在收益值得风险吗？
9. 有没有风险更低的同观点表达？

最后才讨论是否投资。GPT 有研究权、反对权和纪律提醒权，没有仓位修改权、参数修改权和交易授权。

## 十二、不做清单

1. 不让价格下跌提高业务概率。
2. 不在亏损后改头寸角色。
3. 不用固定权重和主观 EV 掩盖硬门失败。
4. 不把未知写成 50%。
5. 不重复计算同根证据和 AI 共识。
6. 不用 DCF 包装市梦率，不用峰值 PE 处理周期。
7. 不把市梦率、PEG、周期资产当成熟价值越跌越买。
8. 不让同一 thesis 跨工具、账户重复下注。
9. 不裸卖、不依赖 Roll 才能安全。
10. 不为“获得关注权”买信息费仓位。
11. 不因错过上涨否定当时正确的不行动。
12. 不因最终盈利原谅违规流程。
13. 不在成交未确认时更新主账。
14. 不让 AI 成为交易授权者。
15. 证据不足时，不行动就是正确动作。
16. 不用宏观宽松和板块热度提高经营票。
17. 不用卖出后的最高价评价当时流程。
18. 不用一天反弹取消价格纪律、冷静期或资本约束。
19. 不用绝对成交额阈值授权风险增加。
20. 不因识别出被迫卖方，就假定卖压已耗尽或市场必然错。
21. 不把服务器 DRAM、HBM、消费 DRAM 与 NAND 合并成同一个永久周期。

## 一句话总纲

> 用价值决定方向，用供求理解利润，用利率识别环境，用 Attention 判断路径，用贝叶斯修正可校准信念，用资本纪律限制错误，用持续反馈训练直觉；当证据不足时，最正确的投资动作就是不行动。
