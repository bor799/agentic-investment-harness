# Micron Next Questions

## 高优先级（影响分类）

### 1. 毛利率峰值判断
- **问题**: 80%毛利率是否已接近峰值？历史上内存周期毛利率峰值后通常如何回落？
- **验证方式**: 季度毛利率趋势（Q3指引80%→Q4是否维持）、DRAM/NAND ASP环比变化、行业产能投放节奏
- **判断影响**: 毛利率连续两季下降 → 周期顶部确认 → 分类可能从"观察上档"下调

### 2. TurboQuant/AI压缩技术影响
- **问题**: Google TurboQuant等压缩技术能多大程度降低AI模型内存需求？是短期噪音还是结构性威胁？
- **验证方式**: 主力AI模型（GPT/Claude/Gemini）实际内存消耗趋势、压缩算法采纳率
- **判断影响**: 如果模型压缩使内存需求增速从2x/年降至1.2x/年 → 长期需求叙事弱化

### 3. 产能投放时间表 vs 需求曲线
- **问题**: 爱达荷(2027年中)/纽约(2028下半年)新厂投产后，供给能否追赶需求？供需缺口何时弥合？
- **验证方式**: 季度产能利用率、ASP趋势、客户满足率变化
- **判断影响**: 客户满足率从50-67%升至>90% → 短缺缓解 → 定价权削弱

## 中优先级（影响评分）

### 4. HBM vs 标准DRAM收入占比
- **问题**: HBM收入占比多少？如果HBM占比>30%，则结构性转变更可信
- **验证方式**: 财报分部披露、投资者日
- **判断影响**: HBM占比持续上升 → 从周期股向成长股估值切换

### 5. 三寡头竞争动态
- **问题**: SK Hynix(72%营业利润率)和Samsung的扩产速度？市场份额变化？
- **验证方式**: 竞争者季度财报、HBM产能分配
- **判断影响**: Micron份额下降 → 护城河不如预期

### 6. 长期合约价值
- **问题**: 新签5年合约的具体条款？收入锁定比例多少？
- **验证方式**: 财报电话会、投资者日披露
- **判断影响**: 长期合约覆盖>50%产能 → 周期下行保护更强
