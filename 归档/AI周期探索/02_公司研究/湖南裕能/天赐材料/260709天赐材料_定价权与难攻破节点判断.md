# 天赐材料：定价权与难攻破节点判断

## 一句话结论

**天赐材料没有绝对定价权，但有阶段性、条件式、相对定价权。**

它不是“我想涨价客户就必须接受”的垄断节点；它更像是：

> 当电芯和储能需求上来、六氟/电解液有效产能接近满产、客户担心断供时，天赐能凭一体化、认证、保供和规模，把价格波动转成更强的价差、份额和利润弹性。

所以它不是最硬的“长期收费权”，但在这一轮锂电材料链修复里，它是最值得盯的“价差放大节点”之一。

## 定价权要分三层

| 层级 | 含义 | 天赐当前状态 |
|---|---|---|
| 绝对定价权 | 不管行业供需如何，都能持续涨价并保持客户 | **没有** |
| 相对定价权 | 行业紧平衡时，比同行更能提价、守价差、拿订单 | **有，正在验证** |
| 成本/价差控制权 | 原料波动时，凭自供和一体化把成本涨幅压住，或把价格回落留成利润 | **有，但要看 H1/H2 财报确认** |

如果说“天赐有定价权”，必须说清楚是第二层和第三层，而不是第一层。

## 它控制了什么

天赐控制的不是单一电解液产能，而是一个组合节点：

```text
LiPF6 / LiFSI / 添加剂 / 溶剂
-> 配方和工艺
-> 电解液
-> 客户认证
-> 长协保供
-> 区域交付
```

这个节点难攻破，原因有五个：

1. **材料不是普通化工品。** 电解液直接影响电池安全、一致性、循环寿命和快充表现，进客户供应链需要认证。
2. **客户怕断供。** 储能和动力电池排产上行时，客户不只是买便宜货，而是买确定交付。
3. **天赐有溶质自供。** 旧框架里记录，港交所申请版本披露公司 LiPF6 自供比例约 `99%`，LiFSI 自供比例约 `97%`。
4. **规模和长协形成供应秩序。** 公司 H1 预告披露上半年电解液出货同比超 `40%`，6 月电解液和六氟产能利用率接近满产。
5. **产能重配更贴近客户。** 南通低进度项目终止，福鼎等现有基地改扩建，本质是用更低资本开支、更短交付半径服务确定订单。

这说明天赐不是靠“产能多”难攻破，而是靠“关键原料 + 配方认证 + 交付稳定 + 长协关系”难攻破。

## 但为什么还不能说强定价权

反证也很硬：

1. **下游电芯厂议价强。** 宁德、比亚迪、中创新航、国轩等客户规模大，多供体系成熟，不会轻易把利润让给材料商。
2. **长协多数锁量，不锁利润。** 框架协议保障供应资格和出货可见度，但具体价格、采购量、规格仍要靠订单。
3. **行业名义产能仍多。** 总产能过剩没有完全消失，真正稀缺的是有效产能、认证产能、六氟/添加剂配套和交付能力。
4. **公司自己的项目可研也偏谨慎。** 福鼎 `25 万吨`电解液项目预计年均收入 `38.76 亿元`、净利润 `1.59 亿元`，净利率约 `4.1%`。这说明新增产能不是天然高利润池。
5. **H1 预告还没有现金流。** 预告证明 Q2 利润没有塌，但没有证明经营现金流、应收、存货和单吨利润质量。

所以它不是“强垄断定价权”，而是“紧平衡时的价差控制权”。

## 这个节点是不是最难攻破

在电解液链条里，**天赐是最难攻破的一类节点**。

但在整个电力系统重构链里，它不是最难攻破的节点。核能、电网核心设备、特高压、部分电芯龙头的系统地位可能更硬。

更精确的排序：

| 范围 | 天赐位置 |
|---|---|
| 普通电解液产能 | 明显难攻破 |
| 电解液 + 六氟 + LiFSI 一体化龙头 | 顶级节点之一 |
| 整个锂电材料链 | 强节点，但不唯一；隔膜、部分高端正极也有壁垒 |
| 整个电力系统重构 | 不是最硬节点，更适合作为高弹性材料修复标的 |

因此，天赐的投资价值不是“最硬”，而是：

> 它足够难攻破，又足够周期化，所以当市场恐慌时会给出波动机会；当供需紧平衡时，利润弹性比很多更硬但更稳的节点大。

## 如果它有定价权，应该看到什么

不能靠口号判断。要看这七个信号：

| 信号 | 说明 |
|---|---|
| 电解液售价不跟随碳酸锂/六氟快速下跌 | 成本跌但售价稳，价差扩大 |
| 六氟、电解液价格上涨时出货不降 | 客户接受更高价格 |
| 长协能调价 | 不是只在小额现货涨价 |
| 产能利用率接近满产 | 供应商从求订单变成筛订单 |
| 毛利率守住 `30%-33%`以上 | 报表确认价差 |
| 经营现金流转正 | 利润不是只变成应收账款 |
| 新项目实际吨利高于低利润可研 | 证明扩量不是薄利抢份额 |

其中最关键的是：

```text
价差 = 电解液售价 - 六氟/溶剂/添加剂/制造/折旧成本
```

碳酸锂下跌不是直接利空天赐。真正的问题是：

```text
售价跌得比成本慢？
成本跌了但售价稳？
产能利用率上升摊薄固定成本？
```

如果答案是是，天赐就有相对定价权。  
如果售价跟着原料一起下跌，吨利不扩，所谓定价权就是幻觉。

## 当前判断

截至 2026-07-09，证据状态是：

- **正证据**：H1 预告归母净利 `27-30 亿`；Q2 隐含 `10.46-13.46 亿`；出货同比超 `40%`；电解液和六氟产能利用率接近满产；Q3 排产预计环比增长。
- **反证/约束**：福鼎项目可研净利率约 `4.1%`；行业过剩没有完全消失；H1 现金流和应收存货未披露；下游客户仍有强议价能力。

所以判断是：

> 天赐已经证明自己是电解液链条里更难被替代的供应秩序节点；但它还没证明自己拥有穿越周期的强定价权。当前可买的是“紧平衡下价差扩大的波动权”，不是“永久收费权”。

## 3/4 季度缺货剧本怎么验证

你提出的关键判断是：

```text
二季度可能是今年较弱季度；
三四季度如果 LFP 排产继续上、六氟库存开始下降，
就可能从“紧平衡还能买到”切换成“缺货买不到”。
```

这个剧本成立时，定价权会发生质变：

| 状态 | 买方行为 | 价格状态 | 天赐权力 |
|---|---|---|---|
| 紧平衡 | 还能买到，压价仍存在 | 区间波动 | 相对定价权 |
| 缺货 | 不补库就断供 | 价格跳升 | 阶段性强定价权 |
| 补库 | 客户提前锁量 | 订单增速高于物理需求 | 价差和利润放大 |

这就是周期股里最关键的一跳：**不是需求增长，而是买方心理从“买便宜”切换成“买得到”。**

### 已核证据

- 天赐 H1 预告披露：截至 2026 年 6 月，公司电解液和六氟磷酸锂产能利用率接近满产；预计 Q3 电解液排产环比进一步增长。
- 天际股份 `1.5 万吨/年`六氟磷酸锂二期项目进入试生产阶段，主流转载称公司年产能将从 `3.7 万吨`增至 `5.2 万吨`。但试生产到正式达产、稳定供货仍需要时间。
- 六氟磷酸锂具备库存周期短、储存要求高的属性。旧研报和行业报道均反复提到库存低时价格弹性会很强。

### 待核证据

以下数字很关键，但我暂时没有找到官方/主流公开源直接确认，不能当成铁证：

| 口径 | 当前处理 |
|---|---|
| 六氟行业产能利用率 `98.68%` | 待核；若成立，说明行业接近物理上限 |
| 磷酸铁锂开工率 `97%` | 待核；若成立，说明 LFP 对六氟的需求拉动进入高压状态 |
| 7 月中开始六氟库存下降 | 待核；需要 SMM/鑫椤/CBC/百川等连续周度库存或交期数据 |
| 2027 年六氟仍紧缺 | 只能作为情景，不能作为结论；需新增供给表和需求表逐季校验 |

### 天际 1.5 万吨影响为什么不必过度放大

年产 `1.5 万吨`折算周产能约：

```text
15000 / 52 ≈ 288 吨/周
```

如果行业真的进入满产和补库状态，这个新增量未必能立刻压住价格，原因有三点：

1. **试生产不是满产。** 从试生产到稳定达产、客户认证、批量供货需要时间。
2. **周度边际供给不大。** 对高排产阶段的全行业需求而言，`288 吨/周`只是边际缓冲。
3. **缺货时看有效供给，不看名义产能。** 客户要的是可认证、可稳定交付、质量一致的六氟，不是 PPT 产能。

但也不能忽视它。若需求斜率放缓，或其他新增产能同时释放，天际这类边际供给会重新压制价格。

## 定价权的最终判别式

天赐到底有没有定价权，不看股价，也不看“龙头”两个字，看下面这个式子：

```text
定价权强度
= 需求排产斜率
× 六氟/电解液库存下降
× 有效产能利用率
× 客户补库意愿
× 天赐自供和长协份额
- 新增供给释放速度
- 下游电芯厂压价能力
```

如果三四季度出现：

```text
LFP / 储能排产继续上行
+ 六氟库存连续下降
+ 六氟和电解液交期拉长
+ 天赐出货不降、毛利率不降
+ 经营现金流转正
```

那就可以把天赐从“相对定价权”上修为“阶段性强定价权”。

如果出现：

```text
排产上行但六氟价格不涨
或六氟涨但电解液售价传导不动
或出货增长但毛利率/现金流下降
```

那说明所谓缺货只是叙事，天赐仍是周期加工股。

## 投资含义

1. **可以参与波动仓。** 因为节点难攻破，市场把它当普通周期品杀跌时，容易出现错价。
2. **确认仓要等价差。** 正式 H1 毛利率、现金流、应收和存货决定它是不是从周期弹性升级为结构权力。
3. **不能用“龙头”替代定价权。** 龙头只说明份额，价差扩大才说明权力。
4. **最强买点来自“原料跌但价差稳”。** 如果碳酸锂/六氟波动导致股价杀跌，但电解液售价和毛利率没有破坏，这是好机会。
5. **最危险的反证是“满产低利润”。** 如果接近满产但净利率、现金流和吨利都弱，说明它只是在薄利跑量。
6. **最大的上修来自“买不到”。** 一旦六氟从紧平衡进入缺货，定价方式会从成本加成切到保供溢价。

## 最后一句

天赐不是“想涨价就能涨价”的垄断者，而是锂电材料链里少数能在紧平衡时把原料、配方、认证、保供和长协组织成价差弹性的节点；这不是永久定价权，但足够构成一轮周期修复里的好交易。
