# 天赐材料：暴跌后的买点与双层结构判断

## 执行摘要

**结论：49 元附近已经进入“可以建立小观察仓”的区域，但还不是高置信度的一次性重仓买点。**

今天的下跌包含两个不同层面的信息：

1. **一级产业结构在被重新定价。**公司一边终止南通 `24.3 万吨`项目，一边把资金改投福鼎 `25 万吨`电解液项目。它不是退出扩产，而是把低效率、远离客户、工艺可能过时的产能换成靠近长协客户的区域产能。这证明需求和龙头份额仍强，也证明行业总供给没有真正锁死。
2. **二级市场发生拥挤交易出清。**天赐不是孤跌，新宙邦、瑞泰新材、多氟多、永太科技、天际股份同步大跌；此前天赐融资余额处于近一年高位，7 月 1—2 日又连续放量上涨。周末公告把“高增长”重新解释为“低利润守份额”，成为去杠杆和获利盘兑现的触发器。

但这不是现货崩盘日。`2026-07-06` SMM 口径下，磷酸铁锂用电解液均价为 `2.79 万元/吨`、日涨 `300 元`；国产六氟磷酸锂主流均价 `10.25 万元/吨`、日内持平，六氟指数小跌约 `0.32%`。因此今天股价跌幅主要来自 **远期利润率和估值预期下修**，而不是当天产品价格突然恶化。

对买点的判断：

- **激进策略**：`47—49 元`只适合投入计划仓位的 `10%—20%`，定义为观察仓，不把触及跌停当成见底证据。
- **赔率更好的左侧区间**：`42—45 元`，前提是行业价格没有出现新的持续下杀。
- **胜率更高的右侧买点**：等 H1/Q2 报表确认，哪怕届时股价高于 50 元。要求 Q2 归母净利润不低于 `10—12 亿元`、毛利率维持 `30%—33%`以上、H1 经营现金流转正，应收和存货不再快于收入。
- **暂停加仓**：Q2 毛利率低于 `28%`、Q2 归母净利润低于 `8—10 亿元`、经营现金流继续为负，或长协扩量同时单吨利润和回款恶化。

信心水平：**中等偏低**。当前价格改善了赔率，但决定全年利润中枢的 Q2/H1 数据尚未披露。

## 一、今天到底发生了什么

### 1. 盘面事实

`2026-07-06`：

| 指标 | 数据 | 含义 |
|---|---:|---|
| 前收 | `54.04 元` | 周末公告前定价 |
| 开盘 | `52.20 元` | 低开约 `3.40%` |
| 最高 | `52.79 元` | 开盘后没有形成有效反攻 |
| 最低 | `48.64 元` | 触及当日跌停价 |
| 收盘 | `49.00 元` | 跌 `9.33%`，收盘仍靠近日内低位 |
| 成交额 | `57.45 亿元` | 约等于近 20 个交易日日均成交额 `57.80 亿元` |
| 换手率 | `7.50%` | 活跃，但不是极端放量出清 |
| 总市值 | 约 `998.9 亿元` | 当日蒸发约 `102.7 亿元` |

开盘只低开约 `3.4%`，随后在连续交易中被卖到跌停，说明这不是集合竞价阶段的一次性错误定价。收盘没有封死跌停是边际正面，但成交额并未显著超过近期均值，且收盘靠近日内低点，不能据此判断恐慌已经出清。

### 2. 它不是孤立的公司闪崩

| 标的 | 2026-07-06 涨跌 |
|---|---:|
| 天赐材料 | `-9.33%` |
| 新宙邦 | `-4.31%` |
| 瑞泰新材 | `-6.32%` |
| 多氟多 | `-7.05%` |
| 永太科技 | `-7.75%` |
| 天际股份 | `-5.94%` |
| 宁德时代 | `-1.44%` |
| 湖南裕能 | `-0.01%` |
| 创业板指 | `-1.77%` |
| 上证指数 | `-0.06%` |

电解液和六氟磷酸锂相关标的集体下跌，而电芯龙头和 LFP 正极龙头明显更稳。市场卖的是“电解液/六氟高利润弹性”这一组预期，天赐又叠加自身公告冲击。

证券时报按行情软件成交分类口径统计，天赐当日主力净流出约 `8.39 亿元`。这类数据不能识别真实机构账户，但可以说明大额主动卖盘显著。

### 3. 直接触发器是两份公告的组合，而不是单份公告

周末两份公告合起来形成一个矛盾信号：

**第一份：终止南通 `24.3 万吨`项目。**

- 原计划总投资 `26.54 亿元`；
- 截至 `2026-06-30`，在建工程余额只有约 `936 万元`，没有开展实质性建设；
- 公司明确承认：2023 年下半年以来头部厂商和新进入者集中扩产，下游需求不及预期，行业供需错配、竞争加剧、价格下降，板块盈利受挤压；
- 公司认为溧阳现有 `20 万吨`产能靠近核心客户，技改扩建比南通新建产线资本效率更高。

**第二份：改投福鼎 `25 万吨`电解液项目。**

- 总投资约 `5.98 亿元`，建设期 `18 个月`；
- 达产后预计年均收入 `38.76 亿元`、年均净利润 `1.59 亿元`；
- 粗算项目净利率约 `4.1%`、单位净利润约 `638 元/吨`；
- 公司称自 2025 年四季度以来，已与部分核心电池企业签订覆盖 `2026—2030`年的 `3—5 年`长协，现有产能难以满足订单交付。

多头看到的是：砍掉低效项目、降低资本开支、靠近客户、锁定订单。

空头看到的是：行业仍过剩，龙头仍在扩产，新项目利润率很薄，长协可能锁住销量却锁不住利润。

今天市场主要交易了第二种解释。

### 4. 百亿市值损失不是项目本身的直接价值损失

从 `54.04 元`跌至 `49.00 元`，按约 `20.39 亿股`粗算，市值减少约 `102.7 亿元`。这远高于福鼎项目预计年均净利润 `1.59 亿元`，也不能由尚未实质建设的南通项目减值解释。

因此，今天不是在计算“一个项目少值多少钱”，而是在重新计算：

```text
Q1 的高利润率究竟是全年新中枢，
还是原材料与产品价格错配下的单季高点？
```

## 二、一级产业结构：需求很强，但供给没有锁死

### 1. 需求端：量的确定性明显高于价的确定性

公司公告引用 EVTank 数据：

- 2025 年全球电解液出货 `240.2 万吨`，同比 `+44.5%`；
- 中国出货 `223.5 万吨`，占全球 `93.05%`；
- 预计 2026 年全球出货突破 `300 万吨`；
- 预计 2030 年达到 `511 万吨`。

天赐 2025 年出货 `72 万吨`、市占率 `32.2%`，连续十年全球第一；天赐、比亚迪自产自用、新宙邦三家合计市占率约 `60%`。

这说明：

- 动力电池和储能带来的物理需求是真实的；
- 天赐作为头部供应商，长协、客户认证、区域交付和一体化能力使其更可能提高利用率；
- 但需求增长首先确保的是出货，不自动确保吨利。

### 2. 供给端：不是退出，而是从低效率产能转向高效率产能

南通终止 `24.3 万吨`，福鼎新增 `25 万吨`，名义规模几乎相当。差异在于：

```text
远离客户、资本开支高、工艺可能过时的综合项目
→ 靠近核心客户、区域配套、以现有产业集群为基础的电解液产能
```

这是资本纪律改善，但不是全行业供给收缩。

同时，新宙邦、永太科技等同行也在扩产或获得长协订单。大客户通过多供应商、长协和区域配套降低供应风险，也增强了采购议价权。

行业呈现一个看似矛盾但很关键的结构：

> **市场份额向头部集中，不等于产品价格由头部决定。**

原因是电解液主体产品仍可扩产，下游电芯客户体量大且倾向多供，长协通常首先锁量，未必给供应商锁定最低价和最低吨利。

### 3. 天赐的真正优势是什么

天赐的优势不是“普通电解液天然稀缺”，而是四件事的组合：

1. 电解液配方、客户认证和协同开发；
2. 六氟磷酸锂、LiFSI、VC、FEC 等核心材料的高自供；
3. 规模化采购、生产和副产物循环带来的成本优势；
4. 靠近核心客户的区域交付与长协能力。

这些优势可以让天赐在价格战中活得更好、抢到更多份额，但只有当 **价差、单吨利润、经营现金流** 同时改善时，才说明优势转化成了股东利润。

### 4. 今天现货没有证实“利润突然崩塌”

SMM `2026-07-06`公开报价：

| 产品 | 均价 | 日变化 |
|---|---:|---:|
| 磷酸铁锂用电解液 | `27,900 元/吨` | `+300` |
| 铁锂储能用电解液 | `27,000 元/吨` | `+300` |
| 国产六氟磷酸锂主流价 | `102,500 元/吨` | `0` |
| SMM 六氟磷酸锂指数 | `98,065 元/吨` | `-310.5` |
| VC | `160,000 元/吨` | `+4,000` |
| FEC | `67,500 元/吨` | `+2,000` |

所以今天的核心不是现货价格，而是市场担心：

```text
未来新增销量
× 低于预期的单吨利润
× 更高的资本投入和回款占用
```

## 三、二级市场情绪：拥挤交易遇到利润叙事反转

### 1. 暴跌前仓位并不干净

`2026-07-01`，天赐上涨 `5.91%`，成交额 `81.20 亿元`，融资买入 `9.93 亿元`、融资净买入 `1.21 亿元`。当日融资余额约 `45.09 亿元`，处于近一年 `90%`分位以上。

这意味着周末公告出现时，盘面上已经积累了：

- 高融资余额；
- 7 月初材料板块轮动形成的短线获利盘；
- 对 Q1 高利润可持续的乐观预期；
- 对长协和扩产的单向看多解释。

公告没有让需求消失，但把“长协扩量”重新解释成“低毛利守份额”，足以触发拥挤仓位松动。

### 2. 今天不是典型的最终恐慌日

支持“可能出现短线反弹”的信号：

- 盘中触及跌停后打开；
- 收盘没有封死；
- 49 元接近 6 月中旬以来的密集交易区。

不支持“已经见底”的信号：

- 收盘仍接近日内最低价；
- 成交额只约等于近 20 日平均，没有出现显著放量换手；
- 同产业链多只股票同步大跌，说明板块风险偏好仍在收缩；
- 天赐此前融资余额高，去杠杆可能不止一个交易日完成。

因此，明天是否反弹并不重要。真正重要的是未来 `3—5` 个交易日能否做到：

- 不再创新低；
- 跌幅和成交额同时收敛；
- 天赐相对新宙邦、多氟多的超额跌幅停止扩大；
- 现货价格没有转为连续下跌。

## 四、财务链：利润很好，但现金质量仍待确认

按统一链条看：

```text
收入
→ 直接成本
→ 毛利
→ 经营费用
→ 经营利润
→ 净利润
→ 现金流
→ 估值
```

### 1. Q1 的强证据

2026Q1：

- 营收 `66.73 亿元`，同比 `+91.29%`；
- 归母净利润 `16.54 亿元`，同比 `+1005.75%`；
- 扣非归母净利润 `15.60 亿元`，同比 `+1062.23%`；
- 按收入和成本粗算毛利率约 `38.65%`。

这证明量价和一体化利润弹性真实存在。

### 2. Q1 没有证明的事

- 经营现金流仍为 `-0.21 亿元`；
- 应收账款由年初 `68.80 亿元`升至 `95.81 亿元`，增长 `39.26%`；
- 存货由 `16.19 亿元`升至 `22.82 亿元`，增长 `40.94%`；
- 当季包含约 `0.8 亿元`商业秘密赔偿等非经常性因素；
- Q1 的产品和原料价差未必能全年维持。

利润已经进报表，但利润转成现金的速度还没有同步证明。

### 3. 新项目的 `4.1%`净利率为何刺眼

福鼎项目预计：

```text
年均收入 38.76 亿元
年均净利润 1.59 亿元
净利率约 4.1%
```

它与 2026Q1 公司整体约 `24.7%`的归母净利率差距巨大。两者口径和周期并不完全可比，新项目可研也可能偏保守，但市场会自然追问：

> Q1 是公司中枢，还是新项目的薄利率更接近行业长期常态？

这正是 8 月半年报必须回答的问题。

## 五、估值：49 元不是 15 倍静态 PE

按当日总市值约 `998.9 亿元`计算。

### 1. 容易误导的“15 倍 PE”

若把 2026Q1 归母净利润 `16.54 亿元`简单乘四，全年约 `66.2 亿元`，对应约 `15.1 倍` PE。这是行情软件常见的“动态 PE”口径。

但 Q1 是单季高利润，直接年化隐含四个季度都能复制同样价差和利润率，不能当作已实现估值。

滚动口径粗算：

```text
2025 全年归母净利润 13.62 亿元
+ 2026Q1 归母净利润 16.54 亿元
- 2025Q1 归母净利润 1.50 亿元
= TTM 归母净利润约 28.66 亿元
```

对应 TTM PE 约 `34.8 倍`。

### 2. 情景估值

| 2026 年归母净利润情景 | 49 元对应 PE | 解释 |
|---|---:|---|
| `20 亿元` | `49.9x` | Q1 基本是高点，明显昂贵 |
| `30 亿元` | `33.3x` | 利润快速回落，仍不便宜 |
| `45 亿元` | `22.2x` | 中性修复，开始合理 |
| `55 亿元` | `18.2x` | 较强修复，已有一定赔率 |
| `65 亿元` | `15.4x` | Q1 高景气大体延续，较有吸引力 |
| `75 亿元` | `13.3x` | 乐观情景，价格明显便宜 |

因此，49 元是不是好买点，不取决于今天跌了多少，而取决于：

> 你是否有足够证据相信公司 2026 年归母净利润至少能达到 `45—55 亿元`，并且利润可以转成现金。

截至今天，证据只完成了一半：Q1 利润很强；Q2/H1 的持续性和现金质量未确认。

## 六、买入决策

### 1. 我的判断

**不建议把今天定义为“一次性重仓的黄金坑”。**

更准确的定义是：

> 价格已经从情绪乐观区回到可以用小仓位换取跟踪权的区域，但基本面仍停留在“利润待验证”，二级市场也没有出现明确的恐慌出清完成信号。

### 2. 三种买法

#### A. 激进左侧

- `47—49 元`；
- 只投入计划仓位的 `10%—20%`；
- 目标不是抄最低点，而是建立观察仓；
- 若连续两日仍创新低，不机械补仓。

适合：能接受个股继续回撤 `15%—20%`，并愿意跟踪产品价格、财报和现金流的人。

#### B. 赔率左侧

- `42—45 元`；
- 相当于总市值约 `856—917 亿元`；
- 在 `45—55 亿元`利润情景下，对应约 `19—20 倍 / 16—17 倍` PE；
- 前提是六氟和电解液没有形成持续跌价，行业需求没有被证伪。

这一带比 49 元提供更像样的安全垫，但不能只因价格到了就买，仍要检查现货和订单。

#### C. 证据右侧

不预设价格，等 `2026-08-21`半年报或更早的业绩预告。

升级确认仓必须同时满足：

- Q2 归母净利润 `≥10—12 亿元`；
- Q2 毛利率 `≥30%—33%`；
- H1 经营现金流转正；
- 应收和存货增速低于收入增速；
- 六氟、电解液价差未持续收缩；
- 长协订单能说明定价联动、执行量或最低采购约束。

如果这些条件成立，即使股价重新回到 52—56 元，买到的也是更高胜率，而不是更差交易。

### 3. 如果已经有仓位

- 小仓：不因单日暴跌恐慌清仓，也不立即补成重仓；
- 中等仓位：把 H1 财报当作是否继续持有的硬闸门；
- 已重仓：首要问题不是猜明天反弹，而是把仓位降到即便跌到 40—42 元也不会被迫卖出的水平。

## 七、失败条件与待验证信号

### 硬失败条件

- Q2 毛利率低于 `28%`；
- Q2 归母净利润低于 `8—10 亿元`；
- H1 经营现金流继续为负；
- 应收和存货继续显著快于收入增长；
- 长协扩量但单吨利润、回款质量恶化；
- 六氟磷酸锂持续跌破 `8—9 万元/吨`，且电解液价格跟跌；
- 福鼎项目实际回报低于可研预测，或主要靠低价抢量。

### 短线企稳信号

- 未来 `3—5` 个交易日不再跌破 `48.64 元`；
- 成交额缩小、跌幅收敛；
- 相对新宙邦和多氟多不再持续跑输；
- 融资余额明显下降后股价仍能站稳；
- 电解液和六氟现货不出现连续下调。

### 基本面升级信号

- Q2 单季利润和毛利率守住；
- H1 经营现金流转正；
- 长协披露更清晰的定价或最低采购机制；
- 海外和区域项目的利用率、单位成本、回款优于行业；
- 高端配方、LiFSI、VC/FEC 等产品的收入和利润占比可量化。

## 八、最终回答

今天的暴跌有情绪过度成分，但并非毫无基本面含义。

**过度之处**在于：

- 终止项目尚未实质建设，不会造成重大当期损失；
- 公司同时新增了规模相近、资本效率更高的项目；
- 当日电解液现货没有下跌，六氟也只是指数小幅回落；
- 百亿市值损失远大于单一项目直接价值变化。

**合理之处**在于：

- 公司亲自确认行业仍有产能供需错配、价格下降和盈利挤压；
- 新项目可研净利率只有约 `4.1%`；
- 头部企业继续区域扩产，说明供给没有锁死；
- Q1 利润很高，但现金流、应收和存货还没证明盈利质量；
- 交易层此前已有融资和短线资金拥挤。

所以，它是一个 **“值得开始跟踪和试仓的价格”**，还不是一个 **“可以忽略验证、直接重仓的价格”**。
