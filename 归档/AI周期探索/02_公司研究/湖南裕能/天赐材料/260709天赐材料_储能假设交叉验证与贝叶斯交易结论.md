# 天赐材料：储能假设交叉验证与贝叶斯交易结论

## 一句话结论

**可以投入一定量交易仓，但不能把它当作储能长期确定性核心仓。**

更准确地说：

> 储能需求假设给天赐提供的是上游物理需求先验；天赐 H1 预告、出货、满产和 Q3 排产给的是材料端利润穿透证据。两者可以相互印证，且是一次有价值的贝叶斯上调，但还没有完成“利润变现金流”的最后闭环。

当前动作：**可用计划仓位的 `20%-30%` 建观察/交易仓；等正式 H1 现金流、毛利率、应收存货和 Q3 价差，再决定是否升级到确认仓。**

这里的计划仓位指单一标的内部计划，不是总资产仓位。

## 储能假设和天赐到底是什么关系

储能主假设是：

```text
电力系统重构 / AI 用电 / 新能源消纳
-> 储能招标、中标、装机和电芯排产上行
-> LFP 电芯出货增长
-> 电解液和六氟磷酸锂物理消耗增长
```

天赐可操作假设是：

```text
电解液和六氟需求上行
-> 认证供应商产能利用率接近满产
-> 客户从压价切到保供
-> 天赐凭 LiPF6 / LiFSI 自供、配方认证、长协和区域交付守住价差
-> 出货、毛利率、扣非利润、经营现金流同步改善
```

所以两者的关系不是“储能好，所以天赐一定好”，而是：

```text
储能是天赐需求侧的上游变量；
天赐是储能材料链利润穿透的下游验证点。
```

储能验证的是 `G1/G2`：物理需求和付款是否存在。  
天赐验证的是 `G4/G5/G6`：有效供给、价格接受和财务兑现是否开始发生。

## 可以相互印证，但不能重复计票

这次最重要的更新，不是又看到一条储能新闻，而是上下两条证据链开始合上：

| 证据 | 证明什么 | 对天赐的权重 |
|---|---|---|
| CNESA 5 月储能系统招标 `23.8GWh`、同比 `+704.9%`，中标 `13.5GWh`、同比 `+154.7%` | 储能系统层需求和付款人仍在 | 中等偏高，但不是公司级利润证据 |
| EVTank 口径下 2025 全球锂电出货 `2280.5GWh`、2026 预计 `3016.3GWh` | 锂电物理需求底座仍扩张 | 中等，是行业先验 |
| 天赐 H1 预告归母净利 `27-30 亿`，同比 `+907.84%-1019.82%` | 利润表已经穿透到材料端 | 高权重 |
| H1 电解液出货同比超 `40%`，6 月电解液和六氟产能利用率接近满产，Q3 排产预计环比进一步增长 | 量、利用率、排产三项共振 | 高权重 |
| Q1 经营现金流仍为负，应收账款和存货增长较快 | 利润质量尚未闭环 | 明确扣分 |
| 7 月 9 日百川口径六氟主流价约 `9.8 万元/吨`、较昨日持平 | 没有跌破反证线，但也不是强涨价证据 | 中性偏弱 |

贝叶斯上不能把这些证据简单相加。储能招标、电芯排产、天赐出货都部分来自同一个底层原因：锂电需求上行。它们有相关性。

但天赐 H1 预告不是纯粹重复证据。因为它已经从“需求”跨到“利润表”：

```text
需求假设
-> 公司出货
-> 产能利用率
-> 产品价格
-> 毛利率
-> 归母利润
```

这条链条越靠后，证据权重越高。现在已经走到利润表，但还没走到现金流。

## 贝叶斯更新

核心假设：

> `H` = 未来两个季度电解液 / 六氟进入紧平衡，天赐单吨利润中枢持续上移，且部分转成经营现金流。

更新前，本库更接近：

| 判断项 | 旧后验 |
|---|---:|
| 储能主假设成立 | `65%-70%` |
| 储能需求能穿透到材料出货 | `55%-60%` |
| 天赐可以做观察仓 | `55%-60%` |
| 天赐可以升级确认仓 | `40%-45%` |

加入 7 月 9 日晚间天赐 H1 预告和价格位置后：

| 判断项 | 新后验 | 更新方向 |
|---|---:|---|
| 储能主假设成立 | `70%-75%` | 小幅上调 |
| 储能需求穿透到电解液 / 六氟出货 | `70%-75%` | 明显上调 |
| 天赐 2026 归母达到 `55-60 亿` | `60%-65%` | 明显上调 |
| 天赐 2026 归母达到 `70 亿+` | `35%-45%` | 只小幅上调 |
| 天赐可以做观察/交易仓 | `65%-70%` | 上调到可行动 |
| 天赐可以升级确认仓 | `50%-55%` | 仍未达重仓阈值 |

最关键的一句：

> 这不是“天赐确定被低估”的证据，而是“市场恐慌杀价时，材料端利润证据突然补上”的证据。

所以交易价值已经强于长期仓位价值。

## 股价三层肉

截至 2026-07-09 收盘，天赐材料收 `41.46 元`，市值约 `845 亿`。这只股票现在不是 DCF 资产，也不是成熟股息资产，而是典型的 **PEG + 周期利润修复 + 事件跳变**。

| 层 | 当前判断 |
|---|---|
| 内在价值 | H1 预告把 2026 利润中枢从“可能修复”推到“初步兑现”；但现金流未确认，不能当成熟内在价值 |
| 流动性溢价 | 锂电材料板块波动大，资金进出会放大股价；不是主要买入理由 |
| 风险偏好 | 7 月初因碳酸锂、固态电池、项目终止等叙事被杀，风险偏好折价明显 |

我买它赚的不是“长期复利钱”，而是：

```text
事件跳变钱 + 基本面修复钱 + 认知差钱
```

事件是 H1 预告和后续正式半年报；基本面是出货、价差和利润；认知差是市场可能把“锂价恐慌 / 固态电池叙事 / 材料过剩”一起砸到天赐身上，但天赐利润表已经比市场恐慌更强。

## 交易结论

### 可以做什么

如果无仓，可以投入计划仓位的 `20%-30%`，买的是观察权和事件窗口，不买重仓确定性。

如果已有小仓，可以持有或小幅补到计划仓位 `30%`附近，但不因为预告利好把仓位追成核心。

如果已经重仓，不应再因为 H1 预告加杠杆。先确认自己能承受股价再次回到 `35-38 元`，且不会被迫卖出。

### 什么时候升级

正式 H1 报告满足以下 5 条中的 3 条，才考虑从观察仓升到确认仓：

1. H1 毛利率守在 `30%-33%`以上；
2. H1 经营现金流转正；
3. 应收账款、存货增速不明显快于收入；
4. 六氟没有持续跌破 `8-9 万元/吨`，电解液价格没有同步破坏；
5. Q3 排产和出货继续兑现，且没有靠低价抢量。

### 什么时候撤

出现任一条，交易逻辑降级：

- 正式 H1 利润强但经营现金流继续明显为负；
- 应收和存货继续快于收入；
- 六氟持续跌破 `8-9 万元/吨`并带动电解液跟跌；
- Q3 利润明显低于 Q2，说明 H1 是阶段高点；
- 满产但低利润，福鼎式 `4%`净利率成为新增产能主流结果。

### 盈利怎么处理

如果从当前位置反弹 `20%-30%`，但正式 H1 现金流和 Q3 价差还没补证据，波动仓应至少部分兑现。

如果正式 H1 现金流、毛利率和 Q3 排产都通过，再重新评估，不急着用短线止盈规则处理全部仓位。

## 不做什么

1. 不把“储能长期需求强”直接等同于“天赐长期重仓确定性”。
2. 不用 DCF 或越跌越买心法处理天赐；它现在不是成熟现金流资产。
3. 不因为 H1 利润高，就自动外推全年 `70 亿+`。
4. 不把六氟 / 电解液的单日价格当唯一信号，要看连续趋势、价差、出货和现金流。
5. 不在上涨后追成核心仓；这笔钱本质是事件跳变和周期修复的钱。

## 最终判断

储能主假设和天赐之间是有真实关联的，而且这次 H1 预告让关联从“逻辑关联”升级成了“初步财务印证”。

但贝叶斯上最清醒的更新是：

```text
储能需求强：提高天赐出货先验；
天赐 H1 预告强：提高材料利润穿透后验；
现金流未确认：压住重仓后验。
```

所以我的当前结论是：

> **可以投一定量交易仓。不是因为天赐已经没有风险，而是因为价格进入观察区、利润表证据刚刚补上、市场仍在用材料过剩和锂价恐慌杀它。仓位要小到能承受二次杀跌，验证点放在正式 H1 和 Q3。**
