# Meta Next Questions

## 升级条件（→核心候选）
- 季度广告营收增速维持 20%+
- CapEx 投资回报率验证（FCF 不严重收缩）
- Llama 商业化路径明确
- 监管风险缓解

## 降级条件（→观察/暂不研究）
- 广告营收增速降至 15% 以下
- CapEx 回报率不足（FCF 持续恶化）
- 监管严重限制数据使用
- TikTok 重新侵蚀用户注意力

## 下一步验证
1. **[最关键] CapEx 实际支出和 FCF 趋势** — 投资回报率
2. **[最关键] 季度广告营收增速** — 是否维持 20%+
3. **Llama 商业化路径** — 开源模型如何变现
4. **WhatsApp 变现规模** — 当前收入和增速
5. **Reality Labs 亏损趋势** — VR/AR 投入是否在收窄

## 重新评估时间
- 下一次财报发布后
- Web search 恢复后（2026-05-26+）可补充 Llama 和 Reality Labs 数据
