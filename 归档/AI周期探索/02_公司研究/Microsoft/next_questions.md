# Microsoft Next Questions

## 高优先级（影响分类和仓位）

### 1. M365 E7 首季度采纳率
- **问题**：$99/用户/月的定价在企业中的实际转化率是多少？
- **验证方式**：Q4 FY26 财报电话会、微软官方博客、IT 采购社区反馈
- **预期时间**：2026 Q3-Q4（GA 后 1-2 个季度）
- **判断影响**：若采纳率 >10% → 定价权确认，上调分类权重

### 2. CapEx→Revenue 传导时间表
- **问题**：CapEx 增速何时开始与 Revenue 增速收敛？
- **验证方式**：Q4 FY26 和 FY27 Q1 财报中的 CapEx 指引和利润率趋势
- **预期时间**：2026 Q4 - 2027 Q1
- **判断影响**：若 CapEx 仍 >40% 增速且毛利率继续压缩 → 下调利润率变化评分

### 3. Agent 365 竞争护城河深度
- **问题**：Google Agentspace / Salesforce Agentforce 是否能替代 Agent 365 的治理层？
- **验证方式**：跟踪竞品发布、企业 IT 决策者反馈、Gartner/IDC 对比报告
- **预期时间**：持续跟踪
- **判断影响**：若竞品在治理层形成可行替代 → 下调结构性转变评分

## 中优先级（影响估值判断）

### 4. OpenAI 模型获取成本变化
- **问题**：非独家许可后，微软的模型获取成本是否增加？是否需要自建模型能力？
- **验证方式**：财报中"成本 of revenue"分项变化、Azure AI 服务定价调整
- **预期时间**：FY27 H1

### 5. Copilot 在 ERP/CRM 深水区的表现
- **问题**：Copilot 是否能从 Office 场景扩展到 Dynamics 365 / Power Platform 的企业流程核心？
- **验证方式**：Dynamics 365 收入增速、Copilot 在 ERP 场景的客户案例
- **预期时间**：2026 H2

### 6. 安全事件是否收敛
- **问题**：Agent 365 / Defender 的代理安全能力是否有效遏制信任边界突破？
- **验证方式**：后续 6 个月是否有新的 Copilot 安全事件
- **预期时间**：2026 H2
- **判断影响**：若再有重大事件 → 下调结构性转变评分至 6/10
