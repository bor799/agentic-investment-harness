# Atlassian (TEAM) Company Research

## 一句话

Atlassian 从协作工具转型为 AI 原生工作平台：Teamwork Graph（1500亿连接）开放 MCP + Rovo 覆盖 75% F500 + Jira Agents GA，但 GAAP 持续亏损 + FCF margin 下滑 + 裁员信任赤字仍在。

## Source Coverage Status

- **MCP 证据**: 3条（Guardian裁员2篇 + Slashdot社区反应1篇），全部media/review级别
- **agent-reach 证据**: StockAnalysis SEC财报（年报+TTM）+ BusinessWire Team'26官方发布 + 分析师预测
- **剩余缺口**: 季度具体数据（Q3 FY2026）、Cloud vs Data Center收入拆分、Atlassian Intelligence独立收入

## 结构性转变

**旧故事**：Jira + Confluence + Bitbucket，卖团队协作 SaaS，高免费层→付费转化模式。

**新故事**：AI 原生工作平台。Teamwork Graph 成为"企业上下文引擎"，通过 Rovo AI 搜索/推理/行动连接所有工作流。FY2026 Team'26 大会宣布开放 Graph 给第三方 Agent（MCP Server + CLI），Claude Code/Codex 可直接访问。

**验证信号**：
1. **Rovo**: 75% F500 + 90% 企业云客户使用，月均 1400 万 AI 辅助行动，自动化 6 个月 7x 增长
2. **Teamwork Graph**: 1500亿连接（人/工作/目标/代码/内容），开放 MCP（Figma/Replit 兼容）
3. **Agents in Jira GA**: Agent 可被分配任务、@mention、嵌入工作流
4. **Rovo Studio GA**: 自然语言设计 Agent + 自动化 + 自定义应用
5. **DX AI Experience GA**: AI 代码生成 ROI 测量工具

**问题**：
1. **GAAP 持续亏损**: TTM 净亏损 $216.81M，虽 FY2026 非GAAP预测首次盈利
2. **FCF margin 下滑**: 32.47% → 27.14% → 19.46%，R&D 激增吞噬现金流
3. **裁员信任赤字**: 1,600人裁员后社区质疑"AI 洗地"，管理层叙事 vs 社区认知冲突
4. **竞争压力**: Linear/Notion 从中小企业向上渗透，AI-native 工具改变项目管理定价

## 飞轮

```
Teamwork Graph（150B连接，85% F500数据）
  → Rovo AI 搜索/推理/行动（75% F500采用）
  → Agent 工作流嵌入（Jira Agents GA）
  → 更多工作数据回流 Graph
  → MCP 开放（Claude Code/Codex 接入）
  → 第三方 Agent 生态 → 更深企业绑定
```

**飞轮验证**: 1400万月度 AI 行动 + 7x 自动化增长 + 350K 客户 + 85% F500 = 飞轮正在加速转动。

## What They Control

- **Teamwork Graph**: 1500亿连接的企业工作图谱，最大规模的工作上下文数据
- **Rovo**: AI 搜索/推理引擎，覆盖 Jira/Confluence/Bitbucket + 第三方 SaaS
- **MCP Server**: 开放标准让外部 AI Agent 访问 Graph 数据
- **分发**: 350K+ 客户 + 85% F500 + Marketplace 生态
- **转换成本**: 项目管理工具迁移成本高，Graph 数据深度绑定

## Market's Old Eyes

市场以传统 SaaS 估值（Forward P/E 14.42）定价 Atlassian，忽略：
- Teamwork Graph 成为"企业上下文层"的结构性价值
- Rovo 75% F500 渗透率代表的 AI 入口地位
- MCP 开放带来的生态网络效应潜力

但也可能正确看到：GAAP 亏损持续 + FCF 下滑 + Linear/Notion 竞争侵蚀 + 裁员损害创新。

## 失败条件

1. **FCF 继续恶化**: 19.46% → 15% 以下，R&D/SG&A 超过收入增速
2. **AI 产品无法货币化**: Rovo 使用量大但无法转化为付费收入
3. **竞争侵蚀加速**: Linear/Notion 在中小企业市占率持续提升
4. **FY2026 盈利未能实现**: 35位分析师预测 EPS $5.36 若落空将严重打击信心
