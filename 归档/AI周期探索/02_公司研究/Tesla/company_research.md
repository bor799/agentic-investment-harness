## 3. ljg-invest 结论（置信度：中）

### 结构变化
电动车 → AI/机器人/能源平台。多重期权叠加：FSD 自动驾驶 + Robotaxi 出行 + Optimus 人形机器人 + 能源存储。但汽车仍是核心业务（营收 95%+），且正在萎缩。

### 飞轮
电动车销量 → FSD 数据积累 → 更好的自动驾驶 → Robotaxi 收入 → Optimus 机器人 → 制造自动化降低成本。但飞轮当前卡在：FSD 技术未突破 + Robotaxi 规模极小 + Optimus 远未量产。

### 权力来源
10B+ FSD 里程数据、超级充电网络、制造规模。但纯视觉路线可能技术落后于 LiDAR 方案（XPENG 已领先）。品牌效应在 Musk 政治争议中受损。

### 失败条件
1. FSD 持续无法实现 L4+（HW3 已证明硬件限制）
2. 中国电动车竞争加剧（BYD 已全球第一）
3. Robotaxi 安全事故导致监管收紧
4. Musk 精力分散影响执行
5. P/E 从 400x+ 回归汽车行业 10-20x（下行 95%+）

## 4. 综合判断

### 真瓶颈
中。FSD 10B 英里数据有壁垒，但纯视觉路线存在技术天花板（HW3 内存限制暴露）。Dojo 超算进展未明确。

### 定价权
低。FY2025 营收 -2.93% 说明在价格战中丧失定价权。汽车毛利率 19.2% 接近传统车企（远低于科技公司）。

### 利润率
低。净利 -46.79%，P/E 431x。即使考虑 AI 期权，当前利润率严重不支持估值。

### 关键矛盾
多重 AI/机器人期权（Robotaxi + Optimus + FSD）vs 当前业务萎缩（营收 -2.93%、净利 -46.79%）+ 极端估值（P/E 431x）。估值隐含了所有期权全部成功的预期。

## 5. 未来 6-12 个月验证信号

1. 季度营收增速能否转正持续
2. Robotaxi 扩大规模和城市数量
3. Optimus 产线投产时间和量产节奏
4. FSD L4+ 无监督批准进展
5. 汽车毛利率趋势

## 6. 三年翻倍路径

**几乎不可能**。$1.59T → $3.18T（全球最大公司）。需：
1. Robotaxi + Optimus + FSD 同时大规模商业化
2. 营收从 $98B 增至 $300B+
3. 估值维持 400x+ P/E 或利润率大幅提升
4. 无重大安全/监管事故

分析师目标低于现价 -4% 是强烈的高估信号。
