# OUST 物理 AI 感知逻辑审计

## 0. 一句话结论

> **需求是真的，平台是期权，供给锁死尚未成立，价格已经很贵。**

OUST 不是伪概念公司：2026Q1 产品收入 $48.2M、同比 +55%，出货 12,600+，GAAP 毛利率 43%，BlueCity 有 700+ contracted deployments。问题是它还主要按一次性产品确认收入，软件收费权未拆，单一客户占收入 31%，而盘中约 $49 对应 EV/2026E revenue 约 12.9x。

当前分类：**结构窗口 / 趋势验证器；观察或极小验证仓，不是核心候选。**

详细证据底稿：[[兴趣领域/股票投资/归档/AI周期探索/02_公司研究/Ouster/260629OUST_物理AI感知逻辑审计_AI长报告原文]]

## 1. 当前到底在赌什么

正确论文不是“机器人爆发，所以 lidar 都涨”，而是：

```text
工业、智能交通和户外机器人需要可靠 3D 感知
-> 部分场景不能只靠摄像头，愿意为 lidar 付费
-> Ouster 用数字 lidar 切入，用 BlueCity/Gemini 嵌入工作流
-> Stereolabs 补相机和边缘计算
-> Rev8 量产 + 软件附着 + 交叉销售 + 经营杠杆同时出现
-> 才从硬件商升级为感知平台
```

前两步已验证；第三步局部验证；最后一步尚未验证。

## 2. 四模型结论

| 模型 | 核心问题 | OUST 当前判断 |
|---|---|---|
| Leontief | 它是不是物理 AI 最短板 | **不是全局短板。** 感知重要，但 lidar 有相机/雷达替代，行业供给充足；机器人当前更可能卡在本体、模型、控制、集成和 ROI |
| 泊松 | 需求事件 `λ` 是否上移 | **上移。** 产品、订单/部署、客户采用、财务四类事件同时变密；但 Rev8 发布后的 PR 高度聚集，不能把合作新闻当收入 |
| 幂律 | 利润会不会集中到它 | **全行业未成立，局部可能。** Hesai Q1 lidar 出货约为 Ouster 的 57 倍；OUST 的局部控制点是美国智能交通、政府合规与复杂工业工作流 |
| 贝叶斯 | 新证据如何改概率 | **赛道后验上调，个股平台后验小幅上调，当前买入后验下调。** |

## 3. 贝叶斯更新

| 假设 | 当前后验 | 关键理由 |
|---|---:|---|
| 物理 AI 会提高感知需求 | 80%-85% | Ouster/Hesai 出货、工业和交通部署共同验证 |
| lidar 会在非消费汽车场景长期存在 | 70%-80% | 交通、矿山、仓储、国防、户外机器人有真实付款 |
| Ouster 能持续获得收入增长 | 55%-65% | 连续 13 季产品收入增长，Q1 产品收入 +55% |
| Ouster 能成为平台级赢家 | 30%-40% | 产品篮子已形成，但软件收入、attach、cross-sell 未披露 |
| Ouster 已形成供给锁死 | 25%-35% | 中国竞品规模大、ASP 下滑、传感路线可替代 |
| 约 $49 是好座位 | 15%-25% | EV/2026E sales 约 12.9x，平台溢价已进入价格 |

贝叶斯纪律：

> `P（物理 AI 成功）` 高，不等于 `P（OUST 成为价值捕获者）` 高；即使后者提高，也不等于 `P（49 美元买入回报好）` 高。

## 4. 最硬的现实证据

| 正面证据 | 投资含义 |
|---|---|
| 2026Q1 收入 $48.58M，+49%；产品收入 $48.23M，+55% | 不是纯主题，需求已进报表 |
| GAAP 毛利率 43%，经营费用仅 +7% | 经营杠杆方向正确 |
| BlueCity 700+ contracted deployments；Chattanooga/Nashville 均从试点扩到 100+ | pilot-to-scale 已在智能交通发生 |
| Q1 有百万美元 BlueCity 合同和多个工业自动化百万美元交易 | 付款人真实 |
| 现金等价物等约 $175M，Q1 粗略 FCF 约 -$9.8M | 短期没有融资悬崖 |

| 反向证据 | 投资含义 |
|---|---|
| 单一客户占 Q1 收入 31%，前两大占 42% | 增长可能比表面更集中、更跳跃 |
| Q2 指引中值约 $51M，较 pro forma Q1 约 $50.2M 仅高约 1.6% | 当前没有环比加速证据 |
| 软件 ARR、attach、renewal、分部毛利均未披露 | “平台”仍是估值期权，不是已验证事实 |
| 2025Q1 至 2026Q1 股数同比约 +18%；潜在稀释证券约 942.8 万股 | 股东经济性弱于公司收入增长 |
| Hesai Q1 收入约 2 倍、lidar 出货约 57 倍且已盈利，市值反而低于 OUST | OUST 已享受显著美国/物理 AI 叙事溢价 |

## 5. 秩序创造机器判定

可能的飞轮：

```text
BlueCity/Gemini 部署
-> 真实场景数据和标注
-> 模型更准、误报更少
-> 更多城市/工业客户
-> 更多部署
```

公司披露模型处理约 800 个站点、400 万+标注对象，飞轮有结构；但数据权、跨客户模型收益、软件收费和续费没有公开。

| 问题 | 判断 |
|---|---|
| 飞轮在转吗 | 结构存在，转速未进软件/现金流报表 |
| 冲击后更强吗 | 公司活下来并扩品类，但累计亏损约 $991M，股东通过稀释付出代价 |
| 资源自己来吗 | 城市从试点扩到 100+ 是引力；高 PR、销售费用 +22%、客户集中仍说明需要推 |

综合判定：

> **有潜力的秩序创造机器，尚未成为自我强化的利润机器。**

## 6. 估值反推

2026-06-29 盘中约 $48.79，市值约 $3.02B；扣除约 $175M 现金等，粗略 EV 约 $2.84B。

| 倍数 | 当前 EV 隐含的未来收入 |
|---:|---:|
| 4x EV/Sales | $710M |
| 6x EV/Sales | $474M |
| 8x EV/Sales | $355M |

文章给 2028 base revenue 约 $500M。当前价格已经是该收入的约 5.7x EV/Sales。

若希望未来约 2.5 年获得年化 25%，届时约需 $5.12B EV：

| 届时倍数 | 所需收入 |
|---:|---:|
| 6x | $853M |
| 8x | $640M |
| 10x | $512M |

所以当前买入要获得好回报，必须满足：

> **收入进入 bull，或平台倍数长期不掉；最好两者同时成立。**

文章的 24 个月 base $100-$120 对应约 $6.4-$7.6B 市值。若收入只有 $500M，就是约 13-15x P/S，不能作为普通 base case，除非软件收费权已被证明。

## 7. 对原文的评价

原文适合做“行业和产品地图”，不适合直接做买入论文。

它做对了：

- 识别 Ouster 不只是消费汽车 lidar；
- 解释不同传感器各自边界；
- 找到真实工业和智能交通场景；
- 注意 Rev8、Stereolabs、BlueCity/Gemini 与盈利路径。

它没做够：

- 没证明 lidar 是 Leontief 最短板；
- 没证明利润按幂律集中到 Ouster；
- 把公司同源材料重复当独立证据；
- 混淆 logo、合作、qualification 和量产订单；
- 忽略 31% 客户集中、18% 股数增长和潜在稀释；
- 没有软件收入与续费数据；
- 目标价缺少收入—倍数—股数—净现金桥梁。

因此，它与你的投资习惯**半匹配**：主题直觉与右尾思维匹配，贝叶斯独立证据、供给锁死、安全边际不匹配。

## 8. 当前动作

| 条件 | 动作 |
|---|---|
| 约 $49 且无新财务硬证据 | 不追；观察 |
| $40-$45 | 只有 Rev8 量产金额或客户集中下降才试仓 |
| $32-$36，且 Q2 收入/毛利不恶化 | 可重新评估小仓赔率 |
| 软件 ARR/attach 首次披露并明显增长 | 即使价格高，也可重做平台估值 |

如果一定要参与物理 AI 右尾，只能把它定义为**极小验证仓**，不是核心仓。仓位升级只跟后验概率，不跟股价兴奋度。

## 9. 必须盯的六个数字

1. 单一客户收入占比：31% 能否降到 20% 以下。
2. 产品收入环比：Q2/Q3 能否连续高于 pro forma 基数。
3. Rev8 production award：金额、数量、周期，而非合作 logo。
4. 软件收入/ARR/attach/renewal：至少披露一项。
5. GAAP 毛利率与经营费用增速：毛利 40%+、费用增速 <10%。
6. 完全稀释股数与 FCF：增长是否继续由股东稀释支付。

## 10. 最终判断

> **OUST 的核心逻辑不是“机器人需要眼睛”，而是“它能否把西方合规的 3D 眼睛嵌入交通和工业工作流，再把工作流变成持续软件收费”。前半段已发生，后半段未发生。**

当前最合理的身份是趋势验证器和结构窗口。赛道信仰可以保留，个股确信要等软件收费权、客户分散和 Rev8 量产；当前价格不提供替错误判断买单的安全边际。

## 11. 最终价格纪律与每日监控锚点

### 最后的价格结论

| 价格 | 判断 | 动作 |
|---:|---|---|
| $44 以上 | 平台溢价已高，默认不买 | 除非软件 ARR/attach/renewal 被硬数据验证 |
| $36-$44 | 证据价，不是便宜价 | 只有平台化后验升至 50%+、客户集中下降或 Rev8 有两个量产订单才试仓 |
| **$32-$36** | **合适价格** | thesis 未恶化时建立 0.25 单位首仓 |
| **$28-$32** | **最理性价格** | 收入、毛利、客户没有反证时，可累计至 0.5 单位 |
| $28 以下 | 可能是机会，也可能是逻辑破裂 | 禁止机械抄底，先检查基本面反证 |

价格不是单独触发器。买入必须同时满足：

```text
价格进入目标区
× 产品收入和毛利没有恶化
× 客户集中没有继续上升
× 稀释没有失控
× 经济事件 λ 没有转弱
```
