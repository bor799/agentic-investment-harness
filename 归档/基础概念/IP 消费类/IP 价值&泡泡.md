# 泡泡玛特


泡泡玛特不是一家零售公司，而是一家 IP 运营平台。平台主力用户是 15–35 岁的年轻白领，核心是 26–27 岁，女性约占 75%。摆放在办公桌彰显个性和满足情绪价值。核心场景是办公桌——年轻人在工位的时间比在家还长，环境冷冰冰，压力大，被 KPI 追着跑。把潮玩摆在桌上，是为自己的微型精神领地加一点温度，一种低成本的情绪缓冲。

泡泡玛特的成功，除开创业团队的努力外，顺应了时代的特点和人口结构的转变。八零后以后出生人口占人口 50%以上，物质条件满足，但精神和情感符号的缺失。千禧年的港台文化潮流，10 年的二次元、韩娱 kpop，这些都给那些个时代印上独特的文化烙印。泡泡玛特是想给这个时代打上‘拉布布’的印记，不是做某个年龄阶段的生意，而是做 95 00 后往后这一整代人的生意。

将过往属于精英们的古典音乐、油画、雕塑，以一种新的形式塞入盲盒做成大众可触达的消费品。

Art Toy 混合画作和雕塑，以触觉和视觉的途径表达这小玩偶中的大情感。盲盒只是销售“包装形式”，是商业的规模性和艺术的稀缺性结合的表达形式，不是护城河。总之，用玩具这种载体，把艺术家的作品标准化、可规模化复制，变成 IP 资产，将简单和高品质的内容传播给大众。

人本能是追求快乐的。收藏欲一直都有，小时候收藏卡片、弹珠、邮票，长大了收藏名画、古董，现在收藏潮玩。需求从来没消失过，只是不同时代有不同的载体。抓住主要人群的主要需求，泡泡玛特做对了这一代人的生意。

当下有很多插画设计师，作品很精彩和很丰富，但这意不意味着他们是一个 IP 呢？叶国富在罗永浩的播客里提到名创优品现在签约了大量的 IP，他也讲了自己在小红书上发现 IP 的案例。但好的内容不一定会成为一个好的 IP，艺术是具有门槛和稀缺的。梵高在世时，大量画作也未被世人理解。艺术是需要时间的沉淀和优秀的策展人的。顶尖的生态更有可能发现好的艺术家。名创店很多，但不意味有顶尖的潮玩 IP 生态。王宁给泡泡玛特的定位就是潮玩界的唱片公司加经纪公司——帮艺术家做“潮玩唱片”，把作品规模化复制，发现、签约、运营头部 IP，让艺术家变成“超级明星”。所以他们不仅依赖单一的爆品，而是打造 IP 的运营能力。实际上拥有 IP 生态掌握了艺术家的源头，那这就是这个行业真正的护城河。

泡泡玛特不仅是围绕着自己做 IP，而且是在搭建着潮玩行业的底座。他们办国内首个潮玩展会，把全球设计师和艺术家引进来；跟高校合作开设潮玩相关课程，培养未来的设计师；整合供应链、渠道，推动行业标准。如果按照这样的叙事发展，泡泡玛特不只是一个品牌，艺术家、品牌、IP 都是要通过他来触达主流的消费者，而其他玩家则会成为渠道商或是代工厂。

关于国际化，王宁的思路很清晰：人类最底层的需求是快乐，这种需求超越了种族、国界和文化。拉布布的流行本质上是一种“快乐平权”——以前收藏名画、古董是贵族的事，现在一个普通人也能拥有自己的私人收藏。文化的本质是什么？是不断迭代的共识性生活方式。泡泡玛特不是要做“中国的迪士尼”，而是要做“世界的泡泡玛特”，用更国际化的方式创造新的中国文化符号。从白领的办公桌延展到年轻一代的文化符号，再延展到全球不同地域的民众，传递温度和美好。

21 年访谈中，我在王宁身上感受两个词：长期和坚持。

25 年的访谈，王宁思考方式和表达方式都没有变化，纯粹诚实的人。所以人的观念和愿景是不怎么变化的，要关注其商业模式的本质和愿景。这是我作为投资人的思考，我的结论是王宁这个人值得投资。我认可这种商业模式，护城河就是：需求不会变化，是普适的，关键是要结合社会结构特别是人的需求去找到对的载体。创始人思考的内容很本质——从人的需求出发，历史都是相似的，需求是不变的，形式在变，但形式只是表达商品或售卖本质的符号。

线下零售公司，运营的经验和积累是有厚度的。王宁说“尊重时间，尊重经营”，应该 10 年做成的事情一定不要想着两三年给做成。从 10 年兴起的互联网至今仍旧坚持线下，非常难得。真正的品牌不是简单的卖货，而是有很强的文化属性——进到门店空间，产品、音乐、灯光、服务，整体营造一个品牌的文化氛围。线下的慢迭代被迫让团队对细节有耐心，这种厚度是快钱堆不出来的。我想这是泡泡玛特传递品牌价值、叙事完整的关键。

创始人王宁的追求，是做一个有故事的人。这段经历本身就是他最骄傲的事情——不是结果，而是创业过程中的跌宕起伏。他讲述故事的方式简单实在，我很喜欢。王宁是诚实纯粹的人，理性和感性结合，没有科技企业创始人那种技术语言浮夸的堆叠，更多是去思考商业和人需求的本质。情感和文化符号带来触动和记忆。信息和各式艺术纷飞的当下，需要一家品味和设计驱动的企业，以更好的品质和 taste 去帮助消费者消化情绪和艺术。

相比于叶国富的访谈，王宁回答更本质简单，从需求和情感符号的角度去思考WHY，这点非常厉害。

访谈中，王宁反复提及：艺术是可以直接售卖的，快乐也是需要平权的。我想这是在解释泡泡玛特商业模式的可持续性。泡泡玛特要平衡艺术稀缺性和商业规模性，<但人物品的稀缺和追捧，下一个“拉布布”？但能否推出其他形式的表达方式烙深文化印记，可能才是叙事能否持续的关键。>

王宁是这样回答泡泡玛特愿景的：

> 首先我们的产品看起来是一个，还是算相对普质化的产品，然后大家都还是接受度很高。从需求上来看，我们发现其实大家对快乐对陪伴，对这些治愈，对这些小确幸，都是一个很普遍的一个需求。是一种永恒的需求，但是找到了它特定的形态。
