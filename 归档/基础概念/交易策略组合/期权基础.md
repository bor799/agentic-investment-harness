## 什么是期权？

期权是一种**合约**，给你一个权利（但不是义务），在特定日期前以特定价格买入或卖出股票。

**核心要素**：
- **行权价 (Strike Price)**：你能买入/卖出的价格
- **到期日 (Expiration)**：合约失效的日期
- **权利金 (Premium)**：期权的价格

---

## 四种基本操作

### 1. 买 Call (Buy Call) - 看涨

```
你支付权利金 → 获得以行权价买入股票的权利
```

| 项目 | 说明 |
|------|------|
| **你的期望** | 股价大涨 📈 |
| **最大收益** | 无限（股价涨多少赚多少） |
| **最大风险** | 损失全部权利金 |
| **行权时机** | 当股价 > 行权价 + 权利金时 |

**例子**：
- LMND 当前 $52
- 买入 $60 Call，权利金 $3
- 若到期时股价 $80：你盈利 $80 - $60 - $3 = $17/股
- 若到期时股价 $50：你损失 $3/股（权利金归零）

---

### 2. 买 Put (Buy Put) - 看跌/对冲

```
你支付权利金 → 获得以行权价卖出股票的权利
```

| 项目 | 说明 |
|------|------|
| **你的期望** | 股价大跌 📉 |
| **最大收益** | 行权价 - 权利金 |
| **最大风险** | 损失全部权利金 |
| **行权时机** | 当股价 < 行权价 - 权利金时 |
| **常用场景** | 保护持仓（保险） |

**例子**：
- 持有 LMND 100股 @ $52
- 买入 $50 Put，权利金 $2
- 若股价跌到 $30：你仍然可以以 $50 卖出，损失有限
- 若股价涨到 $70：Put 作废，你只损失 $200 权利金

---

### 3. 卖 Call (Sell Call / Write Call) - 收租金

```
你收取权利金 → 承诺以行权价卖出股票
```

| 项目 | 说明 |
|------|------|
| **你的义务** | 若被行权，必须卖出股票 |
| **最大收益** | 权利金 |
| **最大风险** | 无限（股价大涨时被迫贱卖） |
| **何时被行权** | 当股价 > 行权价 |

**重要**：卖 Call 需要**持有股票**（Covered Call）或大量保证金（Naked Call，风险极高）

**Covered Call 例子**：
- 持有 LMND 100股 @ $52
- 卖出 $60 Call，权利金 $3
- 若股价维持在 $60 以下：你赚 $300 权利金 ✅
- 若股价涨到 $80：你被迫以 $60 卖出股票 ⚠️

---

### 4. 卖 Put (Sell Put / Write Put) - 收租金 + 承诺接盘

```
你收取权利金 → 承诺以行权价买入股票
```

| 项目 | 说明 |
|------|------|
| **你的义务** | 若被行权，必须买入股票 |
| **最大收益** | 权利金 |
| **最大风险** | 行权价 - 权利金（被迫高价买入） |
| **何时被行权** | 当股价 < 行权价 |

**关键理解**：
- 卖 Put = 你愿意以某个价格买入股票
- 权利金 = 对你承担风险的补偿
- 被行权 = 你以约定的价格买入股票（对长期投资者是好事）

**例子**：
- LMND 当前 $52
- 卖出 $30 Put，权利金 $3.30
- 若股价维持在 $30+：你赚 $330 权利金，无事发生 ✅
- 若股价跌到 $20：你被行权，以 $30 买入 100股（实际成本 $26.70）⚠️

## 关键概念总结

### 虚值 vs 实值 vs 平值

| 类型 | Call | Put |
|------|------|-----|
| **虚值 (OTM)** | 行权价 > 当前价 | 行权价 < 当前价 |
| **平值 (ATM)** | 行权价 = 当前价 | 行权价 = 当前价 |
| **实值 (ITM)** | 行权价 < 当前价 | 行权价 > 当前价 |

### 权利金的影响因素

| 因素 | Call | Put |
|------|------|-----|
| **股价上涨** | ↑ | ↓ |
| **股价下跌** | ↓ | ↑ |
| **波动率上升** | ↑ | ↑ |
| **时间流逝** | ↓ | ↓ |

## 常见误区

### ❌ 误区1："卖 Call 就是看涨"

**正确理解**：卖 Call 是看**跌或横盘**，不是看涨。
- 看涨应该**买 Call**
- 卖 Call 是认为股价不会大涨

### ❌ 误区2："卖 Put 就是看跌"

**正确理解**：卖 Put 是看**涨或横盘**，不是看跌。
- 看跌应该**买 Put**
- 卖 Put 是认为股价不会大跌

### ❌ 误区3："期权买方决定是否行权"

**正确理解**：
- **买方**有权决定是否行权
- **卖方**只能被动接受
- 但美式期权可以提前行权，欧式期权只能到期行权

---

## 行权 vs 到期

### 美式期权（美股常见）
- 任何时候都可以行权
- 到期日前如果成为深度实值，可能被提前行权

### 欧式期权
- 只能在到期日行权
- 常见于指数期权

### 卖方注意事项
- 卖 Call：若股票支付股息，可能在除息日前被行权
- 卖 Put：通常等到到期日，不太可能提前行权

---

## 保证金要求

| 策略 | 保证金要求 |
|------|-----------|
| 买 Call/Put | 支付权利金（100%） |
| 卖 Call（持有股票） | 0（Covered Call） |
| 卖 Call（无股票） | 高额保证金（Naked Call，风险极高） |
| 卖 Put | 行权价的 20-30% |

# 期权心态

**📊 期权本质**                                                                                                                                                                                                  

  _期权不是保险，期权是它标的物波动的凝结_                                                                                                                                                                       

  - 期权的定价不取决于它有多危险，而取决于它的波动有多大

  - 好的公司只要波动够大，它的期权就会变贵

  ---

  **🎯** **卖方心态与策略**


  **核心逻辑**


  不断的卖期权 = 承担更多负伽马（波动） = 换取价值

  过度交易的人在支付代价给卖方


  **卖方的盈利模式**


  **1）期权的期权**

  - 平时在获取期权过度交易的定价上获利

  - 通过动态对冲手法，实现高维度上的加速效果

  - 极端情况下：卖方承担的风险迅速收敛，反脆弱部分的期权以非线性指数方式增长



  **2）脱冰置换成本**

  - 重新建造或替代一个资产所需的实际成本

  - 若资产的脱冰置换成本 >> 市值 → 具有强烈非对称性

  - 前提：负债端要足够的久

  

  **3）尾部风险对冲**

  - 少数交易日贡献所有利润 → 长期持有

  - 买入期权对冲尾部风险，卖出期权获取日常收益

  

  ---

  **⚔️**  **对抗高波动的策略框架**

  

  **杠铃策略（Barbell** **Strategy）**

  

  ┌─────────────┬─────────────┐

  │  90% 安全资产  │  10% 高凸性  │

  │  (国债/现金)  │  (期权/反脆弱) │

  └─────────────┴─────────────┘

  - 关键：**不对称性**（Asymmetry）

  - 下行有限 + 上行开放 = 反脆弱

  

  **动态对冲原则**

  

  - **关注头寸结构，而非市场波动**

  - "我会每天关注我的头寸，但不会随时关注市场"

  - 唯一目标：让世界的不确定性成为朋友

  

  **心态训练**

  

  _"舒服是有代价的，持续承担波动的不适，才能获取到真实的价值"_

  

  - 波动不是敌人，是价值来源

  - 承担不适 = 获取真实价值
