## 一、核心洞察

量化交易的本质不是选方向，是找**定价低效**。

具体来说：用数学工具发现价格与"合理值"之间的系统性偏差，然后在这条偏差消失之前把它吃掉。偏差的来源有两个——信息不对称和结构性摩擦（流动性、交易成本、制度约束）。

这三篇文章讲的是同一件事的不同层次：第一篇讲你需要什么数学武器，第二篇讲怎么用这些武器发现套利，第三篇讲真正赚到 $40M 的人是怎么把数学变成钱的。

### 反常识要点

1. **Black-Scholes 推导中"涨跌预期"互相抵消**。期权价格只跟波动率有关，跟你对标的涨跌的判断无关。这意味着波动率本身是一个独立的可交易维度。
2. **你写的前 10 个策略大概率都是"运气好的猴子"**。1,000 只猴子扔飞镖，总有几只连续命中红心。邦费罗尼校正：测试 N 个策略，显著性门槛 = 0.05/N。
3. **欧几里得距离在价格空间中是错误的度量**。从 $0.05 到 $0.15 和从 $0.50 到 $0.60 都是 10 美分，但信息含量差了几个量级。因为价格代表概率，越接近 0 或 1 的变动信息量越大。正确度量是 KL 散度。
4. **暴力枚举在组合市场中不可行**。63 场 NCAA 比赛 = $2^{63}$ 种可能。但三条线性约束就能替代 16,384 次检查。差距不是算力，是建模方式。
5. **$40M 套利中 41% 来自"市场经常性地偏离 40%"**。中位数定价偏差 $0.60（应该是 $1.00）。市场远没有大多数人以为的有效。

## 二、数学武器库

### 2.1 概率论

**条件概率**是一切量化策略的起点。普通人想"这事会不会发生"，宽客想"已知某些信息时这事发生的概率"。

**贝叶斯更新**是量化交易的灵魂：
```
先验（历史数据合理价格）→ 新信息（财报/公告/事件）→ 后验（更新后的合理价格）
后验期望 vs 市价 = 交易信号
```

**Kelly 公式**告诉你该下注多少：
- 全 Kelly 在理论上让资金增长最快，但对参数误差极度敏感
- 半 Kelly：把波动降约 50%，代价是长期增长率降低约 25%
- 港股小盘股建议：单票上限 5% 总资金，因为流动性风险大

### 2.2 统计学

**p 值与多重检验**：绝大多数回测好看的策略都是数据挖掘的产物。

**Alpha 估计**：
- Alpha = 剔除大盘影响后的超额收益
- 必须用 Newey-West 标准误差修正自相关和异方差
- 策略年赚 20%，但大盘涨 18%，你的 Alpha 只有 2%

**MLE（最大似然估计）**：从观察到的数据反推最可能的模型参数。实战应用——从期权价格反推市场对未来波动的预期。

**肥尾效应**：真实收益率不符合正态分布。港股小盘股肥尾比大盘股更严重，必须用 t 分布或非参数方法。

### 2.3 线性代数

**协方差矩阵**：$\sigma_p^2 = w^T \Sigma w$。Markowitz 投资组合理论的核心。

问题：样本协方差矩阵有估计误差，优化结果极度不稳定。
解决：Ledoit-Wolf 收缩估计。

**PCA 降维**：500 个标的的前 5 个主成分能解释 50-70% 的波动。你不需要理解每个标的，只需理解几个隐藏驱动力。

传闻大奖章基金（年化 30%+）底层就是基于马尔可夫模型，线性代数是基础设施。

### 2.4 凸优化

量化金融中几乎所有优化问题都可以写成凸优化：
- Markowitz 均值-方差优化
- 含交易成本约束的组合调整
- 含整数约束的最小交易单位问题

关键认知：只要问题能写成"碗状"（凸函数），梯度下降一定能到全局最优。

工具：`cvxpy`，几行代码解决含复杂约束的优化问题。

### 2.5 随机微积分

**布朗运动**：$(dW)^2 = dt$。这个性质让随机微积分的二阶项不能忽略（普通微积分可以）。

**伊藤引理**：随机世界的链式法则。在随机过程中，你不能只看方向（一阶项），必须把"颠簸程度"（二阶项）加进去。

**Black-Scholes**：对期权价格用伊藤引理 + 构建对冲组合后，"预期涨跌"变量互相抵消。期权价格只取决于波动率。

**Greeks**：
| Greek | 含义 | 港股小盘股迁移 |
|-------|------|----------------|
| Delta | 价格变动 $1，期权变多少 | 仓位市值占比（方向暴露） |
| Gamma | Delta 的变化速度 | 仓位集中度风险 |
| Theta | 每天损失多少价值 | 持仓时间成本（资金机会成本） |
| Vega | 波动率变化 1% 的影响 | 持仓对市场波动的敏感度 |

## 三、套利检测系统

### 3.1 核心数据

研究分析了 8600 万笔交易（2024.4-2025.4）：

| 指标 | 数值 |
|------|------|
| 总条件数 | 17,218 |
| 存在单一市场套利的条件 | 7,051（41%） |
| 中位数定价偏差 | $0.60（应为 $1.00） |
| 确认的跨市场可利用套利对 | 13 |
| 总提取利润 | $39,688,585 |
| 排名第一套利者利润 | $2,009,632 / 4,049 笔交易 |
| 每笔平均利润 | $496 |

### 3.2 为什么简单加法不够用

单个市场 YES + NO = $1.00 看起来没问题。但多个市场之间存在**逻辑依赖**：

- "特朗普赢宾州" YES=$0.48 + "共和党在宾州赢 5%+" YES=$0.32
- 后者是前者的子集（大胜一定意味着获胜）
- 两个市场各自"正常"，但组合起来有套利

### 3.3 整数规划替代暴力枚举

Duke vs Cornell 的例子：
- 14 个条件 → $2^{14} = 16,384$ 种组合
- 三条线性约束搞定：
  1. Duke 恰好一个盘口为真
  2. Cornell 恰好一个盘口为真
  3. 两队同时赢 5+场的概率之和 ≤ 1

**核心理念**：不枚举所有可能性，只描述"合法答案长什么样"，让算法找违反规则的定价。

### 3.4 Bregman 投影与最优套利

最大保证利润 = 当前市场状态到无套利空间的 **Bregman 投影距离**。

Bregman 投影同时告诉你三件事：
1. 该买卖什么（投影方向 = 交易方向）
2. 该买卖多少（考虑订单簿深度）
3. 能赚多少（投影距离 = 最大利润）

对 LMSR 市场，Bregman 散度 = KL 散度，自动给极端价格附近的变动更高权重。

### 3.5 Frank-Wolfe 算法

直接计算 Bregman 投影不可行（边际多面体有指数级多的顶点）。

Frank-Wolfe 的做法：逐步逼近，每轮只加一个新顶点。
- 50-150 轮迭代收敛
- 每轮求解一个整数线性规划（Gurobi）
- 求解时间：1-30 秒
- 结果随着比赛推进反而更快（可行空间缩小）

### 3.6 三层检测架构

| 层级 | 方法 | 速度 | 功能 |
|------|------|------|------|
| L1 | 简单线性约束（LCMM） | 毫秒 | 概率之和=1、子集关系检查 |
| L2 | 整数规划投影（Frank-Wolfe + Gurobi） | 分钟级 | α=0.9、ε=0.1、收敛阈值 1e-6 |
| L3 | 执行验证 | 秒级 | 流动性/滑点/利润检查，利润 > $0.05 才执行 |

参数配置：
- Alpha = 0.9（提取至少 90% 可用套利）
- 初始 ε = 0.1（10% 收缩）
- 收敛阈值 = 1e-6
- 时间限制 = 30 分钟

## 四、执行层：数学正确 ≠ 能赚钱

### 4.1 非原子执行风险

CLOB 订单顺序执行。计划：买 YES $0.30 + 买 NO $0.30 = 成本 $0.60，回收 $1.00。
现实：YES 成交后价格变动，NO 成交价变成 $0.78，总成本 $1.08，亏 $0.08。

**这是策略失败最常见的死因。**

### 4.2 VWAP（成交量加权平均价格）

不能假设以报价成交。要算实际平均成交价：
```
VWAP = Σ(price_i × volume_i) / Σ(volume_i)
```

研究方法：对 Polygon 每个区块（~2 秒），计算 YES 和 NO 的 VWAP，$|VWAP_{yes} + VWAP_{no} - 1.0| > 0.02$ 记录为套利机会。

### 4.3 流动性约束

套利利润受限于最小流动性：
```
最大可提取利润 = 定价偏差 × min(所有需要仓位的订单簿深度)
```

仓位上限：订单簿深度的 50%。超过这个比例，你自己的订单就会大幅移动市场。

### 4.4 Kelly 公式的执行风险调整

```python
f = (b * p - q) / b * sqrt(p)
# b = 套利利润百分比
# p = 完全执行概率（从订单簿深度估算）
# q = 1 - p
```

### 4.5 延迟层级

| 角色 | 总延迟 | 技术栈 |
|------|--------|--------|
| 散户 | ~2,650ms | API 轮询 + 手动下单 |
| 量化系统 | ~2,040ms | WebSocket + 预计算 + 直接 RPC |
| 快钱包（同块提交） | ~30ms 决策到提交 | 全部仓位在同一区块确认 |

**为什么跟单快钱包必亏**：你在 Block N+1 看到交易时，快系统在 Block N-1 就检测到偏差了。你买到的价格已经是被修正后的。你不是在套利，你在提供退出流动性。

## 五、LLM 辅助发现隐含关系

305 个美国大选市场 → 46,360 对需检查。

用 DeepSeek-R1 做初筛：
```
40,057 对独立（无套利）
  → 1,576 对有依赖（潜在套利）
    → 374 对满足严格条件
      → 13 对经人工验证可利用
```

LLM 准确率 81.45%。足够初筛，执行前需人工验证。

**港股小盘股的价值**：信息覆盖度低，公告和财报中存在大量非 obvious 的隐含关系，LLM 可能是最大的 alpha 来源之一。

## 六、迁移到港股小盘股

### 6.1 为什么港股小盘股反而是量化蓝海

| 维度 | 预测市场 | 港股小盘股 |
|------|----------|-----------|
| 套利窗口 | 毫秒级 | 分钟到小时级 |
| 竞争强度 | 极高 | 中低（覆盖分析师少） |
| 信息优势 | 难建立 | 容易（LLM 从公告发现隐含关系） |
| 基础设施门槛 | 极高 | 较低（普通 API 够用） |
| 买卖价差 | 极小 | 1-5%，天然做市空间 |
| 数学基础设施差距 | 巨大（机构 vs 散户） | 巨大（几乎没有人在用数学） |

核心判断：港股小盘股流动性差、信息不对称严重、参与者以散户为主。这三条恰恰是量化策略发挥最大优势的条件。

### 6.2 可直接实现的方法论

**方法论 A：贝叶斯定价更新**

```
步骤 1：先验分布（历史数据 + 同行业可比公司）
步骤 2：新信息（财报/公告/大股东变动/配股供股）
步骤 3：精确更新后验分布（PyMC / NumPyro）
步骤 4：后验期望 vs 市价 → 交易信号
步骤 5：后验方差过大 → 不交易（信息不足）
```

港股小盘股先验建议用对数正态分布（价格非负，右偏）。

**方法论 B：Kelly 仓位管理**

```python
def half_kelly(bankroll, win_prob, win_loss_ratio):
    kelly = win_prob - (1 - win_prob) / win_loss_ratio
    return bankroll * kelly / 2

# 港股小盘股特殊调整：
# - 单票上限 5% 总资金
# - 盈亏比乘 0.7-0.8 折扣系数（流动性滑点）
# - 止损：2 倍标准差或固定百分比
# - 加仓：盈利后可用 Kelly 计算加仓量，亏损不加仓
```

胜率估计至少需要 200+ 笔交易记录。盈亏比用历史中位数（不是平均数，受极端值影响大）。

**方法论 C：波动率锥**

```
1. 计算历史波动率（20 日 / 60 日滚动标准差）
2. 港股小盘股加：Parkinson 波动率（日内高低价）和 Garman-Klass 波动率
3. 当前波动率 vs 历史分位数：
   - 90% 分位 → 波动率偏高，等待或减仓
   - 10% 分位 → 波动率偏低，可能有突破行情
```

**方法论 D：PCA 因子分析**

```python
# 1. 收集港股小盘股池收益率矩阵（至少 100 只，250 天）
# 2. Ledoit-Wolf 收缩协方差估计
# 3. PCA 降维，保留前 5-10 个主成分
# 4. 在主成分空间做均值-方差优化

# 港股小盘股预期：前 5 个主成分解释 50-60%，前 10 个解释 70-80%
```

**方法论 E：三层信号过滤（迁移自三层套利检测）**

| 层级 | 原版（套利检测） | 港股版（信号过滤） |
|------|------------------|-------------------|
| L1 | 简单线性约束 | 基本面过滤（PE/PB/市值区间/行业） |
| L2 | 整数规划投影 | 跨市场关系（A+H 溢价、同行业联动、可转债套利） |
| L3 | 执行验证（VWAP/滑点） | 流动性检查（日成交额 < 100 万的票限制单笔金额） |

**方法论 F：回测防过拟合 SOP**

```
1. 先定义经济学假设，不是先回测再编故事
2. 单一策略 p < 0.05；测试 N 个策略 p < 0.05/N（邦费罗尼）
3. 港股小盘股建议用 0.01/N（数据量少，更严格）
4. Walk-Forward 验证（滚动窗口）
5. 跨市场验证（港股有效 → A 股小盘也有效？）
6. 交易成本压力测试：
   - 买卖价差 1-5%
   - 印花税 0.13%
   - 佣金 + 冲击成本
   - 停牌概率（小盘股停牌频繁）
```
