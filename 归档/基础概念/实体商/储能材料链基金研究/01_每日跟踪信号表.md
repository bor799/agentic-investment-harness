## 🎯 核心假设

观察仓继续存在需要同时满足：

1. 储能招标、投运与电芯排产没有明显转弱；
2. 招标能够转成中标、交付和回款；
3. 314Ah 电芯和 4h 系统价格没有连续跌破可盈利区间；
4. 材料库存没有重新快速累积；
5. 电解液、LFP 等材料的价差或单吨利润没有持续收缩；
6. 利润增长最终进入经营现金流；
7. 001616 的正式持仓和净值相关性仍能表达材料/电芯链。

**需求、价格、利润三项不能简单并列打分。只有 L1 物理需求 → L2 订单付款 → L3 价格利润完成传导，才允许加仓。**

## 🎯 三段仓位状态

仓位均指预先限定的“储能主题计划仓位”，不是个人总资产。

| 阶段 | 主题计划仓位 | 条件 |
|---|---|---|---|
| 观察仓 | 20%—30% | L1/L2 通过，L3/G6 未完成 |
| 确认仓 | 50%—60% | Q2/H1 至少四项硬验证通过 |
| 完整主题仓 | 最高 100% | L1—L3、G1—G6 和基金映射均通过 |

### 确认仓加仓条件（至少四项满足）

- [ ] 宁德 Q2 储能毛利率 ≥ 25%
- [ ] 湖南裕能利润增长伴随经营现金流、应收或存货改善
- [ ] 天赐/新宙邦 Q2 毛利率、单吨利润没有明显回落
- [ ] 大型集采开标价没有重新坍塌
- [ ] 001616 Q2 持仓仍重仓材料/电芯链
- [ ] 六氟、电解液价差企稳，不是只有股票上涨

## 🧭 非线性状态迁移监控

详细方法：[[兴趣领域/股票投资/归档/基础概念/交易策略组合/260622电解液_需求强度非线性信号框架]]、[[兴趣领域/股票投资/归档/基础概念/交易策略组合/260624电解液_物理需求线性与利润估值非线性]]

每日任务不能再把“需求增长、产品价格、公司利润”简单并列打分，必须按以下六道闸门判断：

| 闸门 | 核心问题 | 当前状态（2026-07-01） |
|---|---|---|
| G1 物理需求 | 动力、储能、重卡是否至少两个终端加速 | 储能强，其他终端待连续验证 |
| G2 付款/订单 | 招标是否转中标、采购、交付和回款 | 系统/电芯层通过，材料回款待验证 |
| G3 库存反转 | 六氟、电解液、电芯是否从去库转补库 | 数据不足，未通过 |
| G4 有效供给 | 利用率、交期、认证是否形成真实约束 | 未通过 |
| G5 价格接受 | 下游是否接受提价，龙头单吨毛利是否扩张 | 电芯厂仍压价，偏负面 |
| G6 财务兑现 | 出货、毛利、应收、存货、现金流是否共振 | Q1 部分通过，等 Q2/H1 |

状态判定：

```text
S0 叙事 -> S1 扩散 -> S2 加速 -> S3 紧平衡 -> S4 财务兑现 -> S5 拥挤/衰减
```

- 当前状态：`S1 扩散`
- S2 加速条件：G1、G2 必须通过，且 G3-G5 至少一项通过。
- 非线性候选：G1、G2 必须通过，且 G3-G5 至少两项同时通过。
- S3 紧平衡：G1-G5 全部通过；S4 公司确认还需 G6 通过。
- 股价、媒体热度、主力资金只做报警，不计入六道闸门。
- 同一政策或订单的多篇转载只算一条证据，禁止重复累计。

### 四层传导验证（每日必填）

每天新增证据必须先落到四层传导里，再判断是否改变仓位。核心区分：

> 终端需求的时间路径可以非线性，但电芯产量到材料消耗的短期换算近似线性；真正容易跳变的是订单、价格、单吨利润和估值。

| 层级 | 核心问题 | 影响位置 | 主要验证数字 |
|---|---|---|---|
| L1 物理消耗 | 终端装机、招标、中标、电芯排产是否变强 | 收入天花板 | 储能 GWh、动力装车、重卡销量、电芯产量 |
| L2 订单采购 | 物理消耗有没有变成采购、交付和回款 | 收入确认 | 材料采购订单、客户库存天数、出货量、回款 |
| L3 价格利润 | 客户是否接受提价，龙头单吨毛利是否扩张 | 毛利、经营利润、净利润 | 六氟/电解液价格、价差、毛利率、单吨利润 |
| L4 估值预期 | 市场是否提前交易状态迁移，估值是否透支 | 估值和赔率 | PE/PB、股价相对基本面证据的提前幅度、成交拥挤度 |

每日判断必须写出：

```text
今天新增证据主要落在 L1/L2/L3/L4 哪一层？
是否从 L1 传导到了 L2？
是否从 L2 传导到了 L3？
L4 的股价反应是提前报警，还是已经透支 S3/S4？
如果只发生 L4，不允许把产业状态上调。
```
