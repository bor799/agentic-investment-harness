# Circle (CRCL) 公司基本面分析

## 一、公司概况

### 1.1 基本信息
- **公司名称**: Circle Internet Financial, LLC
- **股票代码**: CRCL (SPAC上市，首日收盘$82.88，+167%)
- **核心业务**: USDC 稳定币发行与数字货币基础设施服务
- **成立时间**: 2013年
- **总部**: 美国 波士顿

### 1.2 核心定位
Circle 的核心定位正在从**稳定币收益映射工具**向**全球数字美元网络的基础设施层**演进。

> "如果是前者，估值锚更像金融股；如果是后者，估值框架会大很多。" — lufeieth

## 二、核心产品：USDC

### 2.1 市场地位
- **市占率**: 24%（第二大稳定币，仅次于 USDT 的 65%）
- **发行规模**: ~760亿美元（2025年10月数据）
- **年增速**: 流通量同比增长90%（2025年Q2数据）

### 2.2 技术路线
- **类型**: 法币抵押型稳定币（与美元1:1锚定）
- **储备资产**: 美国国债等高流动性资产（现金储备覆盖率98.7%）
- **合规优势**: 持有美国48州货币传输许可证、法国电子货币机构许可证

### 2.3 与 USDT 对比

| 维度 | USDC (Circle) | USDT (Tether) |
|------|---------------|---------------|
| 市占率 | 24% | 65% |
| 合规性 | 高（美国牌照） | 低（迁至萨尔瓦多） |
| 透明度 | 定期审计报告 | 透明度不足 |
| 机构信任 | 高 | 中 |

## 三、商业模式

### 3.1 盈利来源
1. **储备资产利息收入**（核心）
   - USDC储备资产配置于美国国债
   - 2025年Q2收入6.58亿美元（同比+53%）
   - 过去三年收入从7.36亿增长至17亿美元

2. **手续费**
   - USDC铸造/赎回手续费
   - 企业级服务费

3. **RWA产品收益**
   - 货币市场基金类产品
   - 用户可用稳定币直接购买

### 3.2 商业模式特征
- **类SaaS属性**: 随着USDC流通量增长，固定成本不增加，边际收益提升
- **平台控制率**: 日均加权平均占比7.4%（同比+536基点）
- **网络效应**: 接受度提高 → 分发成本降低 → 盈利能力提高

## 四、战略布局

### 4.1 生态合作
- **Coinbase**: 美国最大合规交易所，为USDC提供天然分发渠道
- **万事达卡**: 首选合作伙伴，提供稳定币接收选项
- **跨境支付**: 年均增长>200%

### 4.2 投资布局
- 投资了120多家公司
- 涵盖加密货币、金融科技、社交媒体
- 从单纯发行商向综合科技公司转型

### 4.3 战略定位演进
```
稳定币发行商 (产品)
    ↓
数字美元网络 (平台)
    ↓
全球支付基础设施 (标准)
```

## 五、投资逻辑

### 5.1 核心催化剂
1. **GENIUS法案**: 美国稳定币监管法案，强化合规护城河
2. **信托银行牌照**: 申请中，获批将大幅提升机构信任
3. **银行激励政策**: 允许银行支付USDC奖励，或带来$500B增量

### 5.2 增长空间
- **美债规模**: 37万亿 → 50万亿美元（未来十年）
- **稳定币市场**: 2500亿 → 5-10万亿美元
- **CRCL目标份额**: 25-40%
- **目标市值**: 5000-12000亿美元

**成长空间**: **20倍以上** (从当前340亿美元基数)

### 5.3 类比定位
- "AI时代的Visa"
- 类似 AWS 的平台型基础设施
- 互联网初期的谷歌/微软

## 六、观察指标

### 6.1 核心指标
1. **USDC流通量**: 核心增长指标
2. **平台控制率**: 分发能力提升
3. **非利息收入占比**: 业务多元化程度
4. **链上活跃度**: 实际使用情况

### 6.2 战略指标
1. **支付场景渗透**: 跨境、结算、嵌入能力
2. **开发者/企业接入数**: 生态扩展
3. **机构采用情况**: 合规化进展

### 6.3 风险指标
1. **监管变化**: 各国政策态度
2. **竞争格局**: Stripe、Visa 等传统支付巨头的动作
3. **利率环境**: 降息对利息收入的影响

## 七、风险因素

### 7.1 与 Coinbase 的"不平等条约"
- Circle 需将 56% 的收入分给 Coinbase
- 协议永续续约
- 长期面临利润天花板

### 7.2 竞争风险
- **Stripe**: 从支付入口向内切稳定币
- **Visa**: 公开评估支持 Bridge 资产
- **风险等级**: 从 tail risk 上调为"值得持续重点跟踪的中高等级战略风险"

### 7.3 政策风险
- 各国监管态度仍在演变
- 算法稳定币崩盘影响市场信心

### 7.4 利率风险
- 降息周期：国债收入下降
- 需要发行规模增长来抵消

## 八、投资建议

### 8.1 时机判断
- **当前**: 340亿美元市值，可建立底仓
- **回调机会**: 如果跌回100-200亿美元市值 → 重仓买入
- **目标**: 5-10年持有周期

### 8.2 投资框架
```
确定成长行业 (稳定币 20倍+ 增长)
    +
高竞争力企业 (Circle 合规/透明优势)
    +
还不错的价格 (当前340亿 vs 潜在5000-12000亿)
    =
高EV的下注机会
```

### 8.3 关键观察
> "USDC会不会从一个静态持有资产，逐步演化成支付、跨境、结算、开发者调用、链上金融的标准货币层。" — lufeieth

一旦这个过程成立，Circle的价值会开始从"收益工具"向"网络资产"迁移。

## 九、深度分析：lufeieth 的 17 条核心思考

> **来源**: [@lufeieth](https://x.com/lufeieth) — 长期主义投资者，信奉"避免归零风险、长期正和游戏、认知复利"

### 9.1 核心定位之争

**第1条：估值框架的本质问题**

Circle 到底只是一个**稳定币收益映射工具**，还是正在长成**全球数字美元网络的基础设施层**？

| 定位 | 估值锚 | 想象空间 |
|------|--------|----------|
| 收益映射工具 | 金融股估值 | 有限 |
| 基础设施层 | 网络/SaaS 估值 | 巨大 |

### 9.2 四维观察框架

**第2条：超越利率视角的四大指标**

1. **USDC 的流通量**能不能持续扩大 → 决定天花板
2. **支付和清结算场景**能不能继续渗透 → 决定天花板
3. **开发者和企业接入**能不能加速 → 决定估值质量
4. **非利息收入占比**能不能逐步提升 → 决定估值质量

### 9.3 价值迁移逻辑

**第3条：从"收益工具"到"网络资产"**

USDC 会不会从一个静态持有资产，逐步演化成：
- 支付
- 跨境
- 结算
- 开发者调用
- 链上金融

的**标准货币层**？

一旦这个过程成立，Circle 的价值会开始从"收益工具"向"网络资产"迁移。

### 9.4 稀缺性定位

**第4条：连接权与结算权**

CRCL 真正的稀缺性，在于它卡的位置很好：

| 不是 | 而是 |
|------|------|
| 单纯做交易所 | 数字美元的连接权 |
| 单纯做钱包 | 多场景、多链、多机构之间的结算权 |
| 只做某条链上的应用 | 基础设施层 |

### 9.5 三层估值逻辑

**第5条：不要把三层混着看**

```
短期利率 → 利润弹性
USDC规模 → 收入基数
支付结算网络 → 长期估值中枢
```

**第6条：静态存量 vs 高频流通**

同样 100 亿美元余额：
- "静态存量" → 价值密度低
- "高频流通" → 价值密度高

**第7条：从好公司到另一种级别的公司**

| USDC 定位 | CRCL 级别 |
|-----------|-----------|
| 合规版链上美元 | 好公司 |
| 互联网原生支付和结算的标准层 | 另一种级别的公司 |

### 9.6 双重视角

**第8条：金融 vs 互联网协议**

| 金融视角 | 互联网视角 |
|----------|------------|
| 准备金、利率、合规、收入分成 | 接入、网络、调用、场景扩张、标准化能力 |

真正大的估值抬升，往往发生在市场开始用**第二种语言**去理解它的时候。

### 9.7 清算路由器

**第9条：从利差到路由器**

- "赚利差的稳定币发行方" → 值钱
- "全球数字美元的清算路由器" → 想象空间和战略地位高一个层级

### 9.8 合规的价值

**第10条：入场券理论**

在金融世界里，很多时候不是谁先做出来就赢，而是谁能被：
- 更大的资金
- 更大的机构
- 更复杂的场景

长期接受。

CRCL 拿到的不只是市场份额，还有**进入更大场景的入场券**。

### 9.9 五维共振

**第11条：不能单看任何一个维度**

```
1. USDC流通量
2. 链上活跃度
3. 支付和跨境场景拓展
4. 企业与开发者接入
5. 非利息收入变化
```

真正重要的是它们有没有形成**同向共振**。

### 9.10 线性模型的陷阱

**第12条：脱离纯线性框架**

"稳定币余额 × 利率" = 线性模型

一旦 USDC 开始具备更强的：
- 支付网络属性
- 开发者基础设施属性
- 跨境结算属性

CRCL 的估值方法就会慢慢脱离纯线性框架。

### 9.11 持有 vs 使用

**第13条：从持有走向使用**

| 持有 | 使用 |
|------|------|
| 对应利息逻辑 | 更接近网络逻辑 |
| 金融资产的估值语言 | 平台基础设施的估值语言 |

### 9.12 从产品到标准

**第14条：产品 vs 标准**

- 产品会被比较价格
- 标准会被嵌入流程

如果 USDC 能变成默认选项，Circle 争夺的就不只是收入，还有**未来数字美元世界里的默认入口**。

### 9.13 分层估值法

**第15条：三层估值框架**

```
1. 短期 → 按利率和流通量看利润弹性
2. 中期 → 按支付和清算渗透看业务质量
3. 长期 → 按网络位置和标准化能力看估值上限
```

### 9.14 护城河的四条腿

**第16条：真正的护城河**

1. **合规信任**持续强化
2. **USDC流通规模**持续扩大
3. **真实支付和结算场景**持续增加
4. **开发者和企业接入**形成惯性

四条里只满足一两条 → 阶段性受益者
四条都满足 → 不断加厚的网络

### 9.15 赛道股 vs 平台型资产

**第17条：最大的分歧点**

- 谁能把需求沉淀成长期网络价值？
- 谁只能短期享受红利？

| 受益于行业增长 | 把 USDC 变成核心基础设施 |
|----------------|--------------------------|
| 赛道股 | 平台型资产 |

## 十、核心洞察总结

### 10.1 估值框架转换
- **当前市场定价**: 利率收益工具 (金融股估值)
- **潜在估值方向**: 网络基础设施 (SaaS/平台估值)

### 10.2 核心护城河
1. **合规优势**: GENIUS法案强化领先地位
2. **透明度**: 定期审计，机构信任强
3. **生态集成**: Coinbase、万事达卡等深度合作
4. **网络位置**: 卡在多场景、多链、多机构的连接节点

### 10.3 长期判断
> "CRCL真正的稀缺性，在于它卡的位置很好...它在争夺的，是数字美元在多场景、多链、多机构之间的连接权和结算权。这个位置一旦坐稳，战略价值会越来越高。"
