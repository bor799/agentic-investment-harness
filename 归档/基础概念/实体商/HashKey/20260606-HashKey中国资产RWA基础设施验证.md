# HashKey 中国资产 RWA 基础设施验证

> 数据口径：截至 2026-06-06。股价采用 2026-06-05 港股收盘价 HK$3.23，因为 2026-06-06 是周六。财务数据以 HashKey 2025 年报为主。

## 1. 一页结论

一句话结论：**HashKey 有机会成为“中国资产 RWA 上链 + 香港合规数字资产金融”的重要通道，但目前还不能证明它已经是核心基础设施收费权。**

它不是单一交易所。官方年报把业务分成三块：交易促成服务、链上服务、资产管理服务。交易促成服务里包含交易所、经纪和托管；链上服务里包含 staking 和 tokenisation；资产管理覆盖 VC 基金和二级市场基金。这个组合说明 HashKey 的确在搭“发行、托管、交易、链上服务、资管”的综合基础设施。

但投资判断不能停在“有牌照、有叙事”。2025 年最硬的数据是反证：平台资产增长 60.5% 至 HK$184 亿，香港交易量增长 72.3% 至 HK$5300 亿，RWA 已部署 11 个产品、总价值约 HK$20 亿，但公司收入只增长 0.3% 至 HK$7.23 亿，毛利下降 23.3% 至 HK$4.08 亿，净亏损 HK$10.84 亿，经营现金流流出 HK$6.92 亿。

核心判断：

| 问题 | 判断 |
|---|---|
| HashKey 是什么 | 香港合规数字资产综合平台，不只是交易所 |
| 是否是中国资产 RWA 上链关键节点 | 战略位置成立，财务验证不足 |
| 是否吃到 RWA 收费权 | 证据不足。RWA 有 HK$20 亿 tokenised value，但没有单独收入披露 |
| 是否吃到人民币资产全球化 | 证据不足。香港稳定币牌照首批给了 HSBC 和 Anchorpoint，HashKey更像交易、分发、托管和链上部署通道，不是 stablecoin float 捕获者 |
| 是否像 Circle | 不像。Circle 吃稳定币发行和储备收益，HashKey 吃合规通道服务费 |
| 是否像 BTGO | 部分竞争。BTGO 更偏全球机构 custody/wallet/settlement，HashKey 更偏香港牌照和中国资产通道 |
| 当前投资池 | 证据不足池，偏观察 |

当前市值与估值：

| 指标 | 数据 |
|---|---:|
| 股票代码 | 03887.HK |
| 上市日期 | 2025-12-17 |
| IPO 价 | HK$6.68 |
| 2026-06-05 收盘价 | HK$3.23 |
| 较 IPO 跌幅 | 约 -51.6% |
| 发行后股份数 | 约 27.66 亿股 |
| 当前市值 | 约 HK$89.3 亿 |
| FY2025 收入 | HK$7.23 亿 |
| 当前 P/S | 约 12.4x |

| 当前 P/B | 约 3.1x |
| FY2025 经营现金流 | -HK$6.92 亿 |

投资结论：**不进核心候选池。可以进入观察池/证据不足池，作为“中国资产 RWA + 香港合规数字金融”的政策期权跟踪。**

升级条件很明确：RWA 或 tokenised products 收入单独披露并达到 HK$1 亿级别；on-chain services 不再主要靠 staking；交易促成毛利率从 41% 修复；收入 CAGR 40% 以上；调整后亏损明显收窄或 EBITDA 接近盈亏平衡。

## 2. HashKey 生态位判断

### 2.1 它不是单一交易所

HashKey 2025 年报披露的业务结构：

| 业务 | 官方定义 | FY2025 收入 | 收入占比 | 毛利 | 毛利率 |
|---|---|---:|---:|---:|---:|
| Transaction facilitation services | 数字资产交易所、经纪、托管 | HK$5.228 亿 | 72.3% | HK$2.146 亿 | 41.0% |
| On-chain services | staking、node validation、tokenisation 等 | HK$0.832 亿 | 11.5% | HK$0.770 亿 | 92.6% |
| Asset management services | VC 基金、二级市场基金 | HK$1.171 亿 | 16.2% | HK$1.169 亿 | 99.8% |
| 合计 | 综合数字资产平台 | HK$7.231 亿 | 100.0% | HK$4.085 亿 | 56.5% |

生态位拆解：

| 身份 | 是否成立 | 证据 |
|---|---|---|
| 合规交易所 | 成立 | Hash Blockchain Limited 在 SFC 持有 Type 1、Type 7 和 VATP 相关牌照，HashKey Exchange 是 SFC 正式持牌平台 |
| 数字资产经纪商 | 成立 | 交易促成服务包括 brokerage services 和 OTC/机构交易 |
| 托管和钱包服务商 | 部分成立 | 交易促成服务包括 custody services，另有 TCSP 牌照实体；但托管收入未单独披露 |
| RWA 发行与分发平台 | 早期成立 | 11 个 tokenised products、RWA value 约 HK$20 亿；公司作为 tokenisation service provider、DLT provider、fund share distributor |
| Web3 投资机构 | 成立 | HashKey Capital AUM HK$72 亿，Fund IV 首关 HK$19 亿 |
| 香港虚拟资产金融基础设施 | 部分成立 | 牌照、交易、托管、链、资管、RWA 都有，但收入质量没有证明“绕不开” |
| 中国资产出海链上通道 | 只是期权 | PRC 对境内资产境外 RWA 代币化采取“境内严禁、境外严管”，不是开放闸门 |

结论：**HashKey 的“形”是综合基础设施，但“利”还主要来自交易促成和资管；RWA 基础设施收入没有被证明。**

- 资产管理是唯一清楚增长的高毛利业务，但规模只有 HK$1.17 亿收入。

## 3. 中国资产 RWA 上链逻辑

### 3.1 假设一：香港是中国资产连接全球资本的重要金融通道

判断：**成立，但这只是大背景，不自动等于 HashKey 收费权。**

香港作为国际金融中心，有港股、离岸人民币、Stock Connect/Bond Connect、跨境基金和中资企业境外融资历史。对中国资产而言，香港确实是最自然的合规出海通道之一。

但 RWA 的特殊性在于，链上发行、托管、二级交易、结算和投资者适当性都要被监管重新定义。传统香港金融通道成立，不代表 tokenised China assets 会自动放量，也不代表 HashKey 会成为唯一入口。

结论：通道成立，平台份额不成立。

### 3.2 假设二：RWA 上链需要合规发行、托管、交易、结算和分发平台

判断：**成立。**

SFC 2026 年 4 月框架把 tokenised SFC-authorised open-ended funds 的二级交易引向 SFC-licensed VATPs。这说明香港监管正在从“只允许发行/持有”往“有条件二级交易”推进。

这对 HashKey 有意义，因为它已经具备几块拼图：

- VATP 交易平台。
- Type 1/Type 7 交易和自动化交易服务能力。
- 托管和 TCSP 相关实体。
- HashKey Chain 和 tokenisation 能力。
- 资产管理和分销触点。

但 SFC 框架仍是试点式、逐案式、产品范围有限。它支持 tokenised funds 的合规二级交易，不等于支持所有港股、债券、票据、房地产、收益权自由上链交易。

结论：基础设施需求成立，规模化窗口未打开。

### 3.3 假设三：HashKey 可能成为链路关键节点

判断：**战略上成立，财务上不足。**

支持证据：

- 2025 年 RWA value 约 HK$20 亿。
- 部署 11 个 tokenised products。
- 支持 Bosera HKD Money Market ETF 和 Bosera USD Money Market ETF 的 tokenised classes。
- 与 GF International 推出 GF USD Money Market Fund。
- 披露香港首个 real estate RWA 项目部署在 HashKey Chain。
- 作为 tokenisation service provider、DLT provider、fund share distributor。

反证：

- FY2025 on-chain services 收入从 HK$1.248 亿下降到 HK$0.832 亿。
- RWA/tokenisation 收入没有单独披露。
- On-chain services 主要来自 staking，而 staking monetisation rate 从 0.3% 降至 0.2%。
- HK$20 亿 RWA value 相对当前 HK$89 亿市值和 HK$7.23 亿收入，还不能支撑基础设施高估值。

结论：位置在，但水表还没转。

### 3.4 假设四：对人民币资产国际化和中国企业融资有战略价值

判断：**有战略想象，但当前证据不足。**

正面：

- 香港稳定币监管已经生效，HKMA 在 2026 年 4 月发出首批 stablecoin issuer licences。
- SFC 的 tokenised product 二级交易框架可能为 tokenised funds、money market products、未来债券或其他基金产品提供市场结构。
- PRC 2026 年 2 月新规没有简单“一刀切”否定所有境内资产境外 RWA，而是把一部分 offshore ABS token 纳入备案/审批/外汇/数据安全等框架。

反面：

- HKMA 首批稳定币牌照给了 HSBC 和 Anchorpoint，HashKey 没有披露自己获得 issuer licence。
- 稳定币发行的最大经济价值在 reserves/float，HashKey目前更可能吃交易、上架、分发、托管和链上部署费。
- 中国监管口径是“境内严禁、境外严管”，这更像窄门，不是大规模资产自由出海。
- 人民币资产国际化涉及货币主权、资本项目、外汇和 AML/CFT，不是 HashKey 单个平台能决定。

结论：HashKey 是可能的“合规窄门服务商”，不是人民币资产全球化的主导发行方。

## 4. HashKey vs Circle vs BTGO

### 4.1 三家公司吃的价值层

| 公司 | 核心价值层 | 收费方式 | 当前验证度 |
|---|---|---|---|
| Circle | 链上美元发行、储备资产、稳定币网络 | reserve income、交易/支付/平台服务 | 高 |
| BTGO / BitGo | 全球机构数字资产 custody、wallet、settlement、trading、staking、stablecoin infra | custody fee、wallet/settlement fee、trading spread、staking fee、SaaS/service fee | 中低，取决于收入质量 |
| HashKey | 香港合规数字资产交易、托管、RWA tokenisation、资产分发 | 交易佣金、上架费、服务费、托管/经纪、staking、资管费、RWA服务费 | 中低，RWA收入未验证 |

HashKey吃的不是稳定币发行层，也不是全球 custody 标准层，而是：**香港监管许可下的资产进入链上、在合规平台上交易/托管/分发的通道费。**

### 4.2 和 Circle 是否互补

判断：**互补大于竞争。**

Circle 的核心是 USDC 和链上美元网络，HashKey 的核心是香港持牌平台和资产通道。HashKey 可以把 USDC、未来 HKD stablecoins、tokenised funds 和 RWA 放到交易和结算场景里，但它不会天然拿到 Circle 的 reserve income。

如果稳定币支付和 RWA 结算增长，Circle 捕获底层货币网络价值，HashKey 捕获香港场景里的上架、交易、托管、分发和技术服务价值。

最大区别：Circle 的飞轮已经进收入，HashKey 的 RWA/稳定币飞轮还没有进收入。

### 4.3 和 BTGO 是否竞争

判断：**部分竞争，更多是区域与客户层不同。**

竞争点：

- 机构托管。
- 钱包和结算基础设施。
- OTC/prime brokerage。
- staking 和机构链上服务。
- RWA/tokenisation 后台服务。

差异点：

- BTGO 更全球，面向机构后端基础设施。
- HashKey 更香港，面向监管许可、交易分发和中国/亚洲资产通道。
- BTGO 的优势更偏技术、安全、托管历史；HashKey 的优势更偏牌照、地缘和监管场景。

如果全球 RWA 主要从美国国债、美国基金、美国证券开始，HashKey 会被边缘化为亚洲分发节点，Circle、BlackRock、Securitize、Coinbase、BitGo 和传统托管行更可能捕获主价值。

### 4.4 如果中国资产 RWA 发展慢，HashKey 核心收入能否支撑估值

判断：**目前支撑不足。**

FY2025 收入 HK$7.23 亿，对应当前市值约 HK$89 亿，P/S 约 12.4x。这个估值需要市场相信它会进入高增长、高毛利、亏损快速收窄的基础设施阶段。

但当前报表显示：

- 收入只增长 0.3%。
- 毛利率从 73.9% 降到 56.5%。
- 交易促成毛利率从 65.4% 降到 41.0%。
- 净亏损 HK$10.84 亿，超过全年收入。
- 调整后亏损从 HK$5.45 亿扩大到 HK$7.37 亿。

如果 RWA 慢、稳定币合作慢，HashKey 就是一个亏损的区域合规 crypto beta，不是基础设施收费权。

### 4.5 HashKey 的优势到底是什么

排序：

1. 牌照和合规记录。
2. 香港地缘位置和政策窗口。
3. 肖风、万向系、金融机构连接能力。
4. 产品能力和链上技术。
5. 用户网络效应。

产品能力不是没有，但还不是主要护城河。真正的护城河是“香港想发展合规数字资产时，需要可监管、可上市、可审计的示范平台”。这是一种政策与金融基础设施位置，不是纯技术壁垒。

## 6. 牌照与监管优势验证

### 6.1 HashKey 已有牌照

根据招股书和 SFC 公共资料，HashKey 体系内主要牌照包括：

| 地区 | 实体/业务 | 牌照或资质 |
|---|---|---|
| 香港 | Hash Blockchain Limited | SFC Type 1、Type 7、VATP/AMLO 相关许可，运营 HashKey Exchange |
| 香港 | HashKey Capital Limited | SFC Type 1、Type 4、Type 9 |
| 香港 | HBS (Hong Kong) Limited | SFC Type 1、Type 4 |
| 香港 | HashKey Custody Services / HashKey XPert | TCSP 牌照 |
| 新加坡 | HashKey Technology Services Pte. Ltd. | Major Payment Institution，Digital Payment Token Service |
| 日本 | Tokyo Hash Co., Ltd. | Crypto asset exchange service provider registration |
| 百慕大 | HashKey Bermuda | 数字资产交易平台相关资质 |
| 迪拜 | 相关实体 | Virtual Assets Service Provider / Virtual Assets License 相关许可，需继续跟踪续期 |

牌照结论：**牌照组合是真实优势。**

但牌照不是终点。2026 年 SFC 持牌 VATP 名单已经不止 HashKey 和 OSL，Victory Fintech、NewBX 等也进入列表。竞争者越多，HashKey 的牌照稀缺性越会从“独占”变成“早期合规记录”。

### 6.2 香港监管对 HashKey 的正面意义

正面催化：

- Stablecoins Ordinance 于 2025-08-01 生效，HKMA 开始稳定币发行人监管。
- 2026-04 HKMA 首批发放稳定币发行人牌照，稳定币进入受监管发行阶段。
- SFC 2026-04 框架允许 tokenised SFC-authorised investment products 在 SFC-licensed VATPs 上进行二级交易试点。
- PRC 对境内资产境外 ABS tokens 给出监管框架，虽然严格，但说明不是完全无路径。

对 HashKey 的潜在价值：

- 持牌 VATP 可能成为 tokenised funds 二级交易场所。
- HashKey 可以成为稳定币发行人的交易、部署、结算、支付和 RWA 场景合作方。
- RWA 项目需要 chain、tokenisation、custody、distribution、post-issuance risk monitoring，HashKey 已有产品组合。

### 6.3 监管优势的反面

监管也可能是天花板：

- 香港稳定币发行最肥的经济价值给银行或强金融机构，HashKey 未必能拿 issuer economics。
- 中国内地仍严禁虚拟货币相关经营活动，境内 RWA 只能走严格监管下的境外结构。
- RWA 如果被定义为证券或基金，传统银行、券商、基金公司、托管行、港交所生态可能比 HashKey 更有客户信任。
- HashKey 的牌照越合规，业务越慢、成本越重、产品越受限。

## 7. 反证清单

| 反证 | 当前状态 | 判断 |
|---|---|---|
| 主要收入仍来自交易所/交易促成手续费 | 成立。交易促成收入占 72.3% | 强反证 |
| RWA 项目只是试点，没有规模收入 | 基本成立。披露 HK$20 亿 RWA value，但没有单独收入 | 强反证 |
| 香港合规优势不能转化为利润 | 成立。收入 +0.3%，毛利 -23.3%，净亏 HK$10.84 亿 | 强反证 |
| 中国资产上链受监管限制 | 成立。PRC 口径是“境内严禁、境外严管” | 强反证 |
| 机构更愿意选择传统金融机构 | 部分成立。稳定币首批牌照给 HSBC/Anchorpoint；RWA 产品由基金/券商主导 | 中强反证 |
| 稳定币/RWA 叙事没有落到收入 | 成立。稳定币占交易量 48%，但无稳定币收入拆分；RWA 无收入拆分 | 强反证 |
| 公司更像 crypto beta，而不是基础设施收费权 | 目前偏成立。收入仍受交易、staking、数字资产公允价值影响 | 强反证 |
| 牌照稀缺性下降 | 部分成立。SFC VATP 牌照持有人增加 | 中等反证 |
| 零售客户流失 | 成立。零售交易量从 HK$3530 亿降至 HK$734 亿 | 强反证 |

最硬的反证不是“HashKey 没有 RWA”，而是：**它已经披露 RWA 和机构交易增长，但利润表没有跟上。**

### 8.2 翻倍所需财务条件

HashKey 要在三年后合理支撑 HK$178 亿市值，至少需要两种路径之一。

路径 A：高增长基础设施平台估值

| 变量 | 目标 |
|---|---:|
| 合理 P/S | 6-8x |
| 所需收入 | HK$22-30 亿 |
| 所需 CAGR | 45-60% |
| 毛利率 | 60-65% |
| 所需毛利 | HK$13-19 亿 |
| EBITDA | 接近盈亏平衡至 HK$3 亿 |
| 条件 | RWA/稳定币/机构交易收入真正放量，交易促成毛利率修复 |

路径 B：盈利金融基础设施估值

| 变量 | 目标 |
|---|---:|
| 合理 P/E | 30-45x |
| 所需净利润 | HK$4-6 亿 |
| 所需收入 | HK$25-35 亿 |
| 净利率 | 15-20% |
| 条件 | 高毛利 on-chain/RWA/资管收入占比大幅提高，费用率显著下降 |

为什么收入至少要到 HK$20 亿以上：

- FY2025 R&D、销售、行政费用合计约 HK$12.55 亿。
- 即使费用不再扩张，HashKey 也需要约 HK$12.5 亿毛利来覆盖费用。
- 以 60% 毛利率计算，收入至少需要约 HK$20.9 亿才接近经营盈亏平衡。

### 8.3 三年翻倍需要发生什么

必要条件：

1. RWA tokenised value 从 HK$20 亿增长到 HK$300-500 亿，并且公司能获得 tokenisation、custody、distribution、secondary trading 的可见收入。
2. RWA 或 tokenised product 收入单独披露，至少达到 HK$1 亿级别，且高毛利。
3. 稳定币交易量 48% 不是低费率过账量，而能转化为上架费、交易费、支付服务费、结算费或托管费。
4. 香港 tokenised funds 二级交易从试点走向常态，并且 HashKey 拿到主要份额。
5. 交易促成毛利率从 41% 修复到 55-60%。
6. 零售客户不再继续流失，或机构业务 take-rate 明显提升。
7. 费用率下降，调整后亏损连续收窄。
8. 监管不出现重大反复，且没有安全、AML、托管事故。

最敏感变量：

- 交易量 take-rate，而不是交易量本身。
- RWA fee take-rate，而不是 RWA tokenised value 本身。
- 稳定币业务是否有净收入，而不是稳定币交易量占比。
- 香港监管是否允许更多 tokenised products 二级交易。
- PRC 对境内资产 offshore tokenisation 的审批节奏。
- 机构客户是否选择 HashKey，而不是银行、券商、传统托管行或全球平台。

最大反证：

**2026-2027 年 RWA value 继续增长，但 on-chain services 收入仍不增长或继续主要来自 staking。**

这会说明 HashKey 是 RWA 展示窗口，不是 RWA 收费权。

## 9. 投资池结论：核心候选池 / 观察池 / 证据不足池 / 剔除池

### 9.1 投资池分类

| 投资池 | 是否进入 | 理由 |
|---|---|---|
| 核心候选池 | 不进入 | 收入增长、毛利、现金流、RWA收入验证都不足 |
| 观察池 | 可以进入 | 牌照、上市地位、香港 RWA/稳定币政策窗口真实 |
| 证据不足池 | 应进入 | 核心假设没有被财报证明，尤其 RWA 和稳定币收入 |
| 剔除池 | 暂不剔除 | 不是纯概念股，已有真实平台、牌照、资产、交易量、AUM |

最终分类：**证据不足池，偏观察。**

### 9.2 仓位口径

当前更适合作为研究仓或政策期权，而不是核心仓。

建议仓位口径：

| 情形 | 动作 |
|---|---|
| 只看当前财报 | 不买或极小观察仓 |
| 押香港 RWA 政策窗口 | 0-0.25 个单位研究仓 |
| FY2026H1 收入恢复 30%+、毛利率修复、RWA收入披露 | 可升至观察池上沿 |
| RWA收入 HK$1 亿级别、调整后亏损明显收窄 | 才考虑进入核心候选 |

### 9.3 一句话投资判断

HashKey 是“中国资产 RWA + 香港合规数字金融”的最直接港股纯标的之一，但现在买它不是买已验证基础设施，而是买一个政策和商业模式转化期权。

更直接地说：

**HashKey 的牌照和位置已经成立，RWA 收费权还没成立。**
