# 第一部分：一级市场分析（VC视角）

> 核心问题：HashKey 是一台秩序创造机器，还是秩序搬运工？

## 一、这是什么

| 维度 | 内容 |
|------|------|
| 项目名称 | HashKey Holdings Limited (03887.HK) |
| 赛道定义 | 香港合规加密金融基础设施——不是"亚洲 Coinbase"，是"香港牌照仓库" |
| 阶段 | 上市早期（IPO后103天），从创业公司向公众公司转型中 |
| 上市数据 | IPO融资14.79亿港元，发行估值~190亿港元，当前市值110亿港元（缩水42%） |
| 数据快照 | FY2025营收7.23亿港元，亏损10.87亿港元，平台资产184亿港元，年交易量5908亿港元 |

**赛道定义穿透**：

市场叫它"亚洲 Coinbase"——这是隔的。

穿透看：**HashKey 做的事是——当香港政府决定发展 Web3、需要一个"合规标杆"时，成为那个标杆本身。**

它的核心价值不在交易，不在托管，而在**牌照稀缺性**。

- 「Coinbase」= 美国加密市场的垄断性基础设施
- 「HashKey」= 香港政府 Web3 政策的可视化成果

这个差别决定了一切。

## 二、秩序创造机器判定

### 飞轮在不在转？

**结论：飞轮有结构，但没有在转。甚至在倒转。**

HashKey 的理论飞轮：
```
合规牌照 → 机构信任 → 资金流入 → 交易量增长 → 收入增加 → 更多合规投入 → 更深信任
```

实际数据告诉我们飞轮没有转：

| 指标 | 2024年 | 2025年 | 变化 | 飞轮信号 |
|------|--------|--------|------|----------|
| 营收 | 7.21亿港元 | 7.23亿港元 | **+0.33%** | 🔴 停滞 |
| 平台资产 | 114.6亿港元（推算） | 184亿港元 | +60.5% | 🟡 资产增长但未转化为收入 |
| HK业务交易量 | 3,077亿港元（推算） | 5,300亿港元 | +72.3% | 🟡 交易量暴增但收入未变 |
| 亏损 | ~11.9亿港元 | -10.87亿港元 | 收窄8.6% | 🔴 仍大额亏损 |
| 资产管理收入 | 0.80亿港元（推算） | 1.2亿港元 | +49.8% | ✅ 亮点 |

**致命问题**：交易量暴增72%，营收却**零增长**。

这意味着：
1. HashKey 的交易量增长来自 Omnibus 模式（+6.4倍），这是**过账交易量**，不贡献手续费收入
2. 散户端交易量在下降（否则收入不可能零增长）
3. 2024年的收入暴增（+246.6%）大概率来自 2024 年加密牛市行情，而非飞轮效应

**飞轮卡在哪里**：
1. **交易量不等于收入**：Omnibus模式带来的是过账量，不是真金白银的手续费
2. **合规成本是纯消耗**：每年烧掉超过营收规模的资金在合规上
3. **散户增长天花板**：香港本地市场有限（700万人口），国际化未打开
4. **机构来了但绕过它**：机构资金通过 ETF 进入加密市场，不需要经过 HashKey

### 创生公式

**HashKey 从 0 到 1 的路径**：

```
肖风博士（万向系） → 拿到香港首批牌照 → 建立合规基础设施 → 吸引用户 → 上市
```

这个路径已经走完了。问题是：**从 1 到 N 的路径在哪里？**

**从 1 到 N 的假设路径**：
- 路径A：香港散户爆发 → 散户交易费增长 → 覆盖合规成本 → 盈利
  - 概率：低。香港散户基数太小，且 Binance/OKX 仍可通过 VPN 使用
- 路径B：机构通过 HashKey 交易 → 机构收入增长 → 盈利
  - 概率：中低。机构更倾向于通过 ETF 或 OTC，且 Coinbase 是首选
- 路径C：RWA/代币化爆发 → HashKey 成为亚洲 RWA 基础设施 → 新收入来源
  - 概率：低。RWA 仍在早期，且传统金融机构可能自建
- 路径D：政府政策红利持续放大 → HashKey 成为香港 Web3 唯一入口
  - 概率：中低。OKX 获牌后这个假设就碎了

**结论**：没有一条清晰的从 1 到 N 的路径。

### 换不换

**一级市场视角的结论：不投。**

如果 HashKey 是一家还没有上市的公司，作为 VC 我不会投，原因：
1. **飞轮不转**——收入增长与交易量增长脱节
2. **持续亏损**——4年累计亏损超28亿港元，没有盈利路径
3. **市场天花板低**——香港单一市场，天花板可见
4. **竞争悬剑**——OKX 获牌后直接降维打击
5. **不是秩序创造机器**——是政策套利者

## 三、企业基本面分析（AI时代视角）

### 3.1 企业文化

| 维度 | 评估 | 说明 |
|------|------|------|
| **创始人画像** | 肖风博士，区块链行业"教父级"人物，万向区块链实验室前负责人 | 行业先驱，资源丰富，但"教父"不等于"好CEO" |
| **组织架构** | 事业部制（Exchange/Custody/Capital/Cloud/Tokenisation） | 传统金融架构，非扁平化 |
| **核心文化** | 合规优先 | 合规是双刃剑——保护但也束缚创新速度 |
| **人才密度** | 区块链人才密集，AI 人才稀缺 | AI 时代人才结构错位 |
| **万向系烙印** | 深深打上"万向系"印记——长期主义但节奏偏保守 | 家族资本的优势是耐心，劣势是效率 |

**AI 时代适应性评估：中等偏低**

HashKey 的组织围绕"合规交易所"设计，而非"AI 驱动的金融服务"。在以下方面明显不足：
- 未见明确 AI 战略布局
- 数据驱动的运营能力未见突出
- 事业部制 + 合规层级限制敏捷性
- 区块链人才密集但 AI 人才密度未知

### 3.2 商业模式质量

**商业模式 = 政策期权 + 交易手续费 + 托管费 + 投资收益**

```
                    政策红利（核心驱动力）
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
    交易所交易费      托管服务费     资产管理费
    (40-50%收入)    (15-25%收入)  (10-15%收入)
          │              │              │
          └──────────────┼──────────────┘
                         │
                    合规成本消耗
                   (> 营收规模)
                         │
                         ▼
                    持续亏损
```

**核心问题**：
1. **收入结构脆弱**——交易手续费占 40-50%，高度依赖加密行情
2. **合规成本 > 收入**——每年亏损超过营收，这不是"烧钱换增长"，是"烧钱换合规"
3. **没有网络效应**——用户不会因为"其他人用 HashKey"就用 HashKey
4. **没有转换成本**——用户可以零成本切换到其他持牌平台

**商业模式评级：D+**

这不是一个"差的"商业模式，这是一个**不完整的**商业模式——它只解决了"怎么做"的问题，没有解决"为什么是我"的问题。

### 3.3 财报深度分析

#### 收入趋势

| 年度 | 营收(亿港元) | YoY | 亏损(亿港元) | 平台资产(亿港元) |
|------|-------------|-----|-------------|-----------------|
| 2022 | 1.29 | - | - | - |
| 2023 | 2.08 | +61.2% | - | - |
| 2024 | 7.21 | +246.6% | -11.9(估) | ~115(估) |
| **2025** | **7.23** | **+0.33%** | **-10.87** | **184** |

**关键发现**：
1. **2024年的 246.6% 增长是加密牛市红利**，不是飞轮效应
2. **2025年 BTC 冲高到 $97K，HashKey 收入却零增长**——牛市都没赚到钱，熊市怎么办？
3. **平台资产增长 60.5% 但收入不增长**——资产托管更多了，但没转化成收入
4. **4年累计亏损超 28 亿港元**——烧钱速度惊人

#### 运营数据解读

| 指标 | 2025年数据 | 解读 |
|------|-----------|------|
| HK业务交易量 | 5,300亿港元（+72.3%） | Omnibus模式驱动，过账量 |
| Omnibus交易量 | 864亿港元（+640%） | 过账量暴增，不贡献手续费 |
| 资产管理规模 | 72亿港元 | 规模尚可但增长依赖市场行情 |
| 资产管理收入 | 1.2亿港元（+49.8%） | 亮点——但这只占营收的 16.6% |

**Omnibus 模式解读**：

Omnibus 是一种"批量代理交易"模式——HashKey 作为代理人替机构执行交易，交易量算 HashKey 的，但手续费大部分归机构。这解释了"交易量暴增但收入不增长"的悖论。

这本身不是坏事（Coinbase 也有类似模式），但问题是：
- 如果 Omnibus 是增长主力，那 HashKey 本质上是一个**代理执行商**，不是交易所
- 代理执行商的利润率极低，且没有定价权
