## 第一部分：轨道A — 一级市场 / VC视角

### 1.1 这是什么

| 维度 | 内容 |
|------|------|
| **项目名称** | BitGo Holdings, Inc. (NYSE: BTGO) |
| **赛道定义** | 数字资产的信任锚——在密码学信任层上建造银行 |
| **阶段** | IPO后67天，上市即破发，当前处于叙事崩塌后的重新定价期 |
| **员工** | 603人（2025年12月31日） |
| **CEO** | Mike Belshe（联合创始人，前Google/Microsoft/Netscape工程师，年薪$50万无奖金） |

**赛道穿透**：市场叫它"加密托管公司"。BitGo的本质是在一个没有央行背书的金融世界里，用密码学多签和联邦特许牌照建造"信任的物理基础设施"。它不是在托管资产，它是在给整个数字资产生态提供"可以托付性命的保险柜"。

### 1.2 秩序创造机器判定

**结论：秩序搬运，非秩序创造**

#### 飞轮在不在转？

**停在原地。** 核心飞轮应该是：托管更多资产 → 积累更多安全记录 → 降低信任成本 → 吸引更多机构客户 → 托管更多资产。

| 飞轮指标 | 期望 | 实际 | 判断 |
|----------|------|------|------|
| AoP增长 | 环比+5%+ | YoY **-9.2%**（$89.9B→$81.6B） | 🔴 飞轮倒转 |
| 客户→资产转化 | 客户增长带动资产增长 | 客户翻倍，资产下降 | 🔴 飞轮漏斗化 |
| DAS毛利率 | 稳定或上升 | **0.47%→0.21%，腰斩** | 🔴 补贴换量 |
| Staking规模 | 增长 | $31.9B→$15.6B（**-51.1%**） | 🔴 最大齿轮脱齿 |

客户翻倍但资产下降——这不是飞轮，这是漏斗。水从下面流走了。

#### 冲击后变强还是变弱？

**跟着冲击一起震，没有变成燃料。**

- FTX暴雷（2022）：BitGo没有碎，但也没有明显加速吃掉市场。AoP在$81B-$104B间波动
- BTC暴跌（$126K→$67.8K，-46%）：净亏损$14.8M，DAS毛利率继续下滑
- 真正的秩序创造机器应该在BTC暴跌时增长——因为暴跌=波动增大=机构需要更安全的托管。BitGo没有抓住这个窗口

#### 资源是被推来的还是自己来的？

**推的。** DAS毛利率腰斩=用价格换量。与SoFi、Susquehanna、Clear Street的合作需要逐个谈。没有"不推而聚"的引力。

#### 为什么不是秩序创造机器？

BitGo的核心公式是**防御型的**：牌照积累→合规信任→客户选择你→更高壁垒。这是一个"让别人很难替代你"的公式，不是"让你越来越大"的公式。没有自我加速环节。

### 1.3 创生公式

```
BitGo = 牌照壁垒 × 安全记录 × 密码学技术 → 防御性护城河（线性累加，不加速）
```

对比：
- Coinbase = 用户→交易→流动性→更多用户→更多流动性（**正反馈循环**）
- BitGo = 牌照→信任→客户→更多牌照→更高壁垒（**线性累加**）

保险柜不会自己变贵。

- P/S（真收入）≈ $327M / $164.7M ≈ **2.0x**
