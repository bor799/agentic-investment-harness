# 投资主框架 v1.0

> 上位法：[CONSTITUTION.md](兴趣领域/股票投资/归档/交易宪法/CONSTITUTION.md) ｜ 生效日期：2026-07-21 ｜ 源自：[我的投资框架：从宏观到企业的系统思考](兴趣领域/股票投资/归档/我的投资框架：从宏观到企业的系统思考.md)、[供需泊松闭环 v2.3](兴趣领域/股票投资/归档/基础概念/交易策略组合/260606投资框架_供需泊松闭环.md)、[交易认知体系首轮训练](兴趣领域/股票投资/归档/分析报告/archive/260721组合_交易认知体系首轮训练.md)

## 一句话职责

把宏观变化沿产业需求、供给卡点和公司财务传导到估值与四票，回答“这是什么机会、赚哪种钱、什么事实说明我错”。

## 触发条件（什么情境下必须调用本模块）

- 当首次研究任何市场、行业、ETF 或公司时，必须调用本模块建立完整主链。
- 当政策、产业资金、公司财报或竞争格局发生变化时，必须调用本模块判断信息能更新哪一层。
- 当准备把行业观点变成 ETF、个股或期权表达时，必须调用本模块检查工具是否匹配认知深度。
- 当出现“好公司但价格贵不贵”“股价为什么涨跌”“这笔钱从哪里赚”时，必须调用本模块。

## 核心规则（可执行的 if-then 条款，不写理念性空话）

### 1. 主分析链

- 当收到一个投资方向时，先按 `宏观状态 → 产业需求 → 付款人 → 产业链 → 供给卡点 → 公司财务 → 股价三层肉 → 估值语法 → 四票 → 六档动作` 逐层分析；若中间一层断裂，则不得跳到买入结论。
- 当政策或法案刚发布时，只提高研究优先级；若未转成预算、订单、出货、收入或现金流，则禁止把政策写成业务通过。
- 当宏观结论来自降息、宽松或资金流时，只把它交给 `H_R/H_L`；若没有公司经营证据，则 `H_B` 保持原状态。
- 当任何结论形成时，必须同时写明它能证明什么、不能证明什么、下一验证数字和失败条件；若四项缺一，则结论保持 `unknown`。

### 2. 需求、供给与公司

- 当判断需求增长时，必须指出谁付款、预算从哪里来、为何现在付款和用哪个数字验收；若找不到真实付款人，则需求 thesis 不成立。
- 当寻找受益公司时，必须指出它控制的牌照、产能、良率、认证、数据、渠道、网络或客户集成；若竞争者、客户自建或上下游可以短期绕开，则不得称为供给锁死。
- 当公司收入增长时，必须沿 `收入 → 直接成本 → 毛利/类毛利 → 经营费用 → 经营利润 → 净利润 → 现金流` 检查价值留存；若增长没有走到利润或现金流，则只记为待验证规模。
- 当毛利率下降时，只有在渠道权、客户集成、毛利绝对额、经营杠杆或客户锁定至少一项可验证增强时，才允许解释为战略让利；否则按收费权恶化处理。
- 当管理层文化、创始人品质或组织能力被用作理由时，必须找到历史兑现、资本配置或危机处理证据；若无法落到收入、毛利、效率或现金流，则不得单独成为买入理由。
- 当分析中概消费或即时零售时，必须使用本人物流与履约经验提出可验证的效率问题；若个人经验与财报不一致，则以可核验经营数据为准并记录差异。

### 3. 股价与估值

- 当解释股价时，必须先拆成 `内在价值 / 流动性溢价 / 风险偏好` 三层，并指出当前主要驱动层；若无法判断，则不得把价格结果倒推为业务变化。
- 当确定收益来源时，必须从 `价值创造 / 风险补偿 / 约束转移` 中选择，并写明支付者、本人优势和优势失效事实；若答案只是“有人更高价接盘”，则只能记作未验证路径假设。
- 当估值时，必须先识别市场正在使用 `市梦率 / PEG / DCF / PE / 股息率` 中哪套语法；若语法未识别，则估值结论保持 `unknown`。
- 当资产仍处于市梦率阶段时，若收入、毛利、经营利润和现金流尚未验证，则只能 `不投入/继续观察`；只有四票通过且最大损失被定义时，才可候选 `建立验证仓`，不得当核心仓。
- 当资产处于 PEG 阶段时，必须同时看 EPS、EPS 增长率和增长率边际变化；若利润创新高但增速下行，则默认先防估值收缩。
- 当资产使用 DCF、PE、股息率或“越跌越买”逻辑时，必须证明现金流可验证、内在价值主导且有安全边际；若任一条件缺失，则禁止套用成熟价值语法。
- 当发现低估值时，必须比较生意厚度、控制权、现金流和机会成本；若只是绝对价格低或历史跌幅大，则不得称为安全边际。

### 4. 工具与动作

- 当只理解产业方向而缺少公司级差异证据时，优先研究 ETF；若选择 ETF，则必须审计指数编制、行业纯度、前十大集中度、估值、申赎、折溢价、跟踪误差和风格漂移。
- 当能证明公司在控制权、收入、毛利、经营利润或现金流上优于行业时，才进入个股 alpha 研究；若证据只是关注度或价格弹性，则不得从 ETF 认知跳到个股集中下注。
- 当选择期权表达时，只把“如何定义最大损失”交给资本纪律；若期权被用来补业务证据或把低价格变成高胜率，则拒绝该结构。
- 当主链完成时，输出必须包含 `thesis 类型、三种回报账户、估值语法、H_B/H_R/H_L/H_C、下一硬证据、失败条件、六档动作`；若任一票失败或未知，则不得输出风险增加动作。

## 与其他模块的接口（输入依赖谁、输出交给谁）

- 当分析包含政策、利率或资金流时，从 [03_流动性过滤器](兴趣领域/股票投资/归档/交易宪法/skills/03_流动性过滤器.md) 接收 `H_R/H_L` 状态，不自行越权更新 `H_B`。
- 当分析产业供需和事件时，把需求、供给、财务和验证事件交给 [02_泊松供需闭环](兴趣领域/股票投资/归档/交易宪法/skills/02_泊松供需闭环.md) 建事件账本。
- 当出现情绪、成本锚或冲动时，把动作交给 [04_行为纠偏系统](兴趣领域/股票投资/归档/交易宪法/skills/04_行为纠偏系统.md) 审查。
- 当产生任何风险增加候选时，把四票、最大下行和工具结构交给 [05_资本纪律](兴趣领域/股票投资/归档/交易宪法/skills/05_资本纪律.md) 最终承保。
- 当决策结束时，把 thesis、证据和反馈时钟交给 [06_认知训练协议](兴趣领域/股票投资/归档/交易宪法/skills/06_认知训练协议.md) 记录与复盘。

## 已知失效边界（本模块在什么情况下不适用）

- 当目标是核对成交、现金或持仓事实时，本模块不替代唯一主账与券商回报。
- 当参考类、期限和历史校准缺失时，本模块不能提供数值概率或精确 EV。
- 当市场由突发治理、审计、融资或交易机制事件主导时，本模块只能重建 thesis，不能保证退出流动性。
- 当公司处于跨业务转型且分部数据不足时，必须标记 `⚠️ 待裁决`，不得用综合叙事填补分部证据。
