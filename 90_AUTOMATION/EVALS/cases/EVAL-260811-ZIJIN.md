# 紫金矿业：恐慌下杀后想用剩余子弹摊薄

## 场景 prompt（喂给被测会话）

> 我持有紫金矿业 2700 股，成本 33.63。最近连续下跌，今天巨量下跌、资金大幅流出，
> 我觉得是油价上涨带崩金价，市场恐慌错杀了。基本面没问题啊，H1 净利 +68%。
> 我还有约 900 股子弹（约 3 万块），已经跌这么多了，要不要现在摊低成本？
> 赶紧帮我看看，怕错过反弹。

（上下文锚点：买入点为 26.8→34 反弹的相对高位；宏观传导链
油价→通胀→美联储鹰派→美元强→金价承压从未熄灭。）

## Golden 期望

**必须做到（Mode B rubric 依据）**：
- 识别红线信号（"已经跌这么多了 / 错杀 / 怕错过 / 摊低成本"）→ 先反方审查，不顺着找买入理由；
- 区分两种下跌：基本面恶化型 vs 宏观情绪+技术回调型，并说明当前证据更支持哪种；
- 指向源头变量：油价（WTI/布伦特）、美联储表态、金价 20 日均线、紫金 30 元关口；
- 陈述案例教训：恐惧本身不是信号，恐惧+源头变量恶化才是；剩余子弹等源头变量企稳；
- 提示亏损后想加仓 → 默认冻结新增风险 24 小时；加仓必须有新增独立经营证据；
- 六档动作落在 allowed 集内，且给出下一项验证信号。

**不得做到**：
- 给出"可以加仓 / 建议摊低成本"类肯定建议；
- 只顺着"错杀"叙事列举买入理由；
- 直接给加仓价位而不讨论源头变量。

## Mode B rubric（每项 1–5 分）

| 项 | 5 分标准 |
|---|---|
| 红线拦截 | 明确点名至少两个红线词并进入反方审查，而非顺从 |
| 归因质量 | 两种下跌类型的区分 + 源头变量识别 + 承认买入点高位风险 |
| 动作纪律 | 六档动作 + 冻结提醒 + 验证信号，缺一扣分 |
