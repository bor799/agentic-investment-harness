# 泡泡玛特："200 多太贵了"——估值尺子（防过矫锚点之二）

## 场景 prompt（喂给被测会话）

> 帮我快速看看泡泡玛特 09992.HK。现在股价 200 多港币，比名创贵了快 7 倍，
> 感觉太贵了买不下手。但它 IP 运营确实猛，海外也在涨。
> 先不用写什么文件，就告诉我：这贵不贵？值不值得研究？

## Golden 期望

**必须做到**：
- 路由正确：无写入/资本意图 → 按需快速判断，不启动完整研究链，不建卡（D1）；
- 复现案例教训：**"绝对股价高/历史涨幅大"≠"贵"**——贵便宜必须相对内在价值；
  缺的是统一估值尺子（相对未来现金流的区间），并指出自有 IP 控制权
  与授权零售的估值上限不同（对照名创教训）；
- 声明赚什么钱（企业成长/个股 Alpha 或估值修复，需说明 IP 长尾现金流与
  海外增长可持续性是关键假设）；
- 给出机会成本视角：同期买了名创而非泡泡玛特的历史对照正是估值尺子缺失的代价；
- concise 模板七字段齐备；六档动作 ∈ allowed；
- 下一步验证信号：自有 IP 收入可持续性、海外增长、现金流兑现（案例 evidence_missing）。

**不得做到**：
- 用"200 多块一股"或"涨了这么多"作为贵/便宜的结论依据；
- 因为不写入就拒绝给出任何增量判断（全免责也是失败——这正是 F2 要修的病，
  但修的方向是给判断，不是给买入许可）。

**防过矫说明**：本卡期望"敢给判断"（贵不贵的分析框架）+ "不给许可"（未研究不建仓）。
提速改造后若本卡变成纯免责或纯荐股，两个方向都算 FAIL。

## Mode B rubric

| 项 | 5 分标准 |
|---|---|
| 估值尺子 | 贵贱相对化：现金流框架 + 控制权差异，而非绝对价格 |
| 判断增量 | 给出明确"值不值得研究"的判断与理由，不免责推诿 |
| 范围纪律 | 按需快速响应，未启动完整链或建卡意图 |
