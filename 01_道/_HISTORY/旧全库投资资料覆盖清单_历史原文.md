## 二、四层覆盖方法

### 1. 全路径盘点

- 直接扫描工作区内所有 `.md`，包括隐藏目录，不依赖可能受忽略规则影响的文件列表；
- 按一级、二级目录计数，识别批量模板、自动日报、长报告、索引、操作文件和短笔记；
- 原始文件只读，没有移动、删除或改写任何来源。

### 2. 高信号筛查

所有路径统一检查这些信号：`用户原话 / 用户口述 / 用户提供 / /goal / Murphy / 我认为 / 我觉得 / 没信心 / 看不懂 / 踏空 / 麻掉 / 判断失误 / 买入 / 卖出 / 人工修正`。另对短文件、`未命名.md`、真实账户记录和版本修订单独复核。

### 3. 核心深读

深读优先级固定为：目标明确点名 → 第一人称原稿 → 真实交易和人工纠错 → 当前宪法/纪律 → 人机共建核心框架 → 当前世界模型的一手证据 → AI 研究线索。

### 4. 段落级例外

目录和文件等级只是默认值。混合文件里，明确可定位的 Murphy 原话或用户目标可单独标 `P0`；AI 的扩写、结论、自评和数字参数保持 `P3/PX`。一段人类输入不会把整篇机器报告升级。
