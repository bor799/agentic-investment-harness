# OPTIONS

## 先说人话

**今天发生了什么：**旧期权方法已合并成当前唯一期权 Skill。

**为什么重要：**期权最容易把“高胜率”和“收权利金”误读成低风险。本 Skill 把期权先还原成合约义务、最大损失和退出路径。

**现在做什么：**任何期权表达先过本页，再回到 [[02_术/TRADING_SYSTEM/00_DECISION_CONTRACT]] 做四票和资本审查。

## 职责

只允许定义最大损失、合约可核验、退出路径可执行的期权表达。

## 输入

- 合约类型：Long Call / Long Put / Covered Call / Cash-secured Put / Spread。
- 合约参数：标的、方向、行权价、到期日、权利金、乘数、合约数量。
- 风险参数：最大损失、保证金、被行权后的现金或股票交割义务、组合最坏情景。
- 期权特征：Delta、Gamma、Theta、Vega、IV、IVR、DTE、bid/ask、成交量和未平仓量。
- 交易理由：赚基本面、事件跳变、尾部保护、波动率、流动性溢价还是风险偏好。
- 退出计划：止损、止盈、到期、被行权、提前行权、平仓或重新承保。

## 输出

- `allowed_expression`: 是否允许用期权表达观点。
- `max_loss`: 最坏损失，必须能用现金金额写出来。
- `capital_lock`: 保证金或现金占用。
- `exercise_obligation`: 被行权后会发生什么。
- `exit_path`: 不依赖运气和持续 Roll 的退出路径。
- `review_trigger`: 价格、Delta、DTE、IV 或基本面事件触发器。

## 不能证明什么

- 期权高胜率不能证明组合风险低。
- 权利金不能抵消经营票（H_B）失败。
- IVR 高不能证明标的便宜。
- Roll 不能作为生存前提。
- 卖 Put 降成本不能绕开风险增加审查。
- 外部交易者的统计经验不能替代本账户资本约束。

## 失败条件

最大损失不可承受，或退出依赖运气、融资、持续 Roll。

## 合约基础

| 操作 | 本质 | 最大收益 | 最大损失 | 当前权限 |
|---|---|---:|---:|---|
| Long Call | 付费买上涨权利 | 理论无限 | 权利金 | 可用，但必须承认时间损耗 |
| Long Put | 付费买下跌或尾部保护 | 行权价附近封顶 | 权利金 | 可用，适合定义损失 |
| Covered Call | 持股后卖出上行权利 | 权利金 + 行权价以内上涨 | 飞单与机会成本 | 谨慎可用 |
| Cash-secured Put | 收权利金并承诺接盘 | 权利金 | 行权价 - 权利金 | 仅在愿意真接盘且现金已隔离时可用 |
| Naked Call | 裸卖上行义务 | 权利金 | 理论无限 | 禁止 |
| 裸卖 Put / 保证金 Put | 卖出接盘义务但未全额预留现金 | 权利金 | 可导致强平或被迫加杠杆 | 默认禁止 |

这张表的意思很简单：买方期权是“先付保险费，最多亏保险费”；卖方期权是“收保险费，同时承担事故赔付”。卖方不因为胜率高而天然安全。

## 当前允许的表达

### 1. 定义损失的买方期权

适用场景：

- 事件跳变：财报、监管、产品发布、重大合同等；
- 尾部防御：为已有仓位买保护；
- 小仓右尾：明确把权利金当最大亏损。

硬门：

1. 权利金亏完也不能影响生活费、保证金或核心仓位。
2. 必须写明 `DTE / strike / premium / max_loss / event / review_date`。
3. 不能把买 Call 当作“便宜买股票”；它是会过期的权利。
4. 到期前若事件证伪或 IV 坍塌，必须重新承保。

### 2. Covered Call

适用场景：

- 已持有正股；
- 愿意在行权价卖出；
- 目标是降低波动或执行纪律性减仓。

硬门：

1. 行权价必须是自己愿意卖出的价格，不是为了权利金随便写的价格。
2. 不能覆盖核心长期仓位的全部上行。
3. 需要检查股息、提前行权和流动性。
4. 飞单不是“赚少了”这么简单；如果 thesis 仍在加速，Covered Call 可能破坏长期回报。

### 3. Cash-secured Put

适用场景：

- 已独立通过公司基本面和估值审查；
- 当前价格接近可接受买入区；
- 现金已隔离，行权后不会触发融资、借款或被迫卖其他仓位。

硬门：

1. 被行权后等同于买入正股，必须先过四票：`H_B` 经营 / `H_R` 赔率 / `H_L` 周期 / `H_C` 仓位（其中 H_L 周期为软探测器）。
2. `cash_needed = strike * 100 * contracts` 必须真实可用。
3. 权利金不能作为“便宜所以加仓”的理由。
4. 亏损后、暴跌后、想回本时，卖 Put 默认触发 24 小时冷静期和反方审查。

### 4. Defined-risk spread

适用场景：

- 需要表达方向，但必须封顶损失；
- 标的波动大，单腿卖方尾部不可承受。

硬门：

1. 最大损失必须在下单前固定。
2. 多腿流动性和价差必须可执行。
3. 不得为了降低保证金而制造看不懂的复杂风险。

## 禁止或退役的表达

| 表达 | 当前处理 | 原因 |
|---|---|---|
| 裸卖 Call | 禁止 | 理论无限损失，不符合定义损失 |
| 保证金裸卖 Put | 默认禁止 | 下跌时可能触发强平和被迫加杠杆 |
| 依赖 Roll 才安全 | 退役 | Roll 是补救工具，不是初始安全条件 |
| “卖 Put 降成本”绕过加仓审查 | 禁止 | 本质是增加风险和接盘义务 |
| “白赚权利金 / 咋都不亏” | 退役表达 | 会掩盖尾部风险和机会成本 |
| 用固定 90/9/1 或 10% Roll 率授权交易 | 退役为诊断参考 | 未校准到本账户、标的和市场阶段 |
| 单一外部经验如“50 手以内” | 退役为外部样本 | 本账户必须按资本、流动性和最大损失计算 |

## 期权审查流程

```text
观点是什么
→ 能不用期权表达吗
→ 期权赚哪种钱
→ 合约义务和最大损失
→ 被行权后的现金/股票结果
→ 流动性和提前行权
→ H_B 经营 / H_R 赔率 / H_L 周期 / H_C 仓位
→ 退出路径
→ 只输出六档动作
```

如果任何一步无法写清楚，动作只能是 `不投入` 或 `继续观察`。

## 指标用法

| 指标 | 可以说明 | 不能说明 |
|---|---|---|
| Delta | 大致方向暴露、价内概率的粗略代理 | 真实胜率或仓位大小 |
| Gamma | 接近行权价时风险变化速度 | 风险一定可控 |
| Theta | 时间价值流失 | 收租一定安全 |
| Vega / IV | 波动率暴露 | 标的一定便宜 |
| IVR | 当前 IV 相对历史位置 | 均值回归必然发生 |
| DTE | 时间窗口和衰减速度 | 到期前不会剧烈波动 |
| Bid/ask | 交易成本和退出难度 | 成交后一定能平稳退出 |

旧方法中关于 Delta、Theta、IVR、DTE 的讨论保留为筛选输入；旧公式和固定阈值不直接授权交易。

## Roll 的位置

Roll 只允许作为事后补救或重新承保，不允许作为事前安全理由。

### 允许 Roll 的条件

1. 原仓位最大损失仍可承受。
2. 新仓位的最大损失、保证金和到期日重新计算。
3. Roll 后不是单纯把亏损推到未来。
4. 新合约仍能独立通过四票和资本审查。

### Roll 频率诊断

旧方法里的 “Roll 频率超过 10% 说明策略过激” 保留为诊断信号，但不作为固定校准阈值。

如果 Roll 频率升高，先做四件事：

1. 降低新开仓频率；
2. 检查行权价是否太近、Delta 是否过大；
3. 检查是否为了权利金牺牲安全边际；
4. 复盘是否处于亏损后想回本状态。

## 小资金约束

旧方法明确指出：小资金做卖方期权容错极低。这条保留，并写成当前规则：

- 小资金不能用保证金卖方期权追求“快速做大”；
- 权利金收入不能当工资或稳定现金流；
- 单次期权最大亏损要按账户总资本写成金额；
- 如果一次尾部事件会让账户失去继续研究和等待的能力，禁止开仓。

## 结论模板

```text
期权表达：Long Call / Long Put / Covered Call / Cash-secured Put / Spread / 禁止
赚的钱：基本面 / 事件跳变 / 波动率 / 尾部保护 / 风险偏好
最大损失：
现金或保证金占用：
被行权结果：
退出路径：
H_B：  # 经营
H_R：  # 赔率
H_L：  # 周期（软探测器）
H_C：  # 仓位
动作：不投入 / 继续观察 / 建立验证仓 / 升级确认仓 / 不加仓 / 降级或退出
```
