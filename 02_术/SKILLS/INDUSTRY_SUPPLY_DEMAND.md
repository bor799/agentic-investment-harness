# INDUSTRY_SUPPLY_DEMAND

## 职责

判断需求付款人、供给反应和利润池。

## 输入

需求、付款人、产能、库存、交付期、ASP、成本。

## 输出

供需链路、利润池归属、下一验证数字。

## 不能证明什么

事件密度或泊松类比不能直接当概率或仓位参数。

## 失败条件

需求无法穿透到收入、毛利、经营利润和现金流。

## 产业链验收

```text
宏观变化
→ 需求生成
→ 真实需求
→ 谁付款
→ 钱经过哪些环节
→ 哪个环节必经
→ 哪个供给最难扩、最难替代
→ 是否有收费权
→ 收费权能否留下利润和现金
→ 下一条独立事件
```

只看到基金、补贴标题、政策口号或行业热词，不等于需求成立。产业资金必须追踪到订单、出货、使用量或收入；如果找不到真实付款人、预算来源和现在付款的理由，需求 thesis 不成立。

选择产业链环节时，必须说明为什么该环节最缺、最慢、最难绕开且先获得利润。只是标签最热、价格弹性最大或 AI 讲得最多的环节，从候选池剔除。

## 供给反噬时钟

每个“稀缺”必须同时写：

- 扩产周期；
- 复制时间；
- 客户自建可能性；
- 技术替代；
- 竞争进入；
- 监管放开或强制降价；
- 上下游议价转移；
- 稀缺失效日期。

判断供给锁死时，验证复制所需的时间、资本、监管、信任、工艺、生态或迁移成本。客户可以自建、竞品可以免费打包、上下游可以绕开时，供给结论必须降级；绕开已成为事实时，触发 `H_B` 重评。

收入增长必须沿 `收入 → 直接成本 → 毛利/类毛利 → 经营费用 → 经营利润 → 净利润 → 现金流` 验收。增长如果被低毛利过账、补贴、营运资本或 CapEx 吃掉，不能称为收费权。

飞轮、管理层、组织文化和创始人品质只能作为辅助解释。它们必须落到收入、毛利、效率、资本配置、危机处理或现金流；不能进报表的飞轮，只作叙事。

## 周期与存储专用闭环

周期品按下面链路验收：

```text
有效供给
→ 库存
→ 实现价格 - 单位成本
→ 毛利
→ 经营现金流
→ 资本开支
→ 下一轮供给反应
```

只看价格或峰值 PE，结论无效。近端短缺和远端扩产必须同时记录；只保留看多一侧，证据网络不完整。

存储行业必须分开服务器 DRAM、HBM、消费 DRAM 与 NAND。结构性 HBM 需求不能外推成全部品类永久短缺。

## 事件时钟

`lambda` 只描述独立验证事件在变密、变稀或接近。未固定参考类、期限、结算规则和历史校准时，禁止把 `lambda` 写成数值概率，状态必须写 `uncalibrated`。

同一新闻、同一管理层口径或多个 AI 的重复转述，只计一个根证据。催化剂增多时，也要同时记录下行事件、永久损失、等待成本、脆弱性和机会成本。

高质量等待必须写清已知事实、缺失证据、下一事件、复查时间、失败条件和允许动作。没有复查时钟的等待，是资本钝化。

## 线性需求和非线性利润

很多材料链的物理消耗近似线性：终端产量增加多少，单位用量不大变时，上游材料消耗大致按比例增加。但投资回报通常不是线性的。真正会跳变的是订单、价格、单吨利润、现金流和估值。

用电解液、AI Token、储能材料和铜链这类主题时，必须拆开：

```text
终端有效需求
→ 物理消耗量
→ 采购订单
→ 售价 - 原料/制造/折旧成本
→ 单吨毛利
→ 经营利润和净利润
→ 回款和经营现金流
→ 估值
```

只看到终端需求加速，不等于材料利润爆发。需要同时验证付款、库存、有效供给、价格接受、成本结构和现金流。

## 六道闸门

| 闸门 | 要验证什么 | 失败信号 |
|---|---|---|
| G1 物理需求加速 | 装机、产量、招标、中标、出口、使用量 | 终端热度没有进入实际产量 |
| G2 付款和订单落实 | 采购订单、合同、预算、回款 | 只有意向，没有付款人 |
| G3 库存周期反转 | 电芯/材料/渠道库存天数连续下降 | 终端消耗被库存满足 |
| G4 有效供给接近约束 | 利用率、交期、认证、环保安全、扩产周期 | 扩产和替代先到 |
| G5 价格接受和利润传导 | 售价覆盖成本，单吨毛利扩张 | 收入增，毛利不增 |
| G6 财务兑现 | 扣非利润、应收、存货、经营现金流 | 利润留在报表，不进现金 |

G1 和 G2 是必选项；没有真实需求和付款，其他信号不成立。没有 G6，不把公司级判断写成“已验证”。

## AI Token 需求传导

AI Token 总需求要分成三项：

```text
AI 总账单 = 每个 Token 的价格 × Token 使用量
硬件物理需求 = Token 使用量 ÷ 每单位芯片/电力能处理的 Token
```

Token 变便宜、额度变大和模型变快，不自动等于硬件、电力、储能或机器人公司受益。只有使用量增速大于单位效率增速，且需求继续传到订单、产能利用率、售价、毛利率和现金流，才能更新经营票（H_B）。

Token 需求到股东现金也要过七道闸门：付费使用量、单位效率、芯片/网络/电力需求、供应商订单、供给没有同步过剩、利润转现金、估值未透支。任一道卡住，主题真实也可能股票不赚钱。

## 边界

“需求变大”不等于“公司好投资”。如果供给同时被政策、资本开支或技术路线加速打开，稀缺可能被消灭，需求越强反而越容易吸引竞争。
