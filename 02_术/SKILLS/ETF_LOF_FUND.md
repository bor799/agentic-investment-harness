# ETF_LOF_FUND

## 职责

处理 ETF、LOF、基金和包装层路径。

核心任务不是只判断“基金涨不涨”，而是把两个问题拆开：

1. **底层资产值不值得买**
2. **当前这个交易载体值不值得用**

底层资产与包装层价格必须分账，不能把 LOF/ETF 的折溢价误当成底层资产本身的估值。

## 输入

成分权重、目标 ETF/LOF、申赎规则、场内价格、最新官方 NAV、盘中估算 NAV、历史折溢价序列、证券借贷、经理口径、费用、流动性和退出深度。

## 输出

底层业务、包装层资金和交易路径的分账，并至少给出：

- 底层资产信号
- 当前场内价
- NAV / 估算 NAV
- 当前折溢价率
- 历史溢价分布窗口
- 当前溢价所处分位
- 包装层判断：便宜 / 合理 / 偏贵 / 极端
- 对仓位执行的影响

---

## 核心原则：先看底层，再看包装

### 1. 底层资产负责回答“该不该买”

例如商品、指数、行业本体处于周期低位、估值低位或既定技术买入区时，可以形成底层买入许可。

底层买入许可必须独立于 ETF/LOF 当前是否存在溢价。

### 2. 包装层负责回答“以什么价格买”

ETF/LOF 的折溢价属于**交易载体定价**，不是底层资产定价。

定义：

```
premium = market_price / nav_or_estimated_nav - 1
```

如果官方 NAV 滞后，而底层资产盘中波动明显，应优先提供可解释的估算 NAV，并明确标记“估算”及其误差来源。

---

## 溢价处理：用历史分布，不用固定阈值

### 核心经验

**不要机械规定“溢价超过 10% 就不能买”或“必须等到 0–3% 才能买”。**

不同 LOF/ETF 的申赎约束、资金偏好、流动性和历史交易习惯不同，合理溢价中枢也不同。

因此，判断高低必须相对于**该载体自身的历史溢价分布**。

### 中位数是合理价格锚

历史溢价中位数（P50）定义为包装层的“正常/合理状态”。

- 当前溢价 ≈ P50：**合理，可接受**
- 当前溢价明显低于 P50：**包装层偏便宜**
- 当前溢价明显高于 P50：**包装层偏贵**

Murphy 的执行偏好：

> 只要溢价回到自身历史中位数附近，就可以视为合理交易成本；不要求等待极低溢价。

### 用分位处理“高低”

优先报告当前溢价在历史分布中的 percentile，而不是只报一个绝对百分比。

经验性语言：

| 历史位置 | 包装层解释 | 执行含义 |
|---|---|---|
| ≤ P25 | 低溢价 / 便宜 | 若底层也给出买入许可，可提高买入力度 |
| P25–P75 | 正常区 | P50 附近视为合理价，可正常执行 |
| ≥ P75 | 高溢价 / 偏贵 | 降低追买强度，等待底层上涨或溢价回落 |
| ≥ P90 | 极端溢价 | 主要暴露于“壳回归”风险，不应仅因底层看多而追价 |

这些分位是**描述框架，不是机械自动交易阈值**。

---

## 历史窗口纪律

计算中位数和分位数时必须写清楚样本窗口。

优先：

1. 使用足够覆盖当前市场结构的近期窗口；
2. 若申赎规则、限购、市场制度或资金结构发生变化，应以变化后的 regime 为主；
3. 同时可给长期窗口作对照，但不能让失效的旧制度数据稀释当前中枢。

例如可以同时报告：

```
近 60 个交易日 P50
近 120 个交易日 P50
当前 percentile
```

但不应事先把“60 日”固化成永远正确的参数。

---

## 底层信号 × 包装层信号

最终执行应采用二维判断，而不是只看一个指标。

| 底层资产 | 包装层溢价 | 解释 |
|---|---|---|
| 值得买 | 低于/接近 P50 | 最舒服的执行区 |
| 值得买 | P50 附近 | 合理，可以买 |
| 值得买 | 明显高于 P75 | 方向正确但载体偏贵，控制买入力度 |
| 不值得买 | 低溢价 | 壳便宜不代表底层便宜 |
| 不值得买 | 高溢价 | 双重不利，避免追买 |

**包装层只调节执行强度，不替代底层投资逻辑。**

---

## 典型案例：白银 LOF 161226

白银案例形成的可复用经验：

- 白银本体的周期位置，用白银/沪银自身的周期信号判断；
- 161226 的场内价格与 NAV/估算 NAV 用来计算包装层溢价；
- 不再使用固定“10% 溢价警戒线”作为唯一判断；
- 以 161226 自身近期有效历史分布的 P50 作为合理价格锚；
- 若白银本体处于买入区，161226 溢价回到 P50 附近，即可认为工具价格合理；
- 高于 P75/P90 时才逐步把风险重点从“白银方向”转向“LOF 壳回归”。

该案例只用于说明方法，不能把 161226 的具体中位数直接迁移到其他 ETF/LOF。

---

## 不能证明什么

- 分散不等于低风险。
- 折价不等于底层便宜。
- 溢价低不等于底层值得买。
- 历史高溢价不意味着未来还能维持高溢价。
- 底层上涨不保证高溢价 LOF 同比例上涨：溢价收敛可以吃掉底层收益。
- 某一个历史窗口的 P50 不是永久“公允价值”，市场制度变化后必须重算。

## 失败条件

以下任一发生时，不能直接按历史分位执行：

- 无法验收持仓、申赎、券商路径、费用和退出深度；
- 官方 NAV 严重滞后且无法形成可靠估算 NAV；
- 限购、停牌、申赎暂停等导致套利机制失效；
- 产品规则或市场结构刚发生重大变化，历史溢价分布失真；
- 样本过少或出现明显 regime shift；
- 底层资产与基金实际跟踪标的发生偏离。

## 复盘记录模板

每次因折溢价调整交易时，至少记录：

```
instrument:
underlying:
market_price:
nav_official:
nav_estimated:
premium:
history_window:
premium_p25:
premium_p50:
premium_p75:
premium_p90:
current_percentile:
underlying_signal:
wrapper_signal:
execution:
why:
postmortem:
```

复盘的核心不是问“当时溢价是多少”，而是问：

> 当时这个溢价相对于它自己的历史分布，是便宜、合理，还是贵？
