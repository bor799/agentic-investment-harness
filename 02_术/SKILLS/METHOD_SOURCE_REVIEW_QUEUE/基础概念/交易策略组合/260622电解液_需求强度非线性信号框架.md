# 电解液需求强度：非线性信号与贝叶斯跃迁框架

## 结论先行

电解液的**物理消耗换算关系大体是线性的**：在给定电池路线和单位用量不大变的前提下，电芯产量增加多少 GWh，乘以每 kWh 电解液单耗，大致得到材料消耗量。终端需求的时间路径可以是 S 曲线或阶跃式增长，但电芯产量到电解液消耗这一步通常近似按比例换算。

真正非线性的不是这一步，而是后面四步：

1. 去库存切换成补库存，订单增速突然高于终端消耗增速；
2. 产能利用率越过临界点，边际供给不足，交期和价格跳升；
3. 售价上涨、原料自供和固定成本摊薄叠加，单吨利润增速高于销量增速；
4. 市场确认利润中枢上移，估值从周期底部发生状态重定价。

所以，研究目标不能写成“需求很好”，而应写成：

> 终端有效 GWh 是否加速，付款是否落实，产业库存是否反转，现有有效产能是否接近极限，下游是否接受提价，最后是否进入利润和现金流。

只有这些信号发生**交互共振**，才叫非线性机会。

## 两个概念修正

### 1. 谁是需求方

- 新能源车、储能系统、重卡、电芯厂是沿链条向上的需求来源。
- 天赐材料是电解液、六氟、添加剂等材料的供给方。
- 我们作为投资者既不生产电解液，也不创造产业需求；我们提供的是资本，并判断哪一段需求能够转成可留存利润。

需求方能提供给天赐的不是“高质量电解液”，而是**合格且付费的电芯 GWh、采购订单和回款**。天赐能提供的才是通过认证、稳定交付的高质量电解液。

### 2. 贝叶斯不是情绪叠加

贝叶斯是用新证据更新原判断的概率。情绪只能是一类低权重观察信号。

```text
先验判断
+ 独立的新证据及其似然比
= 后验判断
```

十篇文章转载同一政策，不是十条证据；股价大涨、资金流入、媒体热度通常来自同一个价格事件，也不能重复累计。

## 从终端到利润的完整链条

```text
终端有效需求 GWh
-> 电芯实际产量 GWh
-> 电解液物理消耗量
-> 客户库存变化和安全库存
-> 电解液采购订单
-> 天赐实际出货量和份额
-> 电解液售价 - 原料/制造/折旧成本
-> 单吨毛利
-> 经营费用
-> 经营利润和净利润
-> 回款、经营现金流
-> 估值
```

可以写成三个公式：

```text
物理需求 = 电芯实际产量 × 单位电解液用量

采购需求 = 物理需求 + 下游库存增量 + 安全库存调整

公司利润 = 公司出货量 × 单吨毛利 - 经营费用 - 税费及其他损益
```

其中第二、第三个公式最容易出现非线性。

## 六道闸门

### G1 物理需求加速

看真实终端，不看主题热度：

- 动力、储能、重卡至少两个终端同时加速；
- 电芯产量、装车量、出口和储能中标量互相验证；
- 观察环比斜率和三个月移动平均，不只看低基数同比。

单一政策目标、招标公告或远期规划只能算弱到中等证据。

### G2 付款和订单落实

按强度排序：

```text
政策目标 < 招标 < 中标 < 采购订单 < 交付 < 回款
```

必须区分：

- 框架长单和实际采购订单；
- 项目招标和项目开工；
- 电芯厂排产计划和实际产量；
- 营业收入和销售回款。

### G3 库存周期反转

最容易制造“突然爆发”的变量：

- 下游从去库存转向补库存；
- 六氟、电解液、电芯库存天数连续下降；
- 排产增速高于终端装机增速，但没有形成新库存堆积；
- 客户提高安全库存、提前锁量。

如果没有库存数据，只能把非线性判断降级，不能用价格代替库存。

### G4 有效供给接近约束

名义产能不是有效产能。真正要看：

- 产能利用率是否进入 85%-90% 以上区间；
- 交期是否连续拉长；
- 新产能投产是否延期，良率和客户认证是否卡住；
- 检修、环保、安全事故是否造成有效供给收缩；
- 客户是否开始向第二供应商抢量，而不是继续压价。

`85%-90%` 是初始研究阈值，必须按企业和行业历史校准，不能机械套用。

### G5 价格接受和利润传导

价格上涨不是充分条件。强信号应同时出现：

- 多家供应商而非单一报价源提价；
- 长协和大客户订单也能调价，不只是小额现货；
- 下游接受高价，采购量没有明显下降；
- 电解液售价涨幅能够覆盖六氟、溶剂和添加剂成本；
- 龙头单吨毛利扩张，而不是收入增、毛利不增。

### G6 财务兑现

最终只认：

- 出货量；
- 单吨收入、单吨毛利或主营毛利率；
- 扣非经营利润；
- 应收账款和存货；
- 经营现金流。

利润增长而现金流长期不增长，只能叫报表利润，不能叫完整兑现。

## 非线性状态机

| 状态 | 已通过闸门 | 含义 | 研究动作 |
|---|---|---|---|
| S0 叙事 | 0-1 道 | 政策、新闻或股价单点 | 只建清单 |
| S1 扩散 | G1 + G2 初步 | 终端需求和付款开始发生 | 主题基金小观察仓 |
| S2 加速 | G1 + G2 + G3/G4 任一 | 订单开始快于物理消耗 | 提高跟踪频率，不追完美价格 |
| S3 紧平衡 | G1 + G2 + G3 + G4 + G5 | 库存、产能和提价共振 | 才能称非线性盈利窗口 |
| S4 财务兑现 | S3 + G6 | 单吨利润和现金流确认 | 可讨论确认仓和公司 Alpha |
| S5 拥挤/衰减 | 扩产激增、库存回补完成、估值透支 | 非线性开始反向 | 降低赔率假设、准备退出 |

**硬规则**：

- G1 和 G2 是必选项；没有真实需求和付款，其他信号不成立。
- G3、G4、G5 至少同时满足两项，才能从普通增长升级为非线性候选。
- 没有 G6，不把公司级判断写成“已验证”。
- 股价、媒体热度和所谓主力资金不属于六道闸门。

## 贝叶斯更新规则

核心假设：

> `H` = 未来两个季度电解液进入紧平衡，天赐单吨利润中枢持续上移。

每条证据必须记录：

| 字段 | 内容 |
|---|---|
| 证据 | 具体事实，不写观点 |
| 闸门 | G1-G6 中哪一层 |
| 来源 | 公司公告、政府、行业数据库、媒体或市场价格 |
| 独立性 | 是否与已有证据同源 |
| 方向 | 支持 / 反对 / 分叉 |
| 时效 | 领先、同步还是滞后 |
| 似然比 | 真紧平衡下出现概率 / 非紧平衡下出现概率 |
| 后验 | 更新后的概率区间 |

证据权重原则：

| 等级 | 证据 | 处理 |
|---|---|---|
| A | 实际订单、交付、库存下降、产能利用率、客户接受提价、现金流 | 高权重 |
| B | 中标、排产、长协进展、多个报价源同步变化 | 中权重 |
| C | 政策、规划、扩产意向、公司口头指引 | 低到中权重 |
| D | 媒体叙事、分析师目标价、股价和资金流 | 仅报警，不更新产业后验或最多微调 |

## 交互项：非线性的真正来源

不要把六个维度简单平均。可以用一个门控模型：

```text
非线性机会强度
= 物理需求 × 付款确认 × (库存反转 + 供给约束 + 价格接受中的至少两项)
× 公司份额与自供优势
× 财务兑现概率
```

任一必选项接近零，整体判断就应大幅下降。

典型交互：

- `需求加速 × 去库转补库`：订单增速高于终端消耗增速；
- `补库 × 高利用率`：交期拉长，买方从压价转向保供；
- `提价 × 自供六氟 × 固定成本摊薄`：单吨利润和总利润同时放大；
- `财务确认 × 低预期估值`：股价发生第二次状态迁移。

## 当前实测：截至 2026-06-22

| 闸门 | 当前信号 | 判断 |
|---|---|---|
| G1 物理需求 | 5 月储能系统招标 23.8GWh、同比 +704.9%；中标 13.5GWh、同比 +154.7% | **强，但集中在储能系统层** |
| G2 付款/订单 | 中标量和项目付款人明确；材料端长协存在，但实际采购和回款仍需跟踪 | **中等** |
| G3 库存反转 | 缺少连续、可核验的电解液和六氟库存天数序列 | **未通过** |
| G4 供给约束 | 尚未看到广泛交期拉长或客户抢量；行业仍有扩产能力 | **未通过** |
| G5 价格接受 | SMM 6 月 11 日称电解液价格稳定，但电芯厂继续严控采购成本，对高价六氟接受度低 | **偏负面** |
| G6 财务兑现 | 天赐 Q1 毛利率强，但经营现金流为负，应收和存货增长较快；Q2/H1 未披露 | **部分通过** |

当前状态更接近 **S1 扩散，尚未进入 S3 紧平衡**。

这里已经存在需求加速机会，但还没有足够证据证明“电解液利润将非线性爆发”。最关键的下一批信号不是股价，而是：

1. 电芯实际排产和产量能否持续高于季节性；
2. 六氟和电解液库存是否连续下降；
3. 下游是否从压价转为接受提价和提前锁量；
4. 天赐 Q2 毛利率、应收、存货和经营现金流是否共同改善。

## 跟踪节奏

| 频率 | 看什么 | 作用 |
|---|---|---|
| 每日 | 价格异动、公告、事故、检修 | 只做异常报警 |
| 每周 | 六氟/电解液价格、交期、排产、库存方向 | 判断 G3-G5 是否接近阈值 |
| 每月 | 电池产量/装车/出口、储能招中标、电解液产量 | 判断 G1-G2 和需求广度 |
| 每季度 | 出货、毛利、费用、应收、存货、现金流 | 验证 G6 |

每日小幅波动不应触发仓位。只有产业状态迁移、估值越过事前阈值或组合风险预算被突破，才触发投资动作；其中价格只能改变赔率，不能改变产业事实。

## 胜率的正确目标

不能只追求最高胜率。高胜率但一次亏损巨大，仍然是差系统。

```text
可持续优势
= 胜率 × 赔率 × 可重复性 × 不出局
```

在证据尚处 S1-S2 时，用主题基金承接行业方向，用极小个股仓验证公司 Alpha；进入 S3-S4 后，才允许提高公司级确信。这样牺牲一部分最低买价，换取更高的生存率和可重复性。
