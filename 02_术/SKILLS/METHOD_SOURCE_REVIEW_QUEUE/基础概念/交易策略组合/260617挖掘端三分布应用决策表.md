# 挖掘端三分布应用决策表

> 把 `挖掘端 SOP v1.0` §1 的"四思维模型"落到可操作的决策表。回答：什么环节用什么模型、看什么参数、验证什么信号、对应什么投资动作。

## 0. 为什么是"三分布 + Leontief"

用户原话提到了三种理论：**泊松、幂律、贝叶斯**。严格说，贝叶斯不是一个分布，而是一种"用新证据更新先验"的方法。LOOP_PROMPT 在三者之外加了 **Leontief 互补约束**，凑成"四件套"。理由：

| 模型 | 回答什么 | 不回答什么 |
|---|---|---|
| **Leontief** | 系统产出由谁决定 | 利润如何分配 |
| **泊松** | 事件密度（需求强度） | 利润归谁 |
| **幂律** | 利润向头部集中 | 什么时候爆发 |
| **贝叶斯** | 概率如何更新 | 系统是否互补 |

四个模型各管一段，组合起来覆盖"系统约束 + 需求强度 + 利润归属 + 判断修正"四个维度。任何一个单独使用都会失真。

一句话总纲（来自 LOOP_PROMPT）：

```text
需求是波松到达率；
利润是幂律集中；
判断靠贝叶斯更新；
产出由 Leontief 短板决定。
```

## 1. 四模型决策矩阵（核心表）

按"环节类型"选用模型。同一环节可能跨多个模型，但**先问主导模型**，再叠加辅助模型。

| 环节类型 | 主导模型 | 辅助模型 | 关键参数 | 验证信号 | 投资动作 |
|---|---|---|---|---|---|
| **互补系统硬件瓶颈**（GPU/HBM/CoWoS/电力/冷却） | Leontief | 泊松+幂律 | 各环节产能、扩产周期、互补度 | 哪个环节"卡脖子"导致系统交付失败 | 买最短板的寡头 |
| **寡头垄断材料**（ABF 膜/T-glass/InP 激光器/HBM） | 幂律 | Leontief | CR1/CR3、市占率、毛利率、客户认证 | 头部 1-3 家是否吃下 80%+ 利润 | 买头部控制者 |
| **订单驱动周期**（储能招标/PCB 扩产/铜价） | 泊松 | 幂律 | 事件到达率 `λ`、订单 GWh、招标条数、扩产公告 | 事件密度是否上移 | `λ` 上移时占位 |
| **技术路线不确定**（CPO/LPO/NPO/固态电池/钠电） | 贝叶斯 | 泊松 | 先验概率、新证据强度、路线分叉 | 哪条路线的证据在累积 | 买"共同瓶颈"而非"赌路线" |
| **资源端矿企**（紫金/江西铜/盐湖/中矿） | 幂律+泊松 | Leontief | 资源储量、品位、扩产周期、TC/RC、铜价 `λ` | 矿山产量达成率、铜价是否进入事件密集期 | 资源 Beta + 公司 Alpha 分别估值 |
| **加工制造端**（PCB/CCL/铜箔/电解液） | 泊松+幂律 | Leontief | 客户认证数、产能利用率、ASP、毛利率 | 订单密度 + 头部厂份额 | 找"认证最久+扩产最慢"的环节 |
| **监管驱动链**（稳定币/RWA/特高压并网） | 贝叶斯+泊松 | 幂律 | 法案进度、牌照发放、合规客户数 | 政策事件密度、合规入口集中度 | 法案落地前置占位 |
| **基础设施并网**（电网/变压器/施工） | Leontief+泊松 | 幂律 | 并网排队年数、变压器交付周期、施工能力 | 排队长度是否拉长 + 寡头集中 | 买交付能力最强的 |

## 2. 各模型详解

### 2.1 Leontief：短板识别

**核心公式**：

```text
系统产出 = min(环节 A, 环节 B, 环节 C, ...)
```

任一环节缺位，整体产出归零。AI 数据中心是最典型的 Leontief 系统：

```text
可用算力 = min(GPU, HBM, CoWoS, 网络, PCB/ABF/CCL, 电力, 冷却, 储能, 并网, 运维)
```

**使用纪律**：

- 不要试图把所有环节都按 Leontief 看。**只有互补性强的系统才适用**（如 AI 数据中心、储能系统、电动车电池包、特高压电网）。
- 单一产品（如某个 SaaS）不是 Leontief 系统。
- 一旦识别为 Leontief 系统，**投资重点 = 找最短板**，不是找最大市场。

**判断最短板的指标**：

| 指标 | 含义 | 阈值 |
|---|---|---|
| 扩产周期 | 从决策到投产多久 | ≥ 18 个月为强约束 |
| 客户认证周期 | 新供应商进入需多久 | ≥ 12 个月为强约束 |
| 资本密集度 | 单线投资额 | ≥ 10 亿美元为高门槛 |
| 替代路线成熟度 | 是否有 Plan B | < 2 年内出现替代 = 弱约束 |
| 当前产能利用率 | 是否满产 | ≥ 95% 为紧张 |

**反模式**：把"行业增速"当成 Leontief 短板。错。短板是"扩不出来"的环节，不是"需求大"的环节。

### 2.2 泊松：事件密度计

**核心思想**：不要押单条新闻，要押"事件到达率 `λ` 是否上移"。

**`λ` 上移的验证信号**（任一主题通用）：

| 事件类型 | 验证指标 | 数据源 |
|---|---|---|
| 订单/招标 | 月度订单 GWh、招标条数、YoY 增速 | CNESA/InfoLink/行业网站 |
| 产品发布 | 800G/1.6T/CPO 试点数量、客户采用公告 | 公司财报/官方博客 |
| 涨价/长单 | ASP 季度环比、长期协议签约数 | 公司 IR/行业报告 |
| 政策/法案 | 月度政策密度、合规要求落地比例 | 监管文件/部委网站 |
| 客户采用 | 渗透率、付费主体数量、复购率 | 行业调研/客户访谈 |
| 扩产公告 | 月度扩产公告数、产能增量 | 公司公告 |

**`λ` 上移的判定阈值**：

- 同方向事件 ≥ 3 类同时变密 → `λ` 上移确认
- 同方向事件 ≥ 2 类，但 ≥ 1 类反向 → 待验证
- 仅 1 类事件变密 → 不构成 `λ` 上移，可能是噪音

**应用纪律**：

- 不要把单一新闻当 `λ`。一个招标、一个产品发布、一个客户采用，都是单点。
- `λ` 上移是"事件簇"现象，不是"单点"现象。
- CNESA 5 月储能招标同比 +518% 是典型 `λ` 上移——同类信号同时变密（量、价、招标条数、客户采用）。

**反模式**：看到一两个订单就说"`λ` 上升"。错。要看事件簇。

### 2.3 幂律：控制点识别

**核心思想**：需求扩散，但利润向少数头部集中。

**幂律识别的量化阈值**：

| 指标 | 强幂律 | 中幂律 | 弱幂律/无幂律 |
|---|---|---|---|
| CR1 | ≥ 60% | 30-60% | < 30% |
| CR3 | ≥ 80% | 60-80% | < 60% |
| 头部毛利率 | ≥ 50% | 30-50% | < 30% |
| 头部客户认证数 | ≥ 5 家头部客户 | 2-4 家 | < 2 家 |
| 替代者出现周期 | ≥ 5 年 | 2-5 年 | < 2 年 |

**典型幂律环节（来自训练集）**：

- ABF 膜：味之素 CR1 ≈ 95%，毛利率 ≈ 60%，30 年没人能撼动 → **极强幂律**
- T-glass：日东纺独家顶级规格，新产能 2026 年底才上线 → **极强幂律**
- HBM：SK 海力士 + 三星 + 美光 CR3 ≈ 100% → **强幂律**
- GPU：NVIDIA 占 AI 训练 ≈ 80% → **强幂律**
- LFP 正极：湖南裕能 + 德方纳米 + 万润 + 富临精工 CR4 ≈ 70% → **中幂律**
- 储能电芯：宁德 + 比亚迪 + 亿纬 CR3 ≈ 65% → **中幂律**
- PCB（普通）：分散，CR10 < 40% → **弱幂律**（但 AI PCB 子赛道强幂律）

**应用纪律**：

- 强幂律环节 = 买头部 1-2 家，不要分散。
- 中幂律环节 = 买头部 + 第二梯队对冲。
- 弱幂律环节 = 别买，靠"主题"不靠"控制点"，赚不到超额。
- "参与者"vs"控制者"的判断：公司是否能影响定价、是否能阻止替代路线、是否能锁定客户认证。

**反模式**：把"行业增长"等同于"所有公司都受益"。错。幂律环节里，第 4-5 名之外的公司可能完全不受益。

### 2.4 贝叶斯：先验更新

**核心思想**：研究是一次性下结论的反面。每条新证据都要更新先验概率。

**贝叶斯更新模板**（每个主题必填）：

```text
先验 P(H)：某个判断的概率（如 "CPO 在 2026 全面爆发" = 30%）
新证据 E：一条具体信息（如 "NVIDIA 推 Quantum-X Photonics 到产品层"）
似然 P(E|H)：如果 H 真，E 出现的概率（如 70%）
似然 P(E|¬H)：如果 H 假，E 出现的概率（如 20%）
后验 P(H|E)：用贝叶斯公式更新后的概率
```

**简化版（实战用）**：

| 证据强度 | 上调幅度 | 例子 |
|---|---|---|
| 强证据（产品化、订单、财报验证） | +15-25% | NVIDIA 把 CPO 推到产品层 → "光互连方向真实" 上调 |
| 中证据（路线图、客户意向、试点） | +5-15% | Broadcom 强调 200G SerDes 延长铜互连 → "铜光共存" 上调 |
| 弱证据（高管发言、行业传闻） | +0-5% | 某云厂商高管说"考虑 CPO" → 微调 |

**贝叶斯表必出三张**：

1. **上调的判断**（新证据支持原判断）
2. **下调的判断**（新证据反对原判断）
3. **分叉/待验证**（证据指向多个方向，不收敛）

**应用纪律**：

- 不要写死后验。所有判断都是概率，不是结论。
- 分叉是有价值的——它标记下一轮要训练的能力。
- 三张表各 ≥ 3 行，少于 3 行说明读得不够深。

**反模式**：把单条强证据直接当成"已验证"。错。要累计多条证据才能把概率推到 80%+。

## 3. 四模型组合：三链分布指纹对比

每个主题都不是单模型主导，而是"主+辅"组合。识别主题的"分布指纹"是 SOP 的核心能力。

| 主题链 | 主导模型 | 辅助模型 | 指纹特征 | 当前阶段 |
|---|---|---|---|---|
| **AI 算力链** | Leontief + 幂律 | 泊松 + 贝叶斯 | 互补约束硬（缺一不可）+ 头部控制强（NVIDIA/味之素） | 接力式瓶颈迁移（GPU→HBM→光→电力） |
| **储能材料链** | 泊松 | 幂律 + Leontief | 招标密度驱动 + 价格周期 + 电芯/材料头部集中 | `λ` 上移确认（招标 +518%），等待利润修复 |
| **铜资源链** | 资源端幂律 + 加工端泊松 | Leontief | 资源端矿企集中（紫金/江西铜/Freeport）+ 加工端订单驱动 | 资源 Beta + 加工 Alpha 双层 |
| **特高压设备链**（待验证） | Leontief + 贝叶斯 | 泊松 + 幂律 | 互补约束（发输配用）+ 政策驱动 + 寡头（南瑞/许继/思源） | 法案落地前置期 |
| **稳定币/RWA 链**（待验证） | 贝叶斯 + 泊松 | 幂律 | 监管驱动 + 牌照集中 + 合规入口争夺 | 先验快速更新期 |

**指纹识别的硬规则**：

- 如果一个主题"无论怎么换技术路线，某些环节都绕不开" → Leontief 主导。
- 如果一个主题"订单/招标/产品发布在变密" → 泊松主导。
- 如果一个主题"利润被 1-3 家吃掉" → 幂律主导。
- 如果一个主题"技术路线还在分叉" → 贝叶斯主导。

**重叠时的优先级**：Leontief > 幂律 > 泊松 > 贝叶斯。理由：互补约束是最硬的物理约束，先识别短板再问利润归谁。

## 4. 反模式（什么时候不该用某模型）

| 反模式 | 错在哪 | 正确做法 |
|---|---|---|
| 用泊松分析 Leontief 系统 | 单点订单不能告诉你哪个环节是短板 | 先做 Leontief 短板识别，再看泊松密度 |
| 用幂律分析贝叶斯主题 | 技术路线没定，头部还没出现 | 先做贝叶斯路线判断，再看幂律格局 |
| 用贝叶斯分析已成型赛道 | 行业已经定型，概率没意义 | 直接用幂律找头部 |
| 用 Leontief 分析单一产品 | 单一产品没有互补约束 | 用波特五力或商业模式分析 |
| 三分布同时用 | 失焦 | 先选主导模型，再叠加辅助 |
| 把"行业增速"当泊松 `λ` | 增速是结果，`λ` 是事件密度 | 看订单/招标/产品发布的密度 |

## 5. 应用案例（来自训练集）

### 5.1 AI 算力链：Leontief + 幂律联合

- **Leontief**：识别"GPU→HBM→光→电力→冷却"接力式短板，当前短板在 HBM 和电力
- **幂律**：识别 ABF 膜（味之素 95%）、T-glass（日东纺独家）、HBM（CR3=100%）三个极强幂律环节
- **泊松**：识别 1.6T 光模块出货、CPO 试点、ABF 涨价的事件密度
- **贝叶斯**：修正"CPO 全面爆发"的先验，更新为"2026 是 PCB/ABF/CCL/LPO/NPO，2027-2028 才是 CPO"

### 5.2 储能材料链：泊松主导

- **泊松**：CNESA 5 月招标 +518%、4h 中标价 +27.1%、InfoLink Q1 出货 +98.7% → `λ` 强上升
- **幂律**：储能电芯 CR3 ≈ 65%（中幂律），LFP 正极 CR4 ≈ 70%（中幂律），不极强但够用
- **Leontief**：储能系统 = min(电芯, PCS, EMS, BMS, 热管理, 消防) → 电芯是短板
- **贝叶斯**：先验"储能是新能源主题" → 更新为"储能是 AI 电力链外溢"

### 5.3 铜资源链（待训练）：双层指纹

- **资源端**：幂律主导（紫金矿业、江西铜业、Freeport、Southern Copper），核心看铜价 + 产量 + 海外运营
- **加工端**：泊松主导（PCB/CCL/铜箔订单驱动），核心看认证 + 毛利率 + 扩产
- **关键判断**：不要把资源端 Beta 当成加工端 Alpha（用户原话）

## 6. 决策树：拿到一个新主题怎么选模型

```text
新主题进来
    ↓
Q1: 是否有"互补约束"（缺一不可的系统）？
    Y → Leontief 主导（如 AI 数据中心、储能系统、特高压电网）
    N → 进 Q2
    ↓
Q2: 是否有"少数头部吃大头"的格局？
    Y → 幂律主导（如 ABF 膜、HBM、GPU）
    N → 进 Q3
    ↓
Q3: 是否有"事件密度上移"（订单/招标/产品变密）？
    Y → 泊松主导（如储能招标、铜价周期、PCB 扩产）
    N → 进 Q4
    ↓
Q4: 是否有"技术路线分叉"？
    Y → 贝叶斯主导（如 CPO/LPO/NPO、固态电池、钠电）
    N → 重新审视主题，可能不是挖掘端适用场景
```

**重要**：实际主题常是多个 Y 的组合，选**第一个 Y 对应的模型为主导**，其余为辅助。
