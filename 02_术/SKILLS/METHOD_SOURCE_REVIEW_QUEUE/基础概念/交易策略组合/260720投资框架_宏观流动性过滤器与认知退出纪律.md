# 宏观流动性过滤器与退出纪律

## 先说人话

**今天发生了什么：**一组来自二级市场实战的经验被拆开重组：顺着增量资金、产业趋势和事件催化寻找机会；不追求吃完整段行情；只赚自己能解释、能验证的钱。

**为什么重要：**这些经验里有很强的常识，也混有三个危险跳步：把降息直接等同于股票增量资金，把板块热度直接等同于公司变强，把事后涨跌直接等同于买卖对错。

**现在该做什么：**每次研究先检查“政策水 → 市场水 → 板块水 → 标的水”是否真的传导，再检查公司能否把产业需求变成利润；最后用四张票和资本纪律决定动作。没有传导证据时，新增风险只能是 `继续观察/不加仓`。

## 一句话总纲

> 宏观决定风向和水位，产业决定水流向哪里，公司决定水能否变成利润，估值决定好结果是否已经被买完，资本纪律决定我能不能活到兑现。

最关键的纪律是：

> 宏观宽松和资金流只有权限更新赔率票 `H_R` 与周期票 `H_L`，不能直接提高经营票 `H_B`；它究竟改善还是恶化回报，要继续看传导和价格。如果资金没有进入目标板块，降息只是背景，不是买入信号。

## 一、这套实战经验真正有价值的部分

### 1. 先选有水的市场，再选能留住水的公司

二级市场收益不只来自公司利润增长，也来自流动性和风险偏好抬升估值。对 1—3 个月的事件窗口而言，市场有没有新增承接尤其重要。

但“有水”必须拆成两件事：

- **产业需求的水**：客户预算、订单、出货和收入是否增长。
- **金融市场的水**：资金是否愿意进入股票、目标板块和目标标的。

前者主要更新经营票 `H_B`，后者主要更新赔率票 `H_R` 和周期票 `H_L`。两种水同时出现，才可能形成“利润增长 + 估值抬升”的双击。

### 2. 不追求吃完整段行情，只赚认知范围内的钱

买入前能解释的状态迁移、能验证的经营数字和能承受的风险，构成“认知范围”。退出后股价继续上涨，不自动证明卖错；同样，最后赚钱也不能原谅违规过程。

真正该复盘的是：

```text
当时的 thesis 是否仍成立
→ 当时的估值与路径是否仍合法
→ 退出是否遵守事前规则
→ 后续上涨来自原 thesis，还是新信息和新一轮风险偏好
```

### 3. 行业懂到哪一层，工具就用到哪一层

- 只理解产业方向，没有公司级差异证据：优先研究 ETF。
- 能证明某家公司在收入、毛利、经营利润、现金流或控制权上显著优于行业：才进入个股 alpha 研究。
- 只有关注度、恐慌修复和事件催化，没有经营证据：只能归入 O 赔率职责，不能伪装成 H 高证据投资。

ETF 也不是免研究工具。至少要检查指数编制、行业纯度、前十大集中度、估值、申赎与折溢价、跟踪误差和基金经理风格漂移。

### 4. 信息优势不等于信息数量

“扩大信息面”是对的，但单纯增加新闻量会制造伪确信。真正需要扩大的是**独立根证据**：政策原文、客户预算、产业数据、公司财报、竞争者动作、资金流与市场微观结构。

同一新闻被十个媒体和十个 AI 重复转述，仍然只算一条根证据。信息处理顺序统一为：

```text
来源是谁
→ 它能证明哪张票
→ 它不能证明什么
→ 哪条独立反证会推翻它
→ 下一次用哪个数字验收
```

## 二、宏观流动性四级传导

“降息 = 股市有增量资金”不是恒等式。完整链条必须逐级验收。

| 层级 | 必答问题 | 可观察证据 | 最常见误判 |
|---|---|---|---|
| 1. 政策水 | 货币、财政和信用条件是否边际宽松 | 政策利率、实际利率、央行资产负债表、信用扩张、财政投放、汇率约束 | 把降息本身当成风险资产上涨保证 |
| 2. 市场水 | 新资金是否真的进入权益而非现金、债券或去杠杆 | 股票 ETF/基金净申购、融资余额、总成交、市场宽度、新高新低、股债相对表现 | 只看指数上涨，不看参与面和承接 |
| 3. 板块水 | 权益资金是否集中进入目标产业 | 行业 ETF 申赎、成交占比、板块宽度、相对强弱、盈利预期修正、龙头与跟随股表现 | 把单一龙头上涨当成全行业增量 |
| 4. 标的水 | 目标公司是否有可持续承接和退出通道 | 成交额、换手、价差、机构持仓变化、解禁/减持、指数纳入、事件前后量价 | 把高关注度当成稳定流动性 |

白话解释：央行把水放出来，不代表水一定进股票；进了股票，不代表进科技；进了科技，也不代表进入我买的公司。四层中任何一层断裂，都要把“增量市场”降级为待验证假设。

### 同一层水还要拆成四个坐标

| 坐标 | 它回答什么 | 最低观察项 |
|---|---|---|
| 存量 | 已有多少资金和仓位留在场内 | 两融余额、基金仓位、ETF 份额 |
| 边际流 | 现在是新增还是撤出 | ETF 净申赎、融资净买入、主动资金流 |
| 分布 | 水进入多少资产，还是只拥挤少数龙头 | 涨跌家数、板块宽度、成交集中度 |
| 深度 | 卖压出现时能否低冲击退出 | 价差、盘口、折溢价、冲击成本、好坏消息敏感度 |

成交额只能描述交易活跃度。`1.5/2/3 万亿元` 等绝对数值没有跨状态的固定含义，不得单独授权风险增加。市场总钱变多，也可能同时发生主动基金高仓位、杠杆资金撤退和少数 ETF 承接；必须看边际来源与分布。

### “赚谁的钱”改成三种回报账户

1. **价值创造**：公司收入、利润和现金流增长支付回报。
2. **风险补偿**：市场为期限、波动、流动性和尾部风险支付补偿。
3. **约束转移**：对手因赎回、杠杆、监管、期限或工具限制必须交易，我用更长时间、更低杠杆或更合适工具承接。

对手不需要犯错。每笔研究必须写清：赚哪种钱、由谁或哪个经济过程支付、我的优势是什么、什么事实令优势失效。

### 三种宏观状态

不用固定总分，也不填写主观概率。只记录根证据、反证和状态。

| 状态 | 证据结构 | 对体系的影响 | 默认动作 |
|---|---|---|---|
| 顺风 | 政策水、市场水和板块水互相确认，市场宽度改善 | `H_L` 改善；若价格未透支，`H_R` 可能改善；`H_B` 不变 | 仍须四票全过，才可 `建立验证仓/升级确认仓` |
| 分化 | 政策宽松，但权益承接弱；或指数上涨、板块宽度窄 | 贝塔不稳定，注意力交易占比上升 | `继续观察/不加仓`，优先有经营证据和可退出工具 |
| 逆风 | 信用收缩、赎回/去杠杆、板块资金流出与宽度恶化共振 | `H_L` 恶化，流动性溢价可能收缩 | `不加仓`；若事前失败条件触发，`降级或退出` |

宏观状态不是自动择时器。逆风中仍可能有盈利驱动或供给冲击的结构机会，顺风中也会有基本面恶化的公司。

## 三、把“板块蓄水池”变成可证伪判断

“半导体、存储等板块是蓄水池”只能作为起始比喻，不能直接进入交易。必须回答四个问题：

1. 水从哪里来：政策资金、产业资本、居民资金、机构配置还是杠杆资金？
2. 为什么留下：盈利上修、产业稀缺、指数配置、事件催化还是纯情绪？
3. 谁先拿到水：行业龙头、瓶颈环节、ETF 权重股还是高弹性小票？
4. 什么表示漏水：盈利预期下修、ETF 净赎回、市场宽度收窄、拥挤交易松动还是供给反噬？

板块进入候选池至少需要两类相互独立的证据：

- 一类来自产业/盈利，例如订单、价格、毛利、EPS 预期修正。
- 一类来自市场承接，例如 ETF 申赎、板块宽度、成交与相对强弱。

只有资金流，没有盈利承接，主要赚流动性和风险偏好钱；只有盈利，没有资金承接，可能对但需要更长时间。两者不能互相冒充。

## 四、事件催化与“流动性修复”如何归类

高关注事件导致恐慌、流动性枯竭，随后关注度和承接恢复，确实可能产生短线机会。但这类交易的收益来源通常是：

```text
关注度回流 + 被迫卖压衰减 + 风险偏好修复
```

它不是公司在一两天内突然更赚钱。因此：

- 只更新 `H_R/H_L`，不更新 `H_B`。
- 默认归 O 赔率职责，最大损失必须预先定义。
- O 赔率职责不是四票豁免区，风险增加仍须 `H_B/H_R/H_L/H_C` 全部通过。
- 必须写清事件时钟、流动性恢复证据、失效点和退出通道。
- 单次赚到十几个点不能证明方法有效；需要同口径样本、净成本和失败案例做历史校准。
- 没有固定参考类、期限和结算规则时，概率状态写 `uncalibrated`。

任何需要“它很热门，所以总会有人接盘”才能成立的交易，都不是 H 高证据投资。

## 五、对原观点的批判性审计

| 原观点 | 保留什么 | 必须改写什么 |
|---|---|---|
| 宽松环境才有好贝塔 | 流动性确实影响估值和承接 | 宽松是贝塔加速器，不是必要条件，更不是充分条件；降息也可能是增长恶化的结果 |
| 找增量市场和蓄水池 | 先选资金与产业共振的方向 | 必须同时验证资金来源、板块宽度和盈利承接，不能凭热门标签判断 |
| 跟随国家宏观战略 | 政策可提高产业需求出现的可能 | 政策必须转成预算、订单、收入、毛利和现金流；战略正确不等于标的正确 |
| 优质资产面前动作多余 | 好生意减少无意义交易 | 只在经营票、估值、路径和仓位票持续有效时成立；估值透支或 thesis 失败时，不动也会造成损失 |
| 巴菲特开始卖，行情就结束 | 大资金退出会影响短期供求 | 不能把个别大资金的交易与行情终点建立必然因果；这是容量、执行与后验叙事的混合 |
| 持有 1—3 个月算长线 | 时间比日内长，能等待催化兑现 | 这更接近事件/波段窗口；长期与否由 thesis 的兑现周期决定，不由月数命名 |
| 只懂行业就买 ETF | 能降低单公司判断错误 | 仍要审计指数结构、集中度、估值、工具风险与风格漂移 |
| 信息面越广越好 | 独立信息源能减少盲点 | 信息数量不等于证据质量；同根转载和 AI 共识不得重复计票 |
| 退出后涨十倍也不后悔 | 不用后视镜否定当时正确流程 | 仍要复盘是否过早设窄 thesis、是否忽略新证据；不后悔不等于不学习 |
| 拿总资产固定 20% 投资 | 闲钱与生存资金必须分开 | 固定比例不适用于所有人；以可投资资本 `R`、个人现金需求和压力损失预算为准 |
| 1—10 万散户 90% 亏损 | 提醒小账户交易成本和行为偏差 | 未提供来源和统计口径，不进入体系，不用作仓位或胜率依据 |
| T+1 保护散户 | 交易限制会降低部分冲动频率 | 也会限制日内止损和风险处理；属于市场微观结构，不构成个股投资理由 |

## 六、完整投资流：从有水到留住利润

```text
0. 生存边界：生活现金与可投资资本 R 分开
→ 1. 宏观流动性：政策水是否进入权益、板块和标的
→ 2. 产业需求：谁付钱，真实需求是否增长
→ 3. 供给卡点：谁控制最难扩、最难替代的环节
→ 4. 财务变现：收入 → 毛利 → 经营利润 → 净利润 → 现金流
→ 5. 市场定价：估值语法与股价三层肉
→ 6. 四票闸门：H_B / H_R / H_L / H_C
→ 7. 工具选择：ETF / 个股 / 定义损失的 O 赔率表达
→ 8. 事件监控：经营事件与流动性事件分账更新
→ 9. 退出复盘：按事前 thesis 评价，不用事后最高价评价
```

这条链把三种常被混淆的东西拆开：

- **宏观流动性**回答“市场愿不愿意给钱、是否允许等待”。
- **产业与公司基本面**回答“公司能不能赚到并留下钱”。
- **估值与纪律**回答“现在买是否还有钱可赚、错了会不会出局”。

## 七、认知退出纪律：解决“卖飞”与“频繁交易”

### 买入前冻结五项

```yaml
thesis_type: 基本面 | 流动性 | 风险偏好 | 认知差 | 事件跳变
expected_horizon:
three_verification_numbers:
failure_condition:
allowed_action:
```

退出只能来自事前允许的理由：

| 退出来源 | 典型信号 | 动作语言 |
|---|---|---|
| 经营票失败 | 订单、毛利、经营利润或现金流证伪 | `降级或退出` |
| 赔率票耗尽 | 好结果已被完美定价，净赔率不足 | `不加仓/降级或退出` |
| 周期票失败 | 流动性、期限或退出通道恶化，无法安全等待 | `不加仓/降级或退出` |
| 仓位票失败 | 单票、风险簇或压力损失超限 | `不加仓/降级或退出` |
| 时间窗结束 | 催化落地但没有状态迁移，证据斜率转负 | `降级或退出` |

“优质资产面前动作多余”改写为：

> 当经营票持续通过、估值没有透支、路径允许等待、仓位票合法时，频繁动作通常多余；任一票失败时，不动作同样是主动承担风险。

### 卖出后的正确复盘

- 卖出后继续涨：先判断是原 thesis 延续，还是新信息启动了新 thesis。
- 若当时按冻结规则正确退出：记为“认知边界内的正确动作”，不追高证明自己。
- 若原 thesis 未坏、只是短期波动就卖：记为“退出过早”，修正规则，不用结果羞辱自己。
- 若违规持有最后赚钱：仍记纪律失败。
- 若正确退出后价格大涨：不记失败，但保留“能否用更低风险方式保留少量右尾”的研究问题。

| 模块 | 必答问题 | 状态/证据 |
|---|---|---|
| 政策水 | 货币、财政、信用条件边际如何 |  |
| 市场水 | 权益是否有净承接，市场宽度如何 |  |
| 板块水 | 目标行业的资金、宽度和盈利预期是否共振 |  |
| 标的水 | 成交、价差、解禁减持与退出通道如何 |  |
| 流动性四坐标 | 存量、边际流、分布和深度分别如何 |  |
| 产业需求 | 谁付钱，订单/预算/渗透率看什么 |  |
| 公司差异 | 相比 ETF，个股的 alpha 证据是什么 |  |
| 收益来源 | 赚价值创造、风险补偿或约束转移的钱；谁在支付 |  |

| 下一验证 | 下一个经营数字和流动性数字分别是什么 |  |
| 失败条件 | 什么情况说明我错 |  |
| 动作 | 六档动作之一 |  |

## 九、不做清单

1. 不把全球降息直接写成目标市场增量资金。
2. 不把指数上涨直接写成目标板块有水。
3. 不把板块有水直接写成公司业务变强。
4. 不把高关注和接盘预期当长期流动性。
5. 不用一次短线盈利证明事件策略有效。
6. 不用“优质资产”取消估值、路径和资本纪律。
7. 不因卖出后继续上涨否定当时正确的退出。
8. 不因害怕卖飞而拒绝执行失败条件。
9. 不用信息数量替代独立根证据。
10. 不用固定闲钱比例替代个人资本与生存约束。
11. 不用宏大政策叙事跳过收入、毛利、经营利润和现金流。
12. 不把 1—3 个月的事件交易伪装成长期价值投资。
13. 不用绝对成交额阈值自动触发买卖。
14. 不把市场总资金增加等同于目标标的边际流入。
15. 不把“存在被迫卖方”直接写成卖方已耗尽或价格必然错。
16. 不用一天反弹取消去杠杆、集中度或冷静期纪律。
