# AI Token需求增长与稀缺性迁移投资框架

## 今天发生了什么

用户端的感受是真的：编码套餐的额度在增大，模型的输入理解和输出生成速度也在变快，AI 被塞进越来越多的编程与工作流。

但投资上不能从“我用了更多 Token”一步跳到“所有 AI、半导体、机器人和储能都应该上涨”。

## 这件事为什么重要

最重要的公式只有两个：

```text
AI 总账单 = 每个 Token 的价格 × Token 使用量

硬件物理需求
= Token 使用量 ÷ 每单位芯片/电力能处理的 Token
```

所以有两股力量同时在拉扯：

- Token 变便宜、额度变大，会刺激更多使用。
- encoder / prefill 和 decoder 变快，代表单位硬件效率提高，可能减少每个 Token 需要的硬件和电。

只有当使用量的增速大于单位效率的增速，硬件、网络和电力的总需求才会继续上升。这才是杰文斯悖论在 AI 里的完整版，不是“便宜了，所以一定用更多”。

## 额度变大不等于需求已经进入报表

编码套餐额度增大有三种可能：

1. 客户真的用得更多，且愿意付更多钱。
2. 推理效率提升，供应商用同样的成本能给更多额度。
3. 价格战或获客补贴，供应商先牺牲毛利换使用量。

对用户，三种都是好事；对股东，只有第一种最值钱。第二种可能利好应用层，但压低单位算力需求；第三种甚至会损害模型供应商的利润。

## 从 Token 到股东现金的七道闸门

```text
Token 使用量上升
-> 是付费使用，不是赠送额度
-> GPU / 存储 / 网络的利用率上升
-> 云厂商继续增加资本开支
-> 设备和材料公司拿到订单
-> 供给没有同步增长，售价/毛利没被竞争吃掉
-> 利润转成经营现金流
-> 当前估值还没把这些好消息全部计价
```

前面任何一道闸门卡住，“Token 需求很真”都可能变成“股票不赚钱”。

## 稀缺性最可能搬到哪里

| 层级 | 与 Token 需求的距离 | 利润要看什么 | 当前代表 |
|---|---|---|---|
| HBM / 先进封装 / 高端加速器 | 最直接 | 位元出货、ASP、利用率、毛利率 | 半导体瓶颈链 |
| 高速网络 / 光互连 | 很直接 | 800G/1.6T/特种光纤订单、价格、现金流 | 亨通光电等 |
| 电力 / 并网 / 冷却 / UPS | 中长期直接 | AIDC 订单、交付周期、毛利率 | 电力设备链 |
| 储能电芯 / 材料 | 间接 | AI 配储占比、全社会储能需求、材料价差、回款 | 159566、天赐材料 |
| 机器人 | 更远的下游期权 | 量产、单机毛利、软件收入、客户付款 | 562500 |

最容易犯的错是把“AI 需要电”直接写成“电解液公司受益”，或把“模型更强”直接写成“机器人 ETF 的利润马上到来”。中间都隔着多道收入、成本和现金流闸门。

## 映射到当前五类资产

| 资产 | 估值语法 | 三层肉中最厚的一层 | 买它主要赚什么钱 |
|---|---|---|---|
| 天赐材料 | PEG + 周期利润修复 | 内在价值开始增厚，但现金流未完成 | 基本面钱 + 事件跳变钱 |
| 亨通光电 | PEG + 光纤涨价周期 | 内在价值改善，但风险偏好仍很厚 | 基本面钱 + 认知差钱 |
| 储能电池 ETF | 行业 Beta + PEG | 风险偏好与材料利润修复混合 | 基本面 Beta + 风险偏好钱 |
| 半导体 ETF | PEG + 高风险偏好 | 内在价值与拥挤溢价并存 | 景气扩散钱 + 流动性钱 |
| 机器人 ETF | 市梦率 -> PEG 的过渡期 | 风险偏好 | 右尾期权 + 风险偏好钱 |

## 以后只看四组数字

1. **用量**：付费 Token、AI 收入、客户留存，而不是套餐赠送额度。
2. **效率**：每元、每度电、每张卡能生成多少 Token。
3. **供给和利润**：订单、产能利用率、售价、毛利率、库存、账期。
4. **终端 ROI**：企业用 AI 新增的收入或节约的成本，能不能覆盖 AI 账单。

## 不做什么

1. 不把个人编码额度变大当成全行业收入数据。
2. 不因为 Token 需求真就购买任何价格的芯片和光通信股。
3. 不把 AI 配储当成天赐材料的主要近期利润来源。
4. 不把机器人的长期空间当成当下收入和现金流。
5. 不把一天大跌自动解释成安全边际。

## 失败条件

- Token 使用增速低于推理效率增速，总硬件需求不再增长。
- 云厂商 AI 资本开支下修，或 AI 收入无法覆盖投入。
- HBM、光互连、电力或储能供给快速扩张，销量增长但售价和毛利率下降。
- 企业 AI 试点长期无法形成可衡量的收入、成本节约和现金流。
