# 投资框架：股价三层肉、估值三段式与不做清单

## 0. 版本定位

这篇不是原文摘要，而是把“股价三层肉和估值三段式”练进股票投资库的底层判断直觉。

以后看任何标的，第一反应不是“贵不贵”，也不是“是不是好公司”，而是先问：

> 这只股票现在主要靠哪一层肉定价？市场正在用哪一种估值语法？我买入后到底赚哪一种钱？

如果这三个问题答不出来，不进入买入讨论。

## 1. 一句话总纲

股价不是内在价值的纯函数，而是：

```text
股价 = 内在价值 + 流动性溢价 + 风险偏好
```

不同企业阶段，市场会切换不同估值语法：

```text
0 -> 1：市梦率
1 -> 10：PEG
10 -> 100：DCF / PE / 股息率
```

真正要练成的直觉是：

> 不同阶段赚的钱不是同一种钱。市梦率赚风险偏好和流动性的钱，PEG赚 EPS 增速和边际加速的钱，DCF赚自由现金流和内在价值折价的钱。把三种钱混在一起，是大多数亏损的起点。

## 2. 股价三层肉

| 层 | 它是什么 | 主要验证数字 | 常见幻觉 |
|---|---|---|---|
| 内在价值 | 公司未来能留下的现金流、利润、收费权 | 收入、毛利、经营利润、净利润、自由现金流、ROIC | 把短期景气当永久能力 |
| 流动性溢价 | 市场资金、利率、融资环境、风险资产整体估值抬升 | 利率、信用条件、ETF/基金流入、成交额、估值分位、融资成本 | 把水位上涨误认为公司变强 |
| 风险偏好 | 投资者愿意为未来故事、增长斜率、右尾想象支付的价格 | 估值倍数扩张、叙事强度、机构共识、散户热度、期权 IV、卖方目标价 | 把情绪定价误认为基本面定价 |

判断顺序：

```text
先看股价涨跌主要来自哪层肉
再看这层肉是否还能继续变厚
最后看自己有没有能力赚这层钱
```

一个资产可以是好资产，但不一定是好下注。因为它可能已经把三层肉都吃满了。

流动性溢价不能只用“全球降息”判断。必须沿 [[兴趣领域/股票投资/02_术/SKILLS/METHOD_SOURCE_REVIEW_QUEUE/基础概念/交易策略组合/260720投资框架_宏观流动性过滤器与认知退出纪律]] 的四级传导验收：

```text
政策水 → 市场水 → 板块水 → 标的水
```

政策宽松只能说明第一层可能改善；资金真正进入目标板块和标的，才可能让流动性这层肉变厚。即使变厚，也只更新赔率票 `H_R` 和周期票 `H_L`，不直接更新经营票 `H_B`。

## 3. 估值三段式

| 阶段 | 市场估值语法 | 股价主导变量 | 赚什么钱 | 最危险的错配 |
|---|---|---|---|---|
| 0 -> 1 | 市梦率 | 梦想空间、风险偏好、流动性 | 右尾期权、叙事扩散、融资环境 | 用 DCF 包装梦想，然后把它当核心仓 |
| 1 -> 10 | PEG | EPS、EPS 增长率、增长率的边际变化 | 业绩加速和估值双击 | 利润创新高但增速边际下行时还越跌越买 |
| 10 -> 100 | DCF / PE / 股息率 | 自由现金流、资本回报率、分红、稳定增长 | 内在价值折价和复利 | 用成熟资产心法去接高风险偏好资产的杀估值 |

这三段不是道德排序。市梦率不是天然低级，DCF也不是天然高级。它们只是不同市场阶段的不同语言。

真正重要的是：

> 承认市场正在用哪种语言给它定价，然后用匹配的仓位、验证指标和退出规则处理它。

## 4. 第一反应状态，不用伪精确概率

本文旧版给市梦率、PEG 和成熟资产配置了固定概率区间。按 [[兴趣领域/股票投资/归档/分析报告/archive/260719组合_行为纠偏与资本纪律操作系统]]，这些数字没有固定参考类、期限、结算规则和历史校准，现已废止，不得进入 EV、排序或仓位；概率状态统一写 `uncalibrated`。

### 4.1 市梦率资产

典型特征：没有利润，甚至没有稳定收入；故事很大；估值主要靠愿景、融资、风险偏好和流动性支撑。

| 状态 | 需要什么证据 | 默认动作 |
|---|---|---|
| 纯叙事 | 只有故事、关注和融资想象，没有稳定收入/毛利 | `继续观察/不投入` |
| 可定义损失的事件窗口 | 有明确催化、失效点和退出通道，但财务尚未验证 | 只在 O 赔率职责中讨论 `建立验证仓` |
| 跨过财务门槛 | 收入、毛利、经营利润或现金流开始独立验证 | 重新评估估值语法和四张票，不自动升级 |

### 4.2 PEG 资产

典型特征：已有收入和利润，处于高速增长期；市场主要盯 EPS、EPS 增长率和增长率的边际变化。

| 状态 | 需要什么证据 | 默认动作 |
|---|---|---|
| 一次性景气待排除 | 利润增长但基数、价格或周期贡献不清 | `继续观察/不加仓` |
| 成长窗口 | EPS 斜率、订单、供给与价格互相确认 | 四票全过后才讨论 `建立验证仓` |
| 增速边际下行 | EPS 仍增长，但增长率和盈利预期开始下修 | `不加仓`；估值或经营票失败则 `降级或退出` |

### 4.3 DCF / 成熟资产

典型特征：现金流可估、增长率趋稳、分红或回购清晰，护城河和资本配置成为核心。

| 状态 | 需要什么证据 | 默认动作 |
|---|---|---|
| 价值陷阱待排除 | 低估值但现金流、ROIC 或竞争地位恶化 | `继续观察/不投入` |
| 合理复利但价格一般 | 生意稳定，价格没有安全边际 | `继续观察/不加仓` |
| 质量与价格同时通过 | 内在价值未坏、现金流可验证、保守价值仍有安全边际 | 四票全过后才讨论 `建立验证仓/升级确认仓` |

## 5. “我到底在赚什么钱”

每次买入前必须把收益来源写成一句话。

| 收益来源 | 买的是什么 | 需要什么验证 | 不能用什么话术掩盖 |
|---|---|---|---|
| 基本面钱 | 公司收入、毛利、利润、现金流继续变强 | 财报、订单、RPO、NRR、利润率、现金流 | “长期看好” |
| 流动性钱 | 资金水位上升、估值体系整体抬高 | 利率、信用、资金流、成交、估值分位 | “公司突然更优秀了” |
| 风险偏好钱 | 市场愿意给更远未来、更大梦想、更高斜率定价 | 叙事扩散、估值倍数、机构覆盖、期权情绪 | “DCF算出来也合理” |
| 认知差钱 | 市场用旧标签看它，而它正在变成更高层级资产 | 旧标签失效、分部数据、用户行为、商业模式迁移 | “别人都不懂” |
| 事件跳变钱 | 未来 3-12 个月有状态迁移事件 | 财报、订单、政策、产能、认证、产品拐点 | “总会涨回来” |

最清醒的买入句式：

> 我买入 X，不是因为它“好”，而是因为它现在主要被 [估值语法] 定价，我判断 [某一层肉] 还会变厚，收益来自 [具体的钱]，验证信号是 [数字/事件]，失败条件是 [反证]。

## 6. 不做清单

这部分比“做什么”更重要。

1. 不用 DCF 包装市梦率。明明是在买梦想和右尾，就承认自己在买梦想和右尾。
2. 不把市梦率资产当核心仓。没有收入、毛利、经营利润或现金流验证前，只能小仓、期权化、事件化。
3. 不用价投心法接风险偏好主导资产的杀估值。风险偏好反转时，“越跌越便宜”可能是错觉。
4. 不在 PEG 资产增速边际下行时自动越跌越买。PEG 的短期命门不是利润绝对值，而是 EPS 增长率和增长率的边际变化。
5. 不把利润创新高等同于股价应该创新高。市场买的是下一段增速能不能撑住当前估值。
6. 不把流动性和风险偏好涨出来的钱，误认为自己判断了内在价值。
7. 不只问 PE 贵不贵。先问市场到底是在用市梦率、PEG、DCF、PE 还是股息率给它定价。
8. 不用单一估值方法穿越所有阶段。方法错配比参数误差更致命。
9. 不因为公司伟大就无视三层肉厚度。伟大公司在风险偏好和流动性溢价吃满时也会杀估值。
10. 不因为估值便宜就忽略内在价值正在塌。成熟资产低估值可能是价值陷阱，不是安全边际。
11. 不把故事、行业空间、技术趋势直接当收入、毛利、经营利润和现金流。
12. 不把“别人不懂”当买入理由。认知差必须能落到分部收入、利润池、控制权或现金流。
13. 不和不适合自己体系的估值宗教争论。可以理解市梦率的钱，但不一定要赚。
14. 不买不知道自己赚哪种钱的资产。说不清收益来源，就没有资格承担波动。
15. 不让仓位和估值语法错配。市梦率用小仓右尾，PEG用事件和斜率，DCF才谈重仓复利。
16. 不把政策宽松直接当成板块和标的流动性改善；四级传导未验收时，只能写待验证。

## 7. 与现有框架的合并方式

原有“宏观供需泊松交易闭环”回答的是：

```text
水往哪里流 -> 谁控制闸门 -> 收费权能否进报表 -> 什么时候状态跳变
```

本框架补上的问题是：

```text
市场现在用什么估值语法定价它 -> 三层肉哪一层最厚 -> 我赚哪一层的钱
```

以后完整判断链条调整为：

```text
宏观需求 lambda 上升
-> 政策水到市场水的传导验收
-> 板块水与标的水验收
-> 产业链卡点
-> 供给锁死
-> 财务路径
-> 估值语法识别
-> 三层肉拆解
-> 收益来源确认
-> 仓位和退出规则
```

### 插入研究模板的新增问题

| 模块 | 必须回答 |
|---|---|
| 宏观流动性 | 政策水是否真的进入市场、板块和标的；它更新 `H_R/H_L` 的哪一项 |
| 估值语法 | 市场现在主要用市梦率、PEG、DCF、PE还是股息率给它定价 |
| 三层肉 | 当前股价中内在价值、流动性溢价、风险偏好哪一层最厚 |
| 收益来源 | 我预期赚基本面钱、流动性钱、风险偏好钱、认知差钱，还是事件跳变钱 |
| 错配风险 | 我有没有用错误方法解释这个资产 |
| 仓位匹配 | 这类估值语法允许的仓位上限是什么 |

## 8. Codex 后续判断人格

后续做股票投资分析时，Codex 不要先当“资料整理员”，要先当“切肉师”：

1. 第一刀：切股价。现在涨跌主要来自内在价值、流动性溢价，还是风险偏好？
2. 第二刀：切阶段。它是市梦率、PEG，还是 DCF/成熟现金流资产？
3. 第三刀：切收益来源。我买它到底是在赚哪种钱？
4. 第四刀：切错配。当前使用的方法、仓位、心法是否和估值阶段匹配？
5. 第五刀：切反证。哪个数字出现，说明这层肉会变薄，必须撤退？

这种人格的核心不是悲观，而是不自欺。

好的投资直觉不是看一眼就知道答案，而是看一眼先知道：

```text
这里大概率是哪种游戏
这局游戏我会不会玩
如果要玩，最大亏损在哪里
什么证据会让我改变判断
```
