### 本轮新增判别式

#### 判别式 #9：贝叶斯主导链的"政策事件密度"判定

**一句话**：政策驱动的链上，不要押单一政策，要看政策事件密度（招标 + 开工 + 投运 + 国产替代节点）是否持续上移。

**适用场景**：所有"五年规划"驱动的链（特高压、核电、半导体、新能源车补贴等）。

**判断步骤**：

1. 列出政策事件类型
2. 按月度跟踪事件密度
3. 同方向事件 ≥ 3 类同时变密 → λ 上升确认
4. ≥ 2 类 + ≥ 1 类反向 → 待验证
5. 仅 1 类变密 → 不构成 λ 上升

**正例**：特高压 2024-2025（4 类同时变密）
**反例**：押"特高压必然翻倍"
**失败条件**：政策驱动链上没有月度事件跟踪
**下次测试**：核电链、半导体大基金链

#### 判别式 #10：客户议价能力 ≠ 客户集中度

**一句话**：客户集中度高不一定是风险，关键看客户的议价能力——客户能压价才是真风险。

**适用场景**：所有"单一/少数客户"驱动的链。

**判断步骤**：

1. 看客户集中度（前 3 客户占比）
2. 看客户议价能力（政府采购？大平台？垄断企业？）
3. 看客户切换成本
4. 综合判断：客户集中 + 强议价 = 风险；客户集中 + 弱议价 + 高切换成本 = 锁定

**正例**：
- 特高压链：客户集中度高 + 国网强议价 → Capture 测试是关键
- ABF 载板：客户集中度高 + NVIDIA 弱议价（缺货）+ 高切换成本 → 锁定

**反例**：把"客户集中度高"直接当高风险，忽略议价能力差异

**失败条件**：客户分散但议价能力强（如苹果对供应商）

**v1.1.1 patch 候选**：在 v1.1 §1.5 加"客户议价能力"维度

### 本轮新增判别式

#### 判别式 #6：双层链的 Beta vs Alpha 分离

**一句话**：资源链拆解必须先按"资源端（Beta）vs 加工端（Alpha）"分两层，再分别评估——不要把两层混在一起看。

**适用场景**：所有"资源 → 加工 → 终端"的多层产业链（铜、铝、稀土、锂、钴、镍等）。

**判断步骤**：

1. 找到链里的"资源端"（矿企 / 初级冶炼）和"加工端"（深加工 / 高端制造）
2. 资源端用幂律 + 泊松（看储量、产能、商品价格）
3. 加工端用幂律 + Leontief（看认证、客户、CR3、扩产周期）
4. 分别打分，不要混在一起
5. 给两类标的分别建池：Beta 池 + Alpha 池

**正例**：铜链 — 紫金（Beta）+ ABF 载板/CCL/PCB（Alpha）
**反例**：把紫金 + 沪电放在一起看"铜链受益股"——逻辑混乱
**失败条件**：链里没有明确的"资源 → 加工"分层（如纯 SaaS）
**下次测试**：锂链（锂矿 → 正极 → 电芯）、稀土链（矿 → 永磁 → 电机）

#### 判别式 #7：瓶颈不在源头，而在"认证 + 工艺 + 寡头"

**一句话**：长产业链的瓶颈通常不在最上游（资源端），而在中下游的"认证 T1/T2 + 工艺复杂 + CR3 ≥ 80%"环节。

**适用场景**：所有 5+ 级的长产业链。

**判断步骤**：

1. 列出产业链每一级
2. 标注每级的"认证 Tier"、"工艺复杂度"、"CR3"
3. 找到"认证 T1 + 工艺复杂 + CR3 ≥ 80%"的环节 → 这就是真正的瓶颈
4. 资源端（最上游）通常不是瓶颈（除非有特定的矿种垄断）

**正例**：铜链瓶颈在 ABF 载板 / Very Low-Loss CCL（不在铜矿）；AI 链瓶颈在 ABF 膜 / T-glass / HBM（不在 GPU）；储能链瓶颈在 LFP 正极高端（不在碳酸锂）
**反例**：稀土链确实在矿端（中国稀土矿垄断 + 政策管控）—— 少数反例
**失败条件**：产业链没有显著的认证壁垒（如通用商品）
**下次测试**：特高压链（变压器硅钢 + 偏磁控制 + 寡头）

#### 判别式 #8：地缘集中度 ≠ 垄断溢价

**一句话**：地缘集中度（v1.1 §1.2）是风险因子，不是定价权因子；定价权来自认证 + 工艺壁垒，不是来自"集中在某国"。

**适用场景**：所有地缘集中度 ≥ 4 的环节。

**判断步骤**：

1. 计算地缘集中度评分
2. 计算定价权评分
3. 如果两者方向不一致，说明地缘集中是"被迫的"而非"主动的"
4. 给地缘高的环节加"风险溢价"，而不是直接当成"垄断溢价"

**正例**：ABF 载板地缘集中度 4 + 定价权 10/10 → 同向，因为认证壁垒（30 年）+ CR3 80%
**反例**：中国稀土地缘集中度高，定价权受政策周期影响大（政策松动时价格暴跌）
**失败条件**：把"地缘集中度"直接当投资亮点 → 误把风险当溢价

### 本轮新增判别式

#### 判别式 #4：训练循环的"误差分析驱动升级"

**一句话**：训练循环不是"跑一遍就完"，必须有一步 AUDIT（训练集溯源）→ 找漏检 → 推 patch/minor 升级 → 在下一轮新主题验证修正有效。

**适用场景**：所有训练循环类方法论（不限挖掘端）。

**判断步骤**：
1. 跑完一轮训练后，做训练集溯源（信息单元 → SOP 步骤映射）
2. 找覆盖率 < 30% 的步骤（如 S2/S9 弱命中）
3. 找"已知样本里有但 SOP 没专门处理"的维度（如地缘、客户集中度）

**失败条件**：训练集溯源只看覆盖率（100% 覆盖就觉得 OK），不看"格式严格度"和"维度完整性"

**应写入**：已写入 F8 SOP v1.1 §0.2

#### 判别式 #5：v1.0 → v1.1 的升级边界

#### 判别式 #2：Transmission 是七步测试的硬闸门

**一句话**：需求真实不等于公司受益；必须证明需求能沿链条传导到该公司，且该公司能留下利润。

#### 判别式 #2：瓶颈迁移 ≠ 线性成长

- GPU 扩产 → HBM 暴露
- HBM 改善 → 连接和数据搬运暴露
- 连接改善 → 机柜功耗、电力、冷却暴露
- 电力和储能改善 → 变压器、铜、开关设备、构网型储能暴露

**应用**：投资研究不能只问"什么需求增长"，要问"上一层瓶颈被缓解后，下一层约束在哪里暴露"。

**状态**：写入 `B_AI基础设施瓶颈.md` §2026-2028 瓶颈迁移图。

#### 判别式 #3：反"光进铜退"叙事

```text
不是 CPO 独赢，也不是光完全替代铜；
而是铜、光、PCB、ABF、CCL、封装、测试、系统集成共同升级。
```

**应用**：Scale-up 铜主导，Scale-out 光主导，共存至少 2-3 年。

**状态**：写入 `挖掘端工作流SOP_v1.0.md` §4 反简单叙事测试。

#### 判别式 #4：远期概念之前的前置确定性

```text
2026 买确定性，2027 买订单弹性，2028 买架构期权。
```

**应用**：远期 CPO 之前，先赚钱的是 PCB/ABF/CCL/LPO/NPO/铜缆/光源/测试。

**状态**：写入 `挖掘端工作流SOP_v1.0.md` §4 反简单叙事测试。
