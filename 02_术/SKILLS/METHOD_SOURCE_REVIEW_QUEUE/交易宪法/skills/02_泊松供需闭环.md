# 泊松供需闭环 v2.4

> 上位法：[CONSTITUTION.md](../CONSTITUTION.md) ｜ 生效日期：2026-07-21 ｜ 源自：[供需泊松闭环 v2.3](../../基础概念/交易策略组合/260606投资框架_供需泊松闭环.md)、[交易认知体系首轮训练](../../分析报告/archive/260721组合_交易认知体系首轮训练.md)

## 一句话职责

沿真实付款、产业链卡点、供给锁死、财务变现与事件时钟建立闭环，在不伪造概率的前提下决定研究优先级和等待条件。

## 触发条件（什么情境下必须调用本模块）

- 当研究政策、法案、产业资本、CapEx 或技术跃迁带来的新需求时，必须调用本模块。
- 当判断周期品、AI 硬件、存储、金融基础设施或平台型公司的供给稀缺时，必须调用本模块。
- 当讨论催化剂、事件密度、提前埋伏、等待或“泊松概率”时，必须调用本模块。
- 当一项行业景气尚未完整进入公司利润与现金流时，必须调用本模块查找断点。

## 核心规则（可执行的 if-then 条款，不写理念性空话）

### 1. 产业需求漏斗

- 当宏观变化出现时，按 `宏观变化 → 需求生成 → 付款人 → 产业链 → 变现卡点 → 标的映射 → 供给过滤 → 财务验证 → 事件时钟` 建立漏斗；若任何一环为空，则不得把下游热度直接映射为个股收益。
- 当政策方向清晰但预算、订单或采购未出现时，只建立主题卡与研究清单；若试图以政策单独占位，则动作改为 `继续观察/不投入`。
- 当产业资金出现时，必须追踪资金是否变成订单、出货、使用量或收入；若只看到基金、补贴标题而无付款路径，则不得认定需求上升。
- 当选择产业链环节时，必须说明为什么该环节最缺、最慢、最难绕开且先获得利润；若只是标签最热，则从候选池剔除。

### 2. 供给锁死与财务变现

- 当判断供给锁死时，必须验证复制所需的时间、资本、监管、信任、工艺、生态或迁移成本；若利润出现后竞争者能迅速复制，则只记为暂时供给不足。
- 当客户可以自建、竞品可以免费打包或上下游可以绕开时，必须降低供给结论；若绕开已成为事实，则触发经营票重评。
- 当需求进入公司时，必须依次验收收入、直接成本、毛利、经营费用、经营利润、净利润和现金流；若收入增长被低毛利过账、补贴、营运资本或 CapEx 吃掉，则不得称为收费权。
- 当飞轮被用作长期理由时，必须证明采用增加后带来收入/毛利、生态/数据增强、替代难度和收费权增强；若飞轮不能进报表，则只作叙事。
- 当管理层用更高脆弱性换增长时，必须降低候选等级；若融资、稀释、库存或现金消耗使公司可能活不到兑现，则 `H_B/H_L` 不通过。

### 3. 周期与存储专用闭环

- 当分析周期品时，必须沿 `有效供给 → 库存 → 实现价格－单位成本 → 毛利 → 经营现金流 → 资本开支 → 下一轮供给反应` 验收；若只看价格或峰值 PE，则结论无效。
- 当分析存储时，必须分开服务器 DRAM、HBM、消费 DRAM 与 NAND；若把结构性 HBM 需求外推为全部品类永久短缺，则经营票不得通过。
- 当近端短缺与远端扩产同时出现时，必须同时记录经营景气和供给反噬时钟；若只保留看多一侧，则证据网络不完整。
- 当库存、位元供给、实现价格、毛利/现金流或资本开支任一转差时，必须检查状态迁移是否失败；若多项共振，则触发完整重评。

### 4. `λ` 事件时钟

- 当记录 `λ` 时，只允许描述独立验证事件在变密、变稀或接近；若未固定参考类、期限、结算规则与历史校准，则禁止把 `λ` 写成数值概率。
- 当概率未校准时，状态必须写 `uncalibrated`；若有人要求填 50%、区间中点、固定 LR、固定加减分或主观单点概率，则拒绝进入 EV 与仓位。
- 当事件来自同一新闻、同一管理层口径或多个 AI 的重复转述时，只计一个根证据；若独立来源不足，则不得称为证据网络变密。
- 当催化剂增多但下行事件、永久损失、等待成本、脆弱性或机会成本也增加时，必须双向记录；若只数向上事件，则不得形成交易结论。

### 5. 等待、升级与退出

- 当只看到政策方向时，保持“宏观雷达”；当看到卡点但无财务验证时，保持“结构窗口”；当需求、供给、财务、价格和结构均成立时，才可成为“核心候选”。
- 当高质量等待成立时，必须写明已知事实、缺失证据、下一事件、复查时间、失败条件和允许动作；若没有复查时钟，则等待属于资本钝化。
- 当加仓被讨论时，必须出现比初始买入更强的新增独立证据，且市场未按终局定价；若理由只是亏损摊薄成本或上涨怕错过，则禁止加仓。
- 当宏观、需求、供给、变现、组织、事件、估值或座位假设任一破裂时，必须把对应票交给上位系统重评；若失败条件已触发，则不得用等待阻断 `降级或退出`。

## 已知失效边界（本模块在什么情况下不适用）

- 当事件会互相激发、聚集或随状态突变时，本模块不能把市场当标准独立同分布泊松过程。
- 当参考类和历史样本未建立时，本模块不能计算校准概率、赔率或仓位。
- 当监管、会计或公司披露无法验证真实付款和现金流时，本模块只能输出 `unknown/继续观察`。
- 当短期交易完全由交易机制、停牌或涨跌停限制主导时，本模块不替代工具与流动性风险审计。
