# Method Absorption Map

## 先说人话

**今天发生了什么：**旧方法不再散落在旧 Constitution、旧认知模型、AI 周期总览和基础概念里，而是按 canonical Skill 接管。

**为什么重要：**方法可以进化，但不能因为写得像哲学就自动变成“道”；旧评分、旧参数和旧 prompt 也不能继续隐性授权交易。

**现在做什么：**以后改方法先改本表指向的 canonical 文件；旧文件只作为来源和历史。

## 更新纪律

- 更新 Skill 时必须写来源、版本、失败条件和回滚方式。

- Evidence 可以挑战方法，不能自动让 Murphy 确认哲学。
