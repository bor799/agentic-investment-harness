# 02 Capital And Execution

## 输入

任何风险增加、风险降低、期权、基金申赎、成交、撤单、仓位变化或资本压力问题。

## 输出

允许动作、禁止动作、订单事实、复查时间。

## 执行边界

- 生活资金不进入投资风险。
- AI 没有交易授权权、仓位参数修改权和自动成交权。
- 主账只认券商成交、撤单、废单或到账回报。
- 亏损后想加仓、抄底或卖 Put，默认进入反方审查和冷静期；风险降低动作不被阻断。
- 期权必须定义最大损失，不能依赖 Roll、融资或运气才能生存。

## 资本硬门

新增任何风险前，先把生活费和应急现金从可投资资本 `R` 中剔除。资金如果承担生活安全职责，就不能进入仓位、收益率或压力测试分母。

`90%/10%` 只表示职责分层：高证据/价值职责和赔率职责。它不是单笔预测胜率，也不是必须投满的比例。H-cash 是合法资本角色，没有四票通过的机会时，现金不能被配置焦虑强制投入。

O 侧滚动最大损失预算、单笔最大损失、单 thesis 累计最大损失、单标的暴露、集群暴露、压力损失和组合暴露都只按最新确认参数执行。任何历史报告里的固定仓位、固定比例、旧评分或无 `R` 分母的计划仓位，默认 `superseded/retired`，不能授权新交易。

## 风险增加承保

风险增加必须同时满足三张硬门票，并完成周期扫描：

```yaml
risk_increase_gate:
  H_B: pass  # 经营：硬门
  H_R: pass  # 赔率：硬门
  H_L:       # 周期：软探测器（不强制 pass，但必须填）
    status: pass | watch | fail
    risks_within_period:
    review_dates:
  H_C: pass  # 仓位：硬门
  max_loss_defined: true
  broker_fact_confirmed_or_not_required:
  same_factor_cluster_checked:
  liquidity_exit_checked:
  allowed_action:
```

三张硬门票（H_B / H_R / H_C）任一失败或未知，动作不得高于 `继续观察/不加仓`。H_L 周期票失败时进入 `watch` 警示状态，必须列出持有期内的已知风险和复查日期，但不阻止动作。仓位上限只是上限，不是交易理由；没有足够正边际时，不为了用完额度而交易。

既有持仓如果已经超限，标记 `grandfathered_over_limit`。未完成减险或重新承保前，只允许减险，不允许新增同因子风险；这不是自动强制卖出，也不是继续加风险的许可。

## 工具与订单事实

期权只允许最大损失事前可定义、无需 Roll 才能生存的结构。缺少 bid/ask、IV、Greeks、持仓量、成交量、催化剂或退出通道时，期权动作只能 `继续观察/不投入`。

主账只认券商、交易所、TA 或基金平台回报。已报、部成、已撤、废单、未知、个人口述推断和 AI 计算，都不能伪装成完整成交。

如果目标是降低风险，委托必须具有可成交性并持续核验；只愿等更好价格的单子要标成“等待反弹单”，不能声称已经执行退出。

## 权限拒绝

AI 可以研究、反证、计算、记录和提醒纪律；不得修改 `R`、资本参数、价格线、仓位、交易权限或主账事实。任何参数修改必须由 Murphy 明确决定，并留下版本、来源、适用范围、失效条件和回滚方式。

## 量化和回测边界

量化工具可以用于发现定价低效、检查相关性、评估执行深度和记录样本，但不能绕过四票、资本纪律和主账事实。

回测或数学模型进入研究前，至少检查：

- 经济学假设是否先于回测存在，而不是先拟合曲线再编故事；
- 样本是否足够，是否做样本外验证和多重检验；
- 交易成本、滑点、停牌、报价深度、成交概率和延迟是否计入；
- 相关性在压力期是否会突变；
- 结果是否依赖少数极端样本或不可复制成交。

Kelly、均值方差、PCA、贝叶斯定价和套利检测只允许作为研究工具。没有参考类、期限、结算规则、历史校准和可执行深度时，输出 `uncalibrated`，不得转成仓位。任何旧文中的“单票上限”“半 Kelly”“订单簿 50%”等数字只作历史线索，不授权当前交易。
