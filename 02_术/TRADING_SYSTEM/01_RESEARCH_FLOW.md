# 01 Research Flow

## 输入

一个标的、主题、政策、财报、外部材料或纯公司分析问题。

## 输出

纯公司分析输出商业判断、原因、反证与下一验证；个股投资判断继续输出六问首页和
六档动作之一。

## 新标的先做 60 秒结构先验

只有 `TARGET / 新标的判断` 使用这一段。它发生在读取 Current、价格和新 Source
之前，只调用研究触发、稳定 Entity / Domain Knowledge 与已结算 Case：

```yaml
structural_prior:
  domain_ids: []  # 最多两个
  structural_fit: favorable | unfavorable | mixed | unknown
  evidence_status: uncalibrated
  qualified_patterns: []  # 最多三个
  counter_pattern:
  analogue_case: none_found
  failure_case: none_found
  first_questions: []  # 最多三个
  next_step: proceed_to_verify | ask_identity | out_of_scope
```

它只是结构先验，不是 Current、H_B/H_R/H_L/H_C 或动作。有效投资标的必须继续
读取 Current 与新证据；历史反模式不能阻止验证。`ask_identity` 只用于身份或
研究触发不清，`out_of_scope` 只用于 Murphy 明确排除或明显不是投资对象。

模式只有在至少两个独立根来源、至少两个标的或已结算 Case 中可复用，并且因果链
与失败条件明确时，才能进入 `qualified_patterns`。没有合格模式时如实输出
`unknown`，不为完整性补齐。

## 个股主流程

先判断用户要的是纯公司分析，还是包含当前价格与资本动作的个股投资判断。两者共享
事实和反证，但纯分析可以在第一或第二段结束，不为填满报告强制生成赔率或动作。

### 一、看公司

1. TARGET 先形成 `structural_prior`，再读 Current 与新 Source，让当前事实纠正先验。
2. 用 [[02_术/SKILLS/COMPANY_FUNDAMENTALS]] 说明客户为何付钱、赚钱机制、竞争优势、
   再投资如何转成新收入或壁垒，以及机器在哪里会坏。
3. 把机制接到收入、成本、利润、现金、资本开支、稀释和每股价值。
4. 首次研究检查股东结构；后续只更新新披露或控制权、融资、拥挤风险的变化。

产业、供需、宏观和政策只在它们能改变当前关键命题时调用，不再作为每个个股研究的
固定前置层。政策、利率、ETF 流入、板块热度和价格只允许改变研究优先级或
`H_R / H_L`，不能代替公司事实提高 `H_B`。

### 二、看分歧

拆公司时同步识别毁损变量。财报与公告中的经营事实尽早读取；形成独立判断后，再核对
管理层的增长解释、风险承认和历史承诺兑现。风险、管理层和多空材料合并为一张表：

| 关键命题 | 支持事实 | 最强反证或替代解释 | 下一判定事件 |
|---|---|---|---|

只保留能改变结论的命题，致命问题最多三个且不凑数；同根来源只计一次。必须能说明
“市场为什么可能正确”；无法证明错定价时，明确写“尚未证明市场错”。

### 三、看交易

只有用户需要个股投资判断或资本动作时，才进入当前价格、市场隐含预期、收益来源、
期限、失败条件和资本约束。此时必须过四票与六档动作；纯公司研究完成不自动代表
`H_B: pass`。缺价格、估值分母或账户条件时，相关票保持 `unknown/uncalibrated`，
不得升级风险。

个股投资判断使用 `AGENTS.md §5` 的六问首页与一行决策栏；纯公司分析输出商业判断、
证据表和一个最重要的下一验证，不强制输出动作。

## 按需执行与停止

- 已有 Current 或 Knowledge 时只报告 delta，不重写全篇。
- 只搜索能改变关键命题的根来源；事实、推断与管理层叙事分开。
- 第一关键未知解决但不改变命题、来源同根重复、只增加叙事丰富度，或只能等待新事件
  时停止扩展研究。
- 结果是否写入仍由 `AGENTS.md`、内容路由、Reviewer 与 Validator 决定。

**四票权重区分**：H_B 经营、H_R 赔率、H_C 仓位是硬门，任一失败默认不增加风险；H_L 周期是持有期内的风险扫描器，权重弱于其他三票，起警示作用而非阻止动作。

进入个股投资判断后按同一内部格式承保：

```yaml
conclusion:
reason:
can_prove:
cannot_prove:
next_number:
failure_condition:
valuation_language: 市梦率 | PEG | DCF | PE | 股息率 | unknown
return_account: 基本面钱 | 流动性钱 | 风险偏好钱 | 认知差钱 | 事件跳变钱 | unknown
ticket_state:
  H_B:  # 经营：公司是否真的更赚钱
  H_R:  # 赔率：价格给的回报是否足够
  H_L:  # 周期：持有期内宏观微观风险扫描（权重弱）
  H_C:  # 仓位：错了是否能活下来
allowed_action: 不投入 | 继续观察 | 建立验证仓 | 升级确认仓 | 不加仓 | 降级或退出
```

如果 `can_prove / cannot_prove / next_number / failure_condition` 任一项为空，投资结论保持 `unknown`。如果三张硬门票（H_B 经营 / H_R 赔率 / H_C 仓位）任一失败或未知，动作不得高于 `继续观察/不加仓`。H_L 周期票失败时进入警示状态，须列出风险点和复查日期，但不强制阻止动作。纯公司分析不适用六档动作，`H_R` 可标记 `not_applicable`。

## 政策三层验证

政策只从环境票和周期票开始，不直接进入经营票（H_B）。

| 层级 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 政策文件发布 | 方向、关注度、研究优先级 | 基本面已经改善 |
| 微观数据验证 | 公司现金流、订单、库存、价格、应收或项目利润是否变化 | 全行业已经反转 |
| 宏观指标确认 | CPI/PPI、房价、信用、就业、库存等是否形成共振 | 单家公司一定受益 |

如果只有政策文件，没有微观数据，动作只能是 `继续观察`。如果微观数据改善但宏观未确认，可以研究 alpha，不把行业 beta 当作已经成立。政策口号、会议表述和市场解读不能替代落地规模、资金到位、订单兑现和报表数据。

## 估值语法与收益来源

解释股价前，先拆三层肉：`内在价值 / 流动性溢价 / 风险偏好`。如果无法判断当前主要驱动层，不能用价格结果倒推业务变化。

估值前，先识别市场使用哪套语法：

| 估值语法 | 必须先看什么 | 默认边界 |
|---|---|---|
| 市梦率 | 收入、毛利、经营利润、现金流是否开始验证 | 未验证前只能观察或小仓候选，不能当核心仓 |
| PEG | EPS、EPS 增长率、增长率边际变化 | 利润创新高但增速下行时，先防估值收缩 |
| DCF / PE / 股息率 | 现金流、内在价值、安全边际 | 只适用于现金流可验证、内在价值主导的成熟资产 |

收益来源必须说清楚赚哪种钱：基本面钱、流动性钱、风险偏好钱、认知差钱，还是事件跳变钱。若答案只是“有人会以更高价格接盘”，只能写成未验证路径假设。

## 工具匹配

只理解产业方向但没有公司差异证据时，优先研究 ETF，并审计指数编制、行业纯度、前十大集中度、估值、申赎、折溢价、跟踪误差和风格漂移。

只有能证明公司在控制权、收入、毛利、经营利润或现金流上优于行业时，才进入个股 alpha 研究。证据只是关注度、价格弹性或 AI 共识时，不能从 ETF 认知跳到个股集中下注。

期权只解决“如何定义最大损失”和“是否更合适表达路径”，不能补业务证据，也不能把低价格改写成高胜率。

## Alpha / Beta 切换

工具选择跟周期阶段匹配：

| 阶段 | 默认工具 | 关键验证 |
|---|---|---|
| 底部分化 | 个股 alpha 或小范围对照组 | 新头部、成本优势、利润率、现金流、份额 |
| 右侧确认 | 行业 beta / ETF / 指数工具 | 行业价格、库存、需求、盈利和资金共同转正 |
| 泡沫或拥挤 | 降风险、对冲或更稳健工具 | 估值语法失配、流动性变浅、赚钱效应过热 |

不要在底部分化期用 ETF 买进旧世界的拖累，也不要在右侧确认后只盯单一个股错过板块 beta。工具不是信仰，工具只是表达证据强度、能力圈和最大损失的方式。

能力圈之外，如果只能判断方向、不能判断公司级胜负，优先用宽基、行业 ETF、指数工具或更小风险的表达；不要为了“赚更多”硬做不懂的个股。ETF 仍需审计溢价、折价、流动性、跟踪误差、持仓纯度和退出深度。

## 好生意 / 好公司 / 好价格

公司研究至少拆三层：

1. **好生意：**差异化、规模效应、集中度、客户心智、资产效率和自由现金流。
2. **好公司：**创始人、文化、组织复盘、执行力、不为清单和自我纠错能力。
3. **好价格：**不是低 PE/PB，而是对现金流、机会成本、估值语法和失败条件足够懂。

创始人、文化和个人认可只能生成问题，不能直接证明好公司。必须继续看收入、毛利、费用、经营利润、净利润、现金流、资本开支、竞争反应和估值隐含预期。

个人一线经验可以生成假设，例如物流、履约、渠道、成本或用户体验，但它只是 P0/P1 观察线索。进入公司结论前，必须用财报、经营数据、客户行为和竞争数据验证。

## 基金、ETF 和个股分层

工具选择先问：自己的优势是行业方向判断，还是公司级单吨利润、份额、治理、估值和现金流判断。

| 工具 | 解决的问题 | 主要风险 | 适合条件 |
|---|---|---|---|
| 宽基 / 分散基金 | 分享整体企业盈利和经济增长 | 系统性熊市、估值波动 | 没有持续选股优势，希望长期持有 |
| 行业 / 主题基金 | 表达产业链中等确信 | 行业集中、风格漂移、大幅回撤 | 能判断方向，但不能判断单一公司胜负 |
| 个股 | 表达公司份额、成本、治理和估值的高确信 | 公司特有风险、永久亏损 | 能持续跟踪报表、产品价格、竞争和现金流 |

主题基金不是低波动核心仓替代品；它解决单公司风险，不解决行业周期风险。个股研究仍必要，但在证据不足时，它的用途是验证基金代表的产业假设，而不是每天猜哪只涨得最多。

每次大涨大跌只问三件事：价值表是否变了、失败概率或最大损失是否变了、价格是否只改变赔率。价格上涨且价值没有新证据，不自动升级；价格下跌且核心假设被证伪，不是便宜，是退出信号。

## 不能证明什么

研究完成不等于可以交易；AI 自评不等于方法有效；同一新闻多次转述不等于证据变强。
